PSI • LEKCJA 17 • CSS3

Wprowadzenie do CSS. Style lokalne, wewnętrzne i zewnętrzne. Kaskadowość stylów

Cel lekcji: poznanie przeznaczenia i składni CSS, stosowanie trzech sposobów definiowania stylów, podłączanie zewnętrznego arkusza stylów, rozumienie kaskadowości, specyficzności i dziedziczenia oraz samodzielne stylowanie prostej strony HTML5.

1. Wprowadzenie do CSS

Podczas wcześniejszych lekcji poznaliśmy język HTML5, który pozwala tworzyć strukturę strony internetowej. Za pomocą HTML umieszczaliśmy nagłówki, akapity, listy, obrazy, formularze i inne elementy.

Sama struktura HTML nie wystarcza jednak, aby przygotować atrakcyjną wizualnie witrynę. Do określania wyglądu strony wykorzystujemy CSS.

CSS (Cascading Style Sheets) oznacza kaskadowe arkusze stylów. Jest to język służący do opisywania sposobu prezentacji dokumentów, między innymi stron HTML.

Co można zmieniać za pomocą CSS?

  • Kolory tekstu i tła.
  • Rodzaj, wielkość i wygląd czcionki.
  • Odstępy pomiędzy elementami.
  • Obramowania i zaokrąglenia.
  • Szerokość i wysokość elementów.
  • Położenie elementów na stronie.
  • Układ kolumn i menu.
  • Wygląd strony na telefonach i komputerach.
  • Proste animacje i efekty wizualne.

📌 Ważne

HTML odpowiada przede wszystkim za strukturę i znaczenie treści, a CSS za jej prezentację. Współczesny CSS jest rozwijany modułowo, dlatego nazwa „CSS3” jest często używana w edukacji jako określenie nowoczesnych możliwości języka CSS.

2. HTML a CSS – podział zadań

Aby zrozumieć współpracę HTML i CSS, porównajmy stronę bez stylowania i stronę z dodanymi stylami.

Przykład – sam HTML

<h1>Moja strona</h1>

<p>
    Witaj na mojej stronie internetowej.
</p>

<button>Kliknij mnie</button>

Przeglądarka wyświetli nagłówek, akapit i przycisk, wykorzystując swoje domyślne style.

Przykład – HTML z CSS

<h1 style="color: blue;">
    Moja strona
</h1>

<p style="font-size: 20px;">
    Witaj na mojej stronie internetowej.
</p>

<button style="background-color: orange;">
    Kliknij mnie
</button>

Dzięki CSS możemy określić, że nagłówek będzie niebieski, akapit otrzyma większą czcionkę, a przycisk pomarańczowe tło.

Dlaczego warto oddzielać HTML od CSS?

  • Kod HTML jest bardziej przejrzysty.
  • Łatwiej wprowadzać zmiany w wyglądzie strony.
  • Jeden arkusz CSS może obsługiwać wiele podstron.
  • Zmiana jednego stylu może wpłynąć na wiele elementów.
  • Łatwiej rozwijać i utrzymywać większy projekt.

3. Podstawowa składnia CSS

CSS składa się z reguł, które określają wygląd wybranych elementów.

Budowa reguły CSS

p {
    color: blue;
    font-size: 18px;
}

Reguła zawiera:

  1. Selektor – wskazuje elementy, które mają zostać ostylowane.
  2. Właściwość – określa, co chcemy zmienić.
  3. Wartość – określa sposób zmiany.
  4. Deklarację – parę właściwość–wartość zakończoną średnikiem.

Analiza przykładu

Fragment Znaczenie
p Selektor wskazujący wszystkie elementy p.
{ } Nawiasy klamrowe zawierające deklaracje.
color Właściwość określająca kolor tekstu.
blue Wartość właściwości color.
font-size Właściwość określająca rozmiar czcionki.
18px Wartość określająca rozmiar 18 pikseli CSS.
; Znak kończący deklarację.

Kilka deklaracji w jednej regule

h1 {
    color: darkgreen;
    font-size: 32px;
    text-align: center;
    background-color: lightyellow;
}

Wszystkie deklaracje dotyczą elementów h1 pasujących do selektora.

Komentarze w CSS

/* Styl nagłówka */

h1 {
    color: navy;
}

/*
   Styl akapitów
   na stronie
*/

p {
    font-size: 18px;
}

Komentarze służą do opisywania kodu. Przeglądarka nie interpretuje ich jako reguł stylowania.

📌 Zapamiętaj

W CSS komentarze zapisujemy pomiędzy /* i */. Nie stosujemy komentarzy HTML <!-- --> wewnątrz arkusza CSS.

4. Pierwsze właściwości CSS

Na początku nauki warto poznać kilka podstawowych właściwości, które pozwalają szybko zobaczyć efekty stylowania strony.

Właściwość Przeznaczenie Przykład
color Kolor tekstu. color: red;
background-color Kolor tła. background-color: yellow;
font-size Rozmiar czcionki. font-size: 20px;
font-family Rodzina czcionek. font-family: Arial, sans-serif;
text-align Wyrównanie tekstu. text-align: center;
font-weight Grubość pisma. font-weight: bold;
border Obramowanie. border: 2px solid black;
padding Odstęp wewnętrzny. padding: 15px;
margin Margines zewnętrzny. margin: 20px;

Przykład – stylowanie nagłówka i akapitu

h1 {
    color: white;
    background-color: navy;
    text-align: center;
    padding: 20px;
}

p {
    color: darkslategray;
    font-size: 18px;
}

Podstawowe sposoby zapisu kolorów

h1 {
    color: red;
}

h2 {
    color: #008000;
}

p {
    color: rgb(0, 0, 255);
}

Kolory można zapisywać między innymi za pomocą nazw, kodów szesnastkowych i funkcji rgb().

Szczegółowe formatowanie tekstu, kolory, jednostki i model pudełkowy będą rozwijane w kolejnych lekcjach CSS3.

5. Style lokalne – atrybut style

Styl lokalny, nazywany również stylem liniowym lub inline CSS, zapisujemy bezpośrednio w znaczniku HTML za pomocą atrybutu style.

Przykład – jeden element

<p style="color: red;">
    Ten tekst jest czerwony.
</p>

Styl dotyczy tylko tego elementu, w którym zapisano atrybut style.

Przykład – kilka właściwości

<h1 style="color: white;
           background-color: navy;
           text-align: center;">
    Moja strona
</h1>

Przykład – dwa akapity

<p style="color: green;">
    Pierwszy akapit.
</p>

<p>
    Drugi akapit.
</p>

Pierwszy akapit otrzyma zielony tekst. Drugi zachowa kolor wynikający z pozostałych reguł CSS lub domyślnych stylów przeglądarki.

Zalety stylów lokalnych

  • Szybkie zastosowanie stylu do pojedynczego elementu.
  • Łatwe sprawdzanie prostych przykładów.
  • Brak konieczności tworzenia osobnego pliku CSS.

Wady stylów lokalnych

  • Mieszają strukturę HTML z wyglądem strony.
  • Powodują powtarzanie tych samych deklaracji.
  • Utrudniają wprowadzanie zmian w większym projekcie.
  • Trudniej zarządzać nimi przy wielu podstronach.

📌 Ważne

Style lokalne są poprawnym sposobem stosowania CSS, ale przy tworzeniu większych stron internetowych zazwyczaj korzystamy z zewnętrznych arkuszy stylów.

6. Style wewnętrzne – element style

Style wewnętrzne zapisujemy wewnątrz elementu <style>, najczęściej umieszczonego w sekcji <head> dokumentu HTML.

Dzięki temu możemy określić wygląd wielu elementów za pomocą jednej reguły.

Kompletny przykład

<!DOCTYPE html>
<html lang="pl">

<head>
    <meta charset="UTF-8">
    <title>Style wewnętrzne</title>

    <style>

        body {
            background-color: lightyellow;
            font-family: Arial, sans-serif;
        }

        h1 {
            color: navy;
            text-align: center;
        }

        p {
            color: darkgreen;
            font-size: 18px;
        }

    </style>

</head>

<body>

    <h1>Moja strona</h1>

    <p>Pierwszy akapit.</p>

    <p>Drugi akapit.</p>

</body>
</html>

Co się wydarzy?

  1. Tło całej strony będzie jasnożółte.
  2. Nagłówek będzie granatowy i wyśrodkowany.
  3. Oba akapity otrzymają ciemnozielony tekst.
  4. Rozmiar czcionki akapitów wyniesie 18 pikseli.

Zalety stylów wewnętrznych

  • Reguły CSS są zebrane w jednym miejscu.
  • Jedna reguła może dotyczyć wielu elementów.
  • Nie trzeba tworzyć dodatkowego pliku.
  • Rozwiązanie sprawdza się w prostych, pojedynczych dokumentach.

Wady stylów wewnętrznych

  • Arkusz jest związany z konkretnym dokumentem.
  • Przy wielu podstronach trzeba powtarzać style.
  • Rozbudowany kod CSS zwiększa długość pliku HTML.

📌 Zapamiętaj

W elemencie style zapisujemy zwykłe reguły CSS, zawierające selektory i deklaracje w nawiasach klamrowych.

7. Style zewnętrzne – osobny plik CSS

Zewnętrzny arkusz stylów to osobny plik z rozszerzeniem .css, który zawiera reguły odpowiedzialne za wygląd strony.

Jest to najczęściej stosowany sposób organizacji stylów w projektach internetowych.

Przykładowa struktura folderu

moja-strona/
|
|-- index.html
|
|-- style.css

Plik index.html

<!DOCTYPE html>
<html lang="pl">

<head>
    <meta charset="UTF-8">
    <title>Style zewnętrzne</title>

    <link rel="stylesheet" href="style.css">

</head>

<body>

    <h1>Moja strona</h1>

    <p>Witaj na mojej stronie.</p>

</body>
</html>

Plik style.css

body {
    background-color: #f0f4f8;
    font-family: Arial, sans-serif;
}

h1 {
    color: navy;
    text-align: center;
}

p {
    color: #333333;
    font-size: 18px;
}

Przeglądarka odczytuje plik HTML, znajduje element link, pobiera arkusz style.css i stosuje zapisane w nim reguły.

Znaczenie atrybutów link

Fragment Znaczenie
link Element wskazujący zasób powiązany z dokumentem.
rel="stylesheet" Informuje, że wskazany plik jest arkuszem stylów.
href="style.css" Określa ścieżkę do pliku CSS.

Arkusz CSS w podfolderze

moja-strona/
|
|-- index.html
|
|-- css/
    |-- style.css

W takim przypadku w pliku HTML należy zastosować: 

<link rel="stylesheet"
      href="css/style.css">

Jeden arkusz dla kilku podstron

moja-strona/
|
|-- index.html
|-- oferta.html
|-- kontakt.html
|
|-- style.css

W każdym z trzech dokumentów HTML można umieścić: 

<link rel="stylesheet" href="style.css">

Dzięki temu zmiana koloru nagłówków w jednym pliku style.css może zmienić ich wygląd na wszystkich podstronach.

Zalety stylów zewnętrznych

  • Oddzielają strukturę HTML od wyglądu strony.
  • Umożliwiają ponowne wykorzystanie stylów.
  • Ułatwiają utrzymanie spójnego wyglądu witryny.
  • Pozwalają zmieniać wygląd wielu stron w jednym miejscu.
  • Przeglądarka może przechowywać pobrany arkusz w pamięci podręcznej.

📌 Ważne

W pliku style.css zapisujemy wyłącznie kod CSS. Nie dodajemy do niego znaczników <html>, <head> ani <style>.

Wszystkie trzy sposoby w jednym dokumencie

<!DOCTYPE html>
<html lang="pl">

<head>
    <meta charset="UTF-8">
    <title>Trzy sposoby CSS</title>

    <link rel="stylesheet" href="style.css">

    <style>
        h2 {
            color: green;
        }
    </style>

</head>

    <h1>Style zewnętrzne</h1>

    <h2>Style wewnętrzne</h2>

    </p>

</body>
</html>

Wszystkie trzy sposoby mogą występować jednocześnie. Jeżeli ich reguły dotyczą tej samej właściwości tego samego elementu, o wyniku decyduje kaskada CSS.

9. Podstawowe selektory CSS

Selektor określa, do których elementów HTML ma zostać zastosowana reguła CSS.

Aby zrozumieć kaskadowość, musimy poznać trzy podstawowe rodzaje selektorów.

Selektor elementu

p {
    color: blue;
}

Reguła dotyczy wszystkich elementów p.

Selektor klasy

HTML:

<p class="wazne">
    Ważna informacja.
</p>

<p>
    Zwykła informacja.
</p>

CSS:

.wazne {
    color: red;
    font-weight: bold;
}

Kropka przed nazwą oznacza selektor klasy. Tę samą klasę można przypisać wielu elementom.

Selektor identyfikatora

HTML:

<h1 id="tytul">
    Moja witryna
</h1>

CSS:

#tytul {
    color: darkgreen;
}

Znak # oznacza selektor identyfikatora. W dokumencie HTML wartość atrybutu id powinna być unikatowa.

Porównanie selektorów

Selektor Przykład Co wskazuje?
Elementu p Wszystkie akapity.
Klasy .wazne Elementy z klasą wazne.
Identyfikatora #tytul Element o identyfikatorze tytul.

10. Kaskadowość stylów – na czym polega?

Słowo cascading w nazwie CSS oznacza kaskadowość.

Kaskada to mechanizm, dzięki któremu przeglądarka ustala, które deklaracje CSS zostaną zastosowane, gdy kilka reguł określa tę samą właściwość elementu.

Przykład – dwie reguły dla akapitu

HTML:

<p>Przykładowy tekst.</p>

CSS:

p {
    color: blue;
}

p {
    color: red;
}

Wynik: tekst będzie czerwony.

Obie reguły mają taką samą specyficzność i pochodzenie, dlatego decyduje kolejność. Późniejsza deklaracja color: red; zastępuje wcześniejszą deklarację koloru.

Czy późniejsza reguła zastępuje wszystko?

p {
    color: blue;
    font-size: 20px;
}

p {
    color: red;
}

Wynik: tekst będzie czerwony, ale zachowa rozmiar 20px.

Druga reguła nadpisuje tylko właściwość color. Nie usuwa deklaracji font-size z pierwszej reguły.

📌 Bardzo ważne

Kaskada rozstrzyga konflikty osobno dla każdej właściwości. Nie wybiera jednej całej reguły kosztem wszystkich pozostałych.

Co wpływa na wynik kaskady?

W uproszczeniu, przy rozstrzyganiu konfliktów istotne są:

  1. Pochodzenie i ważność deklaracji, np. reguły autora strony, przeglądarki lub użytkownika oraz !important.
  2. Warstwa kaskady, jeżeli została zastosowana.
  3. Specyficzność selektora.
  4. Odległość w drzewie elementów przy rozstrzyganiu niektórych reguł związanych z @scope.
  5. Kolejność deklaracji w arkuszach stylów.

Na tym etapie skupimy się na najczęściej spotykanych sytuacjach: stylach lokalnych, selektorach, specyficzności i kolejności reguł.

11. Specyficzność selektorów

Specyficzność określa, jak szczegółowo selektor wskazuje element.

Gdy kilka zwykłych reguł autora dotyczy tej samej właściwości, a wcześniejsze etapy kaskady nie rozstrzygają konfliktu, większa specyficzność może zdecydować o wyniku.

Podstawowe porównanie

Rodzaj Przykład Specyficzność
Element p 0-0-1
Klasa .wazne 0-1-0
Identyfikator #komunikat 1-0-0

Dla tych trzech prostych selektorów można zapamiętać:

Identyfikator ma większą specyficzność niż klasa, a klasa większą niż selektor elementu.

Przykład – element i klasa

HTML:

<p class="wazne">
    Komunikat dla użytkownika.
</p>

CSS:

p {
    color: blue;
}

.wazne {
    color: red;
}

Wynik: tekst będzie czerwony, ponieważ selektor klasy ma większą specyficzność niż selektor elementu.

Przykład – klasa i identyfikator

HTML:

<p id="komunikat" class="wazne">
    Ważny komunikat.
</p>

CSS:

#komunikat {
    color: green;
}

.wazne {
    color: red;
}

Wynik: tekst będzie zielony. Reguła identyfikatora ma większą specyficzność, mimo że reguła klasy występuje później.

Przykład – styl lokalny i klasa

HTML:

<p class="wazne"
   style="color: purple;">
    Ważny komunikat.
</p>

CSS:

.wazne {
    color: red;
}

Wynik: tekst będzie fioletowy.

W tym typowym przypadku zwykła deklaracja lokalna ma pierwszeństwo przed zwykłą regułą autora zapisaną w arkuszu stylów.

📌 Ważne

Specyficzność nie jest jedynym kryterium kaskady. Na przykład deklaracje oznaczone !important mogą zmienić wynik porównania. Dlatego nie należy przyjmować, że styl lokalny zawsze wygrywa.

12. Kolejność reguł i arkuszy stylów

Jeżeli dwie deklaracje mają takie samo pierwszeństwo na wcześniejszych etapach kaskady i jednakową specyficzność, decyduje kolejność.

Przykład – kolejność w jednym arkuszu

h1 {
    color: red;
}

h1 {
    color: blue;
}

Wynik: nagłówek będzie niebieski.

Przykład – arkusz zewnętrzny i styl wewnętrzny

Plik style.css:

h1 {
    color: green;
}

Plik index.html:

<head>

    <link rel="stylesheet" href="style.css">

    <style>
        h1 {
            color: red;
        }
    </style>

</head>

<body>
    <h1>Moja strona</h1>
</body>

Wynik: nagłówek będzie czerwony, ponieważ obie reguły mają taką samą specyficzność, a styl wewnętrzny został zapisany później.

A co, jeśli zmienimy kolejność?

<head>

    <style>
        h1 {
            color: red;
        }
    </style>

    <link rel="stylesheet" href="style.css">

</head>

Jeżeli plik style.css nadal zawiera h1 { color: green; }, nagłówek będzie zielony.

📌 Zapamiętaj

Nie istnieje ogólna zasada, że style wewnętrzne zawsze mają pierwszeństwo przed zewnętrznymi. Przy jednakowym pierwszeństwie i specyficzności liczy się ich kolejność.

13. Dziedziczenie właściwości CSS

Dziedziczenie to mechanizm, dzięki któremu niektóre właściwości CSS mogą być przekazywane z elementu nadrzędnego do jego elementów potomnych.

Przykład – kolor tekstu

HTML:

<div>

    <h2>Informacje</h2>

    <p>
        Pierwszy akapit.
    </p>

    <p>
        Drugi akapit.
    </p>

</div>

CSS:

div {
    color: blue;
}

Element div otrzyma niebieski kolor tekstu. Ponieważ color jest właściwością dziedziczoną, jego potomkowie również mogą wyświetlać niebieski tekst, o ile nie mają własnych odpowiednich deklaracji.

Przykład – zmiana stylu potomka

div {
    color: blue;
}

h2 {
    color: red;
}

Nagłówek będzie czerwony, a akapity niebieskie.

Czy wszystkie właściwości są dziedziczone?

Nie. Wiele właściwości związanych z wyglądem tekstu jest dziedziczonych, ale na przykład border, margin i padding nie są domyślnie dziedziczone.

Przykład – obramowanie

div {
    border: 2px solid black;
}

Obramowanie otrzyma element div, ale jego akapity nie odziedziczą automatycznie własnych obramowań.

Wartość inherit

div {
    color: green;
}

p {
    color: inherit;
}

Wartość inherit poleca pobranie wartości właściwości z elementu nadrzędnego.

📌 Ważne

Dziedziczenie i kaskada to powiązane, ale różne mechanizmy. Kaskada wybiera deklaracje dotyczące danego elementu, a dziedziczenie może dostarczyć wartość, gdy właściwość nie została określona bezpośrednio dla tego elementu.

14. Deklaracja !important

W CSS można oznaczyć deklarację słowem kluczowym !important.

Zmienia ono ważność deklaracji w mechanizmie kaskady.

Przykład

HTML:

<p class="komunikat"
   style="color: blue;">
    Ważna wiadomość.
</p>

CSS:

.komunikat {
    color: red !important;
}

Wynik: tekst będzie czerwony.

W tym przykładzie deklaracja z !important wygrywa ze zwykłą deklaracją lokalną.

Składnia

p {
    color: red !important;
}

Dlaczego nie należy go nadużywać?

  • Utrudnia przewidywanie wyników kaskady.
  • Może powodować konieczność stosowania kolejnych deklaracji !important.
  • Komplikuje późniejsze zmiany stylów.
  • Często ukrywa problemy ze specyficznością i organizacją CSS.

📌 Zapamiętaj

!important nie jest sposobem na „naprawianie każdego problemu z CSS”. W zwykłych projektach lepiej najpierw sprawdzić selektory, specyficzność i kolejność reguł.

15. Narzędzia deweloperskie przeglądarki

Podczas nauki CSS bardzo przydatne są narzędzia deweloperskie, które umożliwiają sprawdzanie stylów zastosowanych do elementów.

Jak otworzyć narzędzia?

  1. Otwórz stronę HTML w przeglądarce.
  2. Kliknij prawym przyciskiem myszy wybrany element.
  3. Wybierz opcję Zbadaj lub Inspect.
  4. Odszukaj panel Styles.
  5. Sprawdź, które deklaracje CSS są aktywne.

Co można sprawdzić?

  • Z jakiego pliku pochodzi reguła CSS.
  • Jaki selektor wskazuje element.
  • Które deklaracje zostały nadpisane.
  • Jakie wartości mają właściwości elementu.
  • Jak zmiana deklaracji wpływa na wygląd strony.

W panelu stylów nadpisane deklaracje są zwykle oznaczane przekreśleniem.

📌 Ważne

Zmiany wykonane bezpośrednio w narzędziach przeglądarki są zazwyczaj tymczasowe. Aby zachować je w projekcie, należy poprawić odpowiedni plik HTML lub CSS.

16. Najczęstsze błędy początkujących

Błąd 1 – brak średnika pomiędzy deklaracjami

/* Niepoprawnie */

p {
    color: red
    font-size: 18px;
}


/* Poprawnie */

p {
    color: red;
    font-size: 18px;
}

Błąd 2 – brak nawiasów klamrowych

/* Niepoprawnie */

h1
    color: blue;


/* Poprawnie */

h1 {
    color: blue;
}

Błąd 3 – błędna nazwa właściwości

/* Niepoprawnie */

p {
    text-color: red;
}


/* Poprawnie */

p {
    color: red;
}

Błąd 4 – niepoprawna ścieżka do arkusza

Struktura:

projekt/
|
|-- index.html
|
|-- css/
    |-- style.css
<!-- Niepoprawnie -->

<link rel="stylesheet" href="style.css">


<!-- Poprawnie -->

<link rel="stylesheet" href="css/style.css">

Błąd 5 – dodawanie znaczników HTML do pliku CSS

/* Niepoprawnie w pliku style.css */

/* Nie wpisujemy tutaj znaczników
   <style> i </style> */


/* Poprawnie */

h1 {
    color: navy;
}

Błąd 6 – mylenie class i id

HTML:

<p class="opis">
    Przykładowy tekst.
</p>

Niepoprawny selektor:

#opis {
    color: blue;
}

Poprawny selektor:

.opis {
    color: blue;
}

Błąd 7 – zakładanie, że ostatnia reguła zawsze wygrywa

#tytul {
    color: green;
}

h1 {
    color: red;
}

Jeśli element h1 ma identyfikator tytul, jego tekst będzie zielony. Selektor identyfikatora ma większą specyficzność.

📌 Zwróć uwagę

📌 Zapamiętaj

  • CSS służy do określania wyglądu strony internetowej.
  • HTML odpowiada za strukturę, a CSS za prezentację.
  • Reguła CSS składa się z selektora i deklaracji.
  • Deklaracja zawiera właściwość i jej wartość.
  • Styl lokalny zapisujemy w atrybucie style.
  • Styl wewnętrzny zapisujemy w elemencie style.
  • Styl zewnętrzny zapisujemy w pliku .css.
  • Zewnętrzny arkusz podłączamy za pomocą link.
  • Selektor elementu wskazuje elementy określonego typu.
  • Selektor klasy zapisujemy z kropką, np. .wazne.
  • Selektor identyfikatora zapisujemy ze znakiem #, np. #tytul.
  • Kaskada rozstrzyga konflikty pomiędzy deklaracjami CSS.
  • Specyficzność pomaga ustalić pierwszeństwo selektorów.
  • Przy jednakowej specyficzności i pozostałych warunkach decyduje kolejność.
  • Niektóre właściwości, np. color, są dziedziczone.
  • Właściwości takie jak margin i padding nie są domyślnie dziedziczone.
  • !important zmienia ważność deklaracji i nie powinno być nadużywane.
  • Narzędzia deweloperskie pomagają analizować działanie CSS.
  • W większych projektach najlepiej stosować zewnętrzne arkusze stylów.
