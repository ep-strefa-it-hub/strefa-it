Formatowanie tekstu w CSS – krój, rozmiar, grubość, wyrównanie i dekoracja

Cel lekcji: poznanie właściwości CSS służących do formatowania tekstu, dobieranie kroju, rozmiaru i grubości pisma, wyrównywanie akapitów, stosowanie dekoracji oraz projektowanie czytelnej typografii strony WWW.

1. Wprowadzenie – czym jest typografia?

Typografia to sposób projektowania i prezentowania tekstu. Obejmuje między innymi dobór kroju pisma, rozmiaru liter, grubości, odstępów, wyrównania i dekoracji.

W HTML określamy znaczenie i strukturę tekstu, natomiast w CSS decydujemy o jego wyglądzie.

Przykład HTML

<h1>Moja strona internetowa</h1>

<p>
    Witaj na stronie poświęconej
    projektowaniu witryn WWW.
</p>

Przykład CSS

h1 {
    font-family: Arial, sans-serif;
    font-size: 36px;
    font-weight: bold;
    text-align: center;
}

p {
    font-family: Georgia, serif;
    font-size: 18px;
    line-height: 1.6;
}

Znaczniki HTML pozostają bez zmian, ale tekst otrzymuje określony wygląd.

Najważniejsze właściwości

Właściwość Zastosowanie
font-family Określa krój pisma.
font-size Określa rozmiar pisma.
font-weight Określa grubość pisma.
font-style Określa styl pisma, np. kursywę.
text-align Wyrównuje tekst.
text-decoration Dodaje lub usuwa dekoracje tekstu.
line-height Określa wysokość wiersza.
letter-spacing Określa odstępy między znakami.
word-spacing Określa odstępy między wyrazami.

📌 Zapamiętaj

Dobra typografia nie polega na użyciu jak największej liczby efektów. Jej głównym zadaniem jest zapewnienie czytelności, przejrzystości i spójności strony.

2. Krój pisma – font-family

Właściwość font-family określa rodzinę kroju pisma, którą przeglądarka ma zastosować do tekstu.

Składnia

selektor {
    font-family: nazwa-czcionki;
}

Przykład

h1 {
    font-family: Arial;
}

p {
    font-family: Georgia;
}

Nagłówki będą wyświetlane krojem Arial, a akapity krojem Georgia, jeśli te kroje są dostępne.

Lista zapasowych krojów pisma

Nie wszystkie urządzenia mają zainstalowane te same czcionki. Dlatego warto podać kilka nazw. 

body {
    font-family: Arial, Helvetica, sans-serif;
}

Przeglądarka próbuje wykorzystać pierwszą dostępną rodzinę kroju, która może wyświetlić dany znak. Jeśli Arial nie jest dostępny, może użyć Helvetica, a następnie innego kroju bezszeryfowego.

Nazwy zawierające spacje

Nazwy rodzin krojów zawierające spacje najlepiej zapisywać w cudzysłowie. 

h2 {
    font-family: "Times New Roman", Times, serif;
}

Ustawienie kroju dla całej strony

body {
    font-family: Arial, sans-serif;
}

Większość tekstu na stronie odziedziczy ten krój, o ile nie zostanie określony inny.

📌 Dobra praktyka

Na końcu listy krojów umieszczaj ogólną rodzinę, np. sans-serif lub serif.

3. Podstawowe rodziny krojów pisma

Kroje pisma można podzielić na kilka podstawowych grup.

Serif – kroje szeryfowe

Kroje szeryfowe mają niewielkie ozdobne zakończenia liter, nazywane szeryfami. 

.tekst-szeryfowy {
    font-family: Georgia, "Times New Roman", serif;
}

Przykłady: Georgia, Times New Roman. Często wykorzystuje się je w artykułach, publikacjach i projektach o klasycznym charakterze.

Sans-serif – kroje bezszeryfowe

Nie mają ozdobnych zakończeń liter. Są bardzo popularne w interfejsach stron WWW. 

.tekst-bezszeryfowy {
    font-family: Arial, Helvetica, sans-serif;
}

Przykłady: Arial, Helvetica, Verdana.

Monospace – kroje o stałej szerokości znaków

Każdy znak zajmuje taką samą szerokość. Kroje te wykorzystuje się często do prezentowania kodu programów. 

code {
    font-family: Consolas, "Courier New", monospace;
}

Inne rodziny ogólne

Rodzina Charakterystyka
serif Kroje szeryfowe.
sans-serif Kroje bezszeryfowe.
monospace Znaki o jednakowej szerokości.
cursive Kroje przypominające pismo odręczne.
fantasy Kroje dekoracyjne.
system-ui Krój interfejsu systemowego.

Przykład

h1 {
    font-family: Georgia, serif;
}

p {
    font-family: Arial, sans-serif;
}

pre {
    font-family: Consolas, monospace;
}

Wybierając krój, zwracaj uwagę na polskie znaki, np. ą, ć, ę, ł, ń, ó, ś, ź, ż.

4. Rozmiar pisma – font-size

Właściwość font-size określa rozmiar tekstu.

Składnia

p {
    font-size: 18px;
}

Akapity otrzymają rozmiar pisma równy 18 pikselom CSS.

Różne rozmiary nagłówków

h1 {
    font-size: 36px;
}

h2 {
    font-size: 28px;
}

h3 {
    font-size: 22px;
}

p {
    font-size: 16px;
}

W ten sposób tworzymy wizualną hierarchię informacji.

Rozmiar bez jednostki – błąd

/* Niepoprawnie */

p {
    font-size: 18;
}

/* Poprawnie */

p {
    font-size: 18px;
}

Dla niezerowych długości wymagane jest podanie jednostki.

📌 Ważne

Nie należy dobierać rozmiaru tekstu wyłącznie na podstawie wyglądu na jednym monitorze. Strona powinna być czytelna także na mniejszych ekranach i przy powiększeniu.

5. Jednostki rozmiaru tekstu – px, em, rem i %

Rozmiar tekstu można zapisać przy użyciu różnych jednostek.

px – piksele CSS

p {
    font-size: 18px;
}

Jednostka px pozwala określić konkretny rozmiar w pikselach CSS.

em – rozmiar względny

p {
    font-size: 1.5em;
}

Przy właściwości font-size jednostka em odnosi się do obliczonego rozmiaru pisma rodzica.

Przykład

section {
    font-size: 20px;
}

section p {
    font-size: 1.5em;
}

Jeśli akapit znajduje się bezpośrednio w sekcji i dziedziczy rozmiar 20 px, to 1.5em daje 30 px.

rem – rozmiar względem elementu głównego

p {
    font-size: 1.25rem;
}

Jednostka rem odnosi się do rozmiaru pisma elementu głównego html.

Jeżeli rozmiar pisma elementu html wynosi 16 px, to 1.25rem odpowiada 20 px.

Przykład

html {
    font-size: 16px;
}

h1 {
    font-size: 2rem;
}

p {
    font-size: 1rem;
}

Nagłówek otrzyma 32 px, a akapit 16 px.

% – procent rozmiaru rodzica

p {
    font-size: 120%;
}

Jeśli rozmiar pisma rodzica wynosi 20 px, to 120% oznacza 24 px.

Porównanie jednostek

Jednostka Znaczenie Przykład
px Piksele CSS 18px
em Względem rozmiaru pisma rodzica przy font-size 1.5em
rem Względem rozmiaru pisma html 1.25rem
% Procent rozmiaru pisma rodzica 120%

📌 Dobra praktyka

W projektach stron internetowych warto poznać jednostkę rem, ponieważ ułatwia tworzenie spójnej skali typograficznej. Nie należy jednak blokować użytkownikowi możliwości powiększania tekstu.

6. Grubość pisma – font-weight

Właściwość font-weight określa grubość znaków.

Podstawowe wartości

p {
    font-weight: normal;
}

h1 {
    font-weight: bold;
}

normal odpowiada standardowej grubości, a bold pogrubieniu.

Wartości liczbowe

.tekst1 {
    font-weight: 300;
}

.tekst2 {
    font-weight: 400;
}

.tekst3 {
    font-weight: 600;
}

.tekst4 {
    font-weight: 700;
}
Wartość Typowe określenie
100 Bardzo cienka
300 Lekka
400 Normalna
500 Średnia
600 Półgruba
700 Gruba
900 Bardzo gruba

Wartości 400 i 700 odpowiadają odpowiednio normal i bold.

Współczesny CSS dopuszcza również wartości liczbowe pomiędzy 1 a 1000. Ich rzeczywisty wygląd zależy od dostępnych odmian kroju.

Przykład

h1 {
    font-weight: 700;
}

h2 {
    font-weight: 600;
}

p {
    font-weight: 400;
}

📌 Uwaga

Nie każda czcionka ma wszystkie odmiany grubości. Przeglądarka może wybrać najbliższą dostępną lub syntetycznie pogrubić tekst.

7. Styl pisma – font-style

Właściwość font-style określa, czy tekst ma być wyświetlany zwyczajnie, kursywą lub w odmianie pochyłej.

Podstawowe wartości

.zwykly {
    font-style: normal;
}

.kursywa {
    font-style: italic;
}

.pochylony {
    font-style: oblique;
}

Różnica między italic a oblique

italic oznacza kursywę, która może być specjalnie zaprojektowaną odmianą kroju.

oblique oznacza odmianę pochyłą. Wygląd zależy od możliwości konkretnej czcionki i przeglądarki.

Przykład HTML i CSS

<p class="cytat">
    Wiedza to początek możliwości.
</p>
.cytat {
    font-style: italic;
}

CSS a znaczniki HTML

Znacznik <em> służy do semantycznego zaakcentowania fragmentu tekstu, a font-style: italic zmienia jego wygląd.

Nie należy zastępować znaczenia semantycznego wyłącznie właściwością CSS.

8. Wyrównanie tekstu – text-align

Właściwość text-align określa poziome wyrównanie tekstu i innej zawartości liniowej wewnątrz elementu.

Wyrównanie do lewej

p {
    text-align: left;
}

Wyrównanie do prawej

p {
    text-align: right;
}

Wyśrodkowanie

h1 {
    text-align: center;
}

Justowanie

p {
    text-align: justify;
}

Justowanie polega na wyrównaniu tekstu do obu krawędzi przez odpowiednie rozłożenie odstępów między wyrazami.

Zwykle ostatni wiersz akapitu nie jest rozciągany na całą szerokość.

Porównanie wartości

Wartość Efekt
left Wyrównanie do lewej.
right Wyrównanie do prawej.
center Wyśrodkowanie.
justify Wyrównanie do obu krawędzi.
start Wyrównanie do początku kierunku pisma.
end Wyrównanie do końca kierunku pisma.

Przykład

<h1>Witamy na stronie</h1>

<p class="opis">
    Nasza strona przedstawia
    ciekawe miejsca w Polsce.
</p>

<p class="podpis">
    Autor: Jan Kowalski
</p>
h1 {
    text-align: center;
}

.opis {
    text-align: justify;
}

.podpis {
    text-align: right;
}

📌 Ważne

text-align: center nie służy do wyśrodkowania całego elementu blokowego o określonej szerokości. Wyrównuje zawartość wewnątrz elementu.

Do rozmieszczania bloków poznamy inne techniki, między innymi marginesy, Flexbox i Grid.

9. Dekoracja tekstu – text-decoration

Właściwość text-decoration pozwala dodawać do tekstu podkreślenie, przekreślenie lub linię nad tekstem.

Podkreślenie

.podkreslony {
    text-decoration: underline;
}

Przekreślenie

.przekreslony {
    text-decoration: line-through;
}

Linia nad tekstem

.nad-tekstem {
    text-decoration: overline;
}

Usunięcie dekoracji

a {
    text-decoration: none;
}

Ten zapis usuwa standardowe podkreślenie odnośników.

Kolor dekoracji

.tekst {
    text-decoration-line: underline;
    text-decoration-color: red;
}

Styl linii

.tekst1 {
    text-decoration: underline solid;
}

.tekst2 {
    text-decoration: underline dotted;
}

.tekst3 {
    text-decoration: underline dashed;
}

.tekst4 {
    text-decoration: underline wavy;
}

Grubość dekoracji

.tekst {
    text-decoration-line: underline;
    text-decoration-thickness: 3px;
}

Odstęp podkreślenia od tekstu

a {
    text-decoration: underline;
    text-underline-offset: 4px;
}

Skrócony zapis

a {
    text-decoration: underline wavy red 2px;
}

Jedna deklaracja określa rodzaj dekoracji, styl linii, kolor i grubość.

📌 Dobra praktyka

Odnośniki powinny być łatwe do rozpoznania. Nie usuwaj podkreślenia ze wszystkich linków, jeśli nie zapewniasz innego czytelnego sposobu ich wyróżnienia.

10. Zmiana wielkości liter – text-transform

Właściwość text-transform zmienia sposób wyświetlania wielkich i małych liter.

uppercase – wielkie litery

h1 {
    text-transform: uppercase;
}

lowercase – małe litery

.opis {
    text-transform: lowercase;
}

capitalize – początkowe litery wyrazów

.tytul {
    text-transform: capitalize;
}

none – bez przekształcenia

p {
    text-transform: none;
}

Przykład

<p class="nazwa">
    moja pierwsza strona
</p>
.nazwa {
    text-transform: uppercase;
}

Tekst zostanie wyświetlony wielkimi literami.

📌 Uwaga

text-transform zmienia sposób wyświetlania tekstu, a nie oryginalną zawartość zapisaną w pliku HTML.

11. Wysokość wiersza – line-height

Właściwość line-height określa wysokość wiersza tekstu. W praktyce wpływa na odstęp między kolejnymi liniami akapitu.

Przykład

p {
    font-size: 18px;
    line-height: 1.6;
}

Wartość 1.6 jest bezjednostkowym mnożnikiem rozmiaru pisma.

Przy rozmiarze 18 px wysokość wiersza wyniesie 28,8 px.

Porównanie

.tekst1 {
    line-height: 1;
}

.tekst2 {
    line-height: 1.5;
}

.tekst3 {
    line-height: 2;
}

Im większa wartość, tym większa wysokość wierszy.

Wartości z jednostką

p {
    line-height: 28px;
}

Jest to poprawne, jednak dla zwykłego tekstu często wygodniejsza jest wartość bez jednostki.

Dlaczego bez jednostki?

body {
    line-height: 1.5;
}

Elementy potomne dziedziczą mnożnik 1.5, który jest stosowany do ich własnego rozmiaru pisma.

📌 Dobra praktyka

Dla dłuższych akapitów często sprawdza się line-height w okolicach 1.4–1.7. Ostateczny wybór zależy od kroju, rozmiaru i szerokości tekstu.

12. Odstępy między literami i wyrazami

letter-spacing – odstęp między znakami

h1 {
    letter-spacing: 3px;
}

Litery nagłówka zostaną bardziej rozsunięte.

Ujemny odstęp

h1 {
    letter-spacing: -1px;
}

Ujemna wartość może zmniejszyć odstępy między znakami.

Zbyt duże wartości ujemne utrudniają czytanie i mogą prowadzić do nachodzenia znaków.

word-spacing – odstęp między wyrazami

p {
    word-spacing: 6px;
}

Właściwość zwiększa odstępy między wyrazami.

Przykład łączony

.haslo {
    font-size: 24px;
    font-weight: bold;
    letter-spacing: 2px;
    word-spacing: 5px;
}

Kiedy stosować?

  • W nagłówkach i krótkich hasłach.
  • W napisach na banerach.
  • W elementach identyfikacji wizualnej.
  • Ostrożnie w dłuższych akapitach.

13. Wcięcie pierwszego wiersza – text-indent

Właściwość text-indent pozwala ustawić wcięcie pierwszego wiersza tekstu w bloku.

Przykład

p {
    text-indent: 30px;
}

Pierwszy wiersz każdego akapitu zostanie przesunięty o 30 pikseli CSS.

Wcięcie procentowe

p {
    text-indent: 5%;
}

Wartość procentowa odnosi się do szerokości odpowiedniego bloku zawierającego.

Przykład zastosowania

.artykul p {
    text-align: justify;
    text-indent: 2em;
    line-height: 1.6;
}

Akapity w artykule będą wyjustowane i otrzymają wcięcie pierwszego wiersza.

📌 Uwaga

text-indent nie służy do ustawiania marginesu całego akapitu. Do tego wykorzystujemy inne właściwości, np. margin.

14. Cień tekstu – text-shadow

Właściwość text-shadow pozwala dodać cień do wyświetlanego tekstu.

Składnia

h1 {
    text-shadow: 2px 2px 4px gray;
}

Znaczenie wartości

Wartość Znaczenie
2px Przesunięcie poziome cienia.
2px Przesunięcie pionowe cienia.
4px Promień rozmycia.
gray Kolor cienia.

Przykład – delikatny cień

h1 {
    color: #1E3A8A;
    text-shadow: 1px 1px 2px lightgray;
}

Przykład – mocniejszy efekt

.baner {
    color: white;
    text-shadow: 3px 3px 6px black;
}

Cień może poprawić widoczność tekstu na tle, ale nie zastąpi odpowiedniego kontrastu.

📌 Dobra praktyka

Cienie stosuj oszczędnie. Zbyt mocne lub wielokolorowe efekty mogą utrudniać czytanie.

15. Skrócony zapis właściwości – font

CSS umożliwia zapisanie kilku właściwości tekstu w jednej deklaracji font.

Oddzielne deklaracje

p {
    font-style: italic;
    font-weight: bold;
    font-size: 18px;
    line-height: 1.5;
    font-family: Arial, sans-serif;
}

Zapis skrócony

p {
    font: italic bold 18px/1.5 Arial, sans-serif;
}

Obie reguły określają te same wartości wymienionych właściwości.

Podstawowa postać

p {
    font: 18px Arial, sans-serif;
}

W skróconej deklaracji wymagane są font-size oraz font-family.

Pozostałe składniki, np. font-style i font-weight, są opcjonalne.

Kolejność ma znaczenie

h2 {
    font: bold 24px/1.4 Georgia, serif;
}

W tym przykładzie:

  • bold – grubość pisma.
  • 24px – rozmiar pisma.
  • 1.4 – wysokość wiersza.
  • Georgia, serif – rodzina kroju.

📌 Ważne

Deklaracja skrócona font może zresetować pominięte właściwości związane z fontem do wartości początkowych. Dlatego podczas nauki warto najpierw stosować oddzielne deklaracje.

16. Dziedziczenie formatowania tekstu

Wiele właściwości związanych z tekstem jest dziedziczonych przez elementy potomne.

Przykład HTML

<section class="artykul">

    <h2>Ciekawostki technologiczne</h2>

    <p>
        Pierwszy akapit artykułu.
    </p>

    <p>
        Drugi akapit artykułu.
    </p>

</section>

Przykład CSS

.artykul {
    font-family: Georgia, serif;
    font-size: 18px;
    line-height: 1.6;
    color: #333333;
}

Elementy znajdujące się wewnątrz sekcji mogą odziedziczyć krój, rozmiar, wysokość wiersza i kolor tekstu.

Nie oznacza to jednak, że każdy potomek będzie wyglądał identycznie. Przeglądarka może stosować własne style do nagłówków, a inne reguły CSS mogą nadpisać wartości.

Nadpisanie właściwości

.artykul {
    font-family: Georgia, serif;
    color: #333333;
}

.artykul h2 {
    font-family: Arial, sans-serif;
    color: #1E3A8A;
}

Nagłówek otrzyma osobny krój i kolor, a pozostały tekst może korzystać z wartości odziedziczonych.

Wartość inherit

.przycisk {
    font-family: inherit;
    font-size: inherit;
}

Wartość inherit wymusza odziedziczenie właściwości od rodzica.

📌 Zapamiętaj

Ustawienie podstawowej typografii na elemencie body pomaga zachować spójność strony. Wybrane nagłówki, przyciski i inne elementy można następnie formatować osobno.

17. Czytelność i dobre praktyki typograficzne

Dobrze sformatowany tekst powinien być wygodny do czytania na komputerze, tablecie i telefonie.

1. Odpowiedni rozmiar tekstu

Dla tekstu podstawowego często stosuje się około 16–18 px lub odpowiadające im wartości względne.

2. Odpowiednia wysokość wiersza

p {
    font-size: 1rem;
    line-height: 1.6;
}

3. Ograniczona liczba krojów

Na jednej stronie zwykle wystarczą jeden lub dwa dobrze dobrane kroje pisma.

4. Wyraźna hierarchia nagłówków

h1 {
    font-size: 2.25rem;
}

h2 {
    font-size: 1.75rem;
}

h3 {
    font-size: 1.25rem;
}

p {
    font-size: 1rem;
}

5. Kontrast tekstu i tła

body {
    color: #1F2937;
    background-color: #FFFFFF;
}

Dla zwykłego tekstu na poziomie WCAG AA wymagany współczynnik kontrastu wynosi co najmniej 4,5:1, z określonymi wyjątkami.

6. Unikanie długich wyśrodkowanych akapitów

Wyśrodkowanie dobrze sprawdza się w krótkich nagłówkach i hasłach. Dłuższe akapity zazwyczaj wygodniej czyta się wyrównane do początku kierunku pisma.

7. Rozsądna szerokość wiersza

.artykul {
    max-width: 65ch;
}

Jednostka ch jest związana z szerokością znaku „0” w używanym kroju. Pomaga ograniczyć długość wierszy tekstu.

8. Zachowanie semantyki HTML

Rozmiar i pogrubienie nie zastępują znaczników h1–h6. Nagłówki powinny określać strukturę dokumentu, a CSS jedynie ich wygląd.

📌 Dobra praktyka

Sprawdzaj stronę przy powiększeniu tekstu i zmianie szerokości okna. Czytelność jest ważniejsza od dekoracyjnych efektów.

18. Najczęstsze błędy

Błąd 1 – brak jednostki rozmiaru

/* Niepoprawnie */

p {
    font-size: 20;
}

/* Poprawnie */

p {
    font-size: 20px;
}

Błąd 2 – brak cudzysłowu przy nazwie kroju

/* Zalecany zapis */

p {
    font-family: "Times New Roman", serif;
}

Cudzysłów jest zalecany dla nazw zawierających spacje.

Błąd 3 – mylenie font-weight z font-style

/* Pogrubienie */

h2 {
    font-weight: bold;
}

/* Kursywa */

h2 {
    font-style: italic;
}

Błąd 4 – próba wyśrodkowania bloku przez text-align

.karta {
    width: 300px;
    text-align: center;
}

Powyższy kod wyśrodkowuje tekst wewnątrz karty, ale nie ustawia samej karty na środku strony.

Błąd 5 – nadmierne justowanie

p {
    text-align: justify;
}

Na bardzo wąskich ekranach justowanie może powodować duże odstępy między wyrazami.

Błąd 6 – usuwanie podkreślenia wszystkich linków

a {
    text-decoration: none;
}

Jeśli link nie ma innego wyraźnego wyróżnienia, użytkownik może go nie rozpoznać.

Błąd 7 – zbyt duże odstępy między literami

p {
    letter-spacing: 8px;
}

Tak duży odstęp może znacząco pogorszyć czytelność zwykłego akapitu.

Błąd 8 – zbyt mała wysokość wiersza

p {
    font-size: 20px;
    line-height: 1;
}

W dłuższym tekście wiersze mogą znajdować się zbyt blisko siebie.

Błąd 9 – niepoprawna kolejność w font

/* Poprawnie */

p {
    font: bold 18px/1.5 Arial, sans-serif;
}

W zapisie skróconym rozmiar musi wystąpić przed nazwą rodziny kroju.

📌 Zwróć uwagę

Większość tekstu korzysta z ustawień elementu body. Wyjątki wprowadzamy tylko tam, gdzie są potrzebne.

📌 Zapamiętaj

  • font-family określa rodzinę kroju pisma.
  • Warto podawać zapasowe kroje pisma.
  • serif oznacza kroje szeryfowe.
  • sans-serif oznacza kroje bezszeryfowe.
  • monospace oznacza kroje o stałej szerokości znaków.
  • font-size określa rozmiar pisma.
  • px, em, rem i % są jednostkami stosowanymi przy rozmiarze tekstu.
  • font-weight określa grubość pisma.
  • font-weight: 400 odpowiada wartości normal.
  • font-weight: 700 odpowiada wartości bold.
  • font-style: italic ustawia kursywę.
  • text-align wyrównuje zawartość tekstową.
  • text-align: center nie centruje automatycznie całego bloku.
  • text-decoration służy do dekoracji tekstu.
  • text-transform zmienia sposób wyświetlania wielkich i małych liter.
  • line-height określa wysokość wiersza.
  • letter-spacing ustawia odstępy między znakami.
  • word-spacing ustawia odstępy między wyrazami.
  • text-indent pozwala wykonać wcięcie pierwszego wiersza.
  • text-shadow dodaje cień tekstu.
  • font jest skróconym zapisem kilku właściwości.
  • Wiele właściwości typograficznych jest dziedziczonych.
  • Najważniejszym celem formatowania tekstu jest jego czytelność.

📝 Zadania praktyczne

Cel: samodzielne formatowanie tekstu za pomocą CSS oraz zastosowanie zasad czytelnej typografii w projekcie strony WWW.

Utwórz folder PSI_22, a w nim dwa pliki: index.html i style.css.

Wszystkie zadania wykonaj w ramach jednej strony. Kolejne zadania rozbudowują wcześniej przygotowany projekt.

Zadanie 1 – Struktura strony i kroje pisma

Przygotuj stronę zatytułowaną „Magazyn internetowy”. Tematykę artykułów wybierz samodzielnie.

  1. Utwórz poprawną strukturę dokumentu HTML5.
  2. Podłącz zewnętrzny arkusz style.css.
  3. Dodaj elementy header, main i footer.
  4. W nagłówku umieść tytuł strony i krótki opis.
  5. W części głównej dodaj trzy artykuły z nagłówkami i akapitami.
  6. Ustaw dla całej strony krój Arial, sans-serif.
  7. Dla nagłówków h2 zastosuj Georgia, serif.
  8. W jednym z artykułów umieść fragment kodu i nadaj mu krój Consolas, monospace.

Zadanie 2 – Rozmiar i grubość tekstu

Rozbuduj formatowanie przygotowanej strony.

  1. Ustaw rozmiar głównego tytułu na 36px.
  2. Ustaw rozmiar nagłówków artykułów na 28px.
  3. Ustaw rozmiar akapitów na 18px.
  4. Ustaw grubość tytułu strony na 700.
  5. Ustaw grubość nagłówków artykułów na 600.
  6. Ustaw standardową grubość akapitów na 400.
  7. Dodaj pod każdym tytułem artykułu informację o autorze, sformatowaną kursywą.
  8. Wybierz jeden fragment tekstu i wyróżnij go pogrubieniem.

Zadanie 3 – Wyrównanie i wysokość wiersza

Dopracuj układ tekstu w magazynie internetowym.

  1. Wyśrodkuj główny tytuł strony.
  2. Wyrównaj informacje o autorach do prawej strony.
  3. W pierwszym artykule zastosuj text-align: left.
  4. W drugim artykule zastosuj text-align: justify.
  5. Ustaw dla akapitów line-height: 1.6.
  6. W trzecim artykule dodaj cytat i wyśrodkuj jego tekst.
  7. Dodaj do pierwszego akapitu trzeciego artykułu wcięcie pierwszego wiersza 30px.
  8. Porównaj wygląd akapitów wyrównanych do lewej i wyjustowanych.

Zadanie 4 – Dekoracja i przekształcanie tekstu

Dodaj elementy wykorzystujące dekoracje tekstowe.

  1. Ustaw główny tytuł strony wielkimi literami za pomocą text-transform.
  2. Zastosuj odstęp między literami tytułu równy 2px.
  3. Dodaj do strony trzy odnośniki do zewnętrznych witryn.
  4. Ustaw podkreślenie odnośników.
  5. Zmień kolor podkreślenia jednego odnośnika.
  6. Dodaj przykład tekstu przekreślonego.
  7. Dodaj przykład tekstu podkreślonego linią falistą.
  8. Zastosuj delikatny cień dla tytułu strony.

Zadanie 5 – Porównanie jednostek px, em i rem

Dodaj sekcję „Porównanie rozmiarów tekstu”.

  1. Utwórz trzy akapity zawierające ten sam tekst.
  2. Pierwszemu ustaw rozmiar 20px.
  3. Drugiemu ustaw rozmiar 1.25rem.
  4. Trzeciemu ustaw rozmiar 1.25em.
  5. Ustaw rozmiar pisma elementu html na 16px.
  6. Ustaw rozmiar pisma rodzica trzeciego akapitu na 16px.
  7. Porównaj rozmiary wszystkich trzech akapitów.
  8. Zmień rozmiar pisma rodzica trzeciego akapitu na 24px i sprawdź, który akapit zmieni wygląd.
  9. Pod przykładami wyjaśnij różnicę między em i rem.

Zadanie 6 – Udoskonalenie typografii (dodatkowe)

Dopracuj wygląd całego magazynu internetowego.

  1. Ustal spójny zestaw rozmiarów nagłówków.
  2. Dobierz czytelne kolory tekstu i tła.
  3. Ogranicz liczbę krojów pisma do dwóch.
  4. Zadbaj o odpowiednią wysokość wierszy.
  5. Sprawdź wygląd strony przy zmniejszonej szerokości okna.
  6. Sprawdź czytelność przy powiększeniu strony do 200%.
  7. Usuń dekoracje, które utrudniają czytanie.
