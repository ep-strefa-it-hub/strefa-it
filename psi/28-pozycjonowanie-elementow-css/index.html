Pozycjonowanie elementów w CSS – relative, absolute, fixed, sticky oraz z-index

Cel lekcji: poznanie sposobów pozycjonowania elementów strony internetowej, określania ich położenia za pomocą właściwości top, right, bottom i left oraz kontrolowania kolejności nakładania elementów przy użyciu z-index.

1. Wprowadzenie – czym jest pozycjonowanie?

Elementy HTML są domyślnie rozmieszczane przez przeglądarkę zgodnie z zasadami układu dokumentu.

Elementy blokowe zazwyczaj pojawiają się jeden pod drugim, a elementy liniowe mogą znajdować się obok siebie w tym samym wierszu.

Czasami jednak chcemy umieścić element w konkretnym miejscu, na przykład:

  • odznakę „NOWOŚĆ” w rogu karty produktu,
  • przycisk w prawym dolnym rogu ekranu,
  • menu pozostające na górze podczas przewijania,
  • tekst nałożony na obraz,
  • komunikat wyświetlany nad innymi elementami.

Do takich zadań wykorzystujemy pozycjonowanie CSS.

Przykład

<div class="karta">
    <span class="odznaka">NOWOŚĆ</span>
    <h2>Nowy kurs CSS</h2>
    <p>Poznaj możliwości CSS3.</p>
</div>
.karta {
    position: relative;
}

.odznaka {
    position: absolute;
    top: 10px;
    right: 10px;
}

Odznaka zostanie umieszczona w prawym górnym rogu karty, z odstępem 10 px od jej krawędzi obszaru pozycjonowania.

📌 Zapamiętaj

Pozycjonowanie CSS pozwala kontrolować położenie elementów względem ich zwykłego miejsca, kontenera lub obszaru widocznego w oknie przeglądarki.

2. Właściwość position

Właściwość position określa sposób pozycjonowania elementu HTML.

Składnia

selektor {
    position: wartosc;
}

Najważniejsze wartości

Wartość Znaczenie
static Domyślne pozycjonowanie elementu.
relative Przesuwa element względem jego normalnego położenia.
absolute Pozycjonuje element względem odpowiedniego bloku odniesienia, często pozycjonowanego rodzica.
fixed Zwykle pozycjonuje element względem widocznego obszaru przeglądarki.
sticky Łączy zachowanie normalnego układu z przyklejaniem podczas przewijania.

Przykład

.element {
    position: relative;
}

Samo ustawienie position: relative nie musi powodować widocznego przesunięcia.

Położenie możemy zmienić za pomocą właściwości top, right, bottom i left.

3. Position: static – pozycjonowanie domyślne

Wartość static jest domyślnym sposobem pozycjonowania większości elementów HTML.

Element zajmuje swoje miejsce w normalnym układzie strony.

Przykład HTML

<div class="blok">Blok 1</div>
<div class="blok">Blok 2</div>
<div class="blok">Blok 3</div>

Kod CSS

.blok {
    position: static;

    padding: 20px;
    margin-bottom: 10px;

    background-color: lightblue;
}

Bloki będą rozmieszczone zgodnie z normalnym układem dokumentu.

Czy top i left zadziałają?

.blok {
    position: static;

    top: 30px;
    left: 50px;
}

Nie. Dla elementu z position: static właściwości pozycjonujące top, right, bottom i left nie powodują przesunięcia.

📌 Zapamiętaj

position: static oznacza zwykłe położenie elementu. Nie można przesuwać go za pomocą top, right, bottom i left.

4. Position: relative – pozycjonowanie względne

position: relative pozwala przesunąć element względem miejsca, które zajmowałby w normalnym układzie strony.

Bardzo ważne jest to, że pierwotne miejsce elementu pozostaje zarezerwowane.

Przykład HTML

<div class="blok">Pierwszy blok</div>

<div class="blok przesuniety">
    Drugi blok
</div>

<div class="blok">Trzeci blok</div>

Kod CSS

.blok {
    width: 250px;
    padding: 20px;
    margin-bottom: 15px;

    background-color: lightblue;
    border: 2px solid blue;
}

.przesuniety {
    position: relative;

    top: 20px;
    left: 40px;

    background-color: lightgreen;
}

Co się stanie?

  • Drugi blok przesunie się o 20 px w dół.
  • Drugi blok przesunie się o 40 px w prawo.
  • Jego pierwotne miejsce nadal będzie zarezerwowane.
  • Trzeci blok nie przesunie się automatycznie razem z nim.

Wartości ujemne

.przesuniety {
    position: relative;

    top: -10px;
    left: -20px;
}

Element przesunie się o 10 px w górę i 20 px w lewo.

Do czego służy relative?

Najczęściej do niewielkiego przesuwania elementów oraz tworzenia punktu odniesienia dla elementów z position: absolute.

📌 Zapamiętaj

relative przesuwa element wizualnie, ale nie usuwa jego miejsca z normalnego układu strony.

5. Position: absolute – pozycjonowanie bezwzględne

position: absolute pozwala umieścić element w określonym miejscu względem jego bloku odniesienia.

Element z pozycjonowaniem bezwzględnym zostaje wyjęty z normalnego układu dokumentu.

Oznacza to, że inne elementy nie rezerwują dla niego miejsca w taki sam sposób jak dla zwykłego bloku.

Przykład HTML

<div class="kontener">

    <div class="etykieta">
        PROMOCJA
    </div>

    <h2>Kurs CSS</h2>

    <p>Poznaj podstawy CSS.</p>

</div>

Kod CSS

.kontener {
    position: relative;

    width: 350px;
    min-height: 200px;

    padding: 25px;

    background-color: lightblue;
}

.etykieta {
    position: absolute;

    top: 10px;
    right: 10px;

    padding: 8px;

    color: white;
    background-color: red;
}

Etykieta pojawi się w prawym górnym rogu kontenera.

Co oznaczają top i right?

top: 10px;
right: 10px;

Górna krawędź elementu znajduje się 10 px od odpowiedniej górnej krawędzi obszaru odniesienia, a prawa krawędź 10 px od jego prawej strony.

📌 Ważne

Element absolute nie musi być pozycjonowany względem całej strony. Bardzo często jego punktem odniesienia jest najbliższy odpowiednio pozycjonowany przodek.

6. Rodzic relative i dziecko absolute

Jednym z najważniejszych zastosowań pozycjonowania CSS jest połączenie: 

.rodzic {
    position: relative;
}

.dziecko {
    position: absolute;
}

Dzięki temu element potomny może być pozycjonowany względem kontenera rodzica.

Przykład – odznaka na karcie

<div class="karta">

    <span class="odznaka">
        NOWOŚĆ
    </span>

    <h2>Kurs HTML5</h2>

    <p>
        Poznaj podstawy tworzenia stron.
    </p>

</div>
.karta {
    position: relative;

    width: 300px;
    min-height: 200px;

    padding: 30px;

    background-color: white;

    border: 2px solid blue;
    border-radius: 10px;
}

.odznaka {
    position: absolute;

    top: 10px;
    right: 10px;

    padding: 5px 10px;

    background-color: red;
    color: white;
}

Dlaczego position: relative jest ważne?

Jeżeli usuniemy position: relative z kontenera, element absolute może zostać pozycjonowany względem innego przodka albo początkowego bloku odniesienia.

Wtedy odznaka może znaleźć się w zupełnie innym miejscu, niż oczekiwaliśmy.

📌 Najważniejsza zasada

Jeśli chcesz umieścić element w konkretnym rogu karty, najczęściej zastosuj: 

.karta {
    position: relative;
}

.odznaka {
    position: absolute;
    top: 10px;
    right: 10px;
}

7. Position: fixed – pozycjonowanie stałe

position: fixed pozwala umieścić element w stałym miejscu względem widocznego obszaru przeglądarki.

W typowym przypadku element pozostaje w tym samym miejscu ekranu, nawet gdy użytkownik przewija stronę.

Przykład – przycisk w rogu ekranu

<a href="#start" class="do-gory">
    ↑
</a>
.do-gory {
    position: fixed;

    right: 20px;
    bottom: 20px;

    padding: 15px;

    background-color: blue;
    color: white;

    text-decoration: none;
    border-radius: 50%;
}

Przycisk będzie znajdował się w prawym dolnym rogu widocznego obszaru strony.

Inne zastosowania

  • przycisk powrotu na górę,
  • przycisk kontaktu,
  • pływający panel pomocy,
  • stały pasek nawigacji,
  • komunikat wyświetlany na ekranie.

Element fixed a układ strony

Podobnie jak absolute, element fixed jest wyjęty z normalnego układu dokumentu.

Może więc zasłaniać inne elementy strony.

📌 Zapamiętaj

fixed najczęściej oznacza stałą pozycję względem okna przeglądarki. Niektóre właściwości przodków, np. transform, mogą jednak zmienić jego blok odniesienia.

8. Position: sticky – pozycjonowanie przyklejone

position: sticky łączy cechy pozycjonowania względnego i przyklejania elementu podczas przewijania.

Początkowo element znajduje się w swoim zwykłym miejscu. Po osiągnięciu określonej pozycji podczas przewijania może pozostać przyklejony do krawędzi obszaru przewijania.

Przykład

<nav class="menu">

    <a href="#start">Start</a>

    <a href="#oferta">Oferta</a>

    <a href="#kontakt">Kontakt</a>

</nav>
.menu {
    position: sticky;

    top: 0;

    padding: 15px;

    background-color: #1E3A8A;
}

Menu będzie przyklejać się do górnej krawędzi odpowiedniego obszaru przewijania.

Dlaczego top: 0 jest ważne?

position: sticky;
top: 0;

Właściwość top wskazuje granicę, przy której element ma zacząć się przyklejać.

Sticky a fixed

Element fixed zwykle pozostaje stale w tym samym miejscu ekranu.

Element sticky początkowo uczestniczy w normalnym układzie i przykleja się dopiero podczas przewijania.

📌 Uwaga

Działanie sticky zależy od obszaru przewijania oraz granic kontenera. Jeśli element nie ma miejsca na przyklejenie lub odpowiedniego przewijania, efekt może być niewidoczny.

9. Właściwości top, right, bottom i left

Właściwości te określają położenie elementów z odpowiednim position.

Właściwość Znaczenie
top Określa odsunięcie od górnej strony.
right Określa odsunięcie od prawej strony.
bottom Określa odsunięcie od dolnej strony.
left Określa odsunięcie od lewej strony.

Przykład 1 – lewy górny róg

.element {
    position: absolute;

    top: 10px;
    left: 10px;
}

Przykład 2 – prawy górny róg

.element {
    position: absolute;

    top: 10px;
    right: 10px;
}

Przykład 3 – lewy dolny róg

.element {
    position: absolute;

    bottom: 10px;
    left: 10px;
}

Przykład 4 – prawy dolny róg

.element {
    position: absolute;

    bottom: 10px;
    right: 10px;
}

Wartości ujemne

.element {
    position: absolute;

    top: -10px;
    right: -10px;
}

Element może częściowo wystawać poza kontener.

📌 Ważne

Działanie top, right, bottom i left zależy od wartości właściwości position. Nie zawsze oznaczają one odsunięcie od krawędzi całego okna przeglądarki.

10. Porównanie sposobów pozycjonowania

Position Punkt odniesienia Miejsce w normalnym układzie Typowe zastosowanie
static Normalny układ strony Tak Zwykłe elementy
relative Własne normalne położenie Tak Drobne przesunięcia, rodzic dla absolute
absolute Odpowiedni blok odniesienia Nie Odznaki, nakładki, elementy w rogach kart
fixed Zwykle obszar widoczny przeglądarki Nie Pływające przyciski i panele
sticky Normalne położenie i obszar przewijania Tak Przyklejone menu i nagłówki

Jak zapamiętać różnice?

  • static – zwykłe położenie.
  • relative – przesunięcie względem siebie.
  • absolute – położenie względem bloku odniesienia.
  • fixed – zwykle stałe miejsce na ekranie.
  • sticky – przyklejenie podczas przewijania.

11. Właściwość z-index – kolejność nakładania elementów

Elementy strony mogą częściowo lub całkowicie nakładać się na siebie.

Właściwość z-index pomaga określić, który element ma być wyświetlany nad innym.

Przykład HTML

<div class="obszar">

    <div class="kwadrat pierwszy">
        1
    </div>

    <div class="kwadrat drugi">
        2
    </div>

</div>

Kod CSS

.obszar {
    position: relative;

    height: 220px;
}

.kwadrat {
    position: absolute;

    width: 130px;
    height: 130px;
}

.pierwszy {
    top: 20px;
    left: 20px;

    background-color: lightblue;

    z-index: 1;
}

.drugi {
    top: 70px;
    left: 70px;

    background-color: lightcoral;

    z-index: 2;
}

Drugi kwadrat będzie wyświetlany nad pierwszym, ponieważ w tym samym kontekście nakładania ma wyższą wartość z-index.

Przykładowe wartości

z-index: 1;

z-index: 10;

z-index: 100;

z-index: -1;

Wartości mogą być dodatnie, zerowe lub ujemne.

Ważna zasada

z-index nie jest prostym numerem warstwy dla całej strony. Jego działanie zależy od kontekstów nakładania.

📌 Zapamiętaj

z-index służy do kontrolowania kolejności nakładania elementów. W typowych przykładach działa dla elementów pozycjonowanych, a także m.in. dla elementów flex i grid.

12. Kontekst nakładania – stacking context

Podczas pracy z z-index można spotkać sytuację, w której bardzo wysoka wartość nie powoduje wyświetlenia elementu nad wszystkimi innymi.

Wynika to z istnienia kontekstów nakładania (ang. stacking contexts).

Przykład

<div class="panel1">

    <div class="odznaka">
        Odznaka
    </div>

</div>

<div class="panel2">
    Drugi panel
</div>
.panel1 {
    position: relative;
    z-index: 1;
}

.panel2 {
    position: relative;
    z-index: 2;
}

.odznaka {
    position: absolute;
    z-index: 9999;
}

Mimo że odznaka ma z-index: 9999, nie może samodzielnie przeskoczyć ponad cały kontekst nakładania panelu o wyższej warstwie.

Co może utworzyć stacking context?

  • pozycjonowany element z z-index innym niż auto,
  • element z position: fixed lub sticky,
  • element z opacity mniejszym niż 1,
  • element z transform innym niż none,
  • niektóre elementy flex i grid z ustawionym z-index.

📌 Ważne

Jeśli z-index nie działa zgodnie z oczekiwaniami, sprawdź nie tylko sam element, ale również jego rodziców.

13. Praktyczny przykład – odznaki na kartach

Pozycjonowanie bezwzględne często wykorzystuje się do umieszczania informacji w narożnikach kart.

HTML

<article class="karta">

    <span class="odznaka">
        HIT
    </span>

    <h2>Kurs CSS3</h2>

    <p>
        Naucz się projektować
        nowoczesne strony WWW.
    </p>

</article>

CSS

.karta {
    position: relative;

    width: 300px;
    min-height: 200px;

    padding: 45px 20px 20px;

    background-color: white;

    border: 2px solid #CBD5E1;
    border-radius: 12px;
}

.odznaka {
    position: absolute;

    top: 10px;
    right: 10px;

    padding: 5px 12px;

    background-color: #DC2626;
    color: white;

    border-radius: 5px;
}

Zwróć uwagę na większy górny padding karty. Dzięki niemu odznaka nie zasłania nagłówka.

📌 Dobra praktyka

Elementy pozycjonowane bezwzględnie mogą nachodzić na treść. Dlatego należy zaplanować dla nich odpowiednio dużo miejsca.

14. Praktyczny przykład – przyklejona nawigacja

Menu z position: sticky może pozostać widoczne podczas przewijania strony.

HTML

<header id="start">

    <h1>Moja strona</h1>

</header>

<nav class="menu">

    <a href="#start">Start</a>

    <a href="#oferta">Oferta</a>

    <a href="#kontakt">Kontakt</a>

</nav>

CSS

.menu {
    position: sticky;

    top: 0;
    z-index: 100;

    padding: 15px;

    background-color: #1E3A8A;
}

.menu a {
    display: inline-block;

    padding: 10px 20px;

    color: white;
    text-decoration: none;
}

Wartość z-index: 100 pomaga wyświetlać menu nad zwykłą zawartością w odpowiednim kontekście nakładania.

Dlaczego warto ustawić kolor tła?

Bez wyraźnego tła tekst i elementy znajdujące się pod przyklejonym menu mogą prześwitywać, utrudniając czytanie.

15. Praktyczny przykład – przycisk powrotu na górę

Za pomocą position: fixed możemy utworzyć przycisk, który pozostaje w prawym dolnym rogu ekranu.

HTML

<header id="start">

    <h1>Moja strona</h1>

</header>

<a href="#start"
   class="do-gory"
   aria-label="Powrót na górę strony">
    ↑
</a>

CSS

.do-gory {
    position: fixed;

    right: 20px;
    bottom: 20px;

    z-index: 200;

    display: inline-block;

    width: 50px;
    height: 50px;

    line-height: 50px;
    text-align: center;

    background-color: #2563EB;
    color: white;

    text-decoration: none;

    border-radius: 50%;
}

.do-gory:hover {
    background-color: #1D4ED8;
}

Przycisk pozostaje w stałym miejscu ekranu podczas przewijania.

Po kliknięciu odnośnika przeglądarka przechodzi do elementu o identyfikatorze start.

Płynne przewijanie

html {
    scroll-behavior: smooth;
}

Ta właściwość umożliwia płynne przewijanie przy przechodzeniu do kotwic strony.

16. Pozycjonowanie a responsywność strony

Pozycjonowanie elementów wymaga uwzględnienia różnych rozmiarów ekranów.

Element umieszczony w konkretnym miejscu na dużym monitorze może zasłaniać treść na ekranie telefonu.

Przykład problemu

.panel {
    position: absolute;

    left: 800px;
    top: 100px;
}

Na małym ekranie panel może znaleźć się poza widocznym obszarem.

Lepsze rozwiązanie

.kontener {
    position: relative;
}

.panel {
    position: absolute;

    top: 10px;
    right: 10px;
}

Panel będzie pozycjonowany względem kontenera, a nie za pomocą dużej, sztywnej odległości od lewej strony.

Media queries

@media (max-width: 600px) {

    .do-gory {
        right: 10px;
        bottom: 10px;

        width: 42px;
        height: 42px;

        line-height: 42px;
    }

}

Na mniejszych ekranach przycisk zajmuje mniej miejsca.

📌 Dobra praktyka

Nie używaj position: absolute do rozmieszczania wszystkich elementów całej strony. Do głównego układu zwykle lepiej nadają się normalny przepływ dokumentu, Flexbox lub Grid.

17. Najczęstsze błędy

Błąd 1 – top i left bez odpowiedniego position

.element {
    top: 20px;
    left: 30px;
}

Element ma domyślnie position: static, więc właściwości te nie przesuną go.

Poprawnie:

.element {
    position: relative;

    top: 20px;
    left: 30px;
}

Błąd 2 – absolute bez punktu odniesienia

.odznaka {
    position: absolute;

    top: 10px;
    right: 10px;
}

Jeśli nie ustawimy odpowiedniego rodzica, odznaka może zostać pozycjonowana względem innego obszaru.

Typowe rozwiązanie:

.karta {
    position: relative;
}

.odznaka {
    position: absolute;

    top: 10px;
    right: 10px;
}

Błąd 3 – fixed zasłania treść

Element fixed nie rezerwuje miejsca w normalnym układzie. Może więc zasłaniać nagłówki, tekst lub przyciski.

Błąd 4 – sticky bez określenia granicy

.menu {
    position: sticky;
}

Bez odpowiedniej wartości takiej jak top: 0 przyklejanie w pionie może nie być widoczne.

Poprawnie:

.menu {
    position: sticky;
    top: 0;
}

Błąd 5 – z-index bez uwzględnienia kontekstu

.element {
    z-index: 9999;
}

Wysoka wartość nie gwarantuje, że element znajdzie się nad wszystkimi innymi.

Błąd 6 – absolute do całego układu strony

Pozycjonowanie wszystkich elementów za pomocą sztywnych współrzędnych może powodować nakładanie się treści i problemy na różnych ekranach.

Błąd 7 – relative jako sposób tworzenia odstępów

position: relative przesuwa element wizualnie, ale pozostawia jego pierwotne miejsce w układzie.

Do zwykłych odstępów między elementami lepiej wykorzystać margin, padding lub gap.

📌 Wskazówka

Jeśli element znajduje się w niewłaściwym miejscu, sprawdź kolejno: position, jego blok odniesienia, wartości top, right, bottom, left oraz z-index.

Analiza zastosowanych właściwości

Element Właściwość Efekt
.menu position: sticky Menu przykleja się podczas przewijania.
.karta position: relative Tworzy punkt odniesienia dla odznaki.
.odznaka position: absolute Odznaka znajduje się w rogu karty.
.do-gory position: fixed Przycisk pozostaje w rogu ekranu.
.kwadrat1 z-index: 1 Pierwszy poziom nakładania.
.kwadrat2 z-index: 2 Wyświetla się nad pierwszym kwadratem.
.kwadrat3 z-index: 3 Wyświetla się nad pozostałymi kwadratami.

📌 Zapamiętaj

  • Właściwość position określa sposób pozycjonowania elementu HTML.
  • position: static jest domyślną wartością.
  • Element static nie jest przesuwany przez top, right, bottom i left.
  • position: relative przesuwa element względem jego normalnego położenia.
  • Element relative zachowuje swoje miejsce w normalnym układzie strony.
  • position: absolute wyjmuje element z normalnego układu.
  • Element absolute jest pozycjonowany względem odpowiedniego bloku odniesienia.
  • Połączenie rodzica relative i dziecka absolute jest często wykorzystywane do umieszczania odznak w rogach kart.
  • position: fixed zwykle utrzymuje element w stałym miejscu ekranu.
  • Element fixed nie zajmuje miejsca w normalnym układzie strony.
  • position: sticky pozwala przyklejać element podczas przewijania.
  • Sticky wymaga odpowiedniej granicy, np. top: 0.
  • top, right, bottom i left służą do określania położenia elementu.
  • z-index pomaga kontrolować kolejność nakładania elementów.
  • Wyższy z-index nie zawsze oznacza, że element znajdzie się nad wszystkimi innymi.
  • Kontekst nakładania wpływa na działanie z-index.
  • Pozycjonowanie należy stosować świadomie, zwłaszcza na stronach przeznaczonych na różne rozmiary ekranów.

📝 Zadania praktyczne

Cel: zastosowanie różnych sposobów pozycjonowania CSS oraz kontrolowanie kolejności nakładania elementów.

Utwórz folder PSI_28, a w nim pliki index.html i style.css.

Wszystkie zadania wykonaj w ramach jednej strony WWW. Każde kolejne zadanie rozbudowuje ten sam projekt.

Zadanie 1 – Pozycjonowanie względne

Utwórz stronę „Moja oferta kursów”.

  1. Przygotuj poprawny dokument HTML5.
  2. Podłącz plik style.css.
  3. Dodaj nagłówek strony z tytułem.
  4. Utwórz trzy bloki opisujące wybrane kursy.
  5. Ustaw dla bloków szerokość, padding i obramowanie.
  6. Drugiemu blokowi nadaj position: relative.
  7. Przesuń go o 20 px w dół i 30 px w prawo.
  8. Sprawdź, czy pozostałe bloki zmieniły swoje położenie.
  9. Zapisz obserwację w komentarzu CSS.

Zadanie 2 – Odznaki absolute

Zmień bloki w karty z odznakami.

  1. Każdej karcie nadaj klasę karta.
  2. Ustaw dla kart position: relative.
  3. W każdej karcie dodaj element span z odznaką.
  4. Dla odznak zastosuj position: absolute.
  5. Umieść pierwszą odznakę w prawym górnym rogu.
  6. Umieść drugą odznakę w lewym górnym rogu.
  7. Umieść trzecią odznakę w prawym dolnym rogu.
  8. Dodaj odznakom kolory tła i padding.
  9. Sprawdź, czy odznaki nie zasłaniają tekstu kart.

Zadanie 3 – Przyklejone menu sticky

Dodaj nawigację na górze strony.

  1. Utwórz element nav.
  2. Dodaj odnośniki: Start, Oferta, Kontakt.
  3. Dodaj odpowiednie identyfikatory sekcji.
  4. Ustaw position: sticky.
  5. Dodaj top: 0.
  6. Ustaw z-index: 100.
  7. Dodaj kolor tła i odpowiedni padding.
  8. Rozbuduj stronę o treść, aby można było ją przewijać.
  9. Sprawdź, czy menu przykleja się podczas przewijania.

Zadanie 4 – Przycisk fixed

Dodaj przycisk umożliwiający powrót na górę strony.

  1. Dodaj odnośnik z symbolem ↑.
  2. Ustaw jego adres na #start.
  3. Nadaj mu klasę do-gory.
  4. Zastosuj position: fixed.
  5. Ustaw right: 20px i bottom: 20px.
  6. Dodaj kolor tła, padding i zaokrąglenie.
  7. Ustaw z-index: 200.
  8. Sprawdź działanie przycisku podczas przewijania.

Zadanie 5 – Nakładanie elementów z-index

Utwórz sekcję prezentującą trzy nakładające się kwadraty.

  1. Dodaj kontener z klasą obszar.
  2. Ustaw position: relative.
  3. Wewnątrz umieść trzy elementy div.
  4. Każdemu nadaj szerokość i wysokość 120 px.
  5. Zastosuj position: absolute.
  6. Ustaw różne wartości top i left, aby kwadraty na siebie nachodziły.
  7. Ustaw kolejno z-index: 1, z-index: 2 i z-index: 3.
  8. Zmieniając wartości z-index, sprawdź kolejność nakładania kwadratów.
  9. Zapisz obserwację w komentarzu CSS.

Zadanie 6 – Porównanie position (dodatkowe)

Dodaj sekcję porównującą różne sposoby pozycjonowania.

  1. Przygotuj pięć elementów opisanych: static, relative, absolute, fixed i sticky.
  2. Zastosuj dla każdego odpowiednią wartość position.
  3. Dla elementu absolute przygotuj osobny kontener relative.
  4. Dla sticky zastosuj top: 0 i zapewnij odpowiednią przestrzeń do przewijania.
  5. Dla fixed wybierz miejsce, które nie zasłania przycisku powrotu na górę.
  6. Sprawdź zachowanie elementów podczas przewijania.
  7. Pod przykładami dodaj krótkie wyjaśnienie różnic między sposobami pozycjonowania.
