Formatowanie list i odnośników. Tworzenie menu nawigacyjnego za pomocą CSS

Cel lekcji: poznanie sposobów formatowania list HTML, zmiany wyglądu odnośników i ich stanów oraz samodzielne przygotowanie estetycznego, funkcjonalnego i responsywnego menu nawigacyjnego.

1. Wprowadzenie

Listy i odnośniki należą do najczęściej wykorzystywanych elementów stron WWW.

Listy pomagają uporządkować informacje, natomiast odnośniki umożliwiają przechodzenie między stronami, podstronami oraz sekcjami dokumentu.

Dzięki CSS możemy zmienić ich domyślny wygląd:

  • rodzaj i położenie znaczników list,
  • odstępy między elementami listy,
  • kolor i dekorację odnośników,
  • wygląd odnośnika po najechaniu myszą,
  • wygląd aktywnej pozycji menu,
  • rozmieszczenie elementów menu.

Przykład zwykłej listy HTML

<ul>
    <li>Strona główna</li>
    <li>Oferta</li>
    <li>Kontakt</li>
</ul>

Przykład menu z odnośnikami

<nav>
    <ul>
        <li><a href="#start">Start</a></li>
        <li><a href="#oferta">Oferta</a></li>
        <li><a href="#kontakt">Kontakt</a></li>
    </ul>
</nav>

W drugim przykładzie lista stanowi strukturę menu, a odnośniki odpowiadają za nawigację.

📌 Zapamiętaj

HTML określa strukturę list i odnośników, natomiast CSS odpowiada za ich wygląd oraz rozmieszczenie.

2. Rodzaje list HTML

Przed rozpoczęciem formatowania przypomnijmy trzy podstawowe rodzaje list HTML.

Lista nieuporządkowana – ul

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Domyślnie elementy listy są oznaczane punktami.

Lista uporządkowana – ol

<ol>
    <li>Utwórz plik HTML.</li>
    <li>Dodaj arkusz CSS.</li>
    <li>Otwórz stronę w przeglądarce.</li>
</ol>

Domyślnie elementy listy są numerowane.

Lista opisowa – dl

<dl>
    <dt>HTML</dt>
    <dd>Język znaczników.</dd>

    <dt>CSS</dt>
    <dd>Język arkuszy stylów.</dd>
</dl>

Lista opisowa wykorzystuje elementy dt i dd.

Podstawowe znaczniki

Znacznik Zastosowanie
ul Lista nieuporządkowana
ol Lista uporządkowana
li Element listy ul lub ol
dl Lista opisowa
dt Termin
dd Opis terminu

3. Właściwość list-style-type

Właściwość list-style-type określa rodzaj znacznika elementu listy.

Przykład – lista punktowana

ul {
    list-style-type: square;
}

Zamiast domyślnych punktów pojawią się kwadraty.

Wartości dla list nieuporządkowanych

Wartość Wygląd znacznika
disc Pełne kółko
circle Puste kółko
square Kwadrat
none Brak widocznego znacznika

Przykład

.lista1 {
    list-style-type: disc;
}

.lista2 {
    list-style-type: circle;
}

.lista3 {
    list-style-type: square;
}

.lista4 {
    list-style-type: none;
}

Wartości dla list numerowanych

Wartość Przykładowa numeracja
decimal 1, 2, 3
decimal-leading-zero 01, 02, 03
lower-alpha a, b, c
upper-alpha A, B, C
lower-roman i, ii, iii
upper-roman I, II, III

Przykład numeracji rzymskiej

<ol class="rzymska">
    <li>Wprowadzenie</li>
    <li>Ćwiczenia</li>
    <li>Podsumowanie</li>
</ol>
.rzymska {
    list-style-type: upper-roman;
}

📌 Zapamiętaj

list-style-type zmienia wygląd znaczników list punktowanych i numerowanych.

4. Właściwość list-style-position

Właściwość list-style-position określa położenie znacznika listy względem zawartości elementu.

Dostępne są dwie podstawowe wartości:

  • outside – znacznik znajduje się poza głównym obszarem treści elementu listy,
  • inside – znacznik jest umieszczony wewnątrz obszaru treści elementu listy.

Przykład HTML

<ul class="lista-outside">
    <li>Pierwszy element listy z dłuższym opisem.</li>
    <li>Drugi element listy.</li>
</ul>

<ul class="lista-inside">
    <li>Pierwszy element listy z dłuższym opisem.</li>
    <li>Drugi element listy.</li>
</ul>

Kod CSS

.lista-outside {
    list-style-position: outside;
}

.lista-inside {
    list-style-position: inside;
}

Różnica jest szczególnie widoczna, gdy tekst elementu listy zajmuje kilka wierszy.

📌 Zapamiętaj

outside jest wartością domyślną. inside umieszcza znacznik wewnątrz obszaru treści.

5. Właściwość list-style-image

Zamiast standardowego znacznika listy można wykorzystać obraz.

Służy do tego list-style-image.

Przykład HTML

<ul class="lista-obrazkowa">
    <li>HTML5</li>
    <li>CSS3</li>
    <li>JavaScript</li>
</ul>

Kod CSS

.lista-obrazkowa {
    list-style-image: url("img/znacznik.png");
}

Przeglądarka spróbuje użyć obrazu znacznik.png jako znacznika listy.

Struktura plików

projekt/
|
|-- index.html
|-- style.css
|
|-- img/
    |
    |-- znacznik.png

Ścieżka w url() jest liczona względem położenia pliku CSS.

Ważne ograniczenie

list-style-image nie pozwala wygodnie sterować rozmiarem obrazu.

Jeśli chcemy dokładnie ustawić wielkość własnego znacznika, często lepszym rozwiązaniem będzie pseudoelement ::before.

6. Skrócona właściwość list-style

Zamiast zapisywać kilka właściwości osobno, możemy użyć skrótu list-style.

Przykład – zapis pełny

ul {
    list-style-type: square;
    list-style-position: inside;
}

Przykład – zapis skrócony

ul {
    list-style: square inside;
}

Oba zapisy ustawiają kwadratowe znaczniki wewnątrz obszaru treści.

Usuwanie znaczników

ul {
    list-style: none;
}

Ten zapis jest bardzo często wykorzystywany podczas tworzenia menu nawigacyjnego.

📌 Ważne

Usunięcie znaczników nie oznacza automatycznego usunięcia domyślnych odstępów listy. W menu zwykle ustawiamy również margin: 0 i padding: 0.

7. Odstępy i wygląd elementów listy

Listy można formatować tak samo jak inne elementy HTML.

Możemy zmieniać:

  • marginesy,
  • padding,
  • kolory tła,
  • obramowania,
  • zaokrąglenia,
  • odstępy między elementami.

Przykład HTML

<ul class="lista-kursow">
    <li>HTML5</li>
    <li>CSS3</li>
    <li>JavaScript</li>
</ul>

Kod CSS

.lista-kursow {
    list-style-type: square;

    padding-left: 30px;
}

.lista-kursow li {
    margin-bottom: 10px;
    padding: 12px;

    background-color: #DBEAFE;

    border-left: 4px solid #2563EB;
    border-radius: 5px;
}

Co oznaczają właściwości?

Właściwość Działanie
padding-left Ustawia wewnętrzny odstęp po lewej stronie listy.
margin-bottom Tworzy odstęp między elementami listy.
padding Dodaje przestrzeń wewnątrz elementu.
background-color Ustawia kolor tła.
border-left Dodaje obramowanie z lewej strony.
border-radius Zaokrągla narożniki.

Zmiana koloru znacznika

Do stylizowania samego znacznika listy możemy wykorzystać pseudoelement ::marker. 

.lista-kursow li::marker {
    color: #DC2626;
    font-size: 20px;
}

Znaczniki listy będą czerwone, a ich rozmiar zostanie zwiększony.

📌 Zapamiętaj

::marker pozwala formatować znacznik listy, ale obsługuje ograniczony zestaw właściwości CSS.

8. Własne znaczniki list – ::before

Za pomocą pseudoelementu ::before możemy dodać własny symbol przed tekstem elementu listy.

Przykład HTML

<ul class="lista-zalety">
    <li>Łatwa obsługa</li>
    <li>Nowoczesny wygląd</li>
    <li>Responsywność</li>
</ul>

Kod CSS

.lista-zalety {
    list-style: none;

    margin: 0;
    padding: 0;
}

.lista-zalety li {
    padding: 8px 0;
}

.lista-zalety li::before {
    content: "✓";

    color: green;
    font-weight: bold;

    margin-right: 10px;
}

Przed każdym elementem listy pojawi się zielony symbol ✓.

Inne symbole

.lista li::before {
    content: "★";
}
.lista li::before {
    content: "→";
}
.lista li::before {
    content: "✔";
}

Symbole dodane przez ::before są dekoracją wizualną. Nie należy opierać wyłącznie na nich ważnych informacji.

📌 Wskazówka

Jeśli lista ma przedstawiać kolejność wykonywania czynności, użyj elementu ol. Jeśli kolejność nie ma znaczenia, zastosuj ul.

9. Formatowanie odnośników w CSS

Odnośnik HTML tworzymy za pomocą znacznika a.

Przykład HTML

<a href="https://www.wikipedia.org/">
    Wikipedia
</a>

Domyślnie odnośniki są zwykle podkreślone, a ich kolor zależy od stanu odnośnika i ustawień przeglądarki.

Zmiana koloru

a {
    color: #2563EB;
}

Usunięcie podkreślenia

a {
    text-decoration: none;
}

Dodanie podkreślenia

a {
    text-decoration: underline;
}

Zmiana grubości tekstu

a {
    font-weight: bold;
}

Połączenie kilku właściwości

a {
    color: #1D4ED8;

    font-size: 18px;
    font-weight: bold;

    text-decoration: none;
}

📌 Dobra praktyka

Odnośniki w zwykłym tekście powinny być łatwe do rozpoznania. Jeśli usuwasz podkreślenie, zapewnij inny wyraźny sposób odróżnienia ich od tekstu.

10. Stany odnośników – pseudoklasy CSS

Wygląd odnośnika może zmieniać się w zależności od jego stanu.

Do tego służą pseudoklasy CSS.

Pseudoklasa Znaczenie
:link Odnośnik, którego adres nie został odwiedzony.
:visited Odnośnik prowadzący do odwiedzonego adresu.
:hover Element wskazywany kursorem.
:active Element w trakcie aktywowania, np. naciskania.
:focus-visible Element, dla którego przeglądarka powinna pokazać widoczny wskaźnik fokusu, np. podczas nawigacji klawiaturą.

Przykład HTML

<a class="link-testowy"
   href="https://www.wikipedia.org/">
    Odwiedź Wikipedię
</a>

Kod CSS

.link-testowy:link {
    color: blue;
}

.link-testowy:visited {
    color: purple;
}

.link-testowy:hover {
    color: red;
    text-decoration: underline;
}

.link-testowy:active {
    color: orange;
}

.link-testowy:focus-visible {
    outline: 3px solid #F59E0B;
    outline-offset: 3px;
}

Kolejność zapisu

W przypadku stylizowania czterech klasycznych stanów odnośnika warto zachować kolejność: 

a:link { }

a:visited { }

a:hover { }

a:active { }

Ułatwia to uniknięcie nieoczekiwanego nadpisywania stylów przez reguły o takiej samej szczegółowości.

Dlaczego focus-visible jest ważne?

Nie wszyscy użytkownicy korzystają z myszy. Niektóre osoby poruszają się po stronie za pomocą klawisza Tab.

Wskaźnik fokusu pomaga rozpoznać, który odnośnik jest aktualnie wybrany.

📌 Ważne

Nie usuwaj widocznego obramowania fokusu bez zapewnienia odpowiedniego zamiennika. Pseudoklasa :visited ma ograniczenia dotyczące stylowania ze względów prywatności.

11. Odnośnik wyglądający jak przycisk

Odnośnik może wyglądać jak przycisk, jeśli zastosujemy odpowiednie formatowanie CSS.

HTML

<a href="#oferta" class="przycisk">
    Zobacz ofertę
</a>

CSS

.przycisk {
    display: inline-block;

    padding: 12px 24px;

    color: white;
    background-color: #2563EB;

    text-decoration: none;
    font-weight: bold;

    border-radius: 8px;
}

.przycisk:hover {
    background-color: #1D4ED8;
}

.przycisk:focus-visible {
    outline: 3px solid orange;
    outline-offset: 3px;
}

Dlaczego display: inline-block?

Element a jest domyślnie elementem liniowym.

display: inline-block umożliwia wygodne ustawianie jego wymiarów i odstępów, a jednocześnie pozwala mu znajdować się obok innych elementów.

Odnośnik czy button?

Jeśli element służy do przechodzenia do innej strony lub sekcji, używamy a.

Jeśli ma wykonywać działanie, np. wysłać formularz, zwykle odpowiedniejszy jest button.

📌 Zapamiętaj

Wygląd przycisku nie zmienia znaczenia elementu HTML. Odnośnik nadal służy przede wszystkim do nawigacji.

12. Struktura menu nawigacyjnego w HTML

Menu nawigacyjne pomaga użytkownikowi poruszać się po stronie internetowej.

Do utworzenia menu możemy wykorzystać:

  • nav – obszar nawigacji,
  • ul – lista pozycji menu,
  • li – pojedyncza pozycja menu,
  • a – odnośnik do strony lub sekcji.

Przykład HTML

<nav aria-label="Menu główne">

    <ul>

        <li>
            <a href="#start">Start</a>
        </li>

        <li>
            <a href="#oferta">Oferta</a>
        </li>

        <li>
            <a href="#galeria">Galeria</a>
        </li>

        <li>
            <a href="#kontakt">Kontakt</a>
        </li>

    </ul>

</nav>

Dlaczego używamy listy?

Lista przedstawia zbiór powiązanych ze sobą pozycji.

Dzięki temu struktura menu jest czytelna, uporządkowana i semantycznie poprawna.

Dlaczego nav?

Znacznik nav informuje, że dany fragment strony zawiera ważne odnośniki nawigacyjne.

📌 Zapamiętaj

W menu nawigacyjnym odnośniki odpowiadają za przechodzenie między sekcjami lub stronami, a CSS określa ich wygląd.

13. Tworzenie pionowego menu nawigacyjnego

Menu pionowe składa się z pozycji ułożonych jedna pod drugą.

Często jest wykorzystywane w panelach bocznych i spisach treści.

HTML

<nav class="menu-pionowe"
     aria-label="Menu boczne">

    <ul>
        <li><a href="#start">Start</a></li>
        <li><a href="#oferta">Oferta</a></li>
        <li><a href="#galeria">Galeria</a></li>
        <li><a href="#kontakt">Kontakt</a></li>
    </ul>

</nav>

CSS

.menu-pionowe {
    width: 250px;
    max-width: 100%;
}

.menu-pionowe ul {
    list-style: none;

    margin: 0;
    padding: 0;
}

.menu-pionowe li {
    margin-bottom: 5px;
}

.menu-pionowe a {
    display: block;

    padding: 15px;

    color: white;
    background-color: #1E3A8A;

    text-decoration: none;

    border-radius: 6px;
}

.menu-pionowe a:hover {
    background-color: #2563EB;
}

.menu-pionowe a:focus-visible {
    outline: 3px solid orange;
    outline-offset: 2px;
}

Dlaczego display: block?

Odnośnik staje się elementem blokowym i wypełnia szerokość swojej pozycji menu.

Dzięki temu można kliknąć nie tylko tekst, ale również obszar wokół niego.

📌 Zapamiętaj

W pionowym menu bardzo często stosujemy display: block dla odnośników.

14. Tworzenie poziomego menu nawigacyjnego

Menu poziome zawiera pozycje rozmieszczone obok siebie.

Jest często stosowane w górnej części strony.

HTML

<nav class="menu-poziome"
     aria-label="Menu główne">

    <ul>
        <li><a href="#start">Start</a></li>
        <li><a href="#oferta">Oferta</a></li>
        <li><a href="#galeria">Galeria</a></li>
        <li><a href="#kontakt">Kontakt</a></li>
    </ul>

</nav>

CSS

.menu-poziome {
    background-color: #1E3A8A;
}

.menu-poziome ul {
    display: flex;
    flex-wrap: wrap;

    justify-content: center;
    gap: 10px;

    list-style: none;

    margin: 0;
    padding: 12px;
}

.menu-poziome a {
    display: block;

    padding: 12px 20px;

    color: white;
    text-decoration: none;

    border-radius: 6px;
}

.menu-poziome a:hover {
    background-color: #2563EB;
}

.menu-poziome a:focus-visible {
    outline: 3px solid orange;
    outline-offset: 2px;
}

Co oznacza display: flex?

display: flex włącza układ Flexbox, dzięki któremu elementy listy można wygodnie rozmieszczać obok siebie.

Co oznacza gap?

gap: 10px;

Tworzy odstępy między pozycjami menu.

Co oznacza justify-content?

justify-content: center;

W tym przykładzie wyśrodkowuje pozycje menu wzdłuż osi poziomej.

Co oznacza flex-wrap?

flex-wrap: wrap;

Pozwala przenosić pozycje menu do kolejnego wiersza, jeśli brakuje miejsca.

📌 Ważne

Flexbox zostanie szczegółowo omówiony w osobnej lekcji. Na tym etapie wykorzystujemy jego podstawowe właściwości do stworzenia menu.

15. Wyróżnienie aktywnej pozycji menu

Aktywna pozycja menu informuje użytkownika, na której stronie lub w której części serwisu aktualnie się znajduje.

HTML

<nav class="menu-glowne">

    <ul>

        <li>
            <a href="index.html"
               class="aktywna"
               aria-current="page">
                Start
            </a>
        </li>

        <li>
            <a href="oferta.html">
                Oferta
            </a>
        </li>

        <li>
            <a href="kontakt.html">
                Kontakt
            </a>
        </li>

    </ul>

</nav>

CSS

.menu-glowne a {
    display: block;

    padding: 12px 20px;

    color: white;
    text-decoration: none;
}

.menu-glowne a:hover {
    background-color: #2563EB;
}

.menu-glowne a.aktywna {
    background-color: #F59E0B;
    color: #111827;

    font-weight: bold;
}

Do czego służy klasa aktywna?

Pozwala nadać wyróżniony wygląd wybranemu odnośnikowi.

Do czego służy aria-current="page"?

Informuje technologie wspomagające, że odnośnik wskazuje aktualną stronę.

📌 Uwaga

Klasa aktywna nie zmienia się automatycznie po kliknięciu odnośnika. Na osobnych podstronach trzeba odpowiednio oznaczyć bieżącą pozycję menu.

16. Przyklejone menu – position: sticky

Menu może pozostawać widoczne podczas przewijania strony.

Wykorzystujemy do tego właściwość position: sticky.

HTML

<nav class="menu-sticky">

    <ul>
        <li><a href="#start">Start</a></li>
        <li><a href="#oferta">Oferta</a></li>
        <li><a href="#kontakt">Kontakt</a></li>
    </ul>

</nav>

CSS

.menu-sticky {
    position: sticky;

    top: 0;
    z-index: 100;

    background-color: #1E3A8A;
}

.menu-sticky ul {
    display: flex;
    flex-wrap: wrap;

    gap: 10px;

    list-style: none;

    margin: 0;
    padding: 10px;
}

.menu-sticky a {
    display: block;

    padding: 12px 18px;

    color: white;
    text-decoration: none;
}

Dlaczego top: 0?

Określa granicę przyklejenia menu do górnej krawędzi odpowiedniego obszaru przewijania.

Dlaczego z-index: 100?

Pomaga utrzymać menu nad zwykłą zawartością strony w odpowiednim kontekście nakładania.

📌 Zapamiętaj

position: sticky pozwala przygotować przyklejone menu bez użycia JavaScriptu.

17. Responsywne menu nawigacyjne

Responsywne menu dostosowuje swój wygląd do rozmiaru ekranu.

Na dużym ekranie pozycje menu mogą znajdować się obok siebie.

Na małym ekranie można ustawić je jedna pod drugą.

Menu na większym ekranie

.menu ul {
    display: flex;

    justify-content: center;
    gap: 10px;

    list-style: none;

    margin: 0;
    padding: 10px;
}

Zmiana układu na telefonie

@media (max-width: 600px) {

    .menu ul {
        flex-direction: column;
    }

    .menu a {
        display: block;
        text-align: center;
    }

}

Co oznacza max-width: 600px?

Reguły wewnątrz @media zostaną zastosowane, gdy szerokość obszaru wyświetlania nie przekracza 600 px.

Co oznacza flex-direction: column?

Elementy menu zostaną ułożone pionowo.

Dlaczego to ważne?

Dzięki temu menu pozostaje czytelne również na mniejszych ekranach.

📌 Dobra praktyka

Sprawdzaj działanie menu na ekranach o różnych szerokościach. Pozycje nie powinny nachodzić na siebie ani wychodzić poza ekran.

18. Najczęstsze błędy

Błąd 1 – usunięcie znaczników bez usunięcia odstępów

.menu ul {
    list-style: none;
}

Lista może nadal posiadać domyślne marginesy i padding.

Lepszy zapis:

.menu ul {
    list-style: none;

    margin: 0;
    padding: 0;
}

Błąd 2 – stylowanie wszystkich list na stronie

ul {
    list-style: none;
}

Ten selektor usunie znaczniki ze wszystkich list nieuporządkowanych, także z tych, które powinny pozostać punktowane.

Lepszy zapis:

.menu ul {
    list-style: none;
}

Błąd 3 – brak efektu hover

Użytkownik może mieć trudność z rozpoznaniem, który odnośnik jest wskazywany kursorem. 

.menu a:hover {
    background-color: #2563EB;
}

Błąd 4 – usunięcie widocznego fokusu

a:focus {
    outline: none;
}

Taki zapis bez odpowiedniego zamiennika utrudnia korzystanie z nawigacji klawiaturą.

Lepszy zapis:

.menu a:focus-visible {
    outline: 3px solid orange;
    outline-offset: 2px;
}

Błąd 5 – odnośniki bez prawidłowego href

<a href="#oferta">Oferta</a>

Taki odnośnik wymaga istnienia elementu o identyfikatorze oferta. 

<section id="oferta">
    <h2>Oferta</h2>
</section>

Błąd 6 – zbyt mały obszar klikania

Jeśli odnośnik jest bardzo mały, może być niewygodny w obsłudze na telefonie.

Warto dodać padding i zastosować display: block.

Błąd 7 – brak responsywności

Poziome menu z dużą liczbą pozycji może nie mieścić się na wąskim ekranie.

Można zastosować flex-wrap lub zmianę kierunku za pomocą @media.

Błąd 8 – zbyt słaby kontrast

Kolor tekstu i tła powinny być dobrane tak, aby odnośniki były czytelne.

📌 Wskazówka

Podczas tworzenia menu sprawdzaj nie tylko wygląd, ale także działanie wszystkich odnośników oraz obsługę klawiaturą.

Analiza zastosowanych właściwości

Właściwość Zastosowanie
list-style: none Usunięcie znaczników listy w menu.
display: flex Poziome rozmieszczenie pozycji menu.
display: block Powiększenie obszaru klikania odnośników.
:hover Zmiana wyglądu odnośnika po wskazaniu kursorem.
:focus-visible Wyróżnienie odnośnika podczas nawigacji klawiaturą.
::marker Zmiana wyglądu znacznika listy.

📌 Zapamiętaj

  • Listy HTML można formatować za pomocą CSS.
  • list-style-type określa rodzaj znacznika listy.
  • list-style-position określa położenie znacznika.
  • list-style-image umożliwia użycie obrazu jako znacznika listy.
  • list-style jest właściwością skróconą.
  • list-style: none usuwa widoczne znaczniki listy.
  • Usunięcie znaczników nie usuwa automatycznie marginesów i paddingu.
  • ::marker pozwala stylizować znacznik listy.
  • ::before może dodawać własne symbole przed elementami.
  • Odnośniki HTML tworzymy za pomocą znacznika a.
  • text-decoration pozwala zmieniać dekorację odnośników.
  • :link dotyczy nieodwiedzonych odnośników.
  • :visited dotyczy odwiedzonych adresów.
  • :hover reaguje na wskazanie elementu kursorem.
  • :active dotyczy elementu podczas jego aktywowania.
  • :focus-visible pomaga wyróżnić element podczas nawigacji klawiaturą.
  • Menu nawigacyjne można utworzyć za pomocą nav, ul, li i a.
  • display: block pozwala powiększyć obszar klikania odnośnika.
  • display: flex ułatwia tworzenie poziomego menu.
  • gap tworzy odstępy między elementami Flexbox.
  • position: sticky pozwala przykleić menu podczas przewijania.
  • @media umożliwia zmianę układu menu na mniejszych ekranach.
  • Wszystkie odnośniki w menu powinny prowadzić do istniejących stron lub sekcji.
