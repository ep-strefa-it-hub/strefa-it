Selektory atrybutów, pseudoklasy i pseudoelementy

Cel lekcji: stosowanie selektorów atrybutów, pseudoklas i pseudoelementów CSS3 do stylowania elementów HTML na podstawie ich właściwości, stanu i położenia w dokumencie, a także tworzenie interaktywnych efektów wizualnych bez JavaScriptu.

1. Wprowadzenie

W poprzednich lekcjach poznaliśmy selektory elementów, klas i identyfikatorów oraz kombinatory określające relacje między elementami.

CSS umożliwia jednak znacznie bardziej precyzyjne wybieranie elementów HTML.

Możemy na przykład:

  • Wyróżnić wszystkie pola formularza z atrybutem required.
  • Ostylować wyłącznie odnośniki prowadzące do plików PDF.
  • Zmienić wygląd przycisku po najechaniu kursorem.
  • Wyróżnić pole formularza, które otrzymało fokus.
  • Zmienić kolor co drugiego wiersza tabeli.
  • Wyróżnić pierwszą literę akapitu.
  • Dodać dekoracyjny symbol przed nagłówkiem bez modyfikowania HTML.

W tym celu wykorzystujemy trzy grupy:

Grupa Przykład Zastosowanie
Selektory atrybutów input[required] Wybór na podstawie atrybutu HTML.
Pseudoklasy a:hover Wybór na podstawie stanu lub położenia elementu.
Pseudoelementy p::first-letter Stylowanie fragmentu elementu lub tworzenie treści dekoracyjnej.

📌 Ważne

Selektory atrybutów używają nawiasów kwadratowych [ ], pseudoklasy zapisujemy z pojedynczym dwukropkiem :, a pseudoelementy zazwyczaj z podwójnym dwukropkiem ::.

2. Selektory atrybutów – podstawy

Selektor atrybutu pozwala wskazać element HTML posiadający określony atrybut.

Nie musimy przypisywać mu dodatkowej klasy ani identyfikatora.

Przykład – wymagane pola formularza

HTML:

<form>

    <input type="text"
           name="imie"
           required>

    <input type="text"
           name="drugie-imie">

</form>

CSS:

input[required] {
    border: 2px solid red;
}

Czerwone obramowanie otrzyma tylko pierwsze pole, ponieważ posiada atrybut required.

Wybieranie dowolnego elementu z atrybutem

[title] {
    border-bottom: 1px dotted gray;
}

Reguła wskazuje wszystkie elementy, które mają atrybut title, niezależnie od rodzaju znacznika.

Wybieranie konkretnego elementu

a[title] {
    color: darkgreen;
}

Reguła wskazuje tylko odnośniki a posiadające atrybut title.

📌 Zapamiętaj

Zapis [required] sprawdza obecność atrybutu, a nie to, czy jego wartością jest tekst true. W HTML required jest atrybutem logicznym.

3. Selektory dokładnej wartości atrybutu

Możemy wskazywać nie tylko elementy posiadające atrybut, ale również takie, których atrybut ma określoną wartość.

Składnia

element[atrybut="wartosc"] {
    właściwość: wartość;
}

Przykład – różne typy pól formularza

HTML:

<input type="text"
       placeholder="Imię">

<input type="email"
       placeholder="Adres e-mail">

<input type="password"
       placeholder="Hasło">

CSS:

input[type="text"] {
    background-color: lightyellow;
}

input[type="email"] {
    background-color: lightblue;
}

input[type="password"] {
    background-color: lightpink;
}

Każdy typ pola otrzyma inny kolor tła.

Przykład – przycisk wysyłania

button[type="submit"] {
    background-color: green;
    color: white;
}

Reguła wskazuje przyciski button z atrybutem type="submit".

Przykład – język elementu

<p lang="pl">
    Dzień dobry!
</p>

<p lang="en">
    Good morning!
</p>
p[lang="en"] {
    font-style: italic;
}

Kursywą zostanie zapisany akapit mający dokładnie lang="en".

4. Selektory fragmentów wartości atrybutów

CSS umożliwia sprawdzanie, czy wartość atrybutu zaczyna się, kończy lub zawiera określony tekst.

Najważniejsze operatory

Selektor Znaczenie
[a="x"] Wartość dokładnie równa x.
[a^="x"] Wartość zaczyna się od x.
[a$="x"] Wartość kończy się na x.
[a*="x"] Wartość zawiera fragment x.
[a~="x"] Wartość zawiera x jako osobne słowo rozdzielone białymi znakami.
[a|="x"] Wartość jest równa x albo zaczyna się od x-.

Operator ^= – zaczyna się od

<a href="https://example.com">
    Strona internetowa
</a>

<a href="kontakt.html">
    Kontakt
</a>
a[href^="https://"] {
    color: green;
}

Reguła wskazuje odnośniki, których wartość href zaczyna się od https://.

Operator $= – kończy się na

<a href="instrukcja.pdf">
    Instrukcja PDF
</a>

<a href="zdjecie.jpg">
    Zdjęcie
</a>
a[href$=".pdf"] {
    color: darkred;
    font-weight: bold;
}

Reguła wskaże odnośnik prowadzący do pliku, którego adres kończy się na .pdf.

Uwaga: adres instrukcja.pdf?wersja=2 nie kończy się na .pdf, więc nie zostanie dopasowany przez ten selektor.

Operator *= – zawiera fragment

a[href*="github"] {
    color: purple;
}

Reguła wskazuje odnośniki, których wartość href zawiera tekst github.

Jest to dopasowanie tekstowe, a nie sprawdzenie, czy odnośnik prowadzi do konkretnej, bezpiecznej domeny.

Operator ~= – zawiera osobne słowo

<p data-tagi="html css js">
    Kurs frontend
</p>
[data-tagi~="css"] {
    background-color: lightyellow;
}

Reguła dopasuje element, ponieważ css występuje jako osobne słowo w wartości atrybutu.

Operator |= – wartość lub prefiks z łącznikiem

[lang|="pl"] {
    font-family: Arial, sans-serif;
}

Reguła dopasuje wartości pl i pl-PL, ale nie planet.

Wielkość liter

W wybranych sytuacjach można zastosować modyfikator i, aby porównywać wartość bez rozróżniania wielkości liter. 

a[href$=".pdf" i] {
    color: darkred;
}

Ten selektor dopasuje zarówno .pdf, jak i .PDF.

5. Czym są pseudoklasy?

Pseudoklasa pozwala wybrać element na podstawie jego określonego stanu, położenia w strukturze dokumentu lub innych warunków.

Składnia

selektor:pseudoklasa {
    właściwość: wartość;
}

Przykład

button:hover {
    background-color: darkblue;
}

Gdy użytkownik najedzie kursorem na przycisk, jego tło zmieni kolor.

Pseudoklasy nie wymagają dopisywania specjalnych atrybutów do HTML.

Podstawowe grupy pseudoklas

  • Pseudoklasy odnośników – np. :link, :visited.
  • Pseudoklasy interakcji – np. :hover, :focus.
  • Pseudoklasy strukturalne – np. :first-child, :nth-child().
  • Pseudoklasy formularzy – np. :checked, :required, :disabled.
  • Pseudoklasy logiczne – np. :not().

6. Pseudoklasy odnośników

Odnośniki mogą znajdować się w różnych stanach.

Pseudoklasa Znaczenie
:link Odnośnik, którego adres nie został odwiedzony.
:visited Odnośnik do odwiedzonego adresu.
:hover Element wskazywany kursorem lub innym urządzeniem wskazującym.
:active Element w stanie aktywacji, np. podczas przytrzymania przycisku myszy.

Przykład

a:link {
    color: blue;
}

a:visited {
    color: purple;
}

a:hover {
    color: red;
}

a:active {
    color: orange;
}

Kolejność reguł

Dla reguł o jednakowej specyficzności warto zachować kolejność: 

:link
:visited
:hover
:active

Jest ona znana pod skrótem LVHA.

📌 Ważne

Ze względów prywatności przeglądarki ograniczają możliwości stylowania odnośników przez :visited. Nie wszystkie właściwości można w ten sposób zmieniać.

7. Pseudoklasy interakcji użytkownika

:hover – najechanie kursorem

button:hover {
    background-color: green;
    color: white;
}

Styl działa podczas wskazywania elementu kursorem.

:active – aktywowanie elementu

button:active {
    background-color: darkgreen;
}

Styl może być widoczny podczas naciskania przycisku.

:focus – fokus

Fokus oznacza, że element jest aktualnym celem wprowadzania danych lub obsługi klawiaturą. 

input:focus {
    border: 2px solid blue;
    background-color: lightyellow;
}

Po kliknięciu pola formularza lub przejściu do niego klawiszem Tab może ono otrzymać ten styl.

:focus-visible – widoczny fokus

button:focus-visible {
    outline: 3px solid orange;
    outline-offset: 3px;
}

Przeglądarka stosuje tę pseudoklasę wtedy, gdy według jej zasad wskaźnik fokusu powinien być widoczny, często podczas obsługi klawiaturą.

:focus-within – fokus wewnątrz

HTML:

<div class="pole-formularza">

    <label for="imie">Imię:</label>

    <input type="text" id="imie">

</div>

CSS:

.pole-formularza:focus-within {
    background-color: lightblue;
}

Cały kontener otrzyma kolor tła, gdy fokus znajduje się na nim lub na jednym z jego elementów potomnych.

📌 Dostępność

Nie usuwaj wskaźnika fokusu bez zapewnienia czytelnego zamiennika. Osoby korzystające z klawiatury muszą widzieć, który element jest aktywny. Efekt :hover nie powinien być jedynym sposobem przekazywania ważnych informacji.

8. Pseudoklasy strukturalne

Pseudoklasy strukturalne wybierają elementy na podstawie ich położenia wśród dzieci danego rodzica.

:first-child – pierwsze dziecko

HTML:

<ul>

    <li>HTML</li>

    <li>CSS</li>

    <li>JavaScript</li>

</ul>

CSS:

li:first-child {
    color: red;
}

Czerwony będzie pierwszy element listy.

:last-child – ostatnie dziecko

li:last-child {
    color: green;
}

Zielony będzie ostatni element listy.

:only-child – jedyne dziecko

p:only-child {
    font-weight: bold;
}

Reguła wskazuje akapit, który jest jedynym dzieckiem swojego rodzica.

:first-of-type – pierwszy danego typu

<section>

    <h2>Aktualności</h2>

    <p>Pierwszy akapit.</p>

    <p>Drugi akapit.</p>

</section>
p:first-of-type {
    color: darkblue;
}

Reguła wskaże pierwszy akapit p wśród rodzeństwa, mimo że pierwszym dzieckiem sekcji jest nagłówek h2.

Porównanie first-child i first-of-type

p:first-child {
    color: red;
}

p:first-of-type {
    font-weight: bold;
}

Jeśli pierwszym dzieckiem sekcji jest h2, pierwszy akapit nie pasuje do p:first-child, ale pasuje do p:first-of-type.

9. Pseudoklasy :nth-child() i :nth-of-type()

Pseudoklasa :nth-child() umożliwia wybieranie dzieci według ich pozycji wśród wszystkich elementów rodzeństwa.

Przykład – drugi element listy

li:nth-child(2) {
    color: red;
}

Reguła wskazuje elementy li, które są drugim dzieckiem rodzica.

Co drugi element – even

li:nth-child(even) {
    background-color: lightgray;
}

Wskazuje elementy znajdujące się na parzystych pozycjach: 2, 4, 6, 8 itd.

Pozycje nieparzyste – odd

li:nth-child(odd) {
    background-color: lightblue;
}

Wskazuje pozycje: 1, 3, 5, 7 itd.

Przykład – tabela z naprzemiennymi wierszami

tbody tr:nth-child(even) {
    background-color: #eeeeee;
}

tbody tr:nth-child(odd) {
    background-color: white;
}

Wiersze tabeli otrzymają naprzemienne kolory tła.

Wzór an + b

li:nth-child(3n) {
    color: green;
}

Wskazuje co trzeci element: 3, 6, 9, 12 itd. 

li:nth-child(3n + 1) {
    font-weight: bold;
}

Wskazuje pozycje: 1, 4, 7, 10 itd.

Różnica między nth-child i nth-of-type

HTML:

<div>

    <h2>Nagłówek</h2>

    <p>Akapit A</p>

    <p>Akapit B</p>

</div>

CSS:

p:nth-child(2) {
    color: red;
}

p:nth-of-type(2) {
    font-weight: bold;
}

Selektor p:nth-child(2) wskazuje akapit A, ponieważ jest drugim dzieckiem elementu div.

Selektor p:nth-of-type(2) wskazuje akapit B, ponieważ jest drugim elementem typu p wśród rodzeństwa.

📌 Zapamiętaj

:nth-child() liczy pozycję wśród wszystkich dzieci. :nth-of-type() liczy pozycję wśród rodzeństwa tego samego typu elementu.

10. Pseudoklasy formularzy

Formularze HTML5 udostępniają wiele stanów, które możemy stylować bez używania JavaScriptu.

:required – wymagane pole

input:required {
    border: 2px solid orange;
}

Reguła wskazuje pola formularza, dla których obowiązuje wymóg wypełnienia.

:optional – pole niewymagane

input:optional {
    border: 1px solid gray;
}

:checked – zaznaczony element

HTML:

<label>

    <input type="checkbox"
           name="zgoda">

    Akceptuję regulamin

</label>

CSS:

input:checked {
    accent-color: green;
}

Zaznaczony checkbox może otrzymać zielony kolor akcentu.

:disabled – element wyłączony

<input type="text"
       value="Niedostępne"
       disabled>
input:disabled {
    background-color: lightgray;
    cursor: not-allowed;
}

:enabled – element aktywny

input:enabled {
    background-color: white;
}

:valid i :invalid – poprawność danych

HTML:

<label for="email">
    Adres e-mail:
</label>

<input type="email"
       id="email"
       name="email"
       required>

CSS:

input:valid {
    border: 2px solid green;
}

input:invalid {
    border: 2px solid red;
}

Pole e-mail może zostać uznane za niepoprawne, jeśli jest puste mimo atrybutu required albo zawiera nieprawidłowy adres e-mail.

Pseudoklasa :invalid może działać już przed pierwszą próbą wysłania formularza.

📌 Dobra praktyka

Nie polegaj wyłącznie na kolorze czerwonym lub zielonym jako informacji o poprawności danych. Użytkownik powinien otrzymać również czytelny komunikat tekstowy. Walidacja CSS nie zastępuje sprawdzania danych po stronie serwera.

11. Pseudoklasa :not()

Pseudoklasa :not() pozwala wybrać elementy, które nie pasują do określonego selektora.

Przykład – wszystkie akapity oprócz wyróżnionych

HTML:

<p>Zwykły akapit.</p>

<p class="wazne">
    Ważna informacja.
</p>

<p>Kolejny zwykły akapit.</p>

CSS:

p:not(.wazne) {
    color: gray;
}

Szare będą akapity, które nie mają klasy wazne.

Przykład – aktywne przyciski

button:not(:disabled) {
    background-color: green;
    color: white;
}

Reguła wskazuje przyciski, które nie są wyłączone.

Przykład – elementy listy oprócz pierwszego

li:not(:first-child) {
    border-top: 1px solid gray;
}

Obramowanie otrzymają elementy listy inne niż pierwsze dziecko.

12. Czym są pseudoelementy?

Pseudoelement pozwala stylować określony fragment elementu albo tworzyć dodatkową zawartość prezentacyjną.

Składnia

selektor::pseudoelement {
    właściwość: wartość;
}

Przykład

p::first-letter {
    font-size: 32px;
    color: red;
}

Reguła zmienia wygląd pierwszej litery akapitu.

Pseudoklasa a pseudoelement

Pseudoklasa Pseudoelement
:hover ::before
:focus ::after
:first-child ::first-letter
:checked ::first-line
:invalid ::selection

📌 Ważne

W nowoczesnym CSS pseudoelementy zapisujemy z podwójnym dwukropkiem. Starszy zapis :before i :after jest nadal obsługiwany ze względów zgodności, ale zaleca się ::before i ::after.

13. Pseudoelementy ::before i ::after

Pseudoelementy ::before i ::after pozwalają dodać zawartość prezentacyjną przed lub po zawartości elementu.

Przykład – symbol przed nagłówkiem

HTML:

<h2 class="sekcja">
    Aktualności
</h2>

CSS:

.sekcja::before {
    content: "★ ";
    color: orange;
}

Przed tekstem nagłówka pojawi się gwiazdka.

Przykład – symbol po komunikacie

<p class="sukces">
    Zapisano dane
</p>
.sukces::after {
    content: " ✓";
    color: green;
}

Po tekście pojawi się symbol potwierdzenia.

Właściwość content

W przypadku standardowego wykorzystania ::before i ::after definiujemy właściwość content. 

.ozdoba::before {
    content: "";
    display: inline-block;
    width: 10px;
    height: 10px;
    background-color: red;
    margin-right: 8px;
}

Pusty tekst w content pozwala utworzyć dekoracyjny element graficzny.

Przykład – etykieta „Nowość”

.nowosc::after {
    content: " NOWOŚĆ";
    color: red;
    font-weight: bold;
    font-size: 12px;
}

Tekst zostanie dodany wizualnie po zawartości elementu z klasą nowosc.

📌 Dostępność

Nie umieszczaj ważnych informacji wyłącznie za pomocą content. Treść generowana przez CSS może być różnie obsługiwana przez technologie wspomagające. Istotne komunikaty powinny znajdować się w HTML.

14. Pseudoelementy tekstowe

::first-letter – pierwsza litera

article p::first-letter {
    font-size: 36px;
    font-weight: bold;
    color: darkred;
}

Pozwala wyróżnić pierwszą literę akapitu, np. na wzór inicjału w artykule prasowym.

::first-line – pierwszy wiersz

article p::first-line {
    font-weight: bold;
}

Reguła wyróżnia pierwszy widoczny wiersz tekstu w obsługiwanym elemencie blokowym.

Długość pierwszego wiersza zależy od szerokości elementu i układu strony.

::selection – zaznaczony tekst

p::selection {
    background-color: yellow;
    color: black;
}

Po zaznaczeniu tekstu akapitu użytkownik zobaczy żółte tło zaznaczenia.

::placeholder – tekst podpowiedzi

HTML:

<input type="text"
       placeholder="Wpisz swoje imię">

CSS:

input::placeholder {
    color: gray;
    font-style: italic;
}

Reguła zmienia wygląd tekstu podpowiedzi.

📌 Ważne

placeholder nie zastępuje etykiety label. Pola formularzy powinny mieć czytelne, odpowiednio powiązane etykiety.

15. Łączenie selektorów atrybutów, pseudoklas i pseudoelementów

Poznane selektory możemy łączyć z klasami, identyfikatorami i kombinatorami.

Przykład – wymagane pole z fokusem

input[required]:focus {
    border: 2px solid blue;
    background-color: lightyellow;
}

Reguła wskazuje pole posiadające atrybut required, które jednocześnie ma fokus.

Przykład – odnośniki PDF po najechaniu

a[href$=".pdf" i]:hover {
    color: red;
    text-decoration: underline;
}

Reguła wskazuje odnośniki kończące się na .pdf niezależnie od wielkości liter, podczas wskazywania kursorem.

Przykład – co drugi wiersz tabeli

table tbody tr:nth-child(even) {
    background-color: #eeeeee;
}

Przykład – pierwszy akapit artykułu

article > p:first-of-type {
    font-weight: bold;
}

Reguła wskazuje akapit, który jest bezpośrednim dzieckiem artykułu i pierwszym elementem typu p wśród swojego rodzeństwa.

Przykład – dekoracja nagłówka

section > h2::before {
    content: "➜ ";
    color: darkblue;
}

Reguła dodaje symbol przed nagłówkami h2, które są bezpośrednimi dziećmi elementów section.

Specyficzność

Selektory atrybutów i pseudoklasy zwiększają specyficzność tak jak klasy. Pseudoelementy zwiększają ją tak jak selektory elementów.

Selektor Specyficzność
p 0-0-1
[required] 0-1-0
input:focus 0-1-1
p::first-letter 0-0-2
input[required]:focus 0-2-1

16. Najczęstsze błędy

Błąd 1 – mylenie klasy z pseudoklasą

/* Klasa o nazwie hover */

.hover {
    color: red;
}

/* Pseudoklasa hover */

a:hover {
    color: red;
}

To dwa zupełnie różne selektory.

Błąd 2 – brak nawiasów kwadratowych

/* Niepoprawny sposób wskazywania atrybutu */

input required {
    border: 2px solid red;
}

/* Poprawnie */

input[required] {
    border: 2px solid red;
}

Błąd 3 – mylenie first-child i first-of-type

p:first-child nie oznacza automatycznie pierwszego akapitu w sekcji.

Oznacza akapit, który jest pierwszym dzieckiem swojego rodzica.

Błąd 4 – brak content w pseudoelementach

/* Nie utworzy typowej dekoracji tekstowej */

.ozdoba::before {
    color: red;
}

/* Poprawnie */

.ozdoba::before {
    content: "★ ";
    color: red;
}

Błąd 5 – usuwanie widocznego fokusu

/* Niewskazane bez alternatywy */

button:focus {
    outline: none;
}

/* Lepsze rozwiązanie */

button:focus-visible {
    outline: 3px solid orange;
    outline-offset: 3px;
}

Błąd 6 – nieprawidłowa kolejność selektorów

/* Poprawny przykład */

a:hover::after {
    content: " ↗";
}

Najpierw wskazujemy element i jego stan, a następnie pseudoelement.

Błąd 7 – zakładanie, że CSS sprawdza bezpieczeństwo danych

Pseudoklasy :valid i :invalid pokazują wynik wbudowanych ograniczeń formularza w przeglądarce.

Nie sprawdzają, czy dane są prawdziwe, ani nie zastępują walidacji po stronie serwera.

📌 Uwaga

Odnośnik do program.pdf jest w tym przykładzie demonstracyjny. Aby pobieranie działało, trzeba umieścić taki plik w folderze projektu. Formularz z action="#" nie zapisuje zgłoszeń na serwerze.

📌 Zapamiętaj

  • Selektory atrybutów wybierają elementy na podstawie atrybutów HTML.
  • [required] wskazuje elementy posiadające atrybut required.
  • [type="email"] wskazuje elementy z określoną wartością atrybutu.
  • ^= sprawdza początek wartości atrybutu.
  • $= sprawdza koniec wartości atrybutu.
  • *= sprawdza występowanie fragmentu tekstu.
  • Pseudoklasy zapisujemy z pojedynczym dwukropkiem.
  • :hover oznacza wskazywanie elementu kursorem.
  • :focus oznacza fokus elementu.
  • :focus-visible pomaga zapewnić czytelny wskaźnik fokusu.
  • :first-child wskazuje element będący pierwszym dzieckiem rodzica.
  • :first-of-type wskazuje pierwszy element danego typu wśród rodzeństwa.
  • :nth-child(even) pozwala wskazać elementy na parzystych pozycjach.
  • :checked wskazuje zaznaczone kontrolki.
  • :required wskazuje wymagane kontrolki formularza.
  • :disabled wskazuje wyłączone elementy.
  • :not() pozwala wykluczyć elementy pasujące do określonego selektora.
  • Pseudoelementy zapisujemy z podwójnym dwukropkiem.
  • ::before i ::after służą do dodawania zawartości prezentacyjnej.
  • ::first-letter styluje pierwszą literę.
  • ::first-line styluje pierwszy wiersz tekstu.
  • ::selection pozwala zmienić wygląd zaznaczenia tekstu.
  • ::placeholder styluje tekst podpowiedzi pola.
  • Selektory atrybutów, pseudoklasy i pseudoelementy można łączyć z innymi selektorami CSS.

📝 Zadania praktyczne

Cel: samodzielne stosowanie selektorów atrybutów, pseudoklas i pseudoelementów w praktycznym projekcie HTML5 i CSS3.

Utwórz folder PSI_20, a w nim dwa pliki: index.html oraz style.css.

Wszystkie zadania wykonaj na jednej stronie internetowej. Każde zadanie powinno znajdować się w osobnej sekcji.

Zadanie 1 – Selektory atrybutów

Przygotuj sekcję „Przydatne materiały”.

  1. Dodaj nagłówek h2.
  2. Utwórz listę zawierającą co najmniej sześć odnośników.
  3. Dwa odnośniki powinny prowadzić do plików z rozszerzeniem .pdf.
  4. Dwa odnośniki powinny rozpoczynać się od https://.
  5. Jeden odnośnik powinien prowadzić do pliku .jpg.
  6. Jeden odnośnik powinien prowadzić do innej podstrony projektu.
  7. Za pomocą selektora a[href$=".pdf"] ustaw czerwony kolor odnośników PDF.
  8. Za pomocą selektora a[href^="https://"] ustaw zielony kolor odnośników zaczynających się od https.
  9. Za pomocą selektora a[href$=".jpg"] ustaw pogrubienie odpowiedniego odnośnika.
  10. Sprawdź, które odnośniki otrzymały poszczególne style.

Uwaga: możesz użyć przykładowych nazw plików i adresów, ale jeśli chcesz sprawdzać działanie odnośników, muszą prowadzić do istniejących zasobów.

Zadanie 2 – Pseudoklasy interakcji

Dodaj sekcję „Interaktywne przyciski”.

  1. Dodaj trzy przyciski typu button.
  2. Nadaj im własne napisy, np. „Zapisz”, „Anuluj”, „Więcej informacji”.
  3. Ustaw wspólny kolor tła, kolor tekstu i odstępy.
  4. Za pomocą button:hover zmień kolor tła po najechaniu kursorem.
  5. Za pomocą button:active ustaw inny kolor podczas naciskania.
  6. Za pomocą button:focus-visible ustaw widoczne obramowanie fokusu.
  7. Sprawdź działanie za pomocą myszy.
  8. Przejdź do przycisków klawiszem Tab i sprawdź wskaźnik fokusu.

Przyciski nie muszą wykonywać dodatkowych operacji. W tym zadaniu ćwiczymy wyłącznie ich wygląd.

Zadanie 3 – Pseudoklasy strukturalne

Dodaj sekcję „Plan zajęć”.

  1. Utwórz tabelę zawierającą trzy kolumny: dzień, przedmiot i godzina.
  2. Dodaj nagłówek tabeli w thead.
  3. Dodaj co najmniej sześć wierszy danych w tbody.
  4. Za pomocą tbody tr:nth-child(even) ustaw jasnoszare tło parzystych wierszy.
  5. Za pomocą tbody tr:nth-child(odd) ustaw białe tło nieparzystych wierszy.
  6. Za pomocą tbody tr:first-child pogrub tekst pierwszego wiersza danych.
  7. Za pomocą tbody tr:last-child ustaw dolne obramowanie ostatniego wiersza.
  8. Sprawdź, czy reguły nie zmieniają nagłówka tabeli.

Zadanie 4 – Pseudoklasy formularzy

Dodaj sekcję „Formularz rejestracyjny”.

  1. Utwórz formularz z polami: imię, e-mail i hasło.
  2. Pola imię i e-mail oznacz jako wymagane.
  3. Dodaj checkbox „Akceptuję regulamin”.
  4. Dodaj przycisk „Wyślij”.
  5. Za pomocą input:required ustaw pomarańczowe obramowanie wymaganych pól.
  6. Za pomocą input:focus ustaw jasnoniebieskie tło aktywnego pola.
  7. Za pomocą input[type="checkbox"]:checked ustaw zielony kolor zaznaczenia.
  8. Dodaj pole tekstowe z atrybutem disabled.
  9. Za pomocą input:disabled ustaw szare tło tego pola.
  10. Sprawdź działanie pseudoklas w przeglądarce.

Ważne: do testowania używaj wyłącznie fikcyjnych danych. Formularz nie powinien przesyłać prawdziwych haseł.

Zadanie 5 – Pseudoelementy

Dodaj sekcję „Artykuł o technologii”.

  1. Dodaj nagłówek h2.
  2. Utwórz trzy akapity własnego tekstu.
  3. Za pomocą h2::before dodaj dekoracyjny symbol przed nagłówkiem.
  4. Za pomocą p::first-letter powiększ pierwszą literę każdego akapitu.
  5. Za pomocą p::first-line pogrub pierwszy wiersz akapitu.
  6. Za pomocą p::selection ustaw żółte tło zaznaczonego tekstu.
  7. Dodaj do jednego akapitu klasę nowosc.
  8. Za pomocą .nowosc::after dodaj dekoracyjny symbol po tekście.

Zadanie 6 – Analiza selektorów (dodatkowe)

Przeanalizuj poniższy kod HTML: 

<section>

    <h2>Produkty</h2>

    <p class="produkt">Laptop</p>

    <p class="produkt nowosc">Monitor</p>

    <p class="produkt">Klawiatura</p>

</section>

Odpowiedz na pytania w postaci listy numerowanej na swojej stronie:

  1. Który element wskaże p:first-of-type?
  2. Który element wskaże p:nth-of-type(2)?
  3. Które elementy wskaże p:not(.nowosc)?
  4. Które elementy wskaże .produkt?
  5. Co zrobi selektor .nowosc::after, jeśli ustawimy content: " ★";?
  6. Czy p:first-child wskaże pierwszy akapit? Uzasadnij odpowiedź.
