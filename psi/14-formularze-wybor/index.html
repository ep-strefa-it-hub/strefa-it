HTML5: Formularze – radio, checkbox, select, option, textarea i przyciski

Cel lekcji: tworzenie formularzy zawierających pola pojedynczego i wielokrotnego wyboru, listy rozwijane, pola wielowierszowe oraz przyciski. Poprawne stosowanie atrybutów name, value, checked, selected, required i disabled.

1. Wprowadzenie

Formularze HTML umożliwiają użytkownikowi nie tylko wpisywanie tekstu, ale również wybieranie odpowiedzi, zaznaczanie opcji, wybieranie wartości z listy oraz wpisywanie dłuższych wiadomości.

W poprzednich lekcjach poznaliśmy budowę formularza, znacznik <form>, atrybuty action i method oraz podstawowe kontrolki.

Teraz przyjrzymy się dokładniej kontrolkom wykorzystywanym w ankietach, formularzach rejestracyjnych, zamówieniach i formularzach kontaktowych.

Najważniejsze kontrolki

Kontrolka Zastosowanie
radio Wybór jednej odpowiedzi z grupy.
checkbox Zaznaczanie niezależnych opcji.
select Tworzenie listy wyboru.
option Określenie opcji dostępnej na liście.
textarea Wprowadzanie dłuższego tekstu.
button Tworzenie przycisków formularza.

📌 Ważne

Wygląd kontrolek formularza może różnić się w zależności od przeglądarki i systemu operacyjnego. Ich podstawowe działanie pozostaje jednak takie samo.

2. Pola radio – wybór jednej odpowiedzi

Pole typu radio służy do wyboru jednej odpowiedzi spośród kilku dostępnych możliwości.

Pola należące do jednej grupy muszą mieć tę samą wartość atrybutu name.

Przykład – wybór języka programowania

<form action="" method="get">

    <p>Wybierz język programowania:</p>

    <label>
        <input type="radio"
               name="jezyk"
               value="javascript">
        JavaScript
    </label>

    <label>
        <input type="radio"
               name="jezyk"
               value="php">
        PHP
    </label>

    <label>
        <input type="radio"
               name="jezyk"
               value="python">
        Python
    </label>

    <button type="submit">Wyślij</button>

</form>

Jak działa name?

Wszystkie trzy pola mają name="jezyk". Dzięki temu użytkownik może zaznaczyć tylko jedną odpowiedź.

Każde pole ma inną wartość value, która określa, co zostanie przesłane po jego wybraniu.

Atrybut checked

Atrybut checked oznacza, że pole jest zaznaczone już podczas otwierania strony. 

<label>
    <input type="radio"
           name="poziom"
           value="podstawowy"
           checked>
    Podstawowy
</label>

<label>
    <input type="radio"
           name="poziom"
           value="zaawansowany">
    Zaawansowany
</label>

W tym przykładzie domyślnie zaznaczona jest odpowiedź „Podstawowy”.

Wymagany wybór

<label>
    <input type="radio"
           name="termin"
           value="rano"
           required>
    Rano
</label>

<label>
    <input type="radio"
           name="termin"
           value="wieczor">
    Wieczór
</label>

Atrybut required wymaga zaznaczenia odpowiedzi z tej grupy przed wysłaniem formularza.

📌 Zapamiętaj

name łączy pola radio w jedną grupę, a value określa wartość wybranej odpowiedzi.

3. Pola checkbox – wybór wielu odpowiedzi

Pole typu checkbox pozwala zaznaczać lub odznaczać poszczególne opcje.

W przeciwieństwie do pól radio użytkownik może zaznaczyć kilka checkboxów jednocześnie.

Przykład – zainteresowania

<form action="" method="get">

    <p>Wybierz zainteresowania:</p>

    <label>
        <input type="checkbox"
               name="html"
               value="tak">
        HTML
    </label>

    <label>
        <input type="checkbox"
               name="css"
               value="tak">
        CSS
    </label>

    <label>
        <input type="checkbox"
               name="javascript"
               value="tak">
        JavaScript
    </label>

    <button type="submit">Wyślij</button>

</form>

Co zostanie przesłane?

Jeśli użytkownik zaznaczy HTML i JavaScript, adres URL może zawierać: 

?html=tak&javascript=tak

Niezaznaczony checkbox nie jest przesyłany jako standardowa dana formularza.

Checkbox z atrybutem checked

<label>
    <input type="checkbox"
           name="newsletter"
           value="tak"
           checked>
    Chcę otrzymywać wiadomości
</label>

Pole będzie początkowo zaznaczone, ale użytkownik może je odznaczyć.

Checkbox z atrybutem required

<label>
    <input type="checkbox"
           name="potwierdzenie"
           value="tak"
           required>
    Potwierdzam zapoznanie się z zasadami
</label>

W tym przypadku checkbox musi zostać zaznaczony, aby formularz przeszedł standardową walidację przeglądarki.

📌 Ważne

Jeśli kilka checkboxów ma oznaczać niezależne odpowiedzi, można nadać im różne nazwy name.

Można też użyć tej samej nazwy i różnych wartości value, aby przesłać kilka wartości jednego pola. Sposób ich odczytu zależy wtedy od programu obsługującego formularz.

4. Radio a checkbox – porównanie

Cecha Radio Checkbox
Liczba odpowiedzi Jedna z grupy. Jedna, kilka lub żadna.
Typowe zastosowanie Wybór sposobu płatności. Wybór zainteresowań.
Atrybut name Taki sam dla pól jednej grupy. Może być różny lub wspólny.
Atrybut checked Może wskazać domyślną odpowiedź. Może wstępnie zaznaczyć opcję.
Atrybut required Wymaga wyboru odpowiedzi z grupy. Wymaga zaznaczenia konkretnego pola.

Kiedy użyć radio?

Gdy użytkownik ma wybrać dokładnie jedną możliwość, np. jeden termin spotkania.

Kiedy użyć checkbox?

Gdy użytkownik może zaznaczyć kilka niezależnych opcji, np. kilka zainteresowań.

5. Lista rozwijana – select i option

Znacznik <select> tworzy listę wyboru.

Poszczególne pozycje listy określamy za pomocą znacznika <option>.

Przykład – wybór miasta

<label for="miasto">Wybierz miasto:</label>

<select id="miasto" name="miasto">

    <option value="lublin">Lublin</option>

    <option value="warszawa">Warszawa</option>

    <option value="krakow">Kraków</option>

</select>

Jak działa option?

<option value="lublin">Lublin</option>

Tekst Lublin jest widoczny na liście, natomiast wartość lublin zostanie przesłana z formularzem.

Lista z opcją „Wybierz”

<label for="klasa">Wybierz klasę:</label>

<select id="klasa" name="klasa" required>

    <option value="">-- Wybierz klasę --</option>

    <option value="1">Klasa 1</option>

    <option value="2">Klasa 2</option>

    <option value="3">Klasa 3</option>

    <option value="4">Klasa 4</option>

</select>

Pierwsza opcja ma pustą wartość value="". Dzięki temu wymagane pole nie zostanie uznane za uzupełnione, dopóki użytkownik nie wybierze właściwej opcji.

📌 Zapamiętaj

select tworzy listę, a option określa pojedynczą pozycję tej listy.

6. Atrybuty selected i disabled

Atrybut selected

Atrybut selected określa opcję wybraną domyślnie na liście. 

<select name="miasto">

    <option value="lublin">Lublin</option>

    <option value="lubartow" selected>Lubartów</option>

    <option value="warszawa">Warszawa</option>

</select>

Po otwarciu strony wybrana będzie opcja „Lubartów”.

Atrybut disabled

Atrybut disabled pozwala wyłączyć kontrolkę lub określoną opcję listy. 

<select name="kurs">

    <option value="html">HTML</option>

    <option value="css">CSS</option>

    <option value="php" disabled>
        PHP – brak miejsc
    </option>

</select>

Użytkownik nie będzie mógł wybrać wyłączonej opcji PHP.

Opcja informacyjna

<select name="termin" required>

    <option value="" selected disabled>
        -- Wybierz termin --
    </option>

    <option value="poniedzialek">Poniedziałek</option>

    <option value="sroda">Środa</option>

</select>

Pierwsza opcja informuje użytkownika, że należy wybrać termin. Nie można jej ponownie wybrać po wskazaniu właściwej odpowiedzi.

7. Lista wielokrotnego wyboru – multiple

Domyślnie lista select pozwala wybrać jedną opcję.

Atrybut multiple umożliwia zaznaczenie kilku pozycji.

Przykład

<label for="technologie">
    Wybierz technologie:
</label>

<select id="technologie"
        name="technologie"
        multiple
        size="4">

    <option value="html">HTML</option>

    <option value="css">CSS</option>

    <option value="javascript">JavaScript</option>

    <option value="php">PHP</option>

</select>

Atrybut size

Atrybut size="4" określa liczbę widocznych pozycji listy.

Jak zaznaczyć kilka pozycji?

Na komputerze można użyć klawisza Ctrl lub Command, a w niektórych przypadkach Shift. Sposób wyboru zależy od systemu i przeglądarki.

📌 Ważne

Lista wielokrotnego wyboru może przesłać kilka wartości o tej samej nazwie. Program obsługujący formularz musi być przygotowany na ich odczyt.

8. Pole wielowierszowe – textarea

Znacznik <textarea> służy do wprowadzania dłuższych wypowiedzi, komentarzy i wiadomości.

Podstawowa składnia

<label for="wiadomosc">Wiadomość:</label>

<textarea id="wiadomosc"
          name="wiadomosc"></textarea>

Atrybuty rows i cols

<textarea name="opinia"
          rows="5"
          cols="40"></textarea>
  • rows – określa liczbę widocznych wierszy.
  • cols – określa przybliżoną szerokość pola w znakach.

Placeholder i required

<label for="komentarz">Komentarz:</label>

<textarea id="komentarz"
          name="komentarz"
          rows="5"
          cols="40"
          placeholder="Wpisz swój komentarz"
          required></textarea>

Ograniczenie liczby znaków

<textarea name="opis"
          rows="4"
          cols="35"
          minlength="10"
          maxlength="300"></textarea>

Użytkownik może wpisać maksymalnie 300 znaków. Jeśli pole zawiera tekst, przeglądarka może również sprawdzić minimalną długość określoną przez minlength.

Tekst początkowy

<textarea name="wiadomosc">Przykładowa wiadomość</textarea>

Wartość początkową umieszczamy pomiędzy znacznikami otwierającym i zamykającym.

📌 Uwaga

Znacznik textarea nie korzysta z atrybutu value do ustawiania tekstu początkowego.

9. Grupowanie pól – fieldset i legend

Rozbudowane formularze warto podzielić na logiczne grupy.

Służą do tego znaczniki:

  • <fieldset> – grupuje powiązane pola,
  • <legend> – nadaje grupie nazwę.

Przykład – dane uczestnika

<fieldset>

    <legend>Dane uczestnika</legend>

    <label for="imie">Imię:</label>

    <input type="text"
           id="imie"
           name="imie">

    <label for="email">E-mail:</label>

    <input type="email"
           id="email"
           name="email">

</fieldset>

Przykład – grupa radio

<fieldset>

    <legend>Wybierz sposób dostawy</legend>

    <label>
        <input type="radio"
               name="dostawa"
               value="kurier">
        Kurier
    </label>

    <label>
        <input type="radio"
               name="dostawa"
               value="odbior">
        Odbiór osobisty
    </label>

</fieldset>

Dzięki temu użytkownik widzi, że obie odpowiedzi dotyczą jednego pytania.

10. Przyciski formularza

Przyciski pozwalają wysłać formularz, przywrócić wartości początkowe lub wykonać inne działanie.

Przycisk submit

<button type="submit">Wyślij formularz</button>

Przycisk submit uruchamia standardową procedurę wysyłania formularza.

Przycisk reset

<button type="reset">Wyczyść formularz</button>

Przycisk reset przywraca początkowe wartości pól.

Nie zawsze oznacza to całkowite wyczyszczenie formularza. Pola z ustawionymi wartościami value, checked lub selected wrócą do tych wartości.

Przycisk button

<button type="button">Sprawdź</button>

Sam przycisk typu button nie wysyła formularza. Można przypisać mu działanie za pomocą JavaScript.

Przyciski tworzone za pomocą input

<input type="submit" value="Wyślij">

<input type="reset" value="Wyczyść">

<input type="button" value="Sprawdź">

Różnica między button a input

<button type="submit">
    Wyślij zgłoszenie
</button>

<input type="submit" value="Wyślij zgłoszenie">

Oba przyciski mogą wysłać formularz. Znacznik <button> pozwala jednak umieszczać wewnątrz dodatkową treść HTML.

📌 Ważne

W znaczniku <button> warto zawsze podawać atrybut type. Przycisk bez tego atrybutu znajdujący się w formularzu domyślnie działa jak submit.

11. Najważniejsze atrybuty kontrolek

Atrybut Zastosowanie
type Określa typ kontrolki lub przycisku.
name Określa nazwę przesyłanej danej.
value Określa wartość pola lub opcji.
id Identyfikuje element i pozwala powiązać go z etykietą.
checked Wstępnie zaznacza radio lub checkbox.
selected Wskazuje domyślnie wybraną opcję listy.
required Oznacza wymagane pole lub wybór.
disabled Wyłącza kontrolkę lub opcję.
multiple Pozwala wybrać kilka opcji z listy select.
size Określa liczbę widocznych pozycji listy.
rows Określa liczbę widocznych wierszy textarea.
cols Określa przybliżoną szerokość textarea.
minlength Określa minimalną długość tekstu.
maxlength Określa maksymalną długość tekstu.
placeholder Wyświetla podpowiedź w pustym polu tekstowym.

Atrybuty logiczne

Niektóre atrybuty są logiczne. Ich obecność oznacza włączenie określonej właściwości. 

<input type="checkbox" checked>

<input type="text" required>

<option value="a" selected>Opcja A</option>

<option value="b" disabled>Opcja B</option>

W takich przypadkach nie trzeba dopisywać ="true".

12. Jak przesyłane są wybrane wartości?

Podczas wysyłania formularza przeglądarka przygotowuje dane na podstawie nazw i wartości kontrolek.

Przykład – radio

<form action="" method="get">

    <label>
        <input type="radio"
               name="platnosc"
               value="karta">
        Karta
    </label>

    <label>
        <input type="radio"
               name="platnosc"
               value="gotowka">
        Gotówka
    </label>

    <button type="submit">Wyślij</button>

</form>

Jeśli użytkownik wybierze „Karta”, w adresie URL może pojawić się: 

?platnosc=karta

Przykład – checkbox

<label>
    <input type="checkbox"
           name="faktura"
           value="tak">
    Chcę otrzymać fakturę
</label>

Jeśli checkbox zostanie zaznaczony, przesłana zostanie wartość: 

faktura=tak

Jeśli checkbox pozostanie niezaznaczony, parametr faktura nie zostanie przesłany.

Przykład – select

<select name="rozmiar">

    <option value="s">Mały</option>

    <option value="m">Średni</option>

    <option value="l">Duży</option>

</select>

Po wybraniu opcji „Średni” zostanie przesłane: 

rozmiar=m

Przykład – textarea

<textarea name="uwagi"></textarea>

Wartością pola będzie tekst wpisany przez użytkownika.

📌 Ważne

W ćwiczeniach stosujemy metodę GET, aby łatwo obserwować przesyłane parametry. Nie należy wpisywać do takich formularzy haseł ani danych poufnych.

13. Najczęstsze błędy

Błąd 1 – różne nazwy w jednej grupie radio

<!-- Niepoprawnie dla jednej grupy -->
<input type="radio" name="opcja1" value="a">
<input type="radio" name="opcja2" value="b">

<!-- Poprawnie -->
<input type="radio" name="opcja" value="a">
<input type="radio" name="opcja" value="b">

Błąd 2 – brak value w radio

<!-- Niezalecane -->
<input type="radio" name="wybor">

<!-- Poprawnie -->
<input type="radio"
       name="wybor"
       value="pierwsza">

Bez value zaznaczone pole radio przesyła domyślnie wartość on.

Błąd 3 – brak name w select

<!-- Wartość nie zostanie przesłana -->
<select id="miasto">
    <option value="lublin">Lublin</option>
</select>

<!-- Poprawnie -->
<select id="miasto" name="miasto">
    <option value="lublin">Lublin</option>
</select>

Błąd 4 – używanie value w textarea

<!-- Niepoprawnie -->
<textarea name="opis" value="Tekst"></textarea>

<!-- Poprawnie -->
<textarea name="opis">Tekst</textarea>

Błąd 5 – brak type w zwykłym przycisku

<!-- Może niezamierzenie wysłać formularz -->
<button>Sprawdź</button>

<!-- Poprawnie -->
<button type="button">Sprawdź</button>

Błąd 6 – mylenie selected i checked

<!-- Radio i checkbox: checked -->
<input type="checkbox" checked>

<!-- Opcja listy: selected -->
<option value="html" selected>HTML</option>

Błąd 7 – brak etykiet

Kontrolki powinny mieć czytelne opisy. Dla pól radio i checkbox wygodnym rozwiązaniem jest umieszczenie kontrolki wewnątrz znacznika <label>.

14. Przykład kompletnego formularza

Poniższy przykład przedstawia formularz zamówienia w szkolnej kawiarni. Wykorzystuje pola radio, checkbox, listę select, textarea i przyciski. 

<!DOCTYPE html>
<html lang="pl">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Zamówienie w kawiarni</title>
</head>

<body>

    <h1>Kawiarnia szkolna</h1>
    <h2>Formularz zamówienia</h2>

    <form action="" method="get">

        <fieldset>

            <legend>Dane klienta</legend>

            <p>
                <label for="imie">Imię:</label>

                <input type="text"
                       id="imie"
                       name="imie"
                       required>
            </p>

        </fieldset>

        <fieldset>

            <legend>Wybierz napój</legend>

            <p>
                <label>
                    <input type="radio"
                           name="napoj"
                           value="kawa"
                           required>
                    Kawa
                </label>
            </p>

            <p>
                <label>
                    <input type="radio"
                           name="napoj"
                           value="herbata">
                    Herbata
                </label>
            </p>

            <p>
                <label>
                    <input type="radio"
                           name="napoj"
                           value="sok">
                    Sok
                </label>
            </p>

        </fieldset>

        <fieldset>

            <legend>Dodatki</legend>

            <p>
                <label>
                    <input type="checkbox"
                           name="cukier"
                           value="tak">
                    Cukier
                </label>
            </p>

            <p>
                <label>
                    <input type="checkbox"
                           name="mleko"
                           value="tak">
                    Mleko
                </label>
            </p>

            <p>
                <label>
                    <input type="checkbox"
                           name="syrop"
                           value="tak">
                    Syrop
                </label>
            </p>

        </fieldset>

        <p>
            <label for="rozmiar">Rozmiar napoju:</label>

            <select id="rozmiar"
                    name="rozmiar"
                    required>

                <option value="">
                    -- Wybierz rozmiar --
                </option>

                <option value="s">Mały</option>

                <option value="m">Średni</option>

                <option value="l">Duży</option>

            </select>
        </p>

        <p>
            <label for="uwagi">Uwagi do zamówienia:</label>
        </p>

        <p>
            <textarea id="uwagi"
                      name="uwagi"
                      rows="4"
                      cols="40"
                      maxlength="200"
                      placeholder="Wpisz dodatkowe informacje"></textarea>
        </p>

        <p>
            <label>
                <input type="checkbox"
                       name="potwierdzenie"
                       value="tak"
                       required>
                Potwierdzam zamówienie
            </label>
        </p>

        <button type="submit">
            Złóż zamówienie
        </button>

        <button type="reset">
            Wyczyść
        </button>

    </form>

</body>
</html>

Co należy sprawdzić?

  1. Czy można wybrać tylko jeden napój?
  2. Czy można zaznaczyć kilka dodatków?
  3. Czy lista pozwala wybrać rozmiar napoju?
  4. Czy można wpisać uwagi do zamówienia?
  5. Czy formularz wymaga zaznaczenia potwierdzenia?
  6. Czy przycisk reset przywraca wartości początkowe?
  7. Czy po wysłaniu dane pojawiają się w adresie URL?

📌 Uwaga

Formularz jest przykładem edukacyjnym. Nie zapisuje zamówień ani nie przekazuje ich do rzeczywistej kawiarni.

📌 Zapamiętaj

  • radio – wybór jednej odpowiedzi z grupy.
  • checkbox – zaznaczanie niezależnych opcji.
  • name – nazwa przesyłanej danej.
  • value – wartość przesyłana po wyborze opcji.
  • checked – wstępne zaznaczenie radio lub checkbox.
  • select – tworzy listę wyboru.
  • option – określa pozycję listy.
  • selected – domyślnie wybiera opcję listy.
  • multiple – pozwala zaznaczyć kilka opcji listy.
  • size – określa liczbę widocznych pozycji listy.
  • disabled – wyłącza kontrolkę lub opcję.
  • textarea – tworzy pole wielowierszowe.
  • rows i cols – określają rozmiar pola textarea.
  • fieldset – grupuje powiązane kontrolki.
  • legend – nadaje nazwę grupie kontrolek.
  • button type="submit" – wysyła formularz.
  • button type="reset" – przywraca wartości początkowe.
  • button type="button" – tworzy przycisk bez domyślnego wysyłania.
  • required – wymaga uzupełnienia pola lub dokonania wyboru.

Zadanie 4 – Poprawianie błędów (dodatkowe)

Przeanalizuj poniższy formularz i popraw błędy w kodzie. 

<form action="" method="get">

    <p>Wybierz język:</p>

    <input type="radio" name="html"> HTML

    <input type="radio" name="css"> CSS

    <p>Wybierz miasto:</p>

    <select id="miasto">

  5. Dodaj etykietę do listy miast.
  6. Popraw początkowy tekst w textarea.
  7. Popraw typ przycisku, aby wysyłał formularz.
