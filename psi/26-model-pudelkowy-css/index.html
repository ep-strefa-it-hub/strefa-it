Model pudełkowy CSS – width, height, margin, padding, border i box-sizing

Cel lekcji: poznanie zasad działania modelu pudełkowego CSS, określania wymiarów elementów, ustawiania marginesów i obramowań oraz obliczania rzeczywistej szerokości i wysokości elementów strony.

1. Wprowadzenie – czym jest model pudełkowy CSS?

Każdy element HTML można traktować jak prostokątne pudełko. Dotyczy to między innymi nagłówków, akapitów, obrazów, przycisków i kontenerów div.

Przeglądarka oblicza wymiary oraz położenie tych pudełek, korzystając z właściwości CSS.

Zasady te nazywamy modelem pudełkowym CSS (ang. CSS Box Model).

Przykład

<div class="karta">
    <h2>Moja karta</h2>
    <p>Przykładowy tekst.</p>
</div>
.karta {
    width: 300px;
    padding: 20px;
    border: 2px solid blue;
    margin: 30px;
}

Element ma określoną szerokość, odstęp między treścią a obramowaniem, obramowanie oraz odstęp od innych elementów.

📌 Zapamiętaj

Model pudełkowy wyjaśnia, ile miejsca zajmuje element i jak jest oddzielony od pozostałych elementów strony.

2. Budowa modelu pudełkowego

Model pudełkowy składa się z czterech podstawowych obszarów.

  1. Content – zawartość elementu.
  2. Padding – margines wewnętrzny, czyli odstęp między zawartością a obramowaniem.
  3. Border – obramowanie elementu.
  4. Margin – margines zewnętrzny, czyli przestrzeń poza obramowaniem.

Schemat modelu pudełkowego

+--------------------------------------+
|                MARGIN                |
|                                      |
|   +------------------------------+   |
|   |            BORDER            |   |
|   |                              |   |
|   |   +----------------------+   |   |
|   |   |       PADDING        |   |   |
|   |   |                      |   |   |
|   |   |   +--------------+   |   |   |
|   |   |   |   CONTENT    |   |   |   |
|   |   |   |              |   |   |   |
|   |   |   +--------------+   |   |   |
|   |   |                      |   |   |
|   |   +----------------------+   |   |
|   |                              |   |
|   +------------------------------+   |
|                                      |
+--------------------------------------+
Obszar Właściwość CSS Znaczenie
Content width, height Wymiary obszaru zawartości przy content-box.
Padding padding Odstęp wewnątrz obramowania.
Border border Obramowanie elementu.
Margin margin Odstęp na zewnątrz obramowania.

📌 Ważne

Kolejność od środka elementu do jego otoczenia to: content → padding → border → margin .

3. Szerokość elementu – width

Właściwość width określa szerokość elementu.

Przykład – szerokość w pikselach

.karta {
    width: 300px;
}

W domyślnym modelu content-box oznacza to szerokość obszaru zawartości równą 300 px.

Szerokość procentowa

.karta {
    width: 50%;
}

W typowym układzie blokowym oznacza to połowę szerokości obszaru zawartości elementu nadrzędnego.

Szerokość automatyczna

.karta {
    width: auto;
}

Wartość auto pozwala przeglądarce obliczyć szerokość zgodnie z zasadami układu.

Przykład HTML

<div class="karta1">
    Karta o szerokości 300 px
</div>

<div class="karta2">
    Karta o szerokości 50%
</div>
.karta1 {
    width: 300px;
    background-color: lightblue;
}

.karta2 {
    width: 50%;
    background-color: lightgreen;
}

📌 Ważne

Samo width: 100% nie zawsze oznacza, że element zmieści się w kontenerze. Znaczenie mają także padding, border i box-sizing.

4. Wysokość elementu – height

Właściwość height określa wysokość elementu.

Przykład

.panel {
    height: 200px;
}

W domyślnym modelu content-box wysokość obszaru zawartości wynosi 200 px.

Wysokość automatyczna

.panel {
    height: auto;
}

W typowym układzie blokowym wysokość elementu dopasowuje się do jego zawartości.

Przykład – stała wysokość

<div class="panel">
    <p>Przykładowy tekst.</p>
</div>
.panel {
    width: 300px;
    height: 150px;

    background-color: #DBEAFE;
}

Porównanie width i height

Właściwość Działanie
width Określa szerokość elementu.
height Określa wysokość elementu.

📌 Dobra praktyka

Nie ustawiaj stałej wysokości dla elementów zawierających dużo tekstu, jeśli nie jest to konieczne. Zawartość może nie zmieścić się w wyznaczonym obszarze.

5. Margines wewnętrzny – padding

Właściwość padding określa odległość między zawartością elementu a jego obramowaniem.

Przykład

.karta {
    padding: 20px;
}

Oznacza to odstęp 20 px z każdej strony zawartości.

Bez padding

.karta1 {
    border: 2px solid blue;
    padding: 0;
}

Tekst może znajdować się bezpośrednio przy obramowaniu.

Z padding

.karta2 {
    border: 2px solid blue;
    padding: 20px;
}

Między tekstem a obramowaniem pojawia się wolna przestrzeń.

Oddzielne właściwości

.karta {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 30px;
    padding-left: 40px;
}
Właściwość Znaczenie
padding-top Odstęp od góry.
padding-right Odstęp od prawej strony.
padding-bottom Odstęp od dołu.
padding-left Odstęp od lewej strony.

📌 Zapamiętaj

padding tworzy przestrzeń wewnątrz elementu. Tło elementu domyślnie obejmuje również obszar padding.

6. Skrócony zapis padding

Właściwość padding pozwala ustawić odstępy za pomocą od jednej do czterech wartości.

Jedna wartość

.karta {
    padding: 20px;
}

Wszystkie cztery strony otrzymują odstęp 20 px.

Dwie wartości

.karta {
    padding: 10px 20px;
}

Pierwsza wartość dotyczy góry i dołu, a druga lewej i prawej strony.

Trzy wartości

.karta {
    padding: 10px 20px 30px;
}

Kolejno: góra 10 px, lewo i prawo 20 px, dół 30 px.

Cztery wartości

.karta {
    padding: 10px 20px 30px 40px;
}

Kolejność:

  1. góra – 10 px,
  2. prawo – 20 px,
  3. dół – 30 px,
  4. lewo – 40 px.

📌 Zapamiętaj

Przy czterech wartościach obowiązuje kolejność: góra → prawo → dół → lewo.

padding nie przyjmuje ujemnych wartości.

7. Obramowanie – border

Obramowanie znajduje się między marginesem wewnętrznym a zewnętrznym.

Przykład

.karta {
    border: 3px solid blue;
}

Właściwość border pozwala określić:

  • grubość obramowania,
  • styl linii,
  • kolor obramowania.

Obramowanie a wymiary

.karta {
    width: 300px;
    border: 5px solid red;
}

Przy domyślnym box-sizing: content-box szerokość elementu razem z obramowaniem wynosi: 

300 px + 5 px + 5 px = 310 px

Jeśli dodamy padding, całkowita szerokość będzie jeszcze większa.

📌 Ważne

W modelu content-box obramowanie zwiększa rzeczywistą szerokość i wysokość elementu.

8. Margines zewnętrzny – margin

Właściwość margin określa przestrzeń na zewnątrz obramowania elementu.

Przykład

.karta {
    margin: 20px;
}

Element otrzymuje margines 20 px z każdej strony.

Przykład – dwie karty

<div class="karta">
    Pierwsza karta
</div>

<div class="karta">
    Druga karta
</div>
.karta {
    padding: 20px;
    border: 2px solid blue;
    margin-bottom: 30px;
}

margin-bottom tworzy odstęp pod każdym elementem.

Oddzielne właściwości

.karta {
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 30px;
    margin-left: 40px;
}

Margin a padding

Właściwość Położenie odstępu
padding Wewnątrz obramowania.
margin Na zewnątrz obramowania.

📌 Zapamiętaj

margin oddziela element od jego otoczenia, natomiast padding oddziela zawartość od obramowania.

9. Skrócony zapis margin

Podobnie jak padding, właściwość margin przyjmuje od jednej do czterech wartości.

Jedna wartość

.karta {
    margin: 20px;
}

Wszystkie strony: 20 px.

Dwie wartości

.karta {
    margin: 10px 20px;
}

Góra i dół: 10 px. Lewo i prawo: 20 px.

Trzy wartości

.karta {
    margin: 10px 20px 30px;
}

Góra: 10 px. Lewo i prawo: 20 px. Dół: 30 px.

Cztery wartości

.karta {
    margin: 10px 20px 30px 40px;
}

Góra: 10 px. Prawo: 20 px. Dół: 30 px. Lewo: 40 px.

Ujemne marginesy

.karta {
    margin-top: -10px;
}

W odróżnieniu od padding, margin może przyjmować wartości ujemne.

Ujemny margines zmienia położenie elementu względem innych elementów i może powodować nakładanie się treści.

10. Wyśrodkowanie elementu – margin: auto

Jednym z częstych zastosowań margin jest poziome wyśrodkowanie elementu blokowego.

Przykład

.kontener {
    width: 800px;
    margin: 0 auto;
}

Zapis margin: 0 auto oznacza:

  • górny i dolny margines – 0,
  • lewy i prawy margines – automatyczny.

Wolne miejsce po obu stronach jest dzielone równo, dzięki czemu element zostaje wyśrodkowany.

Przykład bardziej elastyczny

.kontener {
    width: 90%;
    max-width: 1000px;

    margin: 0 auto;
}

Element może zajmować 90% dostępnej szerokości, ale nie więcej niż 1000 px.

Wyśrodkowanie elementu a tekstu

/* Wyśrodkowanie kontenera */

.kontener {
    width: 80%;
    margin: 0 auto;
}

/* Wyśrodkowanie tekstu */

h1 {
    text-align: center;
}

📌 Ważne

margin: 0 auto wyśrodkowuje poziomo odpowiednio zwymiarowany element blokowy w typowym układzie.

text-align: center wyrównuje tekst i zawartość liniową wewnątrz elementu.

11. Obliczanie rzeczywistych wymiarów elementu

Przy domyślnym box-sizing: content-box wartość width określa szerokość zawartości, a nie całego pudełka.

Przykład 1 – oblicz szerokość

.karta {
    width: 300px;
    padding: 20px;
    border: 5px solid blue;
    margin: 10px;
}

Obliczamy szerokość od lewej do prawej strony: 

Zawartość:           300 px

Padding lewy:         20 px
Padding prawy:        20 px

Border lewy:           5 px
Border prawy:          5 px

----------------------------

Szerokość pudełka:   350 px

Margin lewy:          10 px
Margin prawy:         10 px

----------------------------

Łącznie z marginesami: 370 px

Szerokość pudełka bez marginesów wynosi 350 px.

Po uwzględnieniu obu marginesów otrzymujemy 370 px.

Wzór – content-box

Szerokość pudełka =

width
+ padding-left
+ padding-right
+ border-left
+ border-right

Jeśli chcemy uwzględnić także marginesy, dodajemy margin-left i margin-right.

Przykład 2 – oblicz wysokość

.panel {
    height: 100px;
    padding: 15px;
    border: 3px solid black;
    margin: 20px;
}
Zawartość:           100 px

Padding góra:         15 px
Padding dół:          15 px

Border góra:           3 px
Border dół:            3 px

----------------------------

Wysokość pudełka:   136 px

Margin góra:          20 px
Margin dół:           20 px

----------------------------

Suma z marginesami: 176 px

Wysokość pudełka wynosi 136 px.

Suma wymiarów z oboma marginesami wynosi 176 px. W normalnym układzie blokowym marginesy pionowe mogą jednak podlegać łączeniu.

📌 Zapamiętaj

W modelu content-box do szerokości i wysokości zawartości trzeba dodać odpowiednie wartości padding i border.

12. Właściwość box-sizing

Właściwość box-sizing określa sposób obliczania wymiarów elementu.

Najważniejsze wartości:

  • content-box,
  • border-box.

Content-box

.karta {
    box-sizing: content-box;

    width: 300px;
    padding: 20px;
    border: 5px solid blue;
}

Szerokość pudełka wynosi: 

300 + 20 + 20 + 5 + 5 = 350 px

Border-box

.karta {
    box-sizing: border-box;

    width: 300px;
    padding: 20px;
    border: 5px solid blue;
}

Szerokość pudełka wynosi teraz 300 px.

Padding i obramowanie są uwzględnione w zadanej szerokości.

Obliczenie szerokości zawartości

300 - 20 - 20 - 5 - 5 = 250 px

Obszar zawartości ma szerokość 250 px.

📌 Najważniejsza zasada

content-box: podana szerokość dotyczy samej zawartości.

border-box: podana szerokość obejmuje zawartość, padding i obramowanie.

Margines zewnętrzny nie jest wliczany do żadnej z tych wartości.

13. Porównanie content-box i border-box

Porównajmy dwa elementy o identycznych właściwościach z wyjątkiem box-sizing.

Kod HTML

<div class="pudelko1">
    content-box
</div>

<div class="pudelko2">
    border-box
</div>

Kod CSS

.pudelko1 {
    box-sizing: content-box;

    width: 300px;
    padding: 20px;
    border: 5px solid blue;
}

.pudelko2 {
    box-sizing: border-box;

    width: 300px;
    padding: 20px;
    border: 5px solid green;
}
Cecha content-box border-box
Zadane width 300 px 300 px
Padding 20 px z każdej strony 20 px z każdej strony
Border 5 px z każdej strony 5 px z każdej strony
Szerokość zawartości 300 px 250 px
Szerokość pudełka 350 px 300 px

Popularne ustawienie dla całej strony

*,
*::before,
*::after {
    box-sizing: border-box;
}

Dzięki temu większość wymiarów elementów łatwiej kontrolować.

📌 Dobra praktyka

W wielu współczesnych projektach stosuje się box-sizing: border-box dla wszystkich elementów i pseudoelementów.

14. Minimalne i maksymalne wymiary

Oprócz width i height CSS umożliwia określanie minimalnych oraz maksymalnych wymiarów.

Właściwość Działanie
min-width Minimalna szerokość.
max-width Maksymalna szerokość.
min-height Minimalna wysokość.
max-height Maksymalna wysokość.

Przykład – maksymalna szerokość

.kontener {
    width: 90%;
    max-width: 1000px;

    margin: 0 auto;
}

Kontener dopasowuje się do dostępnego miejsca, ale nie przekracza 1000 px.

Przykład – minimalna wysokość

.karta {
    min-height: 200px;
}

Element ma co najmniej 200 px wysokości, ale może być wyższy, jeśli wymaga tego zawartość.

Przykład – maksymalna szerokość obrazu

img {
    max-width: 100%;
    height: auto;
}

Obraz nie powinien przekraczać szerokości swojego kontenera i zachowuje proporcje.

📌 Dobra praktyka

Przy projektowaniu stron często warto stosować max-width zamiast samej sztywnej szerokości w pikselach.

15. Przepełnienie zawartości – overflow

Jeśli element ma ustaloną wysokość lub szerokość, jego zawartość może nie zmieścić się w wyznaczonym obszarze.

Właściwość overflow określa, jak przeglądarka ma obsłużyć taką sytuację.

Wartość Działanie
visible Zawartość może wystawać poza element.
hidden Wystająca zawartość zostaje przycięta.
scroll Tworzy obszar przewijania.
auto Przewijanie pojawia się w razie potrzeby.

Przykład

.opis {
    width: 300px;
    height: 100px;

    padding: 15px;
    border: 2px solid blue;

    overflow: auto;
}

Jeśli tekst jest dłuższy, użytkownik może przewijać zawartość elementu.

Przykład – ukrycie nadmiaru

.panel {
    height: 150px;
    overflow: hidden;
}

Nadmiar zawartości zostanie przycięty.

📌 Uwaga

Nie używaj overflow: hidden tylko po to, aby ukryć problem z układem strony. Może to spowodować utratę widocznej treści.

16. Łączenie marginesów pionowych

W normalnym układzie blokowym sąsiadujące marginesy pionowe nie zawsze się sumują.

Zjawisko to nazywamy łączeniem marginesów (ang. margin collapsing).

Przykład

<div class="karta1">
    Pierwsza karta
</div>

<div class="karta2">
    Druga karta
</div>
.karta1 {
    margin-bottom: 30px;
}

.karta2 {
    margin-top: 20px;
}

Można przypuszczać, że odstęp między kartami wyniesie 50 px.

Jednak w typowym układzie dwóch sąsiadujących elementów blokowych dodatnie marginesy pionowe mogą się połączyć.

W tym przykładzie odstęp wyniesie 30 px, czyli większą z dwóch wartości.

Marginesy poziome

Marginesy poziome nie podlegają takiemu łączeniu.

📌 Zapamiętaj

Łączenie marginesów dotyczy określonych sytuacji w normalnym układzie blokowym. Nie występuje na przykład między elementami będącymi elementami flex lub grid.

17. Model pudełkowy w narzędziach przeglądarki

Przeglądarki internetowe udostępniają narzędzia dla programistów (ang. Developer Tools).

Można w nich sprawdzić rzeczywiste wymiary elementów oraz wartości marginesów, paddingu i obramowania.

Instrukcja krok po kroku

  1. Otwórz stronę w przeglądarce Chrome lub Edge.
  2. Kliknij wybrany element prawym przyciskiem myszy.
  3. Wybierz Zbadaj.
  4. W panelu narzędzi odszukaj zakładkę Elements lub Elementy.
  5. Zaznacz element HTML.
  6. W zakładce Computed lub Obliczone znajdź schemat modelu pudełkowego.
  7. Sprawdź wartości content, padding, border i margin.

Co można sprawdzić?

  • rzeczywistą szerokość elementu,
  • rzeczywistą wysokość elementu,
  • wartości marginesów wewnętrznych,
  • grubość obramowania,
  • wartości marginesów zewnętrznych,
  • zastosowaną wartość box-sizing.

📌 Wskazówka

Narzędzia deweloperskie pomagają zrozumieć, dlaczego element jest większy, niż wynikałoby to z samego width.

18. Najczęstsze błędy

Błąd 1 – mylenie margin i padding

.karta {
    margin: 20px;
    padding: 20px;
}

Obie właściwości tworzą odstępy, ale w innych miejscach.

margin działa na zewnątrz obramowania, a padding wewnątrz niego.

Błąd 2 – pomijanie padding i border w obliczeniach

.karta {
    width: 300px;
    padding: 20px;
    border: 5px solid blue;
}

Przy content-box szerokość pudełka wynosi 350 px, a nie 300 px.

Błąd 3 – brak jednostki

/* Niepoprawnie */

.karta {
    width: 300;
    padding: 20;
}

Poprawnie:

.karta {
    width: 300px;
    padding: 20px;
}

Błąd 4 – width: 100% i dodatkowy padding

.karta {
    width: 100%;
    padding: 20px;
}

Przy content-box szerokość pudełka może przekroczyć szerokość kontenera.

Rozwiązanie:

.karta {
    box-sizing: border-box;

    width: 100%;
    padding: 20px;
}

Błąd 5 – niepotrzebna stała wysokość

.opis {
    height: 50px;
}

Jeśli tekst jest długi, może wystawać poza element.

Często lepiej użyć: 

.opis {
    min-height: 50px;
}

Błąd 6 – margin: auto bez odpowiednich warunków

.kontener {
    margin: 0 auto;
}

Jeśli zwykły element blokowy automatycznie zajmuje całą dostępną szerokość, wyśrodkowanie może być niewidoczne.

Przykładowe rozwiązanie: 

.kontener {
    width: 80%;
    margin: 0 auto;
}

Błąd 7 – oczekiwanie sumowania marginesów pionowych

W określonych sytuacjach pionowe marginesy sąsiadujących elementów blokowych łączą się zamiast sumować.

📌 Wskazówka

Gdy element ma nieoczekiwane wymiary, sprawdź kolejno: width, height, padding, border, margin i box-sizing.

📌 Zwróć uwagę

W przykładzie zastosowano również display: flex do rozmieszczenia kart. Najważniejszym celem tej lekcji jest jednak zrozumienie wymiarów i odstępów elementów.

📌 Zapamiętaj

  • Każdy element HTML jest przedstawiany przez przeglądarkę jako pudełko.
  • Model pudełkowy składa się z content, padding, border i margin.
  • width określa szerokość elementu.
  • height określa wysokość elementu.
  • padding tworzy odstęp między zawartością a obramowaniem.
  • border tworzy obramowanie elementu.
  • margin tworzy odstęp na zewnątrz obramowania.
  • padding nie przyjmuje wartości ujemnych.
  • margin może przyjmować wartości ujemne.
  • Przy czterech wartościach margin i padding obowiązuje kolejność: góra, prawo, dół, lewo.
  • margin: 0 auto może służyć do poziomego wyśrodkowania kontenera.
  • content-box oznacza, że width dotyczy obszaru zawartości.
  • border-box oznacza, że width obejmuje zawartość, padding i border.
  • box-sizing określa sposób obliczania wymiarów.
  • max-width ogranicza maksymalną szerokość.
  • min-height określa minimalną wysokość.
  • overflow kontroluje przepełnienie zawartości elementu.
  • Marginesy pionowe w określonych sytuacjach mogą się łączyć.
  • Narzędzia deweloperskie umożliwiają sprawdzenie rzeczywistych wymiarów pudełka elementu.

📝 Zadania praktyczne

Cel: zastosowanie modelu pudełkowego do określania szerokości, wysokości, odstępów i obramowań elementów.

Utwórz folder PSI_26, a w nim pliki index.html i style.css.

Wszystkie zadania wykonaj w ramach jednej strony WWW. Każde kolejne zadanie rozbudowuje ten sam projekt.

Zadanie 1 – Budowa strony z kartami

Przygotuj stronę „Moje zainteresowania”.

  1. Utwórz poprawny dokument HTML5.
  2. Podłącz plik style.css.
  3. Dodaj nagłówek strony z tytułem i krótkim opisem.
  4. Utwórz trzy karty opisujące Twoje zainteresowania.
  5. Każda karta powinna zawierać nagłówek i akapit.
  6. Ustaw dla kart width: 300px.
  7. Dodaj padding: 20px.
  8. Dodaj obramowanie 2px solid.
  9. Ustaw margin-bottom: 20px.

Zadanie 2 – Obliczanie szerokości elementu

Dla każdej karty zastosowano: 

.karta {
    box-sizing: content-box;

    width: 300px;
    padding: 20px;
    border: 2px solid blue;
    margin: 10px;
}
  1. Oblicz szerokość obszaru zawartości.
  2. Oblicz łączną szerokość paddingu.
  3. Oblicz łączną szerokość obramowania.
  4. Oblicz szerokość pudełka bez marginesów.
  5. Oblicz sumę szerokości pudełka i obu marginesów.
  6. Zapisz wyniki w komentarzu w pliku style.css.

Zadanie 3 – Porównanie box-sizing

Porównaj działanie content-box i border-box.

  1. Ustaw dla pierwszej karty box-sizing: content-box.
  2. Ustaw dla drugiej karty box-sizing: border-box.
  3. W obu kartach ustaw width: 300px.
  4. Ustaw padding: 20px.
  5. Ustaw border: 5px solid.
  6. Porównaj szerokości obu kart.
  7. Oblicz szerokość pudełka każdej karty.
  8. Zapisz w komentarzu, na czym polega różnica.

Zadanie 4 – Wyśrodkowanie kontenera

Umieść zawartość strony w głównym kontenerze.

  1. Dodaj element main z klasą kontener.
  2. Ustaw width: 90%.
  3. Ustaw max-width: 1000px.
  4. Zastosuj margin: 30px auto.
  5. Dodaj padding: 20px.
  6. Ustaw box-sizing: border-box.
  7. Sprawdź wyśrodkowanie kontenera w przeglądarce.
  8. Zmień szerokość okna i obserwuj działanie max-width.

Zadanie 5 – Marginesy i wysokość

Rozbuduj stronę o dodatkową sekcję informacyjną.

  1. Dodaj sekcję z nagłówkiem i dłuższym akapitem.
  2. Ustaw padding: 25px.
  3. Dodaj margin-top: 30px.
  4. Dodaj lewe obramowanie o grubości 5px.
  5. Ustaw min-height: 150px.
  6. Sprawdź, co się stanie po dodaniu większej ilości tekstu.
  7. Porównaj działanie min-height i height.

Zadanie 6 – Analiza w DevTools (dodatkowe)

  1. Otwórz stronę w przeglądarce Chrome lub Edge.
  2. Kliknij kartę prawym przyciskiem myszy.
  3. Wybierz Zbadaj.
  4. Odszukaj schemat modelu pudełkowego.
  5. Sprawdź wartości width, padding, border i margin.
  6. Porównaj odczytane wartości z obliczeniami z zadania 2.
  7. Zapisz krótką obserwację w komentarzu w pliku CSS.
