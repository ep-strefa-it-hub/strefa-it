Składnia języka HTML. Znaczniki, elementy, atrybuty i zasady poprawnego zagnieżdżania

Cel główny: Poznanie zasad składni języka HTML oraz nabycie umiejętności poprawnego zapisywania znaczników, elementów i atrybutów, a także prawidłowego zagnieżdżania elementów w dokumencie HTML.

1. Czym jest składnia języka HTML?

Każdy język komputerowy posiada określone zasady zapisu. Zasady te nazywamy składnią.

W HTML składnia określa między innymi:

  • jak zapisujemy znaczniki,
  • gdzie umieszczamy atrybuty,
  • jak zapisujemy wartości atrybutów,
  • które elementy posiadają znacznik zamykający,
  • w jaki sposób elementy mogą być umieszczane jeden wewnątrz drugiego,
  • jak zachować poprawną strukturę dokumentu.

Przykład:

<p>To jest akapit.</p>

Przeglądarka interpretuje ten zapis jako element będący akapitem tekstu.

2. Znaczniki HTML

Podstawą języka HTML są znaczniki.

Znacznik zapisuje się pomiędzy znakami < i >.

Przykłady:

<p>
<h1>
<strong>
<body>

Każdy znacznik ma określone znaczenie i pełni konkretną funkcję.

Przykład:

<h1>Moja pierwsza strona</h1>

Element <h1> oznacza nagłówek pierwszego poziomu.

3. Znacznik otwierający i zamykający

Wiele elementów HTML posiada dwa znaczniki.

Znacznik otwierający:

<p>

Znacznik zamykający:

</p>

Znacznik zamykający zawiera znak /.

Całość:

<p>To jest tekst.</p>

Można ją rozłożyć na części:

<p>             → znacznik otwierający
To jest tekst.   → zawartość
</p>            → znacznik zamykający

4. Znacznik a element HTML

Pojęcia znacznik i element nie oznaczają dokładnie tego samego.

Znacznik:

<p>

Element HTML:

<p>To jest akapit.</p>

Element obejmuje znaczniki oraz znajdującą się między nimi zawartość.

Inny przykład:

<h2>Moje zainteresowania</h2>

Tutaj:

  • <h2> – znacznik otwierający,
  • Moje zainteresowania – zawartość,
  • </h2> – znacznik zamykający,
  • całość – element HTML.

5. Elementy puste

Nie wszystkie elementy HTML posiadają zawartość i osobny znacznik zamykający.

Przykład:

<br>

Element br oznacza przejście do nowego wiersza.

Inny przykład:

<img src="kot.jpg" alt="Kot">

Element img służy do umieszczania obrazu.

Elementów pustych nie zapisuje się z osobną zawartością i znacznikiem zamykającym.

Przykładowe elementy puste:

<br>
<hr>
<img src="obraz.jpg" alt="Opis obrazu">
<meta charset="UTF-8">
<link rel="stylesheet" href="style.css">
<input type="text">

6. Atrybuty HTML

Element HTML może posiadać dodatkowe informacje opisujące jego właściwości.

Atrybut przekazuje dodatkową informację dotyczącą danego elementu HTML.

Przykład:

<html lang="pl">

Tutaj:

  • html – nazwa elementu,
  • lang – nazwa atrybutu,
  • "pl" – wartość atrybutu.
Atrybuty zapisuje się wewnątrz znacznika otwierającego.

7. Atrybut i jego wartość

Najczęściej spotykany zapis atrybutu ma postać: 

nazwa="wartość"

Przykład:

<a href="https://example.com">Otwórz stronę</a>

Tutaj:

  • a – nazwa elementu,
  • href – atrybut,
  • "https://example.com" – wartość atrybutu,
  • Otwórz stronę – zawartość elementu.

Atrybut href określa adres, do którego prowadzi odnośnik.

8. Jeden element może mieć kilka atrybutów

Przykład:

<img src="kwiaty.jpg" alt="Kwiaty na łące" width="400">

Element img posiada trzy atrybuty:

Atrybut Znaczenie
src określa źródło obrazu
alt zawiera tekst alternatywny
width określa szerokość obrazu

Kolejne atrybuty oddziela się od siebie spacją.

9. Atrybut id

Atrybut id pozwala nadać elementowi unikalny identyfikator. 

<h2 id="kontakt">Kontakt</h2>

Identyfikator może być później wykorzystywany między innymi w CSS, JavaScript lub odnośnikach prowadzących do konkretnego miejsca strony.

W obrębie jednego dokumentu dana wartość id powinna identyfikować tylko jeden element.

10. Atrybut class

Atrybut class pozwala przypisać element do określonej klasy. 

<p class="wazne">Ważna informacja</p>

Ta sama klasa może być użyta dla wielu elementów: 

<p class="wazne">Pierwsza informacja</p>
<p class="wazne">Druga informacja</p>
id identyfikuje konkretny element, natomiast ta sama class może być przypisana wielu elementom.

11. Zagnieżdżanie elementów

HTML ma strukturę hierarchiczną. Jeden element może zawierać inne elementy.

Przykład:

<p>
    Uczę się <strong>języka HTML</strong>.
</p>

Element strong znajduje się wewnątrz elementu p.

Umieszczanie jednego elementu wewnątrz innego nazywa się zagnieżdżaniem.

12. Element nadrzędny i podrzędny

Przykład:

<div>
    <p>To jest akapit.</p>
</div>

Element div zawiera element p.

  • div jest elementem nadrzędnym – rodzicem,
  • p jest elementem podrzędnym – dzieckiem.

Bardziej rozbudowany przykład:

<body>
    <main>
        <section>
            <h2>Aktualności</h2>
            <p>Treść aktualności.</p>
        </section>
    </main>
</body>

Hierarchia elementów:

body
└── main
    └── section
        ├── h2
        └── p

13. Elementy rodzeństwa

Elementy mające tego samego bezpośredniego rodzica można określić jako elementy rodzeństwa. 

<section>
    <h2>O mnie</h2>
    <p>Mam na imię Anna.</p>
    <p>Interesuję się informatyką.</p>
</section>

Elementy h2 i oba elementy p są bezpośrednimi dziećmi elementu section.

14. Poprawne zagnieżdżanie

Jeżeli jeden element zostanie otwarty wewnątrz drugiego, należy go zamknąć przed zamknięciem elementu nadrzędnego.

Poprawny zapis:

<p>
    To jest <strong>ważna informacja</strong>.
</p>

Można to przedstawić jako:

<p>
    <strong>
    </strong>
</p>
Element otwarty jako ostatni należy zamknąć jako pierwszy.

15. Błędne zagnieżdżanie

Niepoprawny przykład:

<p>
    To jest <strong>ważna informacja.
</p>
</strong>

Element strong został otwarty wewnątrz elementu p, ale element p zamknięto wcześniej.

Poprawna wersja:

<p>
    To jest <strong>ważna informacja</strong>.
</p>

16. Wcięcia i czytelność kodu

Przeglądarka często odczyta kod również wtedy, gdy wszystkie znaczniki znajdują się przy lewej krawędzi.

Mało czytelny zapis:

<body>
<main>
<section>
<h2>O mnie</h2>
<p>To jest moja strona.</p>
</section>
</main>
</body>

Czytelniejszy zapis:

<body>
    <main>
        <section>
            <h2>O mnie</h2>
            <p>To jest moja strona.</p>
        </section>
    </main>
</body>
Wcięcia pozwalają szybciej rozpoznać strukturę dokumentu i ułatwiają wyszukiwanie błędów.

17. Wielkość liter w HTML

W składni HTML nazwy elementów nie są rozróżniane ze względu na wielkość liter.

Przeglądarka może więc zinterpretować:

<P>Tekst</P>

oraz:

<p>Tekst</p>

Przyjętą i zalecaną praktyką jest jednak zapisywanie nazw elementów oraz atrybutów małymi literami. 

<p class="opis">Tekst</p>

18. Cudzysłowy w wartościach atrybutów

Wartości atrybutów najlepiej zapisywać w cudzysłowie.

Przykład:

<img src="zdjecie.jpg" alt="Moje zdjęcie">

Cudzysłów jest szczególnie istotny wtedy, gdy wartość zawiera spacje: 

alt="Zdjęcie mojego kota"
W materiałach i własnym kodzie przyjmujemy zasadę: wartości atrybutów zapisujemy w cudzysłowie.

19. Kolejność atrybutów

Element może posiadać kilka atrybutów. 

<img src="pies.jpg" alt="Pies" width="300">

Możliwy jest również zapis: 

<img width="300" alt="Pies" src="pies.jpg">

Kolejność tych atrybutów nie zmienia podstawowego znaczenia elementu.

Dla czytelności warto jednak stosować konsekwentny sposób zapisu.

20. Komentarze w HTML

Komentarz w HTML zapisuje się:

<!-- To jest komentarz -->

Komentarz:

  • jest widoczny w kodzie źródłowym,
  • nie jest wyświetlany jako zwykła treść strony,
  • może służyć do opisywania fragmentów kodu.

Przykład:

<!-- Sekcja z informacjami o autorze -->
<section>
    <h2>O mnie</h2>
    <p>Mam na imię Jan.</p>
</section>

21. Najczęstsze błędy składniowe

Brak znacznika zamykającego

Błędnie:

<p>Pierwszy akapit
<p>Drugi akapit

W nauce poprawnego zapisu stosujemy:

<p>Pierwszy akapit</p>
<p>Drugi akapit</p>

Brak znaku >

Błędnie:

<h1 Tytuł strony</h1>

Poprawnie:

<h1>Tytuł strony</h1>

Błędnie zapisany znacznik zamykający

Błędnie:

<p>Tekst<p/>

Poprawnie:

<p>Tekst</p>

Atrybut poza znacznikiem

Błędnie:

<img> src="kot.jpg"

Poprawnie:

<img src="kot.jpg" alt="Kot">

Niepoprawne zagnieżdżenie

Błędnie:

<p><strong>Tekst</p></strong>

Poprawnie:

<p><strong>Tekst</strong></p>

22. Przeglądarka czasami poprawia nasze błędy

Kod HTML może zawierać błąd, a strona mimo wszystko może wyglądać poprawnie.

Przeglądarki próbują interpretować niepoprawny HTML i w wielu sytuacjach automatycznie tworzą strukturę, która pozwala wyświetlić stronę.

Nie stosujemy zasady: „Skoro działa, to jest dobrze”.
Kod powinien być poprawny, czytelny i zgodny ze standardem HTML.

23. Walidacja kodu HTML

Walidacja polega na sprawdzeniu, czy dokument jest zgodny z regułami składni HTML.

Walidator może wskazać między innymi:

  • niepoprawne znaczniki,
  • błędy struktury dokumentu,
  • niepoprawnie użyte atrybuty,
  • inne problemy ze składnią HTML.
Otwórz walidator HTML
Brak widocznego błędu w przeglądarce nie jest dowodem poprawności kodu.

📌 Zapamiętaj

  • HTML opisuje strukturę i znaczenie treści strony.
  • Znaczniki zapisuje się pomiędzy znakami < i >.
  • Wiele elementów posiada znacznik otwierający i zamykający.
  • Znacznik i element HTML nie oznaczają dokładnie tego samego.
  • Niektóre elementy HTML są elementami pustymi i nie mają osobnego znacznika zamykającego.
  • Element może posiadać atrybuty.
  • Atrybuty umieszcza się w znaczniku otwierającym.
  • Wartości atrybutów zapisujemy w cudzysłowie.
  • Atrybut id powinien identyfikować konkretny element, a ta sama class może być używana wielokrotnie.
  • Elementy HTML mogą być zagnieżdżane.
  • Element otwarty jako ostatni należy zamknąć jako pierwszy.
  • Wcięcia pomagają odczytać strukturę dokumentu.
  • Nazwy elementów i atrybutów zapisujemy małymi literami.
  • To, że przeglądarka wyświetla stronę, nie oznacza jeszcze, że kod jest poprawny.
  • Walidator pomaga odnajdywać błędy składni HTML.

📝 Zadania

Zadanie 1. Rozpoznaj elementy kodu

Dla kodu:

<a href="kontakt.html">Kontakt</a>

Wskaż:

  1. znacznik otwierający,
  2. znacznik zamykający,
  3. nazwę elementu,
  4. atrybut,
  5. wartość atrybutu,
  6. zawartość elementu.

Zadanie 2. Znajdź błędy

Popraw poniższy kod:

<h1>Moja strona<h1>
<p>Uczę się <strong>języka HTML.</p></strong>
<img> src="komputer.jpg" alt="Komputer"
<p class="opis>HTML jest językiem znaczników.</p>

Po poprawieniu sprawdź dokument w przeglądarce.

Zadanie 3. Zagnieżdżanie

Utwórz fragment strony zawierający:

  • nagłówek h2,
  • pod nim akapit p,
  • w akapicie jedno słowo wyróżnione elementem strong,
  • drugie słowo wyróżnione elementem em.

Zadanie 4. Atrybuty

Utwórz element obrazu i dodaj do niego atrybuty określające:

  • nazwę pliku obrazu,
  • tekst alternatywny,
  • szerokość 300.

Zadanie 5. Hierarchia elementów

Przeanalizuj kod:

<main>
    <section>
        <h2>Moje hobby</h2>
        <p>Interesuję się fotografią.</p>
        <p>Lubię również programowanie.</p>
    </section>
</main>

Odpowiedz:

  1. Który element jest rodzicem elementu section?
  2. Które elementy są dziećmi elementu section?
  3. Które elementy są względem siebie rodzeństwem?
  4. Który element znajduje się najwyżej w przedstawionej strukturze?

Zadanie 6. Utwórz poprawny fragment HTML

Napisz kod zawierający:

  • element div,
  • wewnątrz niego nagłówek h2,
  • dwa akapity,
  • w pierwszym akapicie element strong,
  • w drugim akapicie element em.

Zadbaj o poprawne zagnieżdżenie oraz czytelne wcięcia.

Zadanie 7. Popraw czytelność kodu

Otrzymujesz kod:

<body><main><section><h2>O mnie</h2><p>Uczę się HTML.</p><p>Tworzę swoją pierwszą stronę.</p></section></main></body>

Przepisz go tak, aby dzięki odpowiednim wcięciom jego struktura była od razu widoczna.

Zadanie 8. Samodzielny fragment strony

Utwórz dokument HTML zawierający:

  • poprawną podstawową strukturę dokumentu HTML5 poznaną na poprzedniej lekcji,
  • tytuł strony,
  • nagłówek,
  • dwa akapity,
  • wyróżnienie strong,
  • wyróżnienie em,
  • obraz z atrybutami src i alt,
  • co najmniej jeden element posiadający id,
  • co najmniej dwa elementy posiadające tę samą class,
  • komentarz HTML.

Zwróć szczególną uwagę na poprawne zagnieżdżanie elementów oraz czytelne wcięcia.
