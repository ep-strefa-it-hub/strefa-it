Selektory złożone, potomków, dzieci i elementów sąsiadujących

Cel lekcji: poznanie selektorów złożonych CSS, rozróżnianie relacji pomiędzy elementami HTML, stosowanie selektorów potomków, dzieci oraz elementów sąsiadujących, a także tworzenie precyzyjnych reguł CSS bez konieczności przypisywania osobnej klasy każdemu elementowi.

1. Wprowadzenie

W poprzedniej lekcji poznaliśmy selektory elementów, klas i identyfikatorów.

Wiemy już, że selektor p wskazuje wszystkie akapity, .wazne wskazuje elementy z określoną klasą, a #tytul element z konkretnym identyfikatorem.

W rozbudowanej stronie internetowej nie zawsze chcemy jednak stylować wszystkie elementy tego samego typu.

Możemy na przykład chcieć:

  • Zmienić kolor akapitów tylko w sekcji „Aktualności”.
  • Ostylować wyłącznie bezpośrednie elementy listy.
  • Wyróżnić pierwszy akapit znajdujący się po nagłówku.
  • Zmienić wygląd wszystkich akapitów następujących po określonym nagłówku.
  • Nadać inny wygląd odnośnikom w menu niż odnośnikom w treści strony.

W takich sytuacjach wykorzystujemy selektory złożone i kombinatory CSS.

📌 Ważne

Kombinator określa relację między elementami HTML. Dzięki niemu możemy wskazywać elementy na podstawie ich położenia w strukturze dokumentu.

2. Struktura dokumentu HTML – rodzice, dzieci i rodzeństwo

Aby zrozumieć selektory złożone, należy najpierw poznać relacje między elementami HTML.

Elementy dokumentu tworzą strukturę przypominającą drzewo, nazywaną drzewem DOM.

Przykładowa struktura HTML

<section>

    <h2>Aktualności</h2>

    <p>Pierwsza wiadomość.</p>

    <div>

        <p>Druga wiadomość.</p>

    </div>

    <p>Trzecia wiadomość.</p>

</section>

Element nadrzędny – rodzic

Element section jest rodzicem elementów:

  • h2,
  • pierwszego p,
  • div,
  • ostatniego p.

Element potomny – dziecko

Dziecko to element znajdujący się bezpośrednio wewnątrz elementu nadrzędnego.

Akapit wewnątrz div jest dzieckiem tego elementu div, ale nie jest bezpośrednim dzieckiem elementu section.

Potomek

Potomkiem jest element znajdujący się wewnątrz innego elementu na dowolnym poziomie zagnieżdżenia.

Wszystkie trzy akapity są potomkami elementu section.

Rodzeństwo

Elementy mające tego samego bezpośredniego rodzica nazywamy rodzeństwem.

W naszym przykładzie nagłówek h2, pierwszy akapit, element div i ostatni akapit są elementami rodzeństwa.

📌 Zapamiętaj

Każde dziecko jest potomkiem, ale nie każdy potomek jest bezpośrednim dzieckiem. To rozróżnienie jest kluczowe dla selektorów A B i A > B.

3. Czym są selektory złożone?

Selektory złożone pozwalają wybierać elementy na podstawie kilku warunków lub relacji występujących w strukturze HTML.

Przykłady

/* Akapity wewnątrz sekcji */

section p {
    color: blue;
}

/* Bezpośrednie dzieci listy */

ul > li {
    color: green;
}

/* Akapit bezpośrednio po nagłówku */

h2 + p {
    font-weight: bold;
}

/* Akapity następujące po nagłówku */

h2 ~ p {
    color: darkred;
}

Podstawowe kombinatory

Kombinator Nazwa Znaczenie
A B Potomka B znajdujące się wewnątrz A na dowolnym poziomie.
A > B Dziecka B będące bezpośrednim dzieckiem A.
A + B Bezpośredniego rodzeństwa B występujące bezpośrednio po A i mające tego samego rodzica.
A ~ B Następującego rodzeństwa B występujące później niż A i mające tego samego rodzica.

Litery A i B oznaczają przykładowe selektory. Mogą to być nazwy elementów, klasy lub identyfikatory.

4. Selektor potomków – spacja

Selektor potomków pozwala wskazać elementy znajdujące się wewnątrz innego elementu, niezależnie od poziomu zagnieżdżenia.

Składnia

A B {
    właściwość: wartość;
}

Między selektorami występuje spacja.

Przykład – akapity w sekcji

HTML:

<section class="aktualnosci">

    <h2>Aktualności</h2>

    <p>Pierwsza wiadomość.</p>

    <div>
        <p>Druga wiadomość.</p>
    </div>

</section>

<p>Akapit poza sekcją.</p>

CSS:

.aktualnosci p {
    color: blue;
}

Wynik

  • Pierwsza wiadomość – niebieska.
  • Druga wiadomość – niebieska.
  • Akapit poza sekcją – bez tego stylu.

Drugi akapit również zostanie wskazany, ponieważ jest potomkiem sekcji, mimo że znajduje się wewnątrz dodatkowego elementu div.

Przykład – odnośniki w menu

<nav>

    <a href="index.html">Start</a>

    <a href="oferta.html">Oferta</a>

</nav>

<p>
    <a href="kontakt.html">Kontakt</a>
</p>
nav a {
    color: white;
    background-color: navy;
}

Styl otrzymają tylko odnośniki znajdujące się wewnątrz elementu nav.

Przykład – lista wewnątrz artykułu

article li {
    color: darkgreen;
}

Reguła wskazuje wszystkie elementy li znajdujące się wewnątrz elementu article.

📌 Ważne

Spacja w selektorze oznacza relację potomka. Nie oznacza koniecznie bezpośredniego zagnieżdżenia.

5. Selektor dzieci – znak >

Selektor dzieci wskazuje wyłącznie elementy, które są bezpośrednimi dziećmi wskazanego elementu nadrzędnego.

Składnia

A > B {
    właściwość: wartość;
}

Przykład

HTML:

<section class="oferta">

    <p>Pierwszy akapit.</p>

    <div>

        <p>Drugi akapit.</p>

    </div>

    <p>Trzeci akapit.</p>

</section>

CSS:

.oferta > p {
    color: red;
}

Wynik

  • Pierwszy akapit – czerwony.
  • Drugi akapit – nie otrzyma bezpośrednio tej reguły.
  • Trzeci akapit – czerwony.

Drugi akapit znajduje się wewnątrz div, więc nie jest bezpośrednim dzieckiem sekcji.

Uwaga: jeśli kolor jest właściwością dziedziczoną z innego elementu, akapit może wyglądać podobnie mimo niedopasowania tej reguły. W tym przykładzie nie ma jednak takiego dodatkowego stylu.

Przykład – zagnieżdżona lista

HTML:

<ul class="menu">

    <li>Start</li>

    <li>Oferta

        <ul>
            <li>Komputery</li>
            <li>Monitory</li>
        </ul>

    </li>

    <li>Kontakt</li>

</ul>

CSS:

.menu > li {
    border: 1px solid navy;
    padding: 10px;
}

Obramowanie i odstęp wewnętrzny otrzymają trzy główne elementy listy. Elementy li z listy zagnieżdżonej nie zostaną bezpośrednio wskazane przez tę regułę.

📌 Zapamiętaj

Znak > ogranicza wybór do bezpośrednich dzieci. Jest szczególnie przydatny przy listach zagnieżdżonych, menu i rozbudowanych sekcjach.

6. Selektor potomków a selektor dzieci

Porównajmy dwa bardzo podobne zapisy CSS. 

.kontener p {
    color: blue;
}

.kontener > p {
    font-weight: bold;
}

HTML:

<div class="kontener">

    <p>Akapit A</p>

    <section>

        <p>Akapit B</p>

    </section>

    <p>Akapit C</p>

</div>

Analiza

Akapit .kontener p .kontener > p
A Tak Tak
B Tak Nie
C Tak Tak

Wynik: wszystkie akapity będą niebieskie, ale tylko A i C będą pogrubione.

Kiedy wybrać który selektor?

  • A B – gdy chcemy wskazać wszystkie pasujące elementy wewnątrz A, także głęboko zagnieżdżone.
  • A > B – gdy chcemy wskazać tylko elementy B znajdujące się bezpośrednio w A.

7. Selektor bezpośredniego rodzeństwa – znak +

Selektor z kombinatoriem + wskazuje element, który występuje bezpośrednio po innym elemencie i ma z nim tego samego rodzica.

Składnia

A + B {
    właściwość: wartość;
}

Przykład – pierwszy akapit po nagłówku

HTML:

<h2>Aktualności</h2>

<p>Pierwszy akapit.</p>

<p>Drugi akapit.</p>

<p>Trzeci akapit.</p>

CSS:

h2 + p {
    color: red;
    font-weight: bold;
}

Wynik: tylko pierwszy akapit będzie czerwony i pogrubiony.

Dlaczego tylko pierwszy?

Ponieważ bezpośrednio po nagłówku h2 znajduje się pierwszy akapit.

Drugi akapit występuje bezpośrednio po pierwszym akapicie, a nie po nagłówku.

Przykład – element pomiędzy nagłówkiem a akapitem

<h2>Aktualności</h2>

<hr>

<p>Pierwszy akapit.</p>
h2 + p {
    color: red;
}

Tym razem akapit nie zostanie wskazany, ponieważ bezpośrednio po nagłówku występuje element hr.

Przykład – odstępy między akapitami

p + p {
    margin-top: 20px;
}

Reguła wskazuje akapit, który występuje bezpośrednio po innym akapicie.

📌 Ważne

Kombinator + wskazuje drugi element, czyli ten znajdujący się po lewej stronie warunku w strukturze dokumentu. W zapisie h2 + p stylowany jest akapit, a nie nagłówek.

8. Selektor następującego rodzeństwa – znak ~

Selektor z kombinatoriem ~ wskazuje wszystkie pasujące elementy, które występują później niż wskazany element i mają z nim tego samego rodzica.

Składnia

A ~ B {
    właściwość: wartość;
}

Przykład – akapity po nagłówku

HTML:

<h2>Aktualności</h2>

<p>Pierwszy akapit.</p>

<p>Drugi akapit.</p>

<div>
    Dodatkowa informacja.
</div>

<p>Trzeci akapit.</p>

CSS:

h2 ~ p {
    color: green;
}

Wynik

  • Pierwszy akapit – zielony.
  • Drugi akapit – zielony.
  • Trzeci akapit – zielony.
  • Element div – bez tego stylu.

Element div znajdujący się pomiędzy akapitami nie przeszkadza w dopasowaniu trzeciego akapitu.

Ważne ograniczenie – wspólny rodzic

HTML:

<section>

    <h2>Informacje</h2>

    <p>Akapit A</p>

    <div>
        <p>Akapit B</p>
    </div>

    <p>Akapit C</p>

</section>

CSS:

h2 ~ p {
    color: purple;
}

Reguła wskaże akapity A i C.

Nie wskaże akapitu B, ponieważ znajduje się wewnątrz div i nie jest rodzeństwem nagłówka h2.

📌 Zapamiętaj

Kombinator ~ wskazuje pasujące elementy znajdujące się później wśród rodzeństwa. Nie wybiera elementów wcześniejszych ani potomków innych elementów rodzeństwa.

9. Porównanie selektorów + i ~

Oba selektory dotyczą elementów rodzeństwa, ale różnią się zakresem działania.

Przykładowy HTML

<h2>Wiadomości</h2>

<p>Akapit 1</p>

<p>Akapit 2</p>

<hr>

<p>Akapit 3</p>

Selektor +

h2 + p {
    color: red;
}

Czerwony będzie tylko akapit 1.

Selektor ~

h2 ~ p {
    color: green;
}

Zielone będą akapity 1, 2 i 3.

Porównanie

Cecha + ~
Wymaga wspólnego rodzica Tak Tak
Element musi występować później Tak Tak
Element musi występować bezpośrednio po A Tak Nie
Może wskazać kilka elementów po jednym A Nie Tak

📌 Ważne

Kombinatory + i ~ działają zgodnie z kolejnością elementów w HTML. Nie oznaczają położenia elementów na ekranie.

10. Łączenie kilku selektorów złożonych

W jednej regule CSS można połączyć kilka selektorów i kombinatorów.

Dzięki temu możemy wskazywać bardzo konkretne elementy bez przypisywania im dodatkowych klas.

Przykład – akapity w kartach produktów

.sklep .produkt p {
    color: darkblue;
}

Reguła wskazuje akapity znajdujące się wewnątrz elementów z klasą produkt, które są potomkami elementu z klasą sklep.

Przykład – bezpośrednie elementy menu

nav > ul > li {
    padding: 10px;
}

Reguła wskazuje elementy li, które są bezpośrednimi dziećmi listy ul, będącej bezpośrednim dzieckiem elementu nav.

Przykład – pierwszy akapit po nagłówku w artykule

article h2 + p {
    font-weight: bold;
}

Reguła wskazuje akapit znajdujący się bezpośrednio po nagłówku h2, jeżeli ten nagłówek znajduje się wewnątrz elementu article.

Przykład – klasa i selektor dziecka

.karta > .cena {
    color: darkgreen;
    font-weight: bold;
}

Reguła wskazuje element z klasą cena, który jest bezpośrednim dzieckiem elementu z klasą karta.

Przykład – grupowanie selektorów złożonych

header h1, footer p {
    text-align: center;
}

Reguła wskazuje:

  • Nagłówki h1 wewnątrz header.
  • Akapity wewnątrz footer.

📌 Dobra praktyka

Nie twórz niepotrzebnie bardzo długich selektorów. Im mocniej styl zależy od konkretnej struktury HTML, tym łatwiej go przypadkowo zepsuć podczas przebudowy strony.

11. Specyficzność selektorów złożonych

Selektory złożone również uczestniczą w mechanizmie kaskadowości CSS.

Specyficzność zależy od użytych selektorów prostych. Same kombinatory >, +, ~ i spacja nie zwiększają specyficzności.

Przykłady

Selektor Specyficzność
p 0-0-1
section p 0-0-2
section > p 0-0-2
h2 + p 0-0-2
.oferta p 0-1-1
.oferta > p.wazne 0-2-1
#kontakt p 1-0-1

Przykład – konflikt reguł

HTML:

<section class="oferta">

    <p>Opis oferty.</p>

</section>

CSS:

p {
    color: blue;
}

.oferta p {
    color: red;
}

Wynik: akapit będzie czerwony, ponieważ selektor .oferta p ma większą specyficzność.

Przykład – dwa selektory o takiej samej specyficzności

section p {
    color: blue;
}

section > p {
    color: green;
}

Dla akapitu będącego bezpośrednim dzieckiem sekcji obie reguły pasują i mają taką samą specyficzność.

Jeżeli pozostałe warunki kaskady są jednakowe, wygra reguła zapisana później, czyli kolor zielony.

12. Praktyczne zastosowania selektorów złożonych

Przykład 1 – odnośniki w menu

nav a {
    color: white;
    background-color: navy;
    padding: 10px;
}

Stylujemy tylko odnośniki znajdujące się wewnątrz menu.

Przykład 2 – główne elementy listy

.menu > li {
    font-weight: bold;
}

Wskazujemy główne elementy listy, pomijając głębiej zagnieżdżone elementy li.

Przykład 3 – wprowadzenie do artykułu

article h2 + p {
    font-size: 20px;
    font-weight: bold;
}

Wyróżniamy pierwszy akapit następujący bezpośrednio po nagłówku drugiego poziomu wewnątrz artykułu.

Przykład 4 – wszystkie późniejsze akapity

.opis h3 ~ p {
    color: darkgreen;
}

Wskazujemy akapity będące późniejszym rodzeństwem nagłówka h3 wewnątrz elementu z klasą opis.

Przykład 5 – ceny w kartach produktów

.karta-produktu > .cena {
    color: darkred;
    font-weight: bold;
}

Wskazujemy ceny będące bezpośrednimi dziećmi kart produktów.

13. Najczęstsze błędy

Błąd 1 – mylenie spacji ze znakiem >

/* Wszyscy potomkowie p */

.oferta p {
    color: blue;
}


/* Tylko bezpośrednie dzieci p */

.oferta > p {
    color: red;
}

To nie są równoważne selektory.

Błąd 2 – oczekiwanie, że + wskaże wszystkie akapity

h2 + p {
    color: red;
}

Ten selektor wskazuje wyłącznie akapit będący bezpośrednim następnym rodzeństwem nagłówka h2.

Błąd 3 – zakładanie, że ~ działa na elementy wcześniejsze

<p>Akapit przed nagłówkiem.</p>

<h2>Nagłówek</h2>

<p>Akapit po nagłówku.</p>
h2 ~ p {
    color: green;
}

Zielony będzie tylko akapit znajdujący się po nagłówku.

Błąd 4 – pomijanie wspólnego rodzica

<section>

    <h2>Tytuł</h2>

    <div>
        <p>Opis</p>
    </div>

</section>
h2 + p {
    color: red;
}

Reguła nie wskaże akapitu, ponieważ bezpośrednio po nagłówku występuje element div.

Błąd 5 – niepotrzebnie długie selektory

/* Zbyt zależny od struktury */

body main section article div p {
    color: blue;
}


/* Często prostsze rozwiązanie */

.opis-artykulu {
    color: blue;
}

Selektory złożone są przydatne, ale nie zastępują dobrze zaprojektowanych klas.

Błąd 6 – mylenie przecinka ze spacją

/* Nagłówki h2 oraz akapity */

h2, p {
    color: blue;
}


/* Akapity wewnątrz h2 */

h2 p {
    color: blue;
}

Drugi selektor opisuje inną relację i nie jest prawidłowym sposobem grupowania nagłówków i akapitów.

14. Kompletny przykład – portal informacyjny

    background-color: white;
    padding: 20px;
    margin: 20px;
}

/* Akapity wewnątrz wiadomości */

.wiadomosc p {
    color: darkslategray;
}

/* Pierwszy akapit po h3 */

.wiadomosc h3 + p {
    font-weight: bold;
    color: darkred;
}

/* Późniejsze akapity rodzeństwa h3 */

.wiadomosc h3 ~ p {
    font-size: 18px;
}

/* Główne kategorie listy */

.kategorie > li {
    border: 1px solid gray;
    padding: 10px;
    margin: 5px;
}

/* Akapity w stopce */

footer p {
    text-align: center;
    font-size: 14px;
}

Analiza zastosowanych selektorów

Selektor Co wskazuje?
nav a Odnośniki wewnątrz menu.
.menu > li Bezpośrednie elementy listy menu.
.wiadomosc p Wszystkie akapity wewnątrz wiadomości.
.wiadomosc h3 + p Akapit bezpośrednio po nagłówku h3.
.wiadomosc h3 ~ p Akapity będące późniejszym rodzeństwem nagłówka h3.
.kategorie > li Główne elementy listy kategorii.
footer p Akapity wewnątrz stopki.

📌 Zwróć uwagę

W przykładzie reguła .wiadomosc h3 + p nadaje pierwszemu akapitowi pogrubienie i ciemnoczerwony kolor. Reguła .wiadomosc h3 ~ p ustawia rozmiar czcionki późniejszych akapitów będących rodzeństwem nagłówka. Obie reguły mogą działać jednocześnie na pierwszy akapit.

📌 Zapamiętaj

  • Selektory złożone pozwalają wskazywać elementy na podstawie relacji w HTML.
  • Dokument HTML tworzy strukturę drzewa DOM.
  • Rodzic to element bezpośrednio nadrzędny.
  • Dziecko to element bezpośrednio zagnieżdżony w rodzicu.
  • Potomek może znajdować się na dowolnym poziomie zagnieżdżenia.
  • Rodzeństwo to elementy mające tego samego rodzica.
  • A B wskazuje potomków B wewnątrz A.
  • A > B wskazuje bezpośrednie dzieci B elementu A.
  • A + B wskazuje B występujące bezpośrednio po A wśród rodzeństwa.
  • A ~ B wskazuje B występujące później niż A wśród rodzeństwa.
  • Selektory + i ~ wymagają wspólnego rodzica.
  • Spacja i znak > nie oznaczają tego samego.
  • Selektory złożone można łączyć z klasami i identyfikatorami.
  • Kombinatory same nie zwiększają specyficzności selektora.
  • Warto stosować możliwie czytelne i niezbyt rozbudowane selektory.

📝 Zadania praktyczne

Cel: samodzielne stosowanie selektorów potomków, dzieci i elementów sąsiadujących oraz rozpoznawanie relacji w strukturze HTML.

Utwórz folder PSI_19, a w nim pliki: index.html oraz style.css.

Wszystkie zadania wykonaj w jednym projekcie. Każde zadanie umieść w osobnej sekcji strony.

Zadanie 1 – Selektor potomków

Przygotuj sekcję „Aktualności technologiczne”.

  1. Utwórz element section z klasą aktualnosci.
  2. Dodaj nagłówek h2.
  3. Dodaj dwa akapity bezpośrednio wewnątrz sekcji.
  4. Dodaj element div, a wewnątrz niego kolejny akapit.
  5. Dodaj jeden akapit poza sekcją.
  6. Za pomocą selektora .aktualnosci p ustaw niebieski kolor tekstu.
  7. Sprawdź, które akapity otrzymały ten styl.
  8. Dodaj do sekcji kolejne zagnieżdżenie i sprawdź, czy selektor nadal działa.

Zadanie 2 – Selektor dzieci

Dodaj sekcję „Kategorie produktów”.

  1. Utwórz listę ul z klasą kategorie.
  2. Dodaj trzy główne elementy listy.
  3. W drugim elemencie umieść zagnieżdżoną listę z trzema podkategoriami.
  4. Za pomocą selektora .kategorie > li ustaw obramowanie głównych elementów listy.
  5. Dodaj odstęp wewnętrzny padding: 10px;.
  6. Sprawdź, czy podkategorie otrzymały własne obramowanie z tej reguły.
  7. Dodaj regułę .kategorie li ustawiającą kolor tekstu.
  8. Porównaj działanie obu selektorów.

Zadanie 3 – Bezpośredni sąsiad +

Dodaj sekcję „Artykuł informatyczny”.

  1. Utwórz element article.
  2. Dodaj nagłówek h2.
  3. Dodaj trzy akapity tekstu.
  4. Za pomocą selektora article h2 + p ustaw czerwony kolor pierwszego akapitu.
  5. Dodaj pogrubienie pierwszego akapitu.
  6. Sprawdź, czy pozostałe akapity zachowały swój wygląd.
  7. Wstaw element hr między nagłówkiem a pierwszym akapitem.
  8. Sprawdź, co się zmieniło.
  9. Usuń element hr, aby przywrócić poprzedni efekt.

Zadanie 4 – Następujące rodzeństwo ~

Rozbuduj artykuł z poprzedniego zadania.

  1. Dodaj czwarty akapit.
  2. Za pomocą selektora article h2 ~ p ustaw zielony kolor tekstu akapitów.
  3. Sprawdź, które akapity zostały wskazane.
  4. Dodaj element div między drugim a trzecim akapitem.
  5. Wewnątrz div umieść dodatkowy akapit.
  6. Sprawdź, czy akapit zagnieżdżony w div został wskazany przez selektor h2 ~ p.
  7. Porównaj działanie selektorów h2 + p oraz h2 ~ p.

Zadanie 5 – Analiza selektorów (dodatkowe)

Przeanalizuj poniższy kod HTML: 

<div class="kontener">

    <h2>Tytuł</h2>

    <p>Akapit A</p>

    <section>

        <p>Akapit B</p>

    </section>

    <p>Akapit C</p>

    <p>Akapit D</p>

</div>

Odpowiedz na pytania w postaci listy numerowanej na swojej stronie:

  1. Które akapity wskazuje .kontener p?
  2. Które akapity wskazuje .kontener > p?
  3. Które akapity wskazuje h2 + p?
  4. Które akapity wskazuje h2 ~ p?
  5. Dlaczego akapit B nie jest bezpośrednim dzieckiem elementu div z klasą kontener?
