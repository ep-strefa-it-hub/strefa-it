Formatowanie tabel i formularzy za pomocą CSS

Cel lekcji: poznanie właściwości CSS służących do formatowania tabel, pól formularzy, etykiet, list wyboru i przycisków oraz samodzielne przygotowanie estetycznej i czytelnej strony zawierającej tabelę i formularz.

1. Wprowadzenie

Tabele i formularze są często wykorzystywane na stronach internetowych.

Tabele służą do przedstawiania danych w wierszach i kolumnach, np. cenników, planów zajęć i zestawień wyników.

Formularze umożliwiają użytkownikom wprowadzanie danych, np. podczas rejestracji, logowania, zamawiania produktów czy wysyłania wiadomości.

Za pomocą CSS możemy:

  • zmieniać obramowania i kolory komórek tabeli,
  • ustawiać szerokości kolumn i odstępy,
  • wyróżniać nagłówki i wybrane wiersze,
  • dodawać efekty po najechaniu kursorem,
  • formatować pola tekstowe i listy rozwijane,
  • zmieniać wygląd przycisków,
  • wyróżniać aktywne i niepoprawnie wypełnione pola,
  • dostosowywać układ do różnych ekranów.

📌 Zapamiętaj

HTML określa strukturę tabeli lub formularza, natomiast CSS odpowiada za jego wygląd. Sam CSS nie zapisuje danych przesłanych przez formularz.

2. Przypomnienie struktury tabeli HTML

Tabelę tworzymy za pomocą znacznika table.

Wewnątrz znajdują się wiersze tr oraz komórki th i td.

Przykład HTML

<table>

    <thead>
        <tr>
            <th>Produkt</th>
            <th>Cena</th>
            <th>Dostępność</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Klawiatura</td>
            <td>120 zł</td>
            <td>Dostępna</td>
        </tr>

        <tr>
            <td>Mysz</td>
            <td>80 zł</td>
            <td>Dostępna</td>
        </tr>
    </tbody>

</table>

Najważniejsze znaczniki

Znacznik Znaczenie
table Cała tabela
thead Sekcja nagłówkowa
tbody Sekcja z danymi
tr Wiersz tabeli
th Komórka nagłówkowa
td Komórka danych
caption Podpis tabeli

Dodawanie podpisu tabeli

<table>

    <caption>Cennik akcesoriów</caption>

    <tr>
        <th scope="col">Produkt</th>
        <th scope="col">Cena</th>
    </tr>

    <tr>
        <td>Klawiatura</td>
        <td>120 zł</td>
    </tr>

</table>

caption opisuje zawartość tabeli, a scope="col" określa, że komórka nagłówkowa odnosi się do danej kolumny.

📌 Ważne

Tabel używamy do prezentowania danych tabelarycznych, a nie do budowania układu całej strony.

3. Obramowania tabel – border i border-collapse

Do ustawiania obramowania tabeli i komórek służy właściwość border.

Przykład

table {
    border: 2px solid black;
}

th,
td {
    border: 1px solid gray;
}

Bez dodatkowego formatowania między obramowaniami komórek mogą być widoczne odstępy.

Łączenie obramowań

table {
    border-collapse: collapse;
}

Wartość collapse powoduje, że sąsiadujące obramowania komórek zostają połączone.

Wartości border-collapse

Wartość Działanie
separate Komórki zachowują osobne obramowania.
collapse Sąsiadujące obramowania są łączone.

Kompletny przykład

.tabela {
    width: 100%;
    border-collapse: collapse;
}

.tabela th,
.tabela td {
    border: 1px solid #CBD5E1;
}

📌 Zapamiętaj

border-collapse: collapse jest często stosowane podczas tworzenia klasycznych tabel z siatką.

4. Odstępy w tabelach – padding i border-spacing

Właściwość padding określa wewnętrzne odstępy między treścią komórki a jej obramowaniem.

Przykład

th,
td {
    padding: 12px;
}

Dzięki temu tekst nie przylega bezpośrednio do obramowania.

Różne odstępy

th {
    padding: 15px 20px;
}

td {
    padding: 10px 15px;
}

Pierwsza wartość oznacza odstęp górny i dolny, a druga – lewy i prawy.

Odstępy między komórkami – border-spacing

table {
    border-collapse: separate;
    border-spacing: 8px;
}

border-spacing określa odstępy między sąsiadującymi komórkami.

Właściwość ta działa przy modelu border-collapse: separate.

📌 Zapamiętaj

padding dodaje przestrzeń wewnątrz komórki, natomiast border-spacing ustawia odstępy między komórkami.

5. Szerokość i układ tabel

Szerokość tabeli można określić za pomocą właściwości width.

Przykład

table {
    width: 100%;
}

Tabela zajmie całą dostępną szerokość elementu nadrzędnego.

Ograniczenie szerokości

table {
    width: 100%;
    max-width: 900px;
}

Wyrównanie tekstu

th {
    text-align: center;
}

td {
    text-align: left;
}

Wyrównanie pionowe

td {
    vertical-align: middle;
}

Właściwość table-layout

table-layout określa sposób obliczania szerokości kolumn.

Wartość Znaczenie
auto Układ kolumn zależy między innymi od zawartości komórek.
fixed Układ kolumn wynika przede wszystkim z szerokości tabeli i określonych szerokości kolumn.

Przykład

.tabela {
    width: 100%;
    table-layout: fixed;
}

Przy układzie fixed należy zwrócić uwagę na długie wyrazy i adresy, które mogą wychodzić poza obszar komórki.

6. Formatowanie kolorów tabeli

Kolory pomagają wyróżnić nagłówki, ważne dane i poszczególne sekcje tabeli.

Kolor nagłówków

.tabela th {
    background-color: #1E3A8A;
    color: white;
}

Kolor komórek

.tabela td {
    background-color: #F8FAFC;
    color: #1F2937;
}

Wyróżnienie jednej komórki

<td class="wyrozniona">Promocja</td>
.wyrozniona {
    background-color: #DCFCE7;
    color: #166534;

    font-weight: bold;
}

Dzięki klasom możemy wyróżniać konkretne komórki bez zmieniania wyglądu całej tabeli.

📌 Dobra praktyka

Zadbaj o kontrast między kolorem tekstu i kolorem tła. Ważne informacje nie powinny być przekazywane wyłącznie kolorem.

7. Naprzemienne kolory wierszy – :nth-child()

Długie tabele są łatwiejsze do odczytania, gdy kolejne wiersze mają naprzemienne kolory tła.

Taki efekt nazywany jest często zebra stripes.

Przykład

.tabela tbody tr:nth-child(even) {
    background-color: #E2E8F0;
}

Wiersze parzyste otrzymają inne tło.

Wiersze nieparzyste

.tabela tbody tr:nth-child(odd) {
    background-color: #FFFFFF;
}

Co oznacza nth-child?

Selektor Działanie
:nth-child(even) Wybiera elementy parzyste.
:nth-child(odd) Wybiera elementy nieparzyste.
:nth-child(3) Wybiera trzeci element.
:first-child Wybiera pierwszy element.
:last-child Wybiera ostatni element.

Dlaczego tbody?

Selektor .tabela tbody tr ogranicza działanie do wierszy zawierających dane, bez obejmowania nagłówka znajdującego się w thead.

📌 Uwaga

Jeśli ustawisz nieprzezroczyste tło bezpośrednio dla wszystkich komórek td, kolor ustawiony na tr może nie być widoczny.

8. Efekt hover w tabeli

Możemy wyróżnić wiersz tabeli, na który użytkownik najedzie kursorem.

Przykład

.tabela tbody tr:hover {
    background-color: #BFDBFE;
}

Po wskazaniu wiersza jego tło zmieni kolor.

Płynna zmiana koloru

.tabela tbody tr {
    transition: background-color 0.2s;
}

.tabela tbody tr:hover {
    background-color: #BFDBFE;
}

transition powoduje płynne przejście między kolorami.

📌 Zapamiętaj

:hover działa nie tylko na odnośnikach. Można go stosować także do wierszy tabel, przycisków i innych elementów.

9. Tabele na małych ekranach

Rozbudowana tabela może nie mieścić się na ekranie telefonu.

Jednym z rozwiązań jest umieszczenie jej w kontenerze umożliwiającym przewijanie poziome.

HTML

<div class="tabela-przewijana">

    <table class="tabela">

        <tr>
            <th>Produkt</th>
            <th>Cena</th>
            <th>Producent</th>
            <th>Dostępność</th>
        </tr>

        <tr>
            <td>Klawiatura</td>
            <td>120 zł</td>
            <td>Firma A</td>
            <td>Dostępna</td>
        </tr>

    </table>

</div>

CSS

.tabela-przewijana {
    width: 100%;
    overflow-x: auto;
}

.tabela-przewijana .tabela {
    width: 100%;
    min-width: 650px;
}

Jeśli tabela będzie szersza niż kontener, użytkownik będzie mógł przewijać ją poziomo.

📌 Dobra praktyka

Nie usuwaj ważnych kolumn wyłącznie po to, aby tabela zmieściła się na małym ekranie. Przewijanie poziome często jest prostszym i bezpieczniejszym rozwiązaniem.

10. Przypomnienie struktury formularza HTML

Formularz tworzymy za pomocą znacznika form.

Wewnątrz mogą znajdować się pola tekstowe, etykiety, listy wyboru i przyciski.

Przykład HTML

<form action="zapis.php" method="post">

    <label for="imie">
        Imię:
    </label>

    <input
        type="text"
        id="imie"
        name="imie"
        required
    >

    <label for="email">
        E-mail:
    </label>

    <input
        type="email"
        id="email"
        name="email"
        required
    >

    <button type="submit">
        Wyślij
    </button>

</form>

Najważniejsze elementy

Znacznik Znaczenie
form Formularz
label Etykieta pola
input Pole formularza
select Lista rozwijana
textarea Pole wielowierszowe
button Przycisk
fieldset Grupa powiązanych pól
legend Opis grupy pól

📌 Zapamiętaj

Każde pole powinno mieć czytelną etykietę. Atrybut for etykiety powinien wskazywać odpowiednie id pola.

11. Formatowanie pól formularza

Pola formularzy można formatować podobnie jak inne elementy HTML.

Najczęściej zmieniamy:

  • szerokość,
  • wysokość,
  • padding,
  • obramowanie,
  • kolor tła,
  • kolor tekstu,
  • zaokrąglenie narożników.

Przykład HTML

<label for="nazwisko">
    Nazwisko:
</label>

<input
    type="text"
    id="nazwisko"
    name="nazwisko"
    class="pole"
>

CSS

.pole {
    width: 100%;

    padding: 12px;

    font-size: 16px;
    color: #1F2937;

    background-color: white;

    border: 1px solid #94A3B8;
    border-radius: 8px;

    box-sizing: border-box;
}

Dlaczego box-sizing: border-box?

Przy wartości border-box deklarowana szerokość obejmuje zawartość, padding i obramowanie.

Dzięki temu pole o szerokości 100% łatwiej dopasować do szerokości formularza.

Formatowanie etykiety

label {
    display: block;

    margin-bottom: 6px;

    font-weight: bold;
    color: #334155;
}

Etykieta znajdzie się nad polem formularza.

📌 Zapamiętaj

Nie ustawiaj width: 100% bezpośrednio dla wszystkich elementów input, ponieważ dotyczyłoby to również pól radio i checkbox.

12. Aktywne pole formularza – :focus

Pseudoklasa :focus pozwala zmienić wygląd pola, które aktualnie otrzymało fokus, np. po kliknięciu lub wybraniu klawiszem Tab.

Przykład

input:focus {
    border-color: #2563EB;

    outline: 3px solid #BFDBFE;
}

Po aktywowaniu pola zmieni się kolor jego obramowania i pojawi się dodatkowy kontur.

Płynna zmiana wyglądu

.pole {
    transition:
        border-color 0.2s,
        box-shadow 0.2s;
}

.pole:focus {
    border-color: #2563EB;

    box-shadow:
        0 0 0 3px #DBEAFE;
}

box-shadow tworzy dodatkowy efekt wokół pola.

📌 Ważne

Nie usuwaj widocznego wskaźnika fokusu bez zapewnienia innego wyraźnego sposobu wyróżnienia pola.

13. Formatowanie tekstu placeholder

Atrybut placeholder wyświetla tekst pomocniczy wewnątrz pustego pola.

HTML

<label for="email">
    Adres e-mail:
</label>

<input
    type="email"
    id="email"
    name="email"
    placeholder="np. uczen@example.com"
>

CSS

input::placeholder {
    color: #64748B;
    font-style: italic;
}

Pseudoelement ::placeholder umożliwia zmianę wyglądu tekstu pomocniczego.

Inny przykład

textarea::placeholder {
    color: #64748B;
    font-size: 14px;
}

📌 Zapamiętaj

Placeholder nie zastępuje etykiety label. Tekst pomocniczy znika po rozpoczęciu wpisywania i nie powinien być jedyną informacją o przeznaczeniu pola.

14. Stany pól formularza – :required, :valid, :invalid, :disabled

CSS umożliwia formatowanie pól w zależności od ich stanu.

Pole wymagane

<input
    type="email"
    name="email"
    required
>
input:required {
    border-left: 4px solid #F59E0B;
}

Wymagane pola zostaną wyróżnione pomarańczowym obramowaniem.

Pole z poprawną wartością

input:valid {
    border-color: #16A34A;
}

Pole z niepoprawną wartością

input:invalid {
    border-color: #DC2626;
}

Przeglądarka sprawdza poprawność pola na podstawie jego typu i ograniczeń HTML, np. required, minlength lub pattern.

Ważne – kiedy działa invalid?

Puste pole z atrybutem required może być uznawane za niepoprawne już przed rozpoczęciem wypełniania formularza.

Dlatego nie zawsze warto od razu pokazywać czerwone obramowanie.

Przykład – wyróżnienie po wpisaniu błędnego e-maila

input[type="email"]:not(:placeholder-shown):invalid {
    border-color: #DC2626;
}

W tym przykładzie pole musi posiadać atrybut placeholder. Styl pojawi się, gdy placeholder nie jest wyświetlany, a wartość nie spełnia wymagań pola.

Pole zablokowane

<input
    type="text"
    value="Nie można edytować"
    disabled
>
input:disabled {
    background-color: #E2E8F0;
    color: #64748B;

    cursor: not-allowed;
}

📌 Zapamiętaj

CSS może pokazywać wizualny stan pola, ale nie zastępuje walidacji danych po stronie serwera.

15. Formatowanie pól radio i checkbox

Pola radio pozwalają wybrać jedną opcję z grupy.

Pola checkbox umożliwiają zaznaczanie niezależnych opcji.

Przykład radio

<fieldset>

    <legend>Wybierz poziom kursu</legend>

    <label>
        <input
            type="radio"
            name="poziom"
            value="podstawowy"
        >
        Podstawowy
    </label>

    <label>
        <input
            type="radio"
            name="poziom"
            value="zaawansowany"
        >
        Zaawansowany
    </label>

</fieldset>

Przykład checkbox

<label>
    <input
        type="checkbox"
        name="newsletter"
    >
    Chcę otrzymywać informacje
    o nowych kursach.
</label>

Zmiana koloru zaznaczenia – accent-color

input[type="radio"],
input[type="checkbox"] {
    accent-color: #2563EB;
}

accent-color pozwala zmienić kolor akcentu natywnych kontrolek formularza.

Odstępy między opcjami

.opcja {
    display: flex;
    align-items: center;

    gap: 10px;

    margin-bottom: 10px;
}

HTML

<label class="opcja">
    <input
        type="checkbox"
        name="zgoda"
    >
    Akceptuję regulamin.
</label>

📌 Dobra praktyka

Nie usuwaj domyślnego wyglądu pól radio i checkbox bez potrzeby. Natywne kontrolki są zwykle łatwiejsze do obsługi i bardziej dostępne.

16. Formatowanie select i textarea

Formularze często zawierają listy rozwijane oraz pola wielowierszowe.

Lista rozwijana – select

<label for="kurs">
    Wybierz kurs:
</label>

<select id="kurs" name="kurs">

    <option value="html">HTML</option>
    <option value="css">CSS</option>
    <option value="js">JavaScript</option>

</select>

CSS

select {
    width: 100%;

    padding: 12px;

    font-size: 16px;

    border: 1px solid #94A3B8;
    border-radius: 8px;

    background-color: white;
}

Pole wielowierszowe – textarea

<label for="wiadomosc">
    Wiadomość:
</label>

<textarea
    id="wiadomosc"
    name="wiadomosc"
    rows="5"
    placeholder="Wpisz wiadomość..."
></textarea>

CSS

textarea {
    width: 100%;

    min-height: 120px;
    padding: 12px;

    font-family: Arial, sans-serif;
    font-size: 16px;

    border: 1px solid #94A3B8;
    border-radius: 8px;

    resize: vertical;

    box-sizing: border-box;
}

Właściwość resize

Wartość Działanie
none Wyłącza ręczną zmianę rozmiaru.
vertical Pozwala zmieniać wysokość.
horizontal Pozwala zmieniać szerokość.
both Pozwala zmieniać oba wymiary.

📌 Wskazówka

resize: vertical jest często dobrym wyborem, ponieważ użytkownik może zwiększyć wysokość pola bez zaburzania szerokości formularza.

17. Formatowanie przycisków formularza

Przycisk formularza może być formatowany za pomocą właściwości tła, obramowania, paddingu i tekstu.

HTML

<button type="submit" class="przycisk">
    Wyślij formularz
</button>

CSS

.przycisk {
    padding: 14px 28px;

    color: white;
    background-color: #2563EB;

    font-size: 16px;
    font-weight: bold;

    border: none;
    border-radius: 8px;

    cursor: pointer;
}

Efekt hover

.przycisk:hover {
    background-color: #1D4ED8;
}

Efekt active

.przycisk:active {
    transform: scale(0.98);
}

Efekt focus-visible

.przycisk:focus-visible {
    outline: 3px solid #F59E0B;
    outline-offset: 3px;
}

Płynne przejście

.przycisk {
    transition:
        background-color 0.2s,
        transform 0.2s;
}

Przycisk nieaktywny

.przycisk:disabled {
    background-color: #94A3B8;
    cursor: not-allowed;
}

📌 Zapamiętaj

cursor: pointer zmienia wygląd kursora, ale nie odpowiada za działanie przycisku. Funkcjonalność wynika z HTML i ewentualnych skryptów.

18. Układ formularza – grupowanie i odstępy

Czytelny formularz powinien mieć odpowiednie odstępy między etykietami, polami i grupami.

Przykład HTML

<form class="formularz">

    <div class="grupa">

        <label for="imie">Imię</label>

        <input
            type="text"
            id="imie"
            name="imie"
        >

    </div>

    <div class="grupa">

        <label for="email">E-mail</label>

        <input
            type="email"
            id="email"
            name="email"
        >

    </div>

    <button type="submit">Wyślij</button>

</form>

CSS

.formularz {
    width: 100%;
    max-width: 500px;

    padding: 25px;
    margin: 20px auto;

    background-color: white;

    border: 1px solid #CBD5E1;
    border-radius: 12px;

    box-sizing: border-box;
}

.grupa {
    margin-bottom: 20px;
}

.grupa label {
    display: block;

    margin-bottom: 8px;

    font-weight: bold;
}

.grupa input {
    width: 100%;

    padding: 12px;

    border: 1px solid #94A3B8;
    border-radius: 6px;

    box-sizing: border-box;
}

Grupowanie pól – fieldset i legend

<fieldset>

    <legend>Dane kontaktowe</legend>

    <label for="telefon">
        Telefon:
    </label>

    <input
        type="tel"
        id="telefon"
        name="telefon"
    >

</fieldset>

Formatowanie grupy

fieldset {
    padding: 20px;
    margin-bottom: 20px;

    border: 1px solid #CBD5E1;
    border-radius: 8px;
}

legend {
    padding: 0 8px;

    color: #1E3A8A;
    font-weight: bold;
}

📌 Dobra praktyka

Powiązane pola warto grupować za pomocą fieldset i legend, szczególnie w przypadku zestawów pól radio i checkbox.

19. Najczęstsze błędy

Błąd 1 – podwójne obramowania tabeli

table,
td {
    border: 1px solid black;
}

Przy domyślnym modelu oddzielnych obramowań między komórkami mogą być widoczne odstępy.

Rozwiązanie:

table {
    border-collapse: collapse;
}

Błąd 2 – brak paddingu w komórkach

Tekst przylega do obramowania i jest mniej czytelny. 

th,
td {
    padding: 12px;
}

Błąd 3 – tabela wychodząca poza ekran

Szeroka tabela może powodować przewijanie całej strony. 

.tabela-przewijana {
    overflow-x: auto;
}

Błąd 4 – formatowanie wszystkich input jednakowo

input {
    width: 100%;
}

Ten zapis obejmuje również checkboxy i pola radio.

Lepszy zapis:

input[type="text"],
input[type="email"],
input[type="password"] {
    width: 100%;
}

Błąd 5 – brak etykiet pól

Sam placeholder nie powinien zastępować etykiety pola. 

<label for="imie">Imię</label>

<input
    type="text"
    id="imie"
    name="imie"
>

Błąd 6 – brak widocznego fokusu

Użytkownik może nie wiedzieć, które pole jest aktualnie aktywne podczas obsługi klawiaturą. 

input:focus-visible,
select:focus-visible,
textarea:focus-visible {
    outline: 3px solid #BFDBFE;
}

Błąd 7 – przycisk bez określonego typu

Wewnątrz formularza przycisk button ma domyślnie typ submit.

Dlatego warto określać jego przeznaczenie. 

<button type="submit">Wyślij</button>

<button type="reset">Wyczyść</button>

<button type="button">Inna akcja</button>

Błąd 8 – mylenie wyglądu z działaniem formularza

CSS zmienia wygląd formularza, ale nie zapisuje danych w bazie danych ani nie wysyła wiadomości e-mail.

Do obsługi przesłanych danych potrzebne jest odpowiednie rozwiązanie, np. skrypt po stronie serwera.

📌 Zapamiętaj

Dobrze przygotowany formularz powinien być czytelny, wygodny i możliwy do obsługi zarówno myszą, jak i klawiaturą.

📌 Zapamiętaj

  • border ustawia obramowanie tabeli i komórek.
  • border-collapse: collapse łączy sąsiadujące obramowania.
  • border-spacing ustawia odstępy między oddzielnymi komórkami.
  • padding zwiększa odstęp między treścią komórki a obramowaniem.
  • width określa szerokość tabeli lub pola.
  • text-align ustawia poziome wyrównanie tekstu.
  • vertical-align umożliwia pionowe wyrównanie treści komórek.
  • table-layout określa sposób wyznaczania szerokości kolumn.
  • :nth-child(even) pozwala wyróżnić parzyste wiersze.
  • :nth-child(odd) pozwala wyróżnić nieparzyste wiersze.
  • :hover umożliwia zmianę wyglądu wskazywanego elementu.
  • overflow-x: auto umożliwia poziome przewijanie szerokiej tabeli.
  • label opisuje przeznaczenie pola formularza.
  • padding, border i border-radius pozwalają formatować pola.
  • box-sizing: border-box ułatwia kontrolowanie szerokości pól.
  • :focus wyróżnia aktywne pole.
  • ::placeholder zmienia wygląd tekstu pomocniczego.
  • :required wybiera pola wymagane.
  • :valid i :invalid dotyczą stanu poprawności pola.
  • :disabled wybiera zablokowane kontrolki.
  • accent-color zmienia kolor akcentu pól radio i checkbox.
  • resize określa możliwość zmiany rozmiaru pola textarea.
  • fieldset i legend służą do grupowania powiązanych pól.
  • cursor: pointer zmienia wygląd kursora nad przyciskiem.
  • transition umożliwia płynne zmiany wyglądu.
  • CSS nie zastępuje obsługi formularza ani walidacji po stronie serwera.
