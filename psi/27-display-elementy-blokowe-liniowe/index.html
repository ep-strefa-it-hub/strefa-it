Sposoby wyświetlania elementów – display, elementy blokowe, liniowe i inline-block

Cel lekcji: poznanie właściwości display, rozróżnianie elementów blokowych i liniowych oraz stosowanie wartości block, inline, inline-block i none podczas projektowania stron WWW.

1. Wprowadzenie – jak przeglądarka wyświetla elementy?

Każdy element HTML jest wyświetlany przez przeglądarkę według określonych zasad.

Niektóre elementy rozpoczynają się w nowym wierszu i zajmują całą dostępną szerokość. Inne znajdują się obok siebie, w tym samym wierszu tekstu.

Przykładowo:

  • nagłówek h1 zwykle zajmuje osobny wiersz,
  • akapit p rozpoczyna się w nowym wierszu,
  • znacznik span pozostaje w tym samym wierszu co otaczający go tekst,
  • odnośnik a domyślnie jest elementem liniowym.

Przykład HTML

<h2>Nagłówek strony</h2>

<p>Pierwszy akapit.</p>

<p>Drugi akapit.</p>

<span>Pierwszy tekst</span>

<span>Drugi tekst</span>

Nagłówek i akapity pojawiają się w osobnych wierszach. Natomiast oba elementy span mogą znajdować się obok siebie.

📌 Zapamiętaj

O sposobie wyświetlania elementu decydują między innymi domyślne style przeglądarki oraz zastosowane reguły CSS.

2. Właściwość display

Właściwość display określa sposób wyświetlania elementu oraz jego udział w układzie strony.

Składnia

selektor {
    display: wartosc;
}

Najważniejsze wartości

Wartość Znaczenie
block Element jest wyświetlany jako blok.
inline Element jest wyświetlany liniowo.
inline-block Element pozostaje w wierszu, ale można określić jego wymiary.
none Element nie jest wyświetlany i nie zajmuje miejsca w układzie.
flex Tworzy kontener elastyczny Flexbox.
grid Tworzy kontener siatkowy Grid.

Przykład

.element {
    display: block;
}

Element z klasą element będzie wyświetlany jako blok.

📌 Ważne

Za pomocą display można zmienić domyślny sposób wyświetlania elementu HTML.

3. Elementy blokowe – display: block

Elementy blokowe w normalnym układzie dokumentu rozpoczynają się w nowym wierszu.

Domyślnie typowy element blokowy z width: auto rozciąga się na dostępną szerokość kontenera.

Przykładowe elementy blokowe

  • div,
  • p,
  • h1 – h6,
  • section,
  • article,
  • header,
  • footer,
  • main.

Przykład HTML

<div class="blok">
    Pierwszy blok
</div>

<div class="blok">
    Drugi blok
</div>

<div class="blok">
    Trzeci blok
</div>

Kod CSS

.blok {
    display: block;

    background-color: lightblue;

    border: 2px solid blue;

    padding: 15px;
    margin-bottom: 10px;
}

Każdy element będzie wyświetlany w osobnym wierszu.

Określanie szerokości i wysokości

.blok {
    display: block;

    width: 300px;
    height: 100px;

    background-color: lightgreen;
}

W przypadku zwykłego elementu blokowego można określić szerokość i wysokość.

📌 Zapamiętaj

display: block tworzy pudełko blokowe, które w normalnym układzie znajduje się w osobnym wierszu.

4. Elementy liniowe – display: inline

Elementy liniowe są wyświetlane w tym samym wierszu co otaczający je tekst, jeśli dostępne jest miejsce.

Nie rozpoczynają automatycznie nowego wiersza.

Przykładowe elementy liniowe

  • span,
  • a,
  • strong,
  • em,
  • small,
  • code.

Przykład HTML

<p>
    Uczę się
    <span class="wyroznienie">HTML</span>
    i
    <span class="wyroznienie">CSS</span>.
</p>

Kod CSS

.wyroznienie {
    display: inline;

    background-color: yellow;
    color: black;
}

Elementy span pozostają wewnątrz wiersza tekstu.

Width i height w elementach inline

.wyroznienie {
    display: inline;

    width: 200px;
    height: 100px;

    background-color: yellow;
}

Dla zwykłego, niezamienionego elementu liniowego, takiego jak span, właściwości width i height nie określają jego wymiarów w taki sposób jak dla bloku.

Margin i padding

.wyroznienie {
    display: inline;

    padding: 10px;
    margin: 10px;

    background-color: lightblue;
}

Padding i obramowanie mogą być widoczne, jednak pionowe odstępy nie zmieniają wysokości wiersza tak jak w elementach blokowych.

Marginesy poziome działają, natomiast marginesy pionowe zwykłego elementu inline nie odsuwają sąsiednich wierszy.

📌 Zapamiętaj

display: inline stosujemy wtedy, gdy element ma pozostać częścią wiersza tekstu.

5. Elementy inline-block

Wartość inline-block łączy cechy elementów liniowych i blokowych.

Element może znajdować się obok innych elementów w tym samym wierszu, a jednocześnie pozwala określić szerokość, wysokość i odstępy.

Przykład HTML

<span class="etykieta">HTML</span>

<span class="etykieta">CSS</span>

<span class="etykieta">JavaScript</span>

Kod CSS

.etykieta {
    display: inline-block;

    width: 130px;
    padding: 15px;

    text-align: center;

    background-color: lightblue;

    border: 2px solid blue;
    border-radius: 8px;
}

Etykiety mogą znajdować się obok siebie, a każda z nich ma określoną szerokość i odstępy wewnętrzne.

Ustawianie wysokości

.etykieta {
    display: inline-block;

    width: 150px;
    height: 60px;

    padding: 10px;
}

W przeciwieństwie do zwykłego elementu inline możemy określić wysokość pudełka.

Gdzie stosujemy inline-block?

  • przyciski i odnośniki,
  • etykiety i znaczniki kategorii,
  • niewielkie kafelki,
  • elementy menu,
  • proste układy elementów obok siebie.

📌 Najważniejsze

inline-block pozwala umieszczać elementy obok siebie i jednocześnie kontrolować ich wymiary.

6. Porównanie block, inline i inline-block

Cecha block inline inline-block
Nowy wiersz Tak Nie Nie
Elementy obok siebie Nie w zwykłym układzie blokowym Tak Tak
Width Tak Nie dla zwykłych elementów inline Tak
Height Tak Nie dla zwykłych elementów inline Tak
Padding Tak Tak, z ograniczeniami układu liniowego Tak
Marginesy pionowe Tak Nie odsuwają wierszy Tak
Typowe zastosowanie Sekcje strony Fragmenty tekstu Przyciski, etykiety, kafelki

Przykład porównawczy

<div class="block">BLOCK 1</div>
<div class="block">BLOCK 2</div>

<span class="inline">INLINE 1</span>
<span class="inline">INLINE 2</span>

<div class="inline-block">INLINE-BLOCK 1</div>
<div class="inline-block">INLINE-BLOCK 2</div>
.block {
    display: block;

    width: 200px;
    padding: 15px;

    margin-bottom: 10px;

    background-color: lightblue;
}

.inline {
    display: inline;

    background-color: lightgreen;
}

.inline-block {
    display: inline-block;

    width: 180px;
    padding: 15px;

    background-color: lightcoral;
}

Uruchom kod w przeglądarce i porównaj rozmieszczenie elementów.

7. Zmiana domyślnego sposobu wyświetlania

Każdy element HTML ma domyślny sposób wyświetlania, ale można go zmienić za pomocą CSS.

Przykład – span jako blok

<span class="blok">
    Pierwszy element
</span>

<span class="blok">
    Drugi element
</span>
.blok {
    display: block;

    padding: 15px;
    margin-bottom: 10px;

    background-color: lightblue;
}

Mimo że span jest domyślnie liniowy, po zastosowaniu display: block elementy pojawią się w osobnych wierszach.

Przykład – div jako inline

<div class="linia">HTML</div>
<div class="linia">CSS</div>
<div class="linia">JavaScript</div>
.linia {
    display: inline;

    background-color: yellow;
}

Elementy div mogą być wyświetlane w tym samym wierszu.

📌 Ważne

Zmiana display nie zmienia znaczenia semantycznego elementu HTML.

8. Tworzenie poziomego menu

Właściwość display można wykorzystać do budowania prostego menu nawigacyjnego.

Przykład HTML

<nav class="menu">

    <a href="#start">Start</a>

    <a href="#oferta">Oferta</a>

    <a href="#kontakt">Kontakt</a>

</nav>

Kod CSS

.menu {
    padding: 15px;

    background-color: #1E3A8A;
}

.menu a {
    display: inline-block;

    padding: 12px 20px;
    margin-right: 10px;

    color: white;

    text-decoration: none;

    background-color: #2563EB;

    border-radius: 6px;
}

.menu a:hover {
    background-color: #1D4ED8;
}

Odnośniki zachowują się jak niewielkie przyciski i mogą być rozmieszczone w jednym wierszu.

Dlaczego inline-block?

  • odnośniki pozostają obok siebie,
  • można ustawić padding z każdej strony,
  • można określić szerokość i wysokość,
  • obszar kliknięcia obejmuje całe pudełko odnośnika.

9. Przyciski i odnośniki jako inline-block

Odnośnik a jest domyślnie elementem liniowym.

Jeżeli chcemy nadać mu wygląd przycisku, często stosujemy display: inline-block.

Przykład

<a href="#kontakt" class="przycisk">
    Skontaktuj się
</a>
.przycisk {
    display: inline-block;

    padding: 12px 25px;

    background-color: #16A34A;
    color: white;

    text-decoration: none;

    border: 2px solid #15803D;
    border-radius: 8px;
}

.przycisk:hover {
    background-color: #15803D;
}

Przycisk o stałej szerokości

.przycisk {
    display: inline-block;

    width: 200px;
    padding: 15px;

    text-align: center;
}

Można teraz ustawić konkretną szerokość obszaru przycisku.

📌 Dobra praktyka

Odnośnik a służy do nawigacji, natomiast button do wykonywania działań. Sam wygląd przycisku nie powinien decydować o wyborze znacznika HTML.

10. Wyświetlanie kart obok siebie

inline-block może posłużyć do utworzenia prostego układu kart.

Kod HTML

<div class="karta">

    <h3>HTML</h3>

    <p>Struktura strony WWW.</p>

</div>

<div class="karta">

    <h3>CSS</h3>

    <p>Wygląd strony WWW.</p>

</div>

<div class="karta">

    <h3>JavaScript</h3>

    <p>Interaktywność strony.</p>

</div>

Kod CSS

.karta {
    display: inline-block;

    box-sizing: border-box;

    width: 250px;
    min-height: 180px;

    padding: 20px;
    margin: 10px;

    vertical-align: top;

    background-color: #DBEAFE;

    border: 2px solid #2563EB;
    border-radius: 10px;
}

Karty mogą znajdować się obok siebie, jeśli pozwala na to szerokość kontenera.

Właściwość vertical-align

.karta {
    display: inline-block;

    vertical-align: top;
}

Właściwość vertical-align: top wyrównuje górne krawędzie elementów inline-block w tym samym wierszu.

📌 Ważne

Jeśli suma szerokości kart, ich marginesów oraz odstępów w kodzie HTML przekroczy szerokość kontenera, część kart przejdzie do następnego wiersza.

11. Ukrywanie elementów – display: none

Wartość none powoduje, że element nie jest wyświetlany.

Element nie zajmuje również miejsca w układzie strony.

Przykład HTML

<p>Pierwszy akapit.</p>

<p class="ukryty">
    Ten akapit jest ukryty.
</p>

<p>Trzeci akapit.</p>

Kod CSS

.ukryty {
    display: none;
}

Drugi akapit nie będzie widoczny, a trzeci zajmie miejsce bezpośrednio po pierwszym, zgodnie z pozostałymi regułami układu.

Przykładowe zastosowania

  • ukrywanie wybranych elementów interfejsu,
  • ukrywanie elementów w określonych układach responsywnych,
  • pokazywanie i ukrywanie fragmentów strony za pomocą JavaScript.

📌 Zapamiętaj

display: none usuwa element z układu wizualnego strony, ale nie usuwa go z kodu HTML.

12. Display: none a visibility: hidden

CSS udostępnia różne sposoby ukrywania elementów.

Dwa często spotykane zapisy to: 

display: none;
visibility: hidden;

Przykład HTML

<div class="pierwszy">
    Pierwszy element
</div>

<div class="drugi">
    Drugi element
</div>

<div class="trzeci">
    Trzeci element
</div>

Wariant 1 – display: none

.drugi {
    display: none;
}

Drugi element znika i nie zajmuje miejsca.

Wariant 2 – visibility: hidden

.drugi {
    visibility: hidden;
}

Drugi element jest niewidoczny, ale jego miejsce pozostaje zarezerwowane w układzie strony.

Porównanie

Właściwość Element widoczny? Zajmuje miejsce?
display: none Nie Nie
visibility: hidden Nie Tak
visibility: visible Tak Tak

📌 Zapamiętaj

display: none usuwa miejsce elementu, a visibility: hidden pozostawia to miejsce.

13. Odstępy między elementami inline-block

Elementy inline-block są rozmieszczane podobnie do fragmentów tekstu.

Dlatego białe znaki znajdujące się między nimi w kodzie HTML mogą utworzyć widoczną przerwę.

Przykład

<span class="pole">1</span>
<span class="pole">2</span>
<span class="pole">3</span>
.pole {
    display: inline-block;

    width: 100px;
    padding: 10px;

    background-color: lightblue;
}

Między elementami może być widoczny niewielki odstęp, mimo że nie ustawiono właściwości margin.

Dlaczego tak się dzieje?

Znaki nowego wiersza i spacje pomiędzy elementami mogą być traktowane jak odstępy w tekście.

Rozwiązanie – wykorzystanie Flexbox

<div class="kontener">

    <span class="pole">1</span>
    <span class="pole">2</span>
    <span class="pole">3</span>

</div>
.kontener {
    display: flex;
    gap: 10px;
}

.pole {
    width: 100px;
    padding: 10px;
}

Flexbox pozwala precyzyjnie kontrolować odstępy za pomocą właściwości gap.

📌 Ważne

W tej lekcji poznajemy przede wszystkim block, inline i inline-block. Flexbox będzie przydatny podczas projektowania bardziej rozbudowanych układów.

14. Display a model pudełkowy CSS

W poprzedniej lekcji poznaliśmy model pudełkowy CSS.

Składa się on z:

  • content,
  • padding,
  • border,
  • margin.

Właściwość display wpływa na to, jak element uczestniczy w układzie strony i jak stosowane są jego wymiary oraz odstępy.

Przykład 1 – block

.element {
    display: block;

    width: 200px;
    height: 100px;

    padding: 20px;
    border: 2px solid blue;
}

Element może mieć określoną szerokość i wysokość.

Przykład 2 – inline

.element {
    display: inline;

    width: 200px;
    height: 100px;

    padding: 20px;
    border: 2px solid blue;
}

Dla zwykłego niezamienionego elementu inline właściwości width i height nie wyznaczają jego wymiarów pudełka.

Przykład 3 – inline-block

.element {
    display: inline-block;

    width: 200px;
    height: 100px;

    padding: 20px;
    border: 2px solid blue;
}

Element może pozostać w jednym wierszu z innymi elementami, a jednocześnie mieć określone wymiary.

Połączenie z box-sizing

.element {
    display: inline-block;

    box-sizing: border-box;

    width: 200px;
    padding: 20px;
    border: 2px solid blue;
}

W tym przypadku szerokość pudełka wynosi 200 px. Padding i obramowanie mieszczą się w tej szerokości.

15. Inne wartości display

W CSS istnieją również inne wartości właściwości display.

Display: flex

.kontener {
    display: flex;
}

Tworzy kontener elastyczny, którego elementy potomne można wygodnie rozmieszczać.

Display: grid

.kontener {
    display: grid;
}

Tworzy kontener siatkowy, umożliwiający budowanie układów w wierszach i kolumnach.

Display: list-item

.element {
    display: list-item;
}

Element zachowuje się jak element listy i może otrzymać znacznik listy.

Display: table

.element {
    display: table;
}

Element uczestniczy w układzie podobnym do tabeli.

📌 Zapamiętaj

Właściwość display nie ogranicza się do trzech podstawowych sposobów wyświetlania. Umożliwia również tworzenie nowoczesnych układów Flexbox i Grid.

16. Znaczenie HTML a sposób wyświetlania

HTML określa znaczenie i strukturę treści, natomiast CSS odpowiada za jej wygląd i sposób rozmieszczenia.

Przykład

<nav>
    <a href="#start">Start</a>
    <a href="#kontakt">Kontakt</a>
</nav>
nav a {
    display: block;
}

Odnośniki zostaną wyświetlone jako bloki, ale nadal pozostaną odnośnikami.

Inny przykład

<h2>Tytuł sekcji</h2>
h2 {
    display: inline;
}

Nagłówek może być wyświetlany liniowo, ale nadal pozostaje nagłówkiem drugiego poziomu.

📌 Dobra praktyka

Wybieraj element HTML zgodnie z jego znaczeniem, a nie wyłącznie domyślnym wyglądem.

17. Najczęstsze błędy

Błąd 1 – oczekiwanie działania width dla span

span {
    width: 200px;
}

Dla zwykłego elementu span szerokość nie zostanie zastosowana w oczekiwany sposób.

Rozwiązanie:

span {
    display: inline-block;
    width: 200px;
}

Błąd 2 – mylenie block i inline-block

.karta {
    display: block;
    width: 200px;
}

W normalnym układzie blokowym kolejne karty nadal będą pojawiać się w osobnych wierszach.

Jeżeli mają znajdować się obok siebie, można użyć: 

.karta {
    display: inline-block;
    width: 200px;
}

Błąd 3 – zapominanie o odstępach między inline-block

Między elementami mogą występować odstępy wynikające z białych znaków HTML.

Błąd 4 – display: none zamiast visibility: hidden

Jeśli chcemy zachować miejsce ukrytego elementu, display: none nie będzie właściwym wyborem.

Błąd 5 – błędna składnia

/* Niepoprawnie */

.element {
    display: inline block;
}

Poprawnie:

.element {
    display: inline-block;
}

Błąd 6 – mylenie wyrównania tekstu z display

.kontener {
    text-align: center;
}

text-align: center wyrównuje zawartość liniową wewnątrz kontenera. Nie zamienia jednak elementów blokowych w elementy inline-block.

📌 Wskazówka

Gdy element nie ustawia się zgodnie z oczekiwaniami, sprawdź jego wartość display oraz szerokość, marginesy i padding.

18. Kompletny przykład – strona z ofertą kursów

Przygotujemy prostą stronę, na której zastosujemy różne wartości właściwości display.

Strona będzie zawierała:

  • nagłówek,
  • poziome menu,
  • trzy karty kursów,
  • etykiety technologii,
  • odnośniki wyglądające jak przyciski,
  • ukryty komunikat.

projekt/
|
|-- index.html
|
|-- style.css

Analiza zastosowanych wartości display

Element Display Efekt
header block Nagłówek zajmuje osobny obszar strony.
.menu a inline-block Odnośniki tworzą poziome menu.
.wyroznienie inline Wyróżnienie pozostaje w tekście.
.karta inline-block Karty mogą znajdować się obok siebie.
.etykieta inline-block Etykiety mają odstępy i mogą być w jednym wierszu.
.przycisk inline-block Odnośnik wygląda jak przycisk.
.ukryty none Komunikat nie jest wyświetlany.

📌 Zapamiętaj

  • Właściwość display określa sposób wyświetlania elementu HTML.
  • display: block tworzy element blokowy.
  • Element blokowy w normalnym układzie rozpoczyna się w nowym wierszu.
  • display: inline tworzy element liniowy.
  • Elementy liniowe mogą znajdować się obok siebie w tym samym wierszu.
  • Zwykłe elementy inline, takie jak span, nie przyjmują width i height tak jak elementy blokowe.
  • display: inline-block łączy cechy elementów liniowych i blokowych.
  • Elementy inline-block mogą znajdować się obok siebie i mieć określone wymiary.
  • inline-block jest przydatne do tworzenia przycisków, etykiet i prostych kafelków.
  • display: none ukrywa element i usuwa zajmowane przez niego miejsce w układzie.
  • visibility: hidden ukrywa element, ale zachowuje jego miejsce.
  • Między elementami inline-block mogą występować odstępy wynikające z białych znaków HTML.
  • vertical-align: top może służyć do wyrównywania elementów inline-block do górnej krawędzi wiersza.
  • display: flex i display: grid umożliwiają budowanie bardziej rozbudowanych układów.
  • CSS zmienia sposób prezentacji elementu, ale nie zmienia jego znaczenia w HTML.
