Składnia CSS. Selektory elementów, klas i identyfikatorów

Cel lekcji: utrwalenie składni reguł CSS, poznanie sposobów wybierania elementów HTML za pomocą selektorów elementów, klas i identyfikatorów, grupowanie i łączenie selektorów oraz samodzielne stosowanie poznanych zasad w zewnętrznym arkuszu stylów.

1. Wprowadzenie

W poprzedniej lekcji poznaliśmy język CSS, trzy sposoby definiowania stylów oraz podstawy kaskadowości.

Wiemy już, że CSS odpowiada za wygląd strony internetowej, ale pojawia się pytanie:

Skąd przeglądarka wie, który element HTML ma otrzymać określony styl?

Odpowiadają za to selektory CSS. Pozwalają one wskazać jeden element, wiele elementów tego samego typu albo grupę elementów oznaczonych odpowiednią klasą.

Przykład

<h1>Moja strona</h1>

<p>Pierwszy akapit.</p>

<p>Drugi akapit.</p>
p {
    color: blue;
}

Selektor p wskazuje wszystkie akapity w dokumencie. Oba akapity otrzymają niebieski kolor tekstu.

📌 Ważne

Selektor określa, które elementy mają być stylowane. Deklaracje określają, jak mają wyglądać.

2. Składnia reguły CSS

Podstawowa reguła CSS składa się z selektora oraz bloku deklaracji. 

h1 {
    color: navy;
    font-size: 32px;
    text-align: center;
}

Elementy reguły

Element Opis
h1 Selektor wskazujący nagłówki h1.
{ } Blok zawierający deklaracje CSS.
color Nazwa właściwości.
navy Wartość właściwości.
: Oddziela właściwość od wartości.
; Kończy deklarację.

Jedna deklaracja

p {
    color: red;
}

Kilka deklaracji

p {
    color: red;
    font-size: 18px;
    font-family: Arial, sans-serif;
    text-align: justify;
}

W jednej regule można umieścić wiele deklaracji. Każda określa inną cechę wyglądu.

Znaczenie średnika

Średnik oddziela deklaracje. W ostatniej deklaracji bloku może zostać pominięty, ale zaleca się stosowanie go zawsze. 

/* Zalecany zapis */

h2 {
    color: green;
    font-size: 24px;
}

3. Właściwości i wartości CSS

Właściwość określa, jaki aspekt wyglądu zmieniamy, a wartość wskazuje konkretny efekt.

Przykładowe właściwości

Właściwość Przykład Znaczenie
color red Kolor tekstu.
background-color lightblue Kolor tła.
font-size 20px Rozmiar czcionki.
font-weight bold Grubość pisma.
text-align center Wyrównanie tekstu.
border 1px solid black Obramowanie.
padding 15px Odstęp wewnętrzny.
margin 20px Margines zewnętrzny.

Wartości liczbowe i jednostki

h1 {
    font-size: 36px;
}

p {
    font-size: 1.2rem;
}

px oznacza piksele CSS, natomiast rem odnosi się do rozmiaru czcionki elementu głównego.

Wartości tekstowe

h1 {
    text-align: center;
    font-weight: bold;
}

Wartości kolorów

h1 {
    color: blue;
}

h2 {
    color: #008000;
}

p {
    color: rgb(80, 80, 80);
}

📌 Zapamiętaj

Nazwy właściwości CSS zapisujemy zgodnie ze składnią języka, np. font-size, a nie font_size. Wartość musi być poprawna dla danej właściwości.

4. Selektor elementu

Selektor elementu wskazuje wszystkie elementy HTML o określonej nazwie znacznika.

Przykład – wszystkie akapity

HTML:

<p>Pierwszy akapit.</p>

<p>Drugi akapit.</p>

<p>Trzeci akapit.</p>

CSS:

p {
    color: darkblue;
    font-size: 18px;
}

Wszystkie trzy akapity otrzymają takie same style.

Przykład – nagłówki

h1 {
    color: navy;
    text-align: center;
}

h2 {
    color: darkgreen;
}

h3 {
    color: darkred;
}

Przykład – cała strona

body {
    background-color: #f4f4f4;
    font-family: Arial, sans-serif;
}

Selektor body wskazuje element zawierający widoczną zawartość dokumentu.

Kiedy stosować selektor elementu?

  • Gdy wszystkie akapity mają mieć podobny wygląd.
  • Gdy chcemy ustawić wspólny styl nagłówków danego poziomu.
  • Gdy definiujemy podstawowe style całej strony.
  • Gdy określamy wygląd wszystkich list lub odnośników.

📌 Ważne

Selektor elementu działa na wszystkie pasujące elementy, a nie tylko na pierwszy element danego typu.

5. Selektor klasy

Klasa CSS pozwala przypisać ten sam styl wybranym elementom HTML, nawet jeśli są to elementy różnych typów.

W HTML klasę przypisujemy za pomocą atrybutu class.

W CSS nazwę klasy poprzedzamy kropką.

Przykład – wyróżniony akapit

HTML:

<p class="wazne">
    Uwaga! To ważna informacja.
</p>

<p>
    To zwykły akapit.
</p>

CSS:

.wazne {
    color: red;
    font-weight: bold;
}

Styl otrzyma tylko pierwszy akapit, ponieważ ma klasę wazne.

Ta sama klasa w kilku elementach

<h2 class="wazne">
    Ważny nagłówek
</h2>

<p class="wazne">
    Ważny akapit.
</p>

<div class="wazne">
    Ważny komunikat.
</div>
.wazne {
    color: red;
    font-weight: bold;
}

Wszystkie trzy elementy otrzymają czerwony i pogrubiony tekst.

Przykład – różne klasy

HTML:

<p class="sukces">
    Operacja zakończona pomyślnie.
</p>

<p class="blad">
    Wystąpił błąd.
</p>

<p class="ostrzezenie">
    Sprawdź wprowadzone dane.
</p>

CSS:

.sukces {
    color: green;
}

.blad {
    color: red;
}

.ostrzezenie {
    color: darkorange;
}

Do czego przydają się klasy?

  • Wyróżnianie ważnych informacji.
  • Tworzenie komunikatów o różnych znaczeniach.
  • Stylowanie przycisków.
  • Oznaczanie kart produktów.
  • Wielokrotne wykorzystywanie tych samych stylów.

📌 Zapamiętaj

W HTML zapisujemy class="wazne", a w CSS .wazne. Kropka występuje w selektorze CSS, a nie w wartości atrybutu class.

6. Przypisywanie wielu klas do jednego elementu

Jeden element HTML może mieć więcej niż jedną klasę.

Nazwy klas wpisujemy w jednym atrybucie class, oddzielając je spacjami.

Przykład

HTML:

<p class="wazne duzy-tekst">
    Bardzo ważny komunikat.
</p>

CSS:

.wazne {
    color: red;
    font-weight: bold;
}

.duzy-tekst {
    font-size: 24px;
}

Akapit otrzyma style z obu klas:

  • Czerwony kolor tekstu.
  • Pogrubienie.
  • Rozmiar czcionki 24 piksele.

Przykład – wspólna klasa i różne warianty

HTML:

<p class="komunikat sukces">
    Zapisano dane.
</p>

<p class="komunikat blad">
    Nie udało się zapisać danych.
</p>

CSS:

.komunikat {
    padding: 15px;
    border: 1px solid black;
}

.sukces {
    background-color: lightgreen;
}

.blad {
    background-color: lightpink;
}

Oba komunikaty otrzymają obramowanie i odstęp wewnętrzny, ale będą miały inne kolory tła.

Czy kolejność nazw klas w HTML ma znaczenie?

<p class="wazne duzy-tekst">
    Tekst A
</p>

<p class="duzy-tekst wazne">
    Tekst B
</p>

Oba elementy należą do tych samych dwóch klas. Sama zmiana kolejności nazw w atrybucie class nie zmienia pierwszeństwa deklaracji CSS.

📌 Ważne

Kolejność klas wpisanych w HTML nie decyduje o kaskadzie. Jeśli klasy definiują sprzeczne wartości tej samej właściwości, wynik zależy od reguł kaskady CSS.

7. Selektor identyfikatora

Identyfikator służy do jednoznacznego oznaczenia elementu w dokumencie HTML.

W HTML używamy atrybutu id.

W CSS nazwę identyfikatora poprzedzamy znakiem #.

Przykład

HTML:

<h1 id="tytul">
    Moja strona internetowa
</h1>

CSS:

#tytul {
    color: navy;
    text-align: center;
}

Reguła wskazuje element z identyfikatorem tytul.

Przykład – sekcja strony

<section id="kontakt">

    <h2>Kontakt</h2>

    <p>
        Napisz do nas wiadomość.
    </p>

</section>
#kontakt {
    background-color: lightyellow;
    padding: 20px;
}

Identyfikator powinien być unikatowy

W obrębie jednego dokumentu HTML nie należy nadawać dwóch takich samych identyfikatorów. 

<!-- Niepoprawnie -->

<h2 id="tytul">Pierwszy nagłówek</h2>

<h2 id="tytul">Drugi nagłówek</h2>

Poprawny przykład:

<h2 id="oferta">Oferta</h2>

<h2 id="kontakt">Kontakt</h2>

Identyfikatory i odnośniki

Identyfikatory poznaliśmy już podczas tworzenia odnośników do fragmentów strony. 

<a href="#kontakt">
    Przejdź do kontaktu
</a>

<section id="kontakt">

    <h2>Kontakt</h2>

</section>

Ten sam identyfikator może być wykorzystywany do nawigacji oraz do stylowania.

8. Różnice między class i id

Klasa i identyfikator pozwalają oznaczać elementy HTML, ale pełnią nieco inne funkcje.

Cecha class id
Zapis w HTML class="wazne" id="tytul"
Zapis w CSS .wazne #tytul
Powtarzanie Ta sama klasa może wystąpić wiele razy. Id powinno być unikatowe w dokumencie.
Liczba na elemencie Można przypisać wiele klas. Jeden atrybut id z jedną wartością.
Typowe zastosowanie Wspólne style wielu elementów. Oznaczenie konkretnego elementu.
Specyficzność Niższa niż id. Wyższa niż class.

Przykład – poprawne wykorzystanie

<h1 id="tytul-strony">
    Sklep internetowy
</h1>

<p class="produkt">
    Laptop
</p>

<p class="produkt">
    Monitor
</p>

<p class="produkt">
    Klawiatura
</p>
#tytul-strony {
    color: navy;
    text-align: center;
}

.produkt {
    background-color: lightgray;
    padding: 10px;
}

Tytuł strony jest pojedynczym elementem oznaczonym identyfikatorem. Produkty tworzą grupę elementów, dlatego zastosowano klasę.

📌 Dobra praktyka

Do wielokrotnego stylowania podobnych elementów najczęściej używamy klas. Identyfikatory stosujemy wtedy, gdy potrzebujemy jednoznacznie oznaczyć element.

9. Grupowanie selektorów

Czasami chcemy nadać ten sam styl kilku różnym rodzajom elementów.

Zamiast powtarzać deklaracje, możemy połączyć selektory przecinkiem.

Przykład – bez grupowania

h1 {
    color: navy;
}

h2 {
    color: navy;
}

h3 {
    color: navy;
}

Ten sam efekt – z grupowaniem

h1, h2, h3 {
    color: navy;
}

Reguła dotyczy nagłówków h1, h2 i h3.

Grupowanie różnych typów selektorów

h2, .wazne, #stopka {
    color: darkgreen;
}

Reguła dotyczy:

  • Wszystkich elementów h2.
  • Wszystkich elementów z klasą wazne.
  • Elementu z identyfikatorem stopka.

Przykład – wspólne obramowanie

.produkt, .oferta, .komunikat {
    border: 1px solid gray;
    padding: 15px;
}

Grupowanie ogranicza powtarzanie kodu i ułatwia późniejsze zmiany.

10. Łączenie selektorów

Grupowanie selektorów przecinkiem nie jest tym samym co ich łączenie.

Możemy tworzyć selektory, które wskazują bardziej konkretną grupę elementów.

Selektor elementu z klasą

HTML:

<p class="wazne">
    Ważny akapit.
</p>

<h2 class="wazne">
    Ważny nagłówek.
</h2>

CSS:

p.wazne {
    color: red;
}

Reguła wskazuje wyłącznie elementy p, które mają klasę wazne.

Nagłówek h2 nie otrzyma tego stylu, mimo że ma taką samą klasę.

Element mający jednocześnie dwie klasy

HTML:

<p class="komunikat wazne">
    Ważny komunikat.
</p>

<p class="komunikat">
    Zwykły komunikat.
</p>

CSS:

.komunikat.wazne {
    color: red;
    font-weight: bold;
}

Brak spacji między nazwami klas oznacza, że element musi mieć obie klasy jednocześnie.

Selektor potomka – spacja

HTML:

<section class="oferta">

    <h2>Nasza oferta</h2>

    <p>
        Zapraszamy do zapoznania się
        z ofertą.
    </p>

</section>

<p>
    Akapit poza sekcją.
</p>

CSS:

.oferta p {
    color: green;
}

Selektor wskazuje akapity znajdujące się wewnątrz elementu z klasą oferta.

Akapit poza tą sekcją nie zostanie wskazany.

Porównanie zapisów

Selektor Znaczenie
.wazne Dowolny element z klasą wazne.
p.wazne Akapit mający klasę wazne.
.komunikat.wazne Element mający obie klasy.
.oferta p Akapit będący potomkiem elementu z klasą oferta.
h1, h2 Wszystkie h1 oraz wszystkie h2.

📌 Bardzo ważne

.komunikat.wazne i .komunikat .wazne to dwa różne selektory. Pierwszy wskazuje jeden element mający obie klasy, a drugi element z klasą wazne znajdujący się wewnątrz elementu z klasą komunikat.

11. Selektor uniwersalny

Selektor uniwersalny zapisujemy za pomocą gwiazdki *.

Wskazuje wszystkie elementy pasujące do danego kontekstu.

Przykład

* {
    box-sizing: border-box;
}

Ta reguła ustawia box-sizing: border-box dla wszystkich elementów.

Wartość border-box sprawia, że zadana szerokość i wysokość elementu obejmuje również jego obramowanie i odstępy wewnętrzne.

Selektor uniwersalny w określonej sekcji

.oferta * {
    color: darkblue;
}

Reguła wskazuje wszystkie elementy potomne znajdujące się wewnątrz elementu z klasą oferta.

📌 Ważne

Selektor * ma zerową specyficzność. Nie należy mylić go z selektorem elementu, takim jak p.

12. Specyficzność poznanych selektorów

W poprzedniej lekcji poznaliśmy podstawy kaskadowości. Teraz możemy dokładniej przeanalizować wpływ selektorów na wynik stylowania.

Porównanie specyficzności

Selektor Specyficzność
* 0-0-0
p 0-0-1
.wazne 0-1-0
p.wazne 0-1-1
.komunikat.wazne 0-2-0
#tytul 1-0-0

Przykład – który kolor wygra?

HTML:

<p class="wazne" id="informacja">
    Ważna informacja.
</p>

CSS:

p {
    color: blue;
}

.wazne {
    color: red;
}

#informacja {
    color: green;
}

Wynik: tekst będzie zielony.

Przy zwykłych regułach autora o tym samym pochodzeniu i bez dodatkowych warstw, selektor identyfikatora ma największą specyficzność spośród tych trzech.

Przykład – bardziej szczegółowy selektor klasy

.wazne {
    color: red;
}

p.wazne {
    color: purple;
}

Dla akapitu z klasą wazne wygra kolor fioletowy, ponieważ p.wazne ma większą specyficzność niż samo .wazne.

📌 Zapamiętaj

Większa specyficzność nie oznacza automatycznie lepszego kodu. Do codziennego stylowania warto stosować proste, czytelne selektory, szczególnie klasy.

13. Komentarze i czytelny zapis CSS

Czytelny kod CSS ułatwia rozwijanie strony, poprawianie błędów i pracę nad większym projektem.

Komentarze

/* Wygląd całej strony */

body {
    font-family: Arial, sans-serif;
}

/* Nagłówki */

h1 {
    color: navy;
}

/* Komunikaty */

.komunikat {
    padding: 15px;
}

Wcięcia i nowe linie

Poniższe zapisy są poprawne, ale różnią się czytelnością. 

/* Mało czytelnie */

h1{color:blue;font-size:30px;text-align:center;}


/* Czytelnie */

h1 {
    color: blue;
    font-size: 30px;
    text-align: center;
}

Nazwy klas

Nazwy powinny informować o przeznaczeniu elementu. 

/* Przykładowe nazwy */

.naglowek-strony {
    color: navy;
}

.karta-produktu {
    border: 1px solid gray;
}

.komunikat-bledu {
    color: darkred;
}

Warto stosować krótkie, zrozumiałe nazwy, bez spacji i polskich znaków.

14. Najczęstsze błędy

Błąd 1 – brak kropki przed klasą

HTML:

<p class="wazne">
    Ważna informacja.
</p>

Niepoprawny selektor:

wazne {
    color: red;
}

Poprawny selektor:

.wazne {
    color: red;
}

Błąd 2 – brak znaku # przed identyfikatorem

HTML:

<h1 id="tytul">
    Moja strona
</h1>

Poprawny selektor:

#tytul {
    color: navy;
}

Błąd 3 – wpisanie kropki do wartości class

<!-- Niepoprawnie -->

<p class=".wazne">
    Tekst
</p>


<!-- Poprawnie -->

<p class="wazne">
    Tekst
</p>

Błąd 4 – kilka klas oddzielonych przecinkami

<!-- Niepoprawnie -->

<p class="wazne, duzy-tekst">
    Tekst
</p>


<!-- Poprawnie -->

<p class="wazne duzy-tekst">
    Tekst
</p>

Błąd 5 – powtarzanie identyfikatorów

<!-- Niepoprawnie -->

<p id="opis">Pierwszy opis.</p>

<p id="opis">Drugi opis.</p>


<!-- Lepiej zastosować klasę -->

<p class="opis">Pierwszy opis.</p>

<p class="opis">Drugi opis.</p>

Błąd 6 – mylenie grupowania z łączeniem

/* Wszystkie h1 i wszystkie h2 */

h1, h2 {
    color: blue;
}


/* Element h2 wewnątrz elementu h1 */

h1 h2 {
    color: blue;
}

Drugi selektor nie oznacza „h1 oraz h2”. Oznacza element h2 będący potomkiem h1. Takie zagnieżdżenie nagłówków nie jest prawidłową strukturą HTML.

Błąd 7 – niepoprawne nazwy właściwości

/* Niepoprawnie */

p {
    font_size: 18px;
    text-color: red;
}


/* Poprawnie */

p {
    font-size: 18px;
    color: red;
}

15. Kompletny przykład – strona z selektorami CSS

Przygotujemy prostą stronę prezentującą trzy kursy informatyczne. Wykorzystamy selektory elementów, klas i identyfikatorów.

Struktura projektu

kursy/
|
|-- index.html
|
|-- style.css

Plik index.html

<!DOCTYPE html>
<html lang="pl">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Kursy informatyczne</title>

    <link rel="stylesheet" href="style.css">

</head>

<body>

    <header>

        <h1 id="tytul-strony">
            Kursy informatyczne
        </h1>

        <p>
            Wybierz kurs dla siebie.
        </p>

    </header>

    <main>

        <section class="kurs">

            <h2>HTML5</h2>

            <p>
                Nauczysz się tworzyć
                strukturę stron internetowych.
            </p>

            <p class="cena">
                Cena: 199 zł
            </p>

        </section>

        <section class="kurs polecany">

            <h2>CSS3</h2>

            <p>
                Poznasz sposoby stylowania
                stron internetowych.
            </p>

            <p class="cena">
                Cena: 249 zł
            </p>

            <p class="etykieta">
                Polecany kurs
            </p>

        </section>

        <section class="kurs">

            <h2>JavaScript</h2>

            <p>
                Nauczysz się tworzyć
                interaktywne strony WWW.
            </p>

            <p class="cena">
                Cena: 299 zł
            </p>

📌 Zapamiętaj

  • Reguła CSS składa się z selektora i bloku deklaracji.
  • Selektor określa, które elementy HTML mają otrzymać styl.
  • Selektor elementu zapisujemy nazwą znacznika, np. p.
  • Selektor klasy zapisujemy z kropką, np. .wazne.
  • Selektor identyfikatora zapisujemy ze znakiem #, np. #tytul.
  • Ta sama klasa może być przypisana wielu elementom.
  • Identyfikator powinien być unikatowy w dokumencie HTML.
  • Jeden element może mieć kilka klas oddzielonych spacjami.
  • Selektory można grupować za pomocą przecinków.
  • p.wazne wskazuje akapit mający klasę wazne.
  • .komunikat.wazne wskazuje element mający obie klasy.
  • .oferta p wskazuje akapity znajdujące się wewnątrz elementu z klasą oferta.
  • Selektor * jest selektorem uniwersalnym.
  • Selektory mają różną specyficzność.
  • Przy typowych konfliktach zwykłych reguł autora selektor id ma większą specyficzność niż selektor klasy, a klasa większą niż selektor elementu.
  • Komentarze CSS zapisujemy pomiędzy /* i */.
  • Najlepiej stosować czytelne nazwy klas i unikać niepotrzebnego powtarzania kodu.

📝 Zadania praktyczne

Cel: samodzielne stosowanie selektorów elementów, klas i identyfikatorów, przypisywanie wielu klas oraz grupowanie i łączenie selektorów.

Utwórz folder PSI_18, a w nim dwa pliki: index.html oraz style.css.

Wszystkie zadania wykonaj na jednej stronie internetowej. Każde zadanie powinno tworzyć osobną sekcję dokumentu.

Zadanie 1 – Selektory elementów

Przygotuj stronę „Moje ulubione technologie”.

  1. Utwórz poprawny dokument HTML5.
  2. Podłącz plik style.css.
  3. Dodaj nagłówek h1 z tytułem strony.
  4. Dodaj trzy nagłówki h2 z nazwami wybranych technologii.
  5. Pod każdym nagłówkiem umieść akapit z własnym opisem.
  6. Za pomocą selektora body ustaw kolor tła i rodzaj czcionki.
  7. Za pomocą selektora h1 ustaw kolor i wyśrodkowanie tytułu.
  8. Za pomocą selektora h2 ustaw wspólny kolor nagłówków.
  9. Za pomocą selektora p ustaw rozmiar czcionki 18px.

Zadanie 2 – Klasy CSS

Dodaj sekcję „Komunikaty systemowe”.

  1. Dodaj nagłówek h2 „Komunikaty systemowe”.
  2. Utwórz trzy akapity z przykładowymi komunikatami.
  3. Pierwszemu nadaj klasę sukces.
  4. Drugiemu nadaj klasę blad.
  5. Trzeciemu nadaj klasę ostrzezenie.
  6. W CSS ustaw zielony kolor tekstu dla klasy sukces.
  7. Ustaw czerwony kolor tekstu dla klasy blad.
  8. Ustaw pomarańczowy kolor tekstu dla klasy ostrzezenie.
  9. Dodaj klasę komunikat do wszystkich trzech akapitów.
  10. Za pomocą klasy komunikat ustaw obramowanie i odstęp wewnętrzny.

Zadanie 3 – Identyfikatory i łączenie selektorów

Dodaj sekcję „Moje projekty”.

  1. Utwórz element section z identyfikatorem projekty.
  2. Dodaj nagłówek h2 „Moje projekty”.
  3. Utwórz trzy elementy div z klasą projekt.
  4. W każdym elemencie umieść nagłówek h3 i krótki opis projektu.
  5. Za pomocą selektora #projekty ustaw kolor tła całej sekcji.
  6. Za pomocą selektora .projekt ustaw obramowanie i odstępy.
  7. Za pomocą selektora .projekt h3 ustaw kolor nagłówków projektów.
  8. Dodaj do jednego projektu dodatkową klasę wyrozniony.
  9. Za pomocą klasy .wyrozniony ustaw inne tło tego projektu.
  10. Za pomocą selektora .projekt.wyrozniony ustaw grubsze obramowanie wyróżnionego projektu.

Zadanie 4 – Grupowanie selektorów

Wykorzystaj stronę przygotowaną w poprzednich zadaniach.

  1. Ustaw ten sam kolor tekstu dla nagłówków h1, h2 i h3, wykorzystując jedną regułę CSS z przecinkami.
  2. Dodaj wspólne obramowanie dla klas .sukces, .blad i .ostrzezenie za pomocą grupowania.
  3. Sprawdź, czy style wspólne i indywidualne działają jednocześnie.
  4. Dodaj do arkusza CSS komentarze opisujące poszczególne grupy reguł.

Zadanie 5 – Popraw błędy (dodatkowe)

Znajdź i popraw błędy w poniższym kodzie.

HTML:

<h2 class=".naglowek">
    Aktualności
</h2>

<p class="wazne, komunikat">
    Ważna wiadomość.
</p>

<p id="opis">
    Pierwszy opis.
</p>

<p id="opis">
    Drugi opis.
</p>

CSS:

naglowek {
    color: blue;
}

wazne {
    color: red;
}

#komunikat {
    background-color: yellow;
}

opis {
    font_size: 18px;
}

Popraw kod tak, aby:

  • Nagłówek był niebieski.
  • Ważna wiadomość była czerwona.
  • Wiadomość miała żółte tło.
  • Oba opisy miały rozmiar czcionki 18 pikseli.
  • W dokumencie nie powtarzały się identyfikatory.
