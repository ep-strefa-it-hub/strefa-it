Flexbox – kontener elastyczny, kierunek, rozmieszczanie i wyrównywanie elementów

Cel lekcji: poznanie modelu Flexbox i wykorzystanie jego właściwości do tworzenia elastycznych układów elementów strony internetowej, w tym menu nawigacyjnego, kart informacyjnych i responsywnych sekcji.

1. Wprowadzenie

Podczas projektowania stron internetowych często musimy umieszczać elementy obok siebie, wyrównywać je, rozdzielać wolną przestrzeń lub dostosowywać ich układ do szerokości ekranu.

Do takich zadań służy Flexbox, czyli elastyczny model układu CSS (Flexible Box Layout).

Flexbox pozwala między innymi:

  • ustawiać elementy w jednym wierszu lub kolumnie,
  • wyrównywać elementy w poziomie i pionie,
  • rozdzielać wolne miejsce między elementami,
  • tworzyć elastyczne menu nawigacyjne,
  • budować układy kart i paneli,
  • przenosić elementy do kolejnych wierszy,
  • dostosowywać układ do różnych rozmiarów ekranu.

Przykładowe zastosowania

Flexbox sprawdza się przy tworzeniu:

  • menu poziomego,
  • pasków narzędzi,
  • kart produktów,
  • sekcji z kilkoma kolumnami,
  • układów tekstu i obrazu,
  • przycisków ustawionych obok siebie.

📌 Zapamiętaj

Flexbox służy przede wszystkim do rozmieszczania elementów w jednym wymiarze: w wierszu lub kolumnie. Może też zawijać elementy do kolejnych wierszy.

2. Zasada działania Flexbox

W modelu Flexbox wyróżniamy dwa podstawowe pojęcia:

  • Kontener elastyczny (flex container) – element, któremu nadano display: flex.
  • Elementy elastyczne (flex items) – bezpośrednie elementy potomne kontenera.

Przykład HTML

<div class="kontener">

    <div class="element">1</div>

    <div class="element">2</div>

    <div class="element">3</div>

</div>

CSS

.kontener {
    display: flex;
}

.element {
    padding: 20px;
    background-color: #BFDBFE;
    border: 1px solid #2563EB;
}

Po zastosowaniu display: flex trzy elementy zostaną ustawione obok siebie w jednym wierszu, jeśli pozwoli na to dostępne miejsce.

Ważna zasada

Właściwości kontenera Flexbox wpływają na jego bezpośrednie dzieci. 

<div class="kontener">

    <div class="karta">

        <h3>Tytuł</h3>

        <p>Opis karty.</p>

    </div>

    <div class="karta">
        Druga karta
    </div>

</div>

Elementami Flexbox są tutaj dwa elementy .karta, a nie znajdujące się wewnątrz pierwszej karty nagłówek i akapit.

3. Tworzenie kontenera – display: flex

Aby rozpocząć pracę z Flexbox, należy nadać elementowi nadrzędnemu właściwość: 

display: flex;

Przykład

<div class="pudelka">

    <div>HTML</div>
    <div>CSS</div>
    <div>JavaScript</div>

</div>
.pudelka {
    display: flex;

    padding: 20px;
    background-color: #E2E8F0;
}

.pudelka div {
    padding: 20px;
    background-color: #93C5FD;
    border: 1px solid #1D4ED8;
}

Elementy będą rozmieszczone w jednym wierszu, ponieważ jest to domyślny kierunek Flexbox.

display: flex a display: inline-flex

Właściwość Znaczenie
display: flex Tworzy kontener elastyczny zachowujący się na zewnątrz jak element blokowy.
display: inline-flex Tworzy kontener elastyczny zachowujący się na zewnątrz jak element liniowy.

📌 Zapamiętaj

display: flex ustawiamy na rodzicu, a nie osobno na każdym elemencie, który chcemy rozmieścić w kontenerze.

4. Oś główna i oś poprzeczna

Flexbox działa w oparciu o dwie osie:

  • Oś główna (main axis) – kierunek rozmieszczania elementów.
  • Oś poprzeczna (cross axis) – oś prostopadła do osi głównej.

Przy flex-direction: row

OŚ GŁÓWNA →

+----------------------------------+
|                                  |
|  [ 1 ]   [ 2 ]   [ 3 ]           |
|                                  |
+----------------------------------+

Oś poprzeczna: pionowa

Przy flex-direction: column

+--------------------+
|                    |
|       [ 1 ]        |
|                    |
|       [ 2 ]        |
|                    |
|       [ 3 ]        |
|                    |
+--------------------+

Oś główna: pionowa ↓
Oś poprzeczna: pozioma

Kierunek osi głównej zależy od wartości flex-direction.

📌 Bardzo ważne

justify-content działa wzdłuż osi głównej, natomiast align-items działa wzdłuż osi poprzecznej. Nie zawsze oznacza to odpowiednio poziom i pion.

5. Kierunek elementów – flex-direction

Właściwość flex-direction określa kierunek rozmieszczania elementów.

Dostępne wartości

Wartość Działanie
row Elementy w wierszu – wartość domyślna.
row-reverse Elementy w wierszu, w odwróconym kierunku.
column Elementy w kolumnie.
column-reverse Elementy w kolumnie, w odwróconym kierunku.

Przykład – wiersz

.kontener {
    display: flex;
    flex-direction: row;
}
[ 1 ] [ 2 ] [ 3 ]

Przykład – kolumna

.kontener {
    display: flex;
    flex-direction: column;
}
[ 1 ]
[ 2 ]
[ 3 ]

Przykład – odwrócony wiersz

.kontener {
    display: flex;
    flex-direction: row-reverse;
}

Elementy zostaną rozmieszczone w przeciwnym kierunku, ale kolejność elementów w kodzie HTML nie ulegnie zmianie.

📌 Uwaga

Wartości row-reverse i column-reverse zmieniają kolejność wizualną. Nie zmieniają kolejności w dokumencie HTML ani logicznej kolejności odczytu przez technologie wspomagające.

6. Rozmieszczanie elementów – justify-content

Właściwość justify-content określa sposób rozmieszczenia elementów wzdłuż osi głównej.

Najważniejsze wartości

Wartość Działanie
flex-start Elementy przy początku osi głównej.
flex-end Elementy przy końcu osi głównej.
center Elementy wyśrodkowane.
space-between Wolna przestrzeń między elementami.
space-around Wolna przestrzeń wokół każdego elementu.
space-evenly Równe odstępy między elementami i przy krawędziach kontenera.

Przykład – wyśrodkowanie

.kontener {
    display: flex;
    justify-content: center;
}
|        [1] [2] [3]        |

Przykład – space-between

.kontener {
    display: flex;
    justify-content: space-between;
}
|[1]         [2]         [3]|

Przykład – space-evenly

.kontener {
    display: flex;
    justify-content: space-evenly;
}
|   [1]    [2]    [3]   |

Przykład zastosowania

.menu {
    display: flex;

    justify-content: center;

    gap: 20px;
}

Elementy menu zostaną wyśrodkowane w kontenerze.

📌 Zapamiętaj

justify-content rozdziela dostępną wolną przestrzeń wzdłuż osi głównej. Jeżeli elementy zajmują całą dostępną przestrzeń, efekt niektórych wartości może być niewidoczny.

7. Wyrównywanie elementów – align-items

Właściwość align-items służy do wyrównywania elementów wzdłuż osi poprzecznej.

Najważniejsze wartości

Wartość Działanie
stretch Rozciąga elementy wzdłuż osi poprzecznej, jeśli pozwalają na to ich rozmiary.
flex-start Wyrównuje do początku osi poprzecznej.
flex-end Wyrównuje do końca osi poprzecznej.
center Wyrównuje do środka osi poprzecznej.
baseline Wyrównuje elementy według linii bazowej tekstu.

Przykład – wyrównanie pionowe

.kontener {
    display: flex;

    height: 250px;

    align-items: center;
}

Przy domyślnym flex-direction: row elementy zostaną wyśrodkowane pionowo w kontenerze.

Wyśrodkowanie w obu osiach

.kontener {
    display: flex;

    justify-content: center;
    align-items: center;

    min-height: 300px;
}

Jest to jeden z najprostszych sposobów wyśrodkowania elementu w poziomie i pionie.

HTML

<div class="kontener">

    <div class="element">
        Wyśrodkowany element
    </div>

</div>

📌 Zapamiętaj

Przy flex-direction: column oś główna jest pionowa. Wówczas justify-content steruje rozmieszczeniem pionowym, a align-items wyrównaniem poziomym.

8. Przenoszenie elementów – flex-wrap

Domyślnie Flexbox próbuje umieścić elementy w jednym wierszu lub jednej kolumnie.

Właściwość flex-wrap pozwala przenosić elementy do kolejnych linii.

Dostępne wartości

Wartość Znaczenie
nowrap Elementy nie są zawijane – wartość domyślna.
wrap Elementy mogą przechodzić do kolejnych linii.
wrap-reverse Elementy mogą się zawijać w odwróconym kierunku osi poprzecznej.

Przykład

.kontener {
    display: flex;

    flex-wrap: wrap;

    gap: 15px;
}

.element {
    width: 200px;
    padding: 20px;

    background-color: #BFDBFE;
}

Jeżeli szerokość kontenera będzie zbyt mała, kolejne elementy zostaną przeniesione do następnego wiersza.

Skrócony zapis – flex-flow

.kontener {
    display: flex;

    flex-flow: row wrap;
}

Powyższy zapis odpowiada: 

.kontener {
    display: flex;

    flex-direction: row;
    flex-wrap: wrap;
}

📌 Zapamiętaj

flex-wrap: wrap jest bardzo przydatne podczas tworzenia responsywnych układów kart.

9. Odstępy między elementami – gap

Właściwość gap określa odstępy między elementami kontenera Flexbox.

Przykład

.kontener {
    display: flex;

    gap: 20px;
}

Między elementami pojawi się odstęp 20 px.

Różne odstępy między wierszami i kolumnami

.kontener {
    display: flex;
    flex-wrap: wrap;

    row-gap: 30px;
    column-gap: 15px;
}

Skrócony zapis

.kontener {
    display: flex;
    flex-wrap: wrap;

    gap: 30px 15px;
}

Pierwsza wartość określa odstęp między wierszami, a druga między kolumnami.

gap a margin

Właściwość Zastosowanie
gap Odstępy między elementami w układzie Flexbox.
margin Zewnętrzny odstęp konkretnego elementu.

📌 Dobra praktyka

W układach Flexbox często wygodniej używać gap niż dodawać marginesy do każdego elementu osobno.

10. Wyrównywanie wielu wierszy – align-content

Właściwość align-content określa rozmieszczenie linii elementów wzdłuż osi poprzecznej.

Jest szczególnie przydatna, gdy elementy zostały zawinięte do kilku wierszy.

Przykład

.kontener {
    display: flex;

    flex-wrap: wrap;

    height: 400px;

    align-content: center;
}

Wiersze zostaną zgrupowane bliżej środka osi poprzecznej, jeśli w kontenerze znajduje się wolna przestrzeń.

Najważniejsze wartości

  • flex-start – linie przy początku osi poprzecznej,
  • flex-end – linie przy końcu osi poprzecznej,
  • center – linie wyśrodkowane,
  • space-between – przestrzeń między liniami,
  • space-around – przestrzeń wokół linii,
  • stretch – rozciąganie linii, gdy jest dostępne miejsce.

Różnica między align-items i align-content

Właściwość Co wyrównuje?
align-items Elementy wewnątrz linii.
align-content Linie elementów w kontenerze.

📌 Uwaga

Przy jednej linii lub bez wolnego miejsca w osi poprzecznej efekt align-content może być niewidoczny.

11. Wyrównanie pojedynczego elementu – align-self

Właściwość align-self pozwala zmienić wyrównanie jednego elementu Flexbox.

Przykład HTML

<div class="kontener">

    <div class="element">1</div>

    <div class="element specjalny">2</div>

    <div class="element">3</div>

</div>

CSS

.kontener {
    display: flex;

    height: 250px;

    align-items: flex-start;
}

.specjalny {
    align-self: flex-end;
}

Wszystkie elementy są wyrównane do początku osi poprzecznej, z wyjątkiem drugiego, który zostanie wyrównany do jej końca.

📌 Zapamiętaj

align-items ustawiamy na kontenerze, natomiast align-self na konkretnym elemencie.

12. Rozciąganie elementów – flex-grow

Właściwość flex-grow określa, jak element może powiększać się, wykorzystując dodatnią wolną przestrzeń wzdłuż osi głównej.

Przykład

.kontener {
    display: flex;
    gap: 10px;
}

.element {
    flex-grow: 1;
}

Wszystkie elementy mają taki sam współczynnik rozdzielania wolnego miejsca.

Jeden element szerszy

.pierwszy {
    flex-grow: 2;
}

.drugi {
    flex-grow: 1;
}

.trzeci {
    flex-grow: 1;
}

Pierwszy element otrzyma dwa udziały w dodatkowej wolnej przestrzeni, a pozostałe po jednym.

Nie oznacza to automatycznie, że pierwszy element będzie miał dokładnie dwa razy większą końcową szerokość. Znaczenie mają także rozmiary początkowe elementów.

📌 Zapamiętaj

Domyślna wartość flex-grow wynosi 0, czyli element nie powiększa się automatycznie tylko po to, aby zająć wolne miejsce.

13. Zmniejszanie elementów – flex-shrink

Właściwość flex-shrink określa, w jakim stopniu element może się zmniejszać, gdy wzdłuż osi głównej brakuje miejsca.

Przykład

.element {
    flex-shrink: 1;
}

Wartość 1 jest domyślna.

Blokowanie zmniejszania

.element {
    flex-shrink: 0;
}

Element nie będzie zmniejszany przez mechanizm flex-shrink.

Może to jednak spowodować wyjście elementu poza kontener, jeśli zabraknie miejsca.

Przykład zastosowania

.logo {
    width: 120px;
    flex-shrink: 0;
}

Takie rozwiązanie może być przydatne, gdy nie chcemy, aby logo zmniejszało się razem z innymi elementami menu.

14. Rozmiar początkowy – flex-basis i skrót flex

Właściwość flex-basis określa początkowy rozmiar elementu wzdłuż osi głównej.

Przykład

.karta {
    flex-basis: 250px;
}

Przy kierunku row jest to początkowa szerokość, a przy kierunku column początkowa wysokość.

Skrócona właściwość flex

Właściwość flex pozwala jednocześnie określić:

  • flex-grow,
  • flex-shrink,
  • flex-basis.

Przykład

.karta {
    flex: 1 1 250px;
}

Oznacza to: 

.karta {
    flex-grow: 1;
    flex-shrink: 1;
    flex-basis: 250px;
}

Praktyczne zastosowanie

.karty {
    display: flex;

    flex-wrap: wrap;
    gap: 20px;
}

.karta {
    flex: 1 1 250px;
}

Karty mogą zajmować dostępną przestrzeń, zmniejszać się w razie potrzeby i przechodzić do kolejnych wierszy.

📌 Zapamiętaj

Zapis flex: 1 1 250px jest często wykorzystywany podczas tworzenia elastycznych kart o podobnych rozmiarach.

15. Kolejność wizualna elementów – order

Właściwość order pozwala zmieniać kolejność wizualną elementów Flexbox.

HTML

<div class="kontener">

    <div class="pierwszy">A</div>

    <div class="drugi">B</div>

    <div class="trzeci">C</div>

</div>

CSS

.kontener {
    display: flex;
}

.pierwszy {
    order: 3;
}

.drugi {
    order: 1;
}

.trzeci {
    order: 2;
}

Wizualna kolejność elementów będzie następująca: 

B   C   A

Domyślna wartość order wynosi 0.

📌 Ważne

order nie zmienia kolejności elementów w HTML ani kolejności nawigacji klawiaturą. Nie używaj go do zmieniania logicznej kolejności ważnych treści.

16. Tworzenie menu nawigacyjnego za pomocą Flexbox

Jednym z najczęstszych zastosowań Flexbox jest tworzenie poziomego menu nawigacyjnego.

HTML

<nav class="menu">

    <a href="#start">Start</a>

    <a href="#oferta">Oferta</a>

    <a href="#galeria">Galeria</a>

    <a href="#kontakt">Kontakt</a>

</nav>

CSS

.menu {
    display: flex;

    justify-content: center;
    align-items: center;

    gap: 20px;

    padding: 15px;

    background-color: #1E3A8A;
}

.menu a {
    padding: 10px 15px;

    color: white;
    text-decoration: none;

    border-radius: 6px;
}

.menu a:hover {
    background-color: #2563EB;
}

Menu z logo po lewej stronie

<nav class="pasek">

    <div class="logo">
        STREFA IT
    </div>

    <div class="linki">

        <a href="#start">Start</a>

        <a href="#oferta">Oferta</a>

        <a href="#kontakt">Kontakt</a>

    </div>

</nav>
.pasek {
    display: flex;

    justify-content: space-between;
    align-items: center;

    padding: 15px 30px;

    background-color: #1E3A8A;
    color: white;
}

.linki {
    display: flex;
    gap: 20px;
}

.linki a {
    color: white;
    text-decoration: none;
}

Dzięki justify-content: space-between logo znajduje się przy jednej krawędzi, a grupa odnośników przy drugiej.

17. Elastyczne karty informacyjne

Flexbox świetnie nadaje się do tworzenia kart prezentujących produkty, usługi, projekty lub informacje.

HTML

<div class="karty">

    <article class="karta">

        <h3>HTML5</h3>

        <p>
            Budowanie struktury stron WWW.
        </p>

    </article>

    <article class="karta">

        <h3>CSS3</h3>

        <p>
            Projektowanie wyglądu stron.
        </p>

    </article>

    <article class="karta">

        <h3>JavaScript</h3>

        <p>
            Dodawanie interaktywności.
        </p>

    </article>

</div>

CSS

.karty {
    display: flex;

    flex-wrap: wrap;

    gap: 20px;
}

.karta {
    flex: 1 1 250px;

    padding: 25px;

    background-color: #F8FAFC;

    border: 1px solid #CBD5E1;
    border-radius: 10px;

    box-shadow:
        0 4px 10px rgba(0, 0, 0, 0.08);
}

Jak działa ten układ?

  1. display: flex tworzy kontener elastyczny.
  2. flex-wrap: wrap pozwala przenosić karty do następnego wiersza.
  3. gap: 20px dodaje odstępy między kartami.
  4. flex: 1 1 250px określa sposób powiększania, zmniejszania i początkowy rozmiar kart.

📌 Zapamiętaj

Połączenie display: flex, flex-wrap: wrap, gap i flex-basis umożliwia tworzenie elastycznych układów bez konieczności ustawiania każdej karty osobno.

18. Flexbox i responsywność strony

Responsywna strona dostosowuje swój układ do szerokości urządzenia.

Flexbox ułatwia takie dostosowanie, szczególnie w połączeniu z regułami @media.

Przykład – menu na telefonie

.menu {
    display: flex;

    justify-content: center;

    gap: 20px;
}

@media (max-width: 600px) {

    .menu {
        flex-direction: column;

        align-items: stretch;

        gap: 10px;
    }

    .menu a {
        text-align: center;
    }

}

Na szerokim ekranie odnośniki będą ustawione poziomo.

Na ekranie o szerokości maksymalnie 600 px menu zmieni kierunek na pionowy.

Przykład – dwie kolumny

<div class="uklad">

    <main class="tresc">
        Główna treść
    </main>

    <aside class="panel">
        Panel boczny
    </aside>

</div>
.uklad {
    display: flex;

    gap: 20px;
}

.tresc {
    flex: 3;
    min-width: 0;
}

.panel {
    flex: 1;
    min-width: 0;
}

@media (max-width: 700px) {

    .uklad {
        flex-direction: column;
    }

}

Na większym ekranie główna treść i panel znajdują się obok siebie.

Na mniejszym ekranie zostają ustawione jeden pod drugim.

📌 Zapamiętaj

Flexbox i media queries można łączyć, aby zmieniać układ elementów w zależności od szerokości ekranu.

19. Najczęstsze błędy

Błąd 1 – brak display: flex

.kontener {
    justify-content: center;
}

Samo justify-content nie tworzy kontenera Flexbox.

Poprawnie:

.kontener {
    display: flex;
    justify-content: center;
}

Błąd 2 – ustawianie justify-content na dziecku

.element {
    justify-content: center;
}

Jeśli chcemy rozmieścić elementy wewnątrz kontenera, właściwość powinna znajdować się na tym kontenerze.

Błąd 3 – mylenie osi

justify-content nie zawsze oznacza wyrównanie poziome.

Wszystko zależy od flex-direction.

Błąd 4 – brak flex-wrap

.karty {
    display: flex;
}

Elementy domyślnie nie będą zawijane do kolejnych wierszy.

Rozwiązanie:

.karty {
    display: flex;
    flex-wrap: wrap;
}

Błąd 5 – brak miejsca na wyrównanie

Jeśli kontener nie ma wolnej przestrzeni w odpowiedniej osi, działanie justify-content lub align-content może nie być widoczne.

Błąd 6 – sztywne szerokości kart

.karta {
    width: 400px;
}

Taki układ może być niewygodny na małych ekranach.

Elastyczniejszy zapis:

.karta {
    flex: 1 1 250px;
}

Błąd 7 – niepotrzebna zmiana kolejności

Używanie order do zmiany logicznej kolejności treści może utrudniać nawigację klawiaturą.

Błąd 8 – zbyt wiele właściwości bez potrzeby

Nie zawsze trzeba stosować wszystkie właściwości Flexbox.

Często wystarczą: 

.kontener {
    display: flex;
    gap: 20px;
}

📌 Dobra praktyka

Najpierw określ, czy elementy mają być ustawione w wierszu czy kolumnie. Następnie zdecyduj, jak mają być rozmieszczone i wyrównane.

📌 Zwróć uwagę

W przykładzie zastosowano kilka kontenerów Flexbox. Każdy z nich odpowiada za inny fragment strony. Można zagnieżdżać kontenery elastyczne wewnątrz innych kontenerów.

📌 Zapamiętaj

  • display: flex tworzy kontener elastyczny.
  • Elementami Flexbox są bezpośrednie dzieci kontenera.
  • flex-direction określa kierunek rozmieszczania elementów.
  • row ustawia elementy w wierszu.
  • column ustawia elementy w kolumnie.
  • row-reverse i column-reverse odwracają kierunek wizualny.
  • justify-content rozmieszcza elementy wzdłuż osi głównej.
  • align-items wyrównuje elementy wzdłuż osi poprzecznej.
  • justify-content: center wyśrodkowuje elementy w osi głównej.
  • align-items: center wyśrodkowuje elementy w osi poprzecznej.
  • space-between rozdziela wolne miejsce między elementami.
  • space-around rozmieszcza wolne miejsce wokół elementów.
  • space-evenly tworzy równe odstępy między elementami i przy krawędziach.
  • flex-wrap: wrap pozwala przenosić elementy do kolejnych linii.
  • flex-flow łączy flex-direction i flex-wrap.
  • gap ustawia odstępy między elementami.
  • row-gap i column-gap ustawiają odstępy między liniami i kolumnami.
  • align-content rozmieszcza linie elementów wzdłuż osi poprzecznej.
  • align-self wyrównuje pojedynczy element.
  • flex-grow określa możliwość powiększania elementu.
  • flex-shrink określa możliwość zmniejszania elementu.
  • flex-basis określa początkowy rozmiar elementu.
  • flex jest skrótem dla grow, shrink i basis.
  • order zmienia kolejność wizualną elementów.
  • Flexbox można łączyć z @media w celu tworzenia responsywnych układów.
  • Zmiana kolejności wizualnej nie zmienia logicznej kolejności treści w HTML.

Zadanie 2 – Kierunek i wyrównywanie elementów

Rozbuduj układ przygotowany w zadaniu 1.

  1. Ustaw flex-direction: row dla kontenera kart.
  2. Przetestuj flex-direction: column.
  3. Przetestuj row-reverse.
  4. Przywróć kierunek row.
  5. Ustaw justify-content: center.
  6. Przetestuj space-between i space-evenly.
  7. Dodaj sekcję powitalną z kontenerem Flexbox.
  8. Wyśrodkuj jej zawartość za pomocą justify-content i align-items.

Zadanie 3 – Elastyczne karty i odstępy

Dostosuj karty, aby mogły zmieniać swój układ zależnie od szerokości ekranu.

  1. Ustaw flex-wrap: wrap dla kontenera kart.
  2. Dodaj odstępy między kartami za pomocą gap: 20px.
  3. Ustaw dla kart flex: 1 1 240px.
  4. Dodaj padding i obramowanie kart.
  5. Zaokrąglij narożniki kart.
  6. Dodaj delikatny cień.
  7. Zmniejsz szerokość okna przeglądarki.
  8. Sprawdź, czy karty przechodzą do kolejnych wierszy.

Zadanie 4 – Menu nawigacyjne z Flexbox

Przygotuj menu nawigacyjne strony.

  1. Dodaj element nav.
  2. Utwórz odnośniki: Start, Oferta, Kontakt.
  3. Dodaj odpowiednie identyfikatory sekcjom strony.
  4. Ustaw display: flex dla menu.
  5. Wyśrodkuj odnośniki za pomocą justify-content: center.
  6. Dodaj odstępy między odnośnikami.
  7. Ustaw kolor tła menu.
  8. Usuń podkreślenia odnośników.
  9. Dodaj efekt :hover.
  10. Sprawdź działanie wszystkich odnośników.

Zadanie 5 – Wyrównanie elementów wewnątrz kart

Rozbuduj każdą kartę o przycisk lub odnośnik.

  1. Dodaj do każdej karty odnośnik „Dowiedz się więcej”.
  2. Ustaw display: flex dla każdej karty.
  3. Ustaw flex-direction: column.
  4. Dodaj margin-top: auto do odnośnika w karcie.
  5. Sprawdź, czy odnośniki są wyrównane do dolnej części kart.
  6. Dodaj efekt :hover do przycisków.
  7. Dodaj widoczny styl :focus-visible.

Zadanie 6 – Responsywność i testowanie

Dostosuj stronę do małych ekranów.

  1. Dodaj regułę @media (max-width: 700px).
  2. Na małym ekranie ustaw menu pionowo za pomocą flex-direction: column.
  3. Wyśrodkuj odnośniki menu.
  4. Ustaw karty jedna pod drugą na małych ekranach.
  5. Sprawdź wygląd sekcji powitalnej.
  6. Sprawdź, czy żaden element nie wychodzi poza szerokość ekranu.
  7. Przetestuj stronę w widoku komputera i telefonu.
  8. Popraw ewentualne błędy w rozmieszczeniu elementów.
