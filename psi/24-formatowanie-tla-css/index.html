Formatowanie tła – kolor, obraz, powtarzanie, pozycjonowanie i rozmiar tła

Cel lekcji: poznanie właściwości CSS służących do formatowania tła elementów HTML, stosowanie kolorów i obrazów jako tła, kontrolowanie powtarzania, położenia oraz rozmiaru grafiki, a także tworzenie estetycznych i czytelnych sekcji stron internetowych.

1. Wprowadzenie – czym jest tło elementu?

W CSS możemy zmieniać nie tylko wygląd tekstu, ale również tło elementów HTML.

Tło może być jednolitym kolorem, obrazem, gradientem albo połączeniem kilku warstw graficznych.

Tło można ustawić między innymi dla:

  • całej strony – body,
  • nagłówka – header,
  • sekcji – section,
  • artykułu – article,
  • przycisku – button,
  • dowolnego kontenera – div.

Przykład

body {
    background-color: #F1F5F9;
}

header {
    background-color: #1E3A8A;
}

section {
    background-color: white;
}

Każdy element może posiadać własne tło, niezależnie od tła pozostałych elementów.

📌 Zapamiętaj

Tło elementu jest częścią jego wyglądu. Nie zmienia struktury dokumentu HTML.

Właściwości tła zapisujemy w arkuszu CSS.

2. Kolor tła – background-color

Właściwość background-color określa kolor tła elementu.

Składnia

selektor {
    background-color: kolor;
}

Kolor zapisany nazwą

section {
    background-color: lightblue;
}

Kolor zapisany w HEX

section {
    background-color: #DBEAFE;
}

Kolor zapisany w RGB

section {
    background-color: rgb(219, 234, 254);
}

Kolor z przezroczystością

section {
    background-color: rgba(37, 99, 235, 0.3);
}

Ostatnia wartość w zapisie rgba() określa przezroczystość koloru:

  • 0 – całkowita przezroczystość,
  • 0.5 – częściowa przezroczystość,
  • 1 – pełna nieprzezroczystość.

Przykład HTML

<div class="komunikat">
    <p>Witaj na mojej stronie!</p>
</div>

Przykład CSS

.komunikat {
    background-color: #DCFCE7;
    color: #166534;
    padding: 20px;
}

📌 Ważne

Właściwość background-color zmienia kolor tła, natomiast color zmienia kolor tekstu.

3. Obraz jako tło – background-image

Właściwość background-image pozwala umieścić obraz w tle elementu.

Składnia

selektor {
    background-image: url("obraz.jpg");
}

Przykład

header {
    background-image: url("img/las.jpg");
}

Przeglądarka pobierze obraz las.jpg z folderu img, znajdującego się obok pliku CSS.

Przykład HTML

<section class="baner">

    <h1>Odkrywaj świat</h1>

    <p>
        Poznaj najpiękniejsze miejsca.
    </p>

</section>

Przykład CSS

.baner {
    background-image: url("img/gory.jpg");
    min-height: 350px;
    padding: 40px;
    color: white;
}

Obraz zostanie umieszczony w tle sekcji.

Domyślnie obraz tła może się powtarzać, dlatego często dodajemy kolejne właściwości.

Połączenie obrazu i koloru tła

.baner {
    background-color: #1E3A8A;
    background-image: url("img/gory.jpg");
}

Kolor tła znajduje się pod obrazem. Może być widoczny, gdy obraz nie pokrywa całego elementu, zawiera przezroczyste fragmenty albo nie zostanie załadowany.

📌 Ważne

background-image służy przede wszystkim do obrazów dekoracyjnych.

Jeśli obraz przekazuje istotne informacje, powinien być zwykle umieszczony w HTML za pomocą znacznika <img> z odpowiednim tekstem alternatywnym.

4. Ścieżki do obrazów tła

Przy korzystaniu z background-image bardzo ważna jest poprawna ścieżka do pliku graficznego.

Ścieżka względna w url() zapisana w zewnętrznym arkuszu CSS jest liczona względem położenia tego arkusza CSS.

Przykład 1 – CSS i folder img obok siebie

projekt/
|
|-- index.html
|-- style.css
|
|-- img/
    |-- las.jpg

Poprawny zapis:

.baner {
    background-image: url("img/las.jpg");
}

Przykład 2 – CSS w osobnym folderze

projekt/
|
|-- index.html
|
|-- css/
|   |-- style.css
|
|-- img/
    |-- las.jpg

Tym razem musimy wyjść z folderu css o jeden poziom wyżej. 

.baner {
    background-image: url("../img/las.jpg");
}

Przykład 3 – adres internetowy

.baner {
    background-image: url("https://example.com/obraz.jpg");
}

Można korzystać z adresów URL, ale w projektach szkolnych najwygodniej przechowywać własne obrazy w folderze projektu.

📌 Zapamiętaj

Przy zewnętrznym pliku CSS ścieżkę do obrazu zapisujemy względem lokalizacji pliku CSS, a nie względem index.html.

5. Powtarzanie obrazu – background-repeat

Właściwość background-repeat określa, czy i w jaki sposób obraz tła ma się powtarzać.

Domyślną wartością jest repeat.

Wartość Działanie
repeat Powtarza obraz poziomo i pionowo.
repeat-x Powtarza obraz poziomo.
repeat-y Powtarza obraz pionowo.
no-repeat Nie powtarza obrazu.
space Powtarza całe obrazy z odstępami, jeśli pozwala na to dostępne miejsce.
round Dostosowuje rozmiar powtarzanych obrazów, aby wypełnić obszar całymi kafelkami.

Powtarzanie w obu kierunkach

body {
    background-image: url("img/wzor.png");
    background-repeat: repeat;
}

Powtarzanie poziome

header {
    background-image: url("img/pasek.png");
    background-repeat: repeat-x;
}

Powtarzanie pionowe

aside {
    background-image: url("img/wzor.png");
    background-repeat: repeat-y;
}

Bez powtarzania

.baner {
    background-image: url("img/gory.jpg");
    background-repeat: no-repeat;
}

Typowe zastosowania

  • repeat – drobne wzory i tekstury.
  • repeat-x – dekoracyjne paski poziome.
  • repeat-y – pionowe dekoracje.
  • no-repeat – zdjęcia i duże grafiki.

📌 Dobra praktyka

Dla dużych zdjęć najczęściej stosujemy background-repeat: no-repeat.

Powtarzanie najlepiej sprawdza się przy małych grafikach przygotowanych jako wzory.

6. Pozycjonowanie tła – background-position

Właściwość background-position określa położenie obrazu w obszarze pozycjonowania tła.

Podstawowe wartości

Wartość Znaczenie
left Wyrównanie do lewej.
right Wyrównanie do prawej.
top Wyrównanie do góry.
bottom Wyrównanie do dołu.
center Wyśrodkowanie.

Obraz na środku

.baner {
    background-image: url("img/gory.jpg");
    background-repeat: no-repeat;
    background-position: center;
}

Obraz w prawym górnym rogu

.baner {
    background-image: url("img/gory.jpg");
    background-repeat: no-repeat;
    background-position: right top;
}

Obraz na dole pośrodku

.baner {
    background-image: url("img/gory.jpg");
    background-repeat: no-repeat;
    background-position: center bottom;
}

Pozycjonowanie procentowe

.baner {
    background-position: 50% 50%;
}

Zapis 50% 50% oznacza wyśrodkowanie obrazu.

Inny przykład

.baner {
    background-position: 20% 70%;
}

Pierwsza wartość dotyczy położenia poziomego, a druga pionowego.

Pozycjonowanie w pikselach

.baner {
    background-position: 30px 20px;
}

Obraz jest przesunięty o 30 px w poziomie i 20 px w pionie względem początku obszaru pozycjonowania.

📌 Ważne

W przypadku wartości procentowych przeglądarka dopasowuje wskazany punkt obrazu do odpowiadającego mu punktu obszaru pozycjonowania.

Dlatego 50% 50% oznacza środek obrazu ustawiony na środku obszaru.

7. Rozmiar obrazu tła – background-size

Właściwość background-size określa rozmiar obrazu wykorzystywanego jako tło.

Rozmiar w pikselach

.baner {
    background-image: url("img/gory.jpg");
    background-size: 300px 200px;
}

Obraz otrzyma szerokość 300 px i wysokość 200 px. Jeśli proporcje oryginalnego obrazu są inne, może dojść do jego zniekształcenia.

Rozmiar z zachowaniem proporcji

.baner {
    background-size: 300px auto;
}

Szerokość obrazu wyniesie 300 px, a wysokość zostanie obliczona z zachowaniem proporcji.

Rozmiar procentowy

.baner {
    background-size: 50% auto;
}

Szerokość obrazu tła zostanie obliczona jako 50% szerokości obszaru pozycjonowania.

Wartość auto

.baner {
    background-size: auto;
}

Przeglądarka wykorzystuje naturalne wymiary obrazu, jeśli są dostępne, zgodnie z zasadami obliczania rozmiaru tła.

Najważniejsze wartości

Wartość Działanie
auto Automatyczne wyznaczanie rozmiaru.
300px 200px Dokładna szerokość i wysokość.
50% auto Szerokość procentowa z zachowaniem proporcji.
cover Wypełnienie całego obszaru.
contain Zmieszczenie całego obrazu w obszarze.

8. Różnica między cover a contain

Dwie bardzo ważne wartości właściwości background-size to cover oraz contain.

background-size: cover

.baner {
    background-image: url("img/gory.jpg");
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
}

Obraz zostaje przeskalowany z zachowaniem proporcji tak, aby całkowicie pokrywał obszar tła.

Część obrazu może zostać niewidoczna poza granicami elementu.

background-size: contain

.baner {
    background-image: url("img/gory.jpg");
    background-size: contain;
    background-position: center;
    background-repeat: no-repeat;
}

Cały obraz zostaje zmieszczony w obszarze z zachowaniem proporcji.

Mogą pozostać fragmenty obszaru niepokryte obrazem.

Porównanie

Właściwość cover contain
Cały obraz widoczny Niekoniecznie Tak
Cały obszar pokryty Tak Niekoniecznie
Zachowanie proporcji Tak Tak
Typowe zastosowanie Banery, sekcje ze zdjęciem Grafiki dekoracyjne, ilustracje

📌 Zapamiętaj

cover – wypełnia cały obszar, ale może przyciąć obraz.

contain – pokazuje cały obraz, ale może pozostawić wolną przestrzeń.

9. Przewijanie tła – background-attachment

Właściwość background-attachment określa zachowanie obrazu tła podczas przewijania.

scroll

.baner {
    background-image: url("img/las.jpg");
    background-attachment: scroll;
}

Tło przewija się razem z elementem w dokumencie.

fixed

.baner {
    background-image: url("img/las.jpg");
    background-attachment: fixed;
}

Tło jest przywiązane do obszaru widoku, a nie do przewijanej zawartości elementu.

local

.panel {
    height: 200px;
    overflow: auto;
    background-image: url("img/wzor.png");
    background-attachment: local;
}

Tło przewija się razem z zawartością elementu, jeśli element posiada własny obszar przewijania.

Wartość Zachowanie
scroll Tło przewija się z elementem w dokumencie.
fixed Tło jest związane z obszarem widoku.
local Tło przewija się z zawartością elementu.

📌 Uwaga

Efekt fixed może zachowywać się różnie na urządzeniach mobilnych. Nie należy opierać działania całej strony na tym efekcie.

10. Obszar pozycjonowania tła – background-origin

Właściwość background-origin określa, od którego obszaru pudełka elementu obliczane jest położenie obrazu tła.

Najważniejsze wartości:

  • border-box – obszar wraz z obramowaniem,
  • padding-box – obszar wraz z paddingiem, bez obramowania,
  • content-box – obszar samej zawartości.

Przykład

.karta {
    width: 350px;
    min-height: 250px;
    padding: 30px;
    border: 10px dashed black;

    background-image: url("img/wzor.png");
    background-repeat: no-repeat;
    background-position: left top;

    background-origin: content-box;
}

W tym przypadku pozycjonowanie obrazu rozpoczyna się względem obszaru zawartości.

Inny przykład

.karta {
    background-origin: padding-box;
}

Jest to domyślna wartość dla zwykłego obrazu tła.

📌 Ważne

background-origin określa obszar pozycjonowania obrazu, a nie to, gdzie tło jest widoczne.

Za obszar malowania tła odpowiada background-clip.

11. Obszar malowania tła – background-clip

Właściwość background-clip określa, do którego obszaru pudełka elementu tło może być malowane.

border-box

.karta {
    background-color: lightblue;
    background-clip: border-box;
}

Tło rozciąga się również pod obszarem obramowania. To wartość domyślna.

padding-box

.karta {
    background-color: lightblue;
    background-clip: padding-box;
}

Tło jest malowane pod zawartością i paddingiem, ale nie pod obramowaniem.

content-box

.karta {
    background-color: lightblue;
    background-clip: content-box;
}

Tło jest malowane tylko w obszarze zawartości.

Porównanie

Wartość Obszar tła
border-box Do zewnętrznej krawędzi obramowania.
padding-box Do wewnętrznej krawędzi obramowania.
content-box Tylko obszar zawartości.

12. Skrócony zapis background

Zamiast zapisywać każdą właściwość osobno, możemy użyć skróconej właściwości background.

Pełny zapis

.baner {
    background-color: #1E3A8A;
    background-image: url("img/gory.jpg");
    background-repeat: no-repeat;
    background-position: center;
    background-size: cover;
}

Zapis skrócony

.baner {
    background: #1E3A8A
                url("img/gory.jpg")
                center / cover
                no-repeat;
}

Oba zapisy pozwalają uzyskać taki sam efekt.

Dlaczego stosujemy ukośnik?

W skróconej właściwości background znak / oddziela pozycję tła od jego rozmiaru. 

background: center / cover;

center oznacza pozycję, a cover oznacza rozmiar.

Inny przykład

.sekcja {
    background: url("img/wzor.png")
                left top / 100px auto
                repeat;
}

📌 Uwaga

Zastosowanie skróconego background ustawia również pominięte właściwości tła na ich wartości początkowe.

Dlatego przy poprawianiu istniejących stylów warto sprawdzić, czy zapis skrócony nie nadpisuje wcześniejszych ustawień.

13. Gradienty CSS jako tło

Gradient jest płynnym przejściem między kolorami.

W CSS gradienty można stosować jako wartość background-image.

Gradient liniowy – linear-gradient()

.baner {
    background-image: linear-gradient(
        to right,
        #2563EB,
        #7C3AED
    );
}

Kolor przechodzi od niebieskiego do fioletowego w kierunku od lewej do prawej.

Gradient pionowy

.baner {
    background-image: linear-gradient(
        to bottom,
        #DBEAFE,
        #1D4ED8
    );
}

Gradient pod kątem

.baner {
    background-image: linear-gradient(
        45deg,
        #06B6D4,
        #2563EB
    );
}

Gradient z trzema kolorami

.baner {
    background-image: linear-gradient(
        to right,
        red,
        orange,
        yellow
    );
}

Gradient promienisty – radial-gradient()

.baner {
    background-image: radial-gradient(
        circle,
        #FDE68A,
        #F97316
    );
}

Kolory rozchodzą się promieniście od środka gradientu.

Gradient zamiast pliku graficznego

header {
    background: linear-gradient(
        135deg,
        #1E3A8A,
        #0F172A
    );
}

Gradient nie wymaga pobierania osobnego pliku obrazu.

📌 Zapamiętaj

Gradient jest w CSS rodzajem obrazu generowanego przez przeglądarkę.

Dlatego można stosować go w background-image oraz background.

14. Nakładanie kilku warstw tła

CSS pozwala umieścić kilka obrazów tła w jednym elemencie.

Warstwy oddzielamy przecinkami.

Przykład

.baner {
    background-image:
        url("img/logo.png"),
        url("img/gory.jpg");

    background-repeat:
        no-repeat,
        no-repeat;

    background-position:
        right top,
        center;

    background-size:
        100px auto,
        cover;
}

Pierwszy obraz jest warstwą górną.

Drugi obraz znajduje się pod pierwszym.

Gradient na zdjęciu

.baner {
    background-image:
        linear-gradient(
            rgba(0, 0, 0, 0.5),
            rgba(0, 0, 0, 0.5)
        ),
        url("img/gory.jpg");

    background-position: center;
    background-size: cover;
    background-repeat: no-repeat;
}

Pierwszą warstwą jest półprzezroczysty gradient, a drugą zdjęcie.

Dzięki temu zdjęcie zostaje przyciemnione, co może poprawić czytelność jasnego tekstu.

Przykład HTML

<section class="baner">

    <h1>Witaj w górach!</h1>

    <p>
        Odkrywaj niezwykłe miejsca.
    </p>

</section>

CSS

.baner {
    min-height: 400px;
    padding: 50px;
    color: white;

    background-image:
        linear-gradient(
            rgba(0, 0, 0, 0.6),
            rgba(0, 0, 0, 0.3)
        ),
        url("img/gory.jpg");

    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
}

📌 Ważne

Wiele warstw tła można wykorzystać do uzyskania ciekawych efektów graficznych bez dodatkowych elementów HTML.

15. Czytelność tekstu na tle obrazu

Obraz w tle może wyglądać atrakcyjnie, ale nie powinien utrudniać czytania tekstu.

Przykład problemu

.baner {
    background-image: url("img/las.jpg");
    color: white;
}

Jeśli zdjęcie zawiera jasne fragmenty, biały tekst może być słabo widoczny.

Rozwiązanie 1 – ciemna nakładka

.baner {
    color: white;

    background-image:
        linear-gradient(
            rgba(0, 0, 0, 0.6),
            rgba(0, 0, 0, 0.6)
        ),
        url("img/las.jpg");

    background-size: cover;
    background-position: center;
}

Rozwiązanie 2 – półprzezroczyste tło pod tekstem

<section class="baner">

    <div class="tekst-banera">

        <h1>Poznaj przyrodę</h1>

        <p>
            Odkrywaj niezwykłe miejsca.
        </p>

    </div>

</section>
.baner {
    padding: 50px;
    background: url("img/las.jpg")
                center / cover
                no-repeat;
}

.tekst-banera {
    max-width: 500px;
    padding: 25px;
    color: white;
    background-color: rgba(0, 0, 0, 0.7);
    border-radius: 10px;
}

Rozwiązanie 3 – odpowiedni dobór zdjęcia

Można również wybrać fotografię, na której miejsce przeznaczone na tekst jest spokojne, jednolite lub odpowiednio ciemne.

📌 Dobra praktyka

Zawsze sprawdzaj kontrast tekstu i tła. Tekst musi być czytelny również na małych ekranach.

Sam cień tekstu nie zawsze wystarcza do zapewnienia czytelności.

16. Praktyczne zastosowania formatowania tła

Przykład 1 – kolorowe karty

.karta {
    background-color: #EFF6FF;
    padding: 20px;
    border-radius: 10px;
}

Przykład 2 – nagłówek z gradientem

header {
    padding: 50px;
    color: white;

    background: linear-gradient(
        to right,
        #1D4ED8,
        #7C3AED
    );
}

Przykład 3 – baner ze zdjęciem

.baner {
    min-height: 350px;

    background-image: url("img/miasto.jpg");
    background-repeat: no-repeat;
    background-position: center;
    background-size: cover;
}

Przykład 4 – mały wzór jako tło

body {
    background-image: url("img/wzor.png");
    background-repeat: repeat;
}

Przykład 5 – logo w prawym rogu

.panel {
    background-image: url("img/logo.png");
    background-repeat: no-repeat;
    background-position: right 20px top 20px;
    background-size: 80px auto;
}

Przykład 6 – sekcja z nakładką

.sekcja {
    min-height: 300px;
    color: white;

    background:
        linear-gradient(
            rgba(0, 0, 0, 0.5),
            rgba(0, 0, 0, 0.5)
        ),
        url("img/las.jpg") center / cover no-repeat;
}

W ostatnim przykładzie zastosowano skrócony zapis dwóch warstw tła.

17. Najczęstsze błędy

Błąd 1 – niepoprawna ścieżka

/* Błędna ścieżka, jeśli plik
   znajduje się w folderze img */

. baner {
    background-image: url("las.jpg");
}

Poprawny przykład:

.baner {
    background-image: url("img/las.jpg");
}

Błąd 2 – brak no-repeat

.baner {
    background-image: url("img/gory.jpg");
}

Obraz może powtarzać się w obu kierunkach.

Rozwiązanie:

.baner {
    background-image: url("img/gory.jpg");
    background-repeat: no-repeat;
}

Błąd 3 – mylenie cover i contain

.baner {
    background-size: contain;
}

Jeśli chcemy, aby zdjęcie wypełniało cały baner, często właściwsze będzie: 

.baner {
    background-size: cover;
}

Błąd 4 – brak wymiarów elementu

.baner {
    background-image: url("img/gory.jpg");
}

Sam obraz tła nie nadaje elementowi wysokości.

Jeśli element nie ma zawartości ani określonych wymiarów, może być niewidoczny.

Rozwiązanie:

.baner {
    min-height: 300px;
    background-image: url("img/gory.jpg");
}

Błąd 5 – nieczytelny tekst

.baner {
    background-image: url("img/jasne-zdjecie.jpg");
    color: white;
}

Należy dobrać odpowiedni kontrast lub zastosować przyciemniającą nakładkę.

Błąd 6 – niepoprawny zapis background-size

/* Niepoprawnie */

.baner {
    background-size: cover center;
}

Poprawnie:

.baner {
    background-size: cover;
    background-position: center;
}

Błąd 7 – błędny zapis skrócony

/* Niepoprawnie */

.baner {
    background: url("img/gory.jpg") center cover;
}

Poprawnie:

.baner {
    background: url("img/gory.jpg")
                center / cover
                no-repeat;
}

📌 Wskazówka

Gdy obraz tła nie pojawia się na stronie, sprawdź kolejno: ścieżkę do pliku, nazwę pliku, wielkość liter, rozmiar elementu oraz poprawność kodu CSS.

📌 Zwróć uwagę

W przykładzie wykorzystano również display: flex i flex-wrap do rozmieszczenia kart. Te właściwości dotyczą układu elementów i będą dokładniej omawiane w kolejnych lekcjach.

📌 Zapamiętaj

  • background-color ustawia kolor tła.
  • background-image ustawia obraz lub gradient jako tło.
  • url() wskazuje lokalizację obrazu.
  • Ścieżki względne w zewnętrznym CSS są liczone względem pliku CSS.
  • background-repeat kontroluje powtarzanie obrazu.
  • repeat powtarza obraz poziomo i pionowo.
  • repeat-x powtarza obraz poziomo.
  • repeat-y powtarza obraz pionowo.
  • no-repeat wyłącza powtarzanie.
  • background-position określa położenie obrazu.
  • background-size określa rozmiar obrazu tła.
  • cover wypełnia cały obszar, ale może przyciąć obraz.
  • contain pokazuje cały obraz, ale może pozostawić wolną przestrzeń.
  • background-attachment kontroluje zachowanie tła podczas przewijania.
  • background-origin określa obszar pozycjonowania tła.
  • background-clip określa obszar malowania tła.
  • background umożliwia skrócony zapis właściwości tła.
  • linear-gradient() tworzy gradient liniowy.
  • radial-gradient() tworzy gradient promienisty.
  • Można stosować kilka warstw tła w jednym elemencie.
  • Obraz tła nie nadaje elementowi automatycznie wysokości.
  • Tło nie powinno utrudniać czytania tekstu.

📝 Zadania praktyczne

Cel: zastosowanie właściwości CSS do formatowania tła oraz przygotowanie strony zawierającej kolorowe sekcje, zdjęcie w tle, gradient i poprawnie pozycjonowane grafiki.

Utwórz folder PSI_24, a w nim pliki index.html i style.css oraz folder img.

Wszystkie zadania wykonaj w ramach jednej strony WWW. Każde kolejne zadanie rozbudowuje ten sam projekt.

Zadanie 1 – Kolorowe tła strony

Przygotuj stronę „Moje wymarzone miejsce”. Może ona przedstawiać wybrane miasto, kraj, góry, jezioro, las lub inne interesujące miejsce.

  1. Utwórz poprawny dokument HTML5.
  2. Podłącz zewnętrzny arkusz style.css.
  3. Dodaj elementy header, main i footer.
  4. W nagłówku umieść nazwę wybranego miejsca oraz krótki opis.
  5. W części głównej dodaj trzy sekcje: opis miejsca, atrakcje i ciekawostki.
  6. Ustaw kolor tła całej strony za pomocą background-color.
  7. Ustaw inny kolor tła dla nagłówka.
  8. Każdej z trzech sekcji przypisz inny kolor tła.
  9. Zadbaj o czytelność tekstu na wszystkich tłach.

Zadanie 2 – Obraz w tle banera

Dodaj do swojej strony sekcję z dużym zdjęciem w tle.

  1. Znajdź lub przygotuj zdjęcie pasujące do tematyki strony.
  2. Zapisz obraz w folderze img pod nazwą baner.jpg.
  3. Dodaj do HTML sekcję o klasie baner.
  4. Umieść w banerze nagłówek i krótki tekst.
  5. Ustaw minimalną wysokość banera na 350px.
  6. Dodaj zdjęcie za pomocą background-image.
  7. Ustaw background-repeat: no-repeat.
  8. Wyśrodkuj obraz za pomocą background-position: center.
  9. Ustaw background-size: cover.
  10. Zmień szerokość okna i sprawdź, jak zachowuje się obraz tła.

Zadanie 3 – Powtarzanie i pozycjonowanie tła

Dodaj do strony niewielką dekorację graficzną.

  1. Przygotuj mały obraz wzor.png i zapisz go w folderze img.
  2. Dodaj sekcję o klasie wzor.
  3. Ustaw obraz wzor.png jako tło tej sekcji.
  4. Ustaw background-repeat: repeat.
  5. Sprawdź efekt w przeglądarce.
  6. Zmień wartość na repeat-x i zaobserwuj różnicę.
  7. Następnie ustaw repeat-y.
  8. Na końcu ustaw no-repeat oraz background-position: right top.
  9. Ustaw rozmiar obrazu tła na 100px auto.

Zadanie 4 – Gradient i półprzezroczysta nakładka

Popraw wygląd strony, wykorzystując gradienty CSS.

  1. Zastąp jednolity kolor nagłówka gradientem linear-gradient().
  2. Zastosuj co najmniej dwa różne kolory.
  3. Ustaw kierunek gradientu to right.
  4. W banerze ze zdjęciem dodaj półprzezroczysty ciemny gradient jako pierwszą warstwę tła.
  5. Ustaw zdjęcie jako drugą warstwę.
  6. Sprawdź, czy tekst jest dobrze widoczny na tle zdjęcia.
  7. Jeśli trzeba, zwiększ stopień przyciemnienia obrazu.

Zadanie 5 – Skrócony zapis background

Uporządkuj arkusz stylów.

  1. Znajdź regułę CSS odpowiadającą za tło banera.
  2. Zapisz właściwości background-image, background-repeat, background-position i background-size za pomocą skróconego background.
  3. Pamiętaj o znaku / między pozycją a rozmiarem.
  4. Sprawdź, czy wygląd banera się nie zmienił.
  5. Dodaj komentarz w CSS wyjaśniający, co oznaczają center, cover i no-repeat.

Zadanie 6 – Dopracowanie projektu (dodatkowe)

  1. Dodaj do strony kolejną sekcję z innym obrazem tła.
  2. Wykorzystaj background-size: contain i porównaj wynik z cover.
  3. Dodaj jeden gradient promienisty radial-gradient().
  4. Zastosuj przynajmniej jedną półprzezroczystą powierzchnię pod tekstem.
  5. Przetestuj stronę na wąskim i szerokim oknie przeglądarki.
  6. Sprawdź poprawność ścieżek do wszystkich obrazów.
