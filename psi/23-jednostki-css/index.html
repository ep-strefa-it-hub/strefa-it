Jednostki CSS oraz określanie rozmiarów elementów i tekstu

Cel lekcji: poznanie jednostek długości stosowanych w CSS, rozróżnianie jednostek bezwzględnych i względnych, określanie rozmiarów tekstu i elementów oraz stosowanie elastycznych wymiarów podczas projektowania stron WWW.

1. Wprowadzenie – po co stosujemy jednostki CSS?

Podczas projektowania strony internetowej określamy rozmiary wielu elementów: nagłówków, akapitów, obrazów, przycisków, sekcji, marginesów i odstępów.

W CSS do określania tych wartości wykorzystujemy jednostki miary.

Przykład

h1 {
    font-size: 36px;
}

p {
    font-size: 18px;
}

img {
    width: 300px;
}

section {
    padding: 20px;
}

W powyższym przykładzie jednostka px została zastosowana do określenia rozmiaru tekstu, szerokości obrazu oraz odstępu wewnętrznego sekcji.

Nie zawsze jednak chcemy, aby element miał stały rozmiar. Strona powinna dobrze wyglądać na różnych ekranach.

Przykład szerokości względnej

section {
    width: 80%;
}

Szerokość sekcji zależy teraz od szerokości jej bloku zawierającego.

📌 Zapamiętaj

Dobór jednostki wpływa na to, czy element ma rozmiar stały, czy dostosowuje się do otoczenia, rozmiaru pisma lub okna przeglądarki.

2. Podział jednostek CSS

Jednostki długości w CSS dzielimy na dwie główne grupy: bezwzględne i względne.

Jednostki bezwzględne

Mają ustalone wzajemne przeliczniki i nie są wyrażane jako procent rozmiaru elementu nadrzędnego.

Jednostka Nazwa
px Piksel CSS
cm Centymetr
mm Milimetr
in Cal
pt Punkt typograficzny
pc Pica

Jednostki względne

Ich wartość zależy od określonego punktu odniesienia, np. rozmiaru pisma, wymiarów okna przeglądarki albo wymiarów bloku zawierającego.

Jednostka Punkt odniesienia
% Zależy od właściwości, np. od szerokości bloku zawierającego.
em Rozmiar pisma elementu lub jego rodzica, zależnie od właściwości.
rem Rozmiar pisma elementu głównego.
vw 1% szerokości obszaru widoku.
vh 1% wysokości obszaru widoku.
vmin 1% mniejszego wymiaru obszaru widoku.
vmax 1% większego wymiaru obszaru widoku.
ch W przybliżeniu szerokość znaku „0” w używanym kroju.

📌 Ważne

Jednostki względne nie są automatycznie lepsze w każdej sytuacji. Należy dobierać je do konkretnego zastosowania.

3. Jednostka px – piksele CSS

Jednostka px jest jedną z najczęściej stosowanych jednostek w CSS.

Przykład

h1 {
    font-size: 32px;
}

.karta {
    width: 300px;
    padding: 20px;
    border: 2px solid black;
}

W tym przykładzie rozmiary są określone w pikselach CSS.

Czy 1px oznacza jeden fizyczny piksel ekranu?

Nie zawsze. Piksel CSS jest jednostką wykorzystywaną przez przeglądarkę do wyznaczania układu strony. Na ekranach o dużej gęstości pikseli jeden piksel CSS może odpowiadać kilku fizycznym pikselom urządzenia.

Kiedy stosować px?

  • Do określania grubości obramowania.
  • Do niewielkich, precyzyjnych odstępów.
  • Do rozmiarów ikon i elementów graficznych.
  • Do wymiarów, które mają być określone w pikselach CSS.

Przykład obramowania

.ramka {
    border: 2px solid #2563EB;
    border-radius: 8px;
}

📌 Uwaga

Rozmiary zapisane w px mogą reagować na powiększenie strony w przeglądarce. Nie oznacza to jednak, że automatycznie dopasowują się do rozmiaru elementu nadrzędnego.

4. Jednostka % – wartości procentowe

Zapis procentowy określa wartość względem innej wartości. Punkt odniesienia zależy od konkretnej właściwości CSS.

Przykład szerokości

.kontener {
    width: 800px;
}

.karta {
    width: 50%;
}

Jeżeli blok zawierający kartę ma szerokość 800 px, to 50% odpowiada 400 px.

Przykład HTML

<div class="kontener">
    <div class="karta">
        Zawartość karty
    </div>
</div>

Przykład CSS

.kontener {
    width: 800px;
    background-color: lightgray;
}

.karta {
    width: 50%;
    background-color: lightblue;
}

Procenty a rozmiar tekstu

section {
    font-size: 20px;
}

section p {
    font-size: 150%;
}

Rozmiar pisma akapitu wyniesie 30 px, ponieważ 150% z 20 px to 30 px.

Procentowa wysokość

.rodzic {
    height: 300px;
}

.dziecko {
    height: 50%;
}

W tym przypadku wysokość dziecka wyniesie 150 px.

Warto jednak pamiętać, że procentowa wysokość nie zawsze zadziała zgodnie z oczekiwaniem, jeśli wysokość bloku zawierającego zależy wyłącznie od jego zawartości.

📌 Zapamiętaj

Procent nie ma jednego uniwersalnego punktu odniesienia. Dla width i font-size procenty oznaczają różne zależności.

5. Jednostka em

Jednostka em jest związana z rozmiarem pisma.

Przy właściwości font-size odnosi się do obliczonego rozmiaru pisma rodzica.

Przykład

.kontener {
    font-size: 20px;
}

.kontener p {
    font-size: 1.5em;
}

Rozmiar tekstu akapitu wyniesie 30 px.

Obliczenie

20 px × 1,5 = 30 px.

em przy innych właściwościach

.przycisk {
    font-size: 20px;
    padding: 0.5em 1em;
}

W tym przykładzie em przy padding odnosi się do rozmiaru pisma samego przycisku.

Odstęp pionowy wyniesie 10 px, a poziomy 20 px.

Zagnieżdżone elementy

<div class="zewnetrzny">
    Tekst zewnętrzny

    <div class="wewnetrzny">
        Tekst wewnętrzny
    </div>
</div>
.zewnetrzny {
    font-size: 20px;
}

.wewnetrzny {
    font-size: 1.5em;
}

Tekst wewnętrzny będzie miał rozmiar 30 px.

📌 Ważne

W przypadku zagnieżdżonych elementów rozmiary zapisane w em mogą się kumulować. Należy zwracać uwagę na rozmiar pisma rodzica.

6. Jednostka rem

Jednostka rem oznacza root em. Odnosi się do rozmiaru pisma elementu głównego html.

Przykład

html {
    font-size: 16px;
}

h1 {
    font-size: 2rem;
}

p {
    font-size: 1.25rem;
}

Nagłówek otrzyma 32 px, a akapit 20 px.

Obliczenia

2 × 16 px = 32 px.

1,25 × 16 px = 20 px.

Dlaczego rem jest wygodne?

Jednostka rem pozwala tworzyć spójną skalę rozmiarów niezależnie od zagnieżdżenia elementów HTML.

Przykład

h1 {
    font-size: 2.5rem;
}

h2 {
    font-size: 2rem;
}

h3 {
    font-size: 1.5rem;
}

p {
    font-size: 1rem;
}

Jeżeli rozmiar pisma elementu html wynosi 16 px, otrzymamy odpowiednio 40, 32, 24 i 16 px.

📌 Dobra praktyka

W wielu projektach pozostawia się domyślny rozmiar pisma elementu html, a wielkości nagłówków i akapitów określa za pomocą rem.

7. Porównanie jednostek px, %, em i rem

Załóżmy, że rozmiar pisma elementu html wynosi 16 px, a elementu rodzica 20 px.

Zapis font-size Wynik Dlaczego?
24px 24 px Rozmiar określony bezpośrednio.
150% 30 px 150% z 20 px.
1.5em 30 px 1,5 × 20 px.
1.5rem 24 px 1,5 × 16 px.

Przykład CSS

html {
    font-size: 16px;
}

.kontener {
    font-size: 20px;
}

.tekst1 {
    font-size: 24px;
}

.tekst2 {
    font-size: 150%;
}

.tekst3 {
    font-size: 1.5em;
}

.tekst4 {
    font-size: 1.5rem;
}

Przykład HTML

<div class="kontener">

    <p class="tekst1">Tekst 24px</p>

    <p class="tekst2">Tekst 150%</p>

    <p class="tekst3">Tekst 1.5em</p>

    <p class="tekst4">Tekst 1.5rem</p>

</div>

📌 Zapamiętaj

px określa długość w pikselach CSS, % zależy od właściwości, em jest powiązane z rozmiarem pisma, a rem z rozmiarem pisma elementu głównego.

8. Jednostki vw i vh – rozmiar okna przeglądarki

Jednostki vw i vh odnoszą się do wymiarów obszaru widoku przeglądarki (viewport).

vw – viewport width

1vw odpowiada 1% szerokości obszaru widoku. 

.baner {
    width: 80vw;
}

Jeśli obszar widoku ma szerokość 1000 px, to 80vw odpowiada 800 px.

vh – viewport height

1vh odpowiada 1% wysokości odpowiedniego obszaru widoku. 

.baner {
    height: 50vh;
}

Jeśli wysokość odniesienia wynosi 800 px, to 50vh odpowiada 400 px.

Przykład sekcji na wysokość ekranu

.ekran {
    min-height: 100vh;
    background-color: lightblue;
}

Sekcja otrzymuje minimalną wysokość równą wysokości obszaru widoku określonego dla jednostki vh.

📌 Uwaga

Na urządzeniach mobilnych paski przeglądarki mogą zmieniać dostępną przestrzeń ekranu. Dlatego w niektórych sytuacjach warto używać nowocześniejszych jednostek, np. dvh.

9. Jednostki vmin, vmax i dvh

vmin

1vmin odpowiada 1% mniejszego wymiaru obszaru widoku. 

.kwadrat {
    width: 30vmin;
    height: 30vmin;
}

Jeśli obszar widoku ma wymiary 1200 × 800 px, to 30vmin odpowiada 240 px.

vmax

1vmax odpowiada 1% większego wymiaru obszaru widoku. 

.element {
    font-size: 3vmax;
}

Przy wymiarach 1200 × 800 px wartość 3vmax odpowiada 36 px.

dvh – dynamic viewport height

Jednostka dvh uwzględnia dynamiczną wysokość obszaru widoku, np. zmiany widoczności pasków przeglądarki na urządzeniu mobilnym. 

.ekran {
    min-height: 100dvh;
}

Inne nowoczesne jednostki

Jednostka Znaczenie
svh Wysokość małego obszaru widoku.
lvh Wysokość dużego obszaru widoku.
dvh Wysokość dynamicznego obszaru widoku.
dvw Szerokość dynamicznego obszaru widoku.

W podstawowych projektach najczęściej wystarczy znajomość vw i vh, jednak warto wiedzieć, że istnieją ich nowocześniejsze odmiany.

10. Pozostałe jednostki CSS

ch – szerokość znaku

Jednostka ch jest związana z szerokością znaku „0” w używanym kroju. 

.artykul {
    max-width: 65ch;
}

Dzięki temu można ograniczać długość wierszy tekstu. Nie oznacza to jednak, że każdy wiersz będzie zawierał dokładnie 65 znaków.

cm, mm, in, pt i pc

Są to jednostki bezwzględne wywodzące się z miar fizycznych i typograficznych. 

.druk {
    width: 10cm;
    font-size: 12pt;
}

W CSS obowiązują przeliczniki:

  • 1in = 96px
  • 1in = 2.54cm
  • 1in = 72pt
  • 1pc = 12pt

Na ekranie jednostki fizyczne nie muszą odpowiadać dokładnym wymiarom mierzonym linijką.

Jednostki takie jak cm i pt są szczególnie przydatne podczas przygotowywania stylów do wydruku.

11. Szerokość i wysokość elementów – width i height

Właściwości width i height służą do określania szerokości i wysokości elementów.

Stała szerokość

.karta {
    width: 300px;
}

Szerokość procentowa

.karta {
    width: 80%;
}

Stała wysokość

.baner {
    height: 250px;
}

Wartość auto

.karta {
    width: auto;
    height: auto;
}

Wartość auto pozwala przeglądarce wyznaczyć rozmiar zgodnie z zasadami układu.

Przykład HTML

<div class="karta">
    <h2>Moja karta</h2>
    <p>Przykładowa zawartość.</p>
</div>

Przykład CSS

.karta {
    width: 350px;
    min-height: 200px;
    padding: 20px;
    background-color: lightblue;
}

Karta ma określoną szerokość i minimalną wysokość. Jeśli zawartość będzie dłuższa, element może zwiększyć wysokość.

📌 Dobra praktyka

W przypadku bloków zawierających tekst często lepiej stosować min-height zamiast sztywnego height.

12. Minimalna i maksymalna szerokość

Właściwości min-width i max-width pozwalają ograniczyć szerokość elementu.

min-width

.element {
    min-width: 200px;
}

Określa minimalną szerokość elementu.

max-width

.element {
    max-width: 800px;
}

Ogranicza maksymalną szerokość elementu.

Przykład elastycznego kontenera

.kontener {
    width: 90%;
    max-width: 1000px;
    margin: 0 auto;
}

Kontener wykorzystuje 90% dostępnej szerokości, ale nie przekracza 1000 px.

Przykład dla obrazu

img {
    max-width: 100%;
    height: auto;
}

Obraz może zmniejszyć swoją szerokość, aby nie przekraczać szerokości dostępnego miejsca.

Wartość height: auto pomaga zachować proporcje obrazu podczas skalowania.

📌 Zapamiętaj

Połączenie width i max-width jest bardzo przydatne przy projektowaniu elastycznych kontenerów.

13. Minimalna i maksymalna wysokość

min-height

.karta {
    min-height: 200px;
}

Element będzie miał co najmniej 200 px wysokości, ale może się powiększyć, jeśli wymaga tego zawartość.

max-height

.lista {
    max-height: 300px;
}

Właściwość ogranicza maksymalną wysokość elementu. Jeśli zawartość jest większa, może dojść do przepełnienia.

Przykład

.opis {
    max-height: 200px;
    overflow: auto;
}

Jeśli tekst nie zmieści się w obszarze o maksymalnej wysokości 200 px, przeglądarka może wyświetlić pasek przewijania.

Przykład sekcji

.sekcja {
    min-height: 300px;
    padding: 30px;
}

Minimalna wysokość zapewnia określoną przestrzeń, ale pozwala sekcji rosnąć wraz z treścią.

14. Model pudełkowy a rzeczywisty rozmiar elementu

Każdy element HTML można traktować jak prostokątne pudełko.

Na jego wymiary wpływają:

  • Zawartość (content).
  • Odstęp wewnętrzny (padding).
  • Obramowanie (border).
  • Margines zewnętrzny (margin).

Domyślny model content-box

.karta {
    width: 300px;
    padding: 20px;
    border: 2px solid black;
}

Przy domyślnym box-sizing: content-box szerokość 300 px dotyczy samej zawartości.

Całkowita szerokość pudełka wraz z paddingiem i obramowaniem wynosi:

300 + 20 + 20 + 2 + 2 = 344 px.

Model border-box

.karta {
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 2px solid black;
}

W tym przypadku szerokość 300 px obejmuje zawartość, padding i obramowanie.

Porównanie

Model Znaczenie width
content-box Szerokość samej zawartości.
border-box Szerokość zawartości wraz z paddingiem i obramowaniem.

Ustawienie dla całej strony

*,
*::before,
*::after {
    box-sizing: border-box;
}

Taki zapis ułatwia przewidywanie wymiarów większości elementów strony.

📌 Ważne

Margines zewnętrzny margin nie jest wliczany do wartości width, nawet przy box-sizing: border-box.

15. Co się dzieje, gdy zawartość jest za duża?

Jeśli określimy elementowi zbyt małe wymiary, jego zawartość może się nie zmieścić.

Do kontrolowania przepełnienia służy właściwość overflow.

overflow: visible

.ramka {
    height: 100px;
    overflow: visible;
}

Zawartość może być widoczna poza granicami elementu.

overflow: hidden

.ramka {
    height: 100px;
    overflow: hidden;
}

Nadmiar zawartości zostaje przycięty.

overflow: auto

.ramka {
    height: 100px;
    overflow: auto;
}

W razie potrzeby pojawia się możliwość przewijania zawartości.

overflow: scroll

.ramka {
    height: 100px;
    overflow: scroll;
}

Element tworzy obszar przewijania.

📌 Dobra praktyka

Nie ukrywaj ważnego tekstu za pomocą overflow: hidden. Najpierw sprawdź, czy element może zwiększać swoją wysokość.

16. Obliczanie rozmiarów – funkcja calc()

Funkcja calc() pozwala wykonywać obliczenia na wartościach CSS.

Przykład

.kontener {
    width: calc(100% - 40px);
}

Szerokość elementu jest równa 100% szerokości odniesienia pomniejszonej o 40 px.

Inny przykład

.panel {
    width: calc(50% - 20px);
}

Pozwala to połączyć wartość procentową z wartością w pikselach.

Wysokość obszaru

.zawartosc {
    min-height: calc(100vh - 100px);
}

Minimalna wysokość zostanie obliczona jako wysokość obszaru widoku pomniejszona o 100 px.

Operatory

Operator Działanie
+ Dodawanie.
- Odejmowanie.
* Mnożenie.
/ Dzielenie.

📌 Ważne

Przy operatorach + i - w funkcji calc() stosuj spacje po obu stronach. 

/* Poprawnie */

width: calc(100% - 40px);

/* Niepoprawnie */

width: calc(100%-40px);

17. Funkcje min(), max() i clamp()

Funkcje te pozwalają tworzyć elastyczne rozmiary bez konieczności stosowania wielu osobnych reguł CSS.

min() – wybór mniejszej wartości

.kontener {
    width: min(90%, 1000px);
}

Przeglądarka wybiera mniejszą z dwóch wartości.

Kontener nie przekroczy 1000 px i może zajmować 90% dostępnej szerokości.

max() – wybór większej wartości

.element {
    width: max(300px, 50%);
}

Przeglądarka wybiera większą wartość spośród podanych.

clamp() – wartość minimalna, preferowana i maksymalna

h1 {
    font-size: clamp(24px, 4vw, 48px);
}

Funkcja przyjmuje trzy argumenty:

  1. Wartość minimalną – 24px.
  2. Wartość preferowaną – 4vw.
  3. Wartość maksymalną – 48px.

Rozmiar nagłówka może się zmieniać wraz z szerokością obszaru widoku, ale pozostaje w podanych granicach.

Przykład dla tekstu

p {
    font-size: clamp(16px, 1.5vw, 20px);
}

📌 Dobra praktyka

Funkcja clamp() jest przydatna do tworzenia płynnej typografii, ale zawsze należy sprawdzić czytelność tekstu na małych ekranach i przy powiększeniu.

18. Jednostki CSS a responsywność strony

Responsywna strona WWW dostosowuje układ i rozmiary elementów do różnych ekranów.

Przykład mało elastyczny

.kontener {
    width: 1000px;
}

Na ekranie węższym niż 1000 px element może powodować poziome przewijanie.

Przykład bardziej elastyczny

.kontener {
    width: 90%;
    max-width: 1000px;
    margin: 0 auto;
}

Kontener dostosowuje szerokość do dostępnego miejsca, ale nie staje się nadmiernie szeroki.

Responsywny obraz

img {
    max-width: 100%;
    height: auto;
}

Elastyczny nagłówek

h1 {
    font-size: clamp(1.5rem, 4vw, 3rem);
}

Elastyczna sekcja

section {
    width: min(90%, 1100px);
    min-height: 250px;
    margin: 0 auto;
}

Wskazówki

  • Nie ustawiaj stałej szerokości wszystkich elementów.
  • Stosuj max-width do ograniczania szerokości.
  • Pozwalaj tekstowi zwiększać wysokość elementu.
  • Sprawdzaj wygląd strony na różnych szerokościach.
  • Używaj jednostek odpowiednich do danego zadania.

📌 Zapamiętaj

Responsywność nie polega na stosowaniu wyłącznie procentów lub jednostek vw. Najlepsze efekty daje odpowiednie łączenie jednostek i ograniczeń rozmiaru.

19. Najczęstsze błędy

Błąd 1 – brak jednostki

/* Niepoprawnie */

.karta {
    width: 300;
}

/* Poprawnie */

.karta {
    width: 300px;
}

Błąd 2 – zbyt szeroki element

/* Mało elastyczne */

.karta {
    width: 1200px;
}

/* Bardziej elastyczne */

.karta {
    width: 90%;
    max-width: 1200px;
}

Błąd 3 – mylenie em z rem

.rodzic {
    font-size: 20px;
}

.dziecko {
    font-size: 2em;
}

W tym przykładzie tekst dziecka ma 40 px, a nie automatycznie 32 px.

Błąd 4 – procentowa wysokość bez odpowiedniego odniesienia

.rodzic {
    height: auto;
}

.dziecko {
    height: 50%;
}

Nie można zakładać, że dziecko otrzyma połowę wysokości widocznej zawartości rodzica.

Błąd 5 – pomijanie paddingu i border

.karta {
    width: 300px;
    padding: 20px;
    border: 2px solid black;
}

Przy domyślnym modelu content-box zewnętrzna szerokość pudełka wynosi 344 px.

Błąd 6 – niepoprawny calc()

/* Niepoprawnie */

width: calc(100%-20px);

/* Poprawnie */

width: calc(100% - 20px);

Błąd 7 – sztywna wysokość dla długiego tekstu

/* Może powodować przepełnienie */

.karta {
    height: 100px;
}

/* Często bezpieczniejsze */

.karta {
    min-height: 100px;
}

Błąd 8 – za mały tekst

/* Może być trudny do czytania */

p {
    font-size: 10px;
}

Tekst należy projektować z myślą o czytelności i możliwości powiększania.

📌 Zapamiętaj

  • Jednostki CSS służą do określania rozmiarów i odstępów.
  • Jednostki dzielimy na bezwzględne i względne.
  • px oznacza piksel CSS.
  • % jest wartością procentową, której punkt odniesienia zależy od właściwości.
  • em jest powiązane z rozmiarem pisma.
  • rem odnosi się do rozmiaru pisma elementu głównego.
  • vw odnosi się do szerokości obszaru widoku.
  • vh odnosi się do wysokości obszaru widoku.
  • vmin wykorzystuje mniejszy wymiar obszaru widoku.
  • vmax wykorzystuje większy wymiar obszaru widoku.
  • dvh uwzględnia dynamiczną wysokość obszaru widoku.
  • ch jest związane z szerokością znaku „0”.
  • width określa szerokość elementu.
  • height określa wysokość elementu.
  • min-width i max-width ograniczają szerokość.
  • min-height i max-height ograniczają wysokość.
  • box-sizing: border-box uwzględnia padding i border w określonej szerokości.
  • overflow kontroluje przepełnienie zawartości.
  • calc() pozwala obliczać wartości CSS.
  • min() wybiera mniejszą wartość.
  • max() wybiera większą wartość.
  • clamp() ogranicza wartość do wyznaczonego przedziału.
  • Elastyczne jednostki i ograniczenia wymiarów pomagają tworzyć responsywne strony WWW.

📝 Zadania praktyczne

Cel: zastosowanie jednostek CSS do określania rozmiarów tekstu i elementów oraz przygotowanie strony dostosowującej się do różnych szerokości okna.

Utwórz folder PSI_23, a w nim dwa pliki: index.html oraz style.css.

Wszystkie zadania wykonaj w ramach jednej strony WWW. Każde kolejne zadanie rozbudowuje ten sam projekt.

Zadanie 1 – Struktura strony i podstawowe rozmiary

Przygotuj stronę „Moje centrum technologii”. Treści strony powinny być własne.

  1. Utwórz poprawny dokument HTML5.
  2. Podłącz zewnętrzny arkusz style.css.
  3. Dodaj header, main i footer.
  4. W nagłówku umieść tytuł strony i krótki opis.
  5. W części głównej dodaj trzy sekcje opisujące wybrane technologie.
  6. Ustaw rozmiar głównego tytułu na 36px.
  7. Ustaw rozmiar akapitów na 18px.
  8. Ustaw odstęp wewnętrzny sekcji na 20px.
  9. Dodaj obramowanie o grubości 2px do każdej sekcji.

Zadanie 2 – Jednostki względne em i rem

Zmień sposób określania rozmiarów wybranych tekstów.

  1. Ustaw rozmiar pisma elementu html na 16px.
  2. Zmień rozmiar głównego tytułu na 2.25rem.
  3. Zmień rozmiar nagłówków sekcji na 1.5rem.
  4. Ustaw rozmiar tekstu akapitów na 1rem.
  5. W pierwszej sekcji utwórz element o klasie przyklad-em.
  6. Ustaw dla tego elementu font-size: 1.5em.
  7. Ustaw rozmiar pisma jego rodzica na 20px.
  8. Sprawdź, jaki rozmiar otrzyma tekst zapisany w em.
  9. Dodaj pod przykładem krótkie wyjaśnienie różnicy między em i rem.

Zadanie 3 – Szerokość i wysokość elementów

Dostosuj rozmiary głównej zawartości i poszczególnych sekcji.

  1. Ustaw dla elementu main szerokość 90%.
  2. Ogranicz jego maksymalną szerokość do 1000px.
  3. Wyśrodkuj main za pomocą margin: 0 auto.
  4. Ustaw minimalną wysokość każdej sekcji na 200px.
  5. Dodaj do jednej sekcji więcej tekstu i sprawdź, czy zwiększa wysokość.
  6. Dodaj obraz do jednej z sekcji.
  7. Ustaw obrazowi max-width: 100% i height: auto.
  8. Zmniejsz szerokość okna przeglądarki i obserwuj zachowanie elementów.

Zadanie 4 – Model pudełkowy i box-sizing

Sprawdź wpływ paddingu i obramowania na rzeczywisty rozmiar elementu.

  1. Dodaj dwie karty o klasach karta1 i karta2.
  2. Obu kartom ustaw width: 300px.
  3. Ustaw padding: 20px.
  4. Ustaw border: 2px solid black.
  5. Dla pierwszej karty ustaw box-sizing: content-box.
  6. Dla drugiej karty ustaw box-sizing: border-box.
  7. Porównaj zewnętrzną szerokość obu kart.
  8. Pod kartami zapisz obliczoną szerokość każdej z nich, bez marginesów.

Zadanie 5 – Jednostki vw, vh i funkcja clamp()

Dodaj do strony elastyczny baner.

  1. Utwórz sekcję o klasie baner.
  2. Ustaw jej minimalną wysokość na 30vh.
  3. Dodaj do banera nagłówek i krótki tekst.
  4. Ustaw nagłówkowi font-size: clamp(24px, 4vw, 48px).
  5. Ustaw szerokość banera na 100% dostępnej szerokości.
  6. Zmień szerokość okna przeglądarki.
  7. Zaobserwuj, jak zmienia się rozmiar nagłówka.
  8. Wyjaśnij w komentarzu CSS znaczenie trzech wartości funkcji clamp().

Zadanie 6 – Responsywna strona (dodatkowe)

Dopracuj stronę, aby była wygodna w przeglądaniu na różnych ekranach.

  1. Ustaw box-sizing: border-box dla wszystkich elementów i pseudoelementów.
  2. Sprawdź, czy żaden element nie powoduje niepotrzebnego przewijania poziomego.
  3. Zastosuj max-width dla głównej zawartości.
  4. Sprawdź, czy obrazy zmniejszają się wraz z szerokością kontenera.
  5. Usuń sztywne wysokości, które powodują ucinanie tekstu.
  6. Przetestuj stronę przy szerokości okna około 400 px.
  7. Przetestuj stronę przy szerokości około 1200 px.
  8. Sprawdź wygląd strony przy powiększeniu do 200%.
