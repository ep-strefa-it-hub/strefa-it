JavaScript: Tablice

Tworzenie tablic, odczytywanie i zmienianie elementów, przetwarzanie danych w pętlach oraz metody tablic.
Cel główny: wykorzystanie tablic do przechowywania, wyszukiwania, sortowania i prezentowania danych w aplikacjach internetowych, w tym w zadaniach praktycznych INF.03.

1. Czym jest tablica?

Tablica (Array) to uporządkowana kolekcja danych. Pozwala przechowywać wiele wartości pod jedną nazwą. Każdy element ma swój numer, czyli indeks.

Zamiast deklarować oddzielne zmienne:

let ocena1 = 5;
let ocena2 = 4;
let ocena3 = 3;

możemy utworzyć jedną tablicę:

let oceny = [5, 4, 3];
Indeks012
Wartość543
Ważne! Indeksy tablic rozpoczynają się od 0, nie od 1.

2. Tworzenie tablic

Tablica z gotowymi danymi

const miasta = ["Lublin", "Lubartów", "Warszawa"];
const liczby = [10, 20, 30, 40];

Pusta tablica

const wyniki = [];
wyniki.push(15);
wyniki.push(27);
console.log(wyniki); // [15, 27]

Tworzenie za pomocą new Array()

const kolory = new Array("red", "green", "blue");

W praktyce najczęściej stosujemy krótszy i czytelniejszy zapis [].

Uwaga: new Array(5) tworzy tablicę o długości 5 z pustymi miejscami, a nie tablicę zawierającą liczbę 5. Dlatego do zwykłego tworzenia tablicy zalecany jest zapis [].

3. Odczytywanie i zmiana elementów

const owoce = ["jabłko", "gruszka", "śliwka"];

console.log(owoce[0]); // jabłko
console.log(owoce[2]); // śliwka

Element tablicy można zmienić za pomocą indeksu:

owoce[1] = "banan";
console.log(owoce); // ["jabłko", "banan", "śliwka"]

Ostatni element można odczytać niezależnie od długości tablicy:

console.log(owoce[owoce.length - 1]); // śliwka
Odczyt nieistniejącego elementu, np. owoce[10], zwraca undefined.

4. Długość tablicy – length

Właściwość length określa długość tablicy.

const dni = ["pon", "wt", "śr", "czw", "pt"];

console.log(dni.length); // 5
console.log(dni[dni.length - 1]); // pt
Dla tablicy zawierającej 5 kolejnych elementów indeksy mają wartości 0, 1, 2, 3, 4, a jej długość wynosi 5.

5. Odczyt wszystkich elementów w pętli

Pętla for

const liczby = [4, 8, 12, 16];

for (let i = 0; i < liczby.length; i++) {
    console.log(liczby[i]);
}

Wynik:

4
8
12
16

Pętla for...of

Gdy nie potrzebujemy numeru indeksu, możemy użyć krótszego zapisu:

for (const liczba of liczby) {
    console.log(liczba);
}
W pętli for używamy warunku i < liczby.length, a nie i <= liczby.length. Ten drugi zapis wykonałby jedną iterację za dużo.

6. Wypełnianie tablicy liczbami losowymi

Utwórzmy tablicę zawierającą 10 liczb całkowitych od 0 do 100.

const liczby = [];

for (let i = 0; i < 10; i++) {
    let losowa = Math.floor(Math.random() * 101);
    liczby.push(losowa);
}

console.log(liczby);
ZapisZnaczenie
Math.random()losuje liczbę od 0 (włącznie) do 1 (bez 1)
* 101przekształca zakres na wartości od 0 do mniej niż 101
Math.floor()zaokrągla w dół, dając liczbę całkowitą od 0 do 100
push()dodaje nową liczbę na koniec tablicy

Jeżeli chcemy losować liczby od 1 do 100:

let liczba = Math.floor(Math.random() * 100) + 1;

7. Obliczenia na tablicy – suma i średnia

const oceny = [5, 4, 3, 5, 4];
let suma = 0;

for (let i = 0; i < oceny.length; i++) {
    suma += oceny[i];
}

let srednia = suma / oceny.length;

console.log("Suma: " + suma);       // 21
console.log("Średnia: " + srednia); // 4.2
Ważne! Przed obliczaniem średniej sprawdź, czy tablica nie jest pusta. Dla pustej tablicy suma / 0 da wynik NaN.

8. Wyszukiwanie minimum i maksimum

Przechodzimy po tablicy i porównujemy każdy element z dotychczasowym wynikiem.

const liczby = [-8, -3, -15, -2, -10];

let minimum = liczby[0];
let maksimum = liczby[0];

for (let i = 1; i < liczby.length; i++) {
    if (liczby[i] < minimum) {
        minimum = liczby[i];
    }
    if (liczby[i] > maksimum) {
        maksimum = liczby[i];
    }
}

console.log("Minimum: " + minimum); // -15
console.log("Maksimum: " + maksimum); // -2
Nie ustawiaj automatycznie maksimum = 0. Jeśli wszystkie liczby są ujemne, wynik będzie błędny. W tym przykładzie tablica jest niepusta, więc zaczynamy od liczby[0].

Wbudowane funkcje Math.min() i Math.max()

console.log(Math.min(...liczby)); // -15
console.log(Math.max(...liczby)); // -2

Operator ... przekazuje elementy tablicy jako osobne argumenty funkcji.

9. Łączenie elementów w tekst – join()

join() łączy wszystkie elementy tablicy w jeden napis.

const kolory = ["czerwony", "zielony", "niebieski"];

console.log(kolory.join());
console.log(kolory.join(" - "));

Wynik:

czerwony,zielony,niebieski
czerwony - zielony - niebieski
join() nie zmienia tablicy – zwraca nowy tekst.

10. Sortowanie i odwracanie kolejności

sort() – sortowanie tekstu

const owoce = ["śliwka", "banan", "jabłko"];
owoce.sort();
console.log(owoce);

sort() – sortowanie liczb

Bez funkcji porównującej sort() porównuje elementy jako tekst, co może dać nieprawidłową kolejność liczb.

const liczby = [2, 15, 100, 8];

liczby.sort();
console.log(liczby); // [100, 15, 2, 8]

Poprawne sortowanie rosnące i malejące:

liczby.sort(function(a, b) {
    return a - b;
});
console.log(liczby); // [2, 8, 15, 100]

liczby.sort(function(a, b) {
    return b - a;
});
console.log(liczby); // [100, 15, 8, 2]

reverse() – odwrócenie aktualnej kolejności

const litery = ["A", "B", "C"];
litery.reverse();
console.log(litery); // ["C", "B", "A"]
reverse() nie sortuje danych, tylko odwraca ich aktualną kolejność. Metody sort() i reverse() zmieniają oryginalną tablicę.

11. Dodawanie i usuwanie elementów

const imiona = ["Anna", "Jan", "Ola"];

imiona.push("Ewa");       // dodaje na końcu
imiona.pop();              // usuwa ostatni element
imiona.unshift("Adam");  // dodaje na początku
imiona.shift();            // usuwa pierwszy element

console.log(imiona); // ["Anna", "Jan", "Ola"]
MetodaDziałanie
push(element)dodaje element na końcu
pop()usuwa i zwraca ostatni element
unshift(element)dodaje element na początku
shift()usuwa i zwraca pierwszy element

12. Zmiana fragmentu tablicy – splice() i slice()

splice() – usuwa lub wstawia elementy

const liczby = [10, 20, 30, 40, 50];

liczby.splice(2, 1); // usuwa 1 element od indeksu 2
console.log(liczby); // [10, 20, 40, 50]

liczby.splice(2, 0, 30); // wstawia 30 pod indeks 2
console.log(liczby); // [10, 20, 30, 40, 50]

Ogólna postać: tablica.splice(indeks, ileUsunac, noweElementy).

slice() – pobiera fragment bez zmiany oryginału

const dane = [10, 20, 30, 40, 50];
const fragment = dane.slice(1, 4);

console.log(fragment); // [20, 30, 40]
console.log(dane);     // [10, 20, 30, 40, 50]
Różnica: splice() zmienia tablicę, a slice() zwraca wybrany fragment bez zmiany oryginału. W slice(1, 4) indeks 4 nie jest uwzględniany.

13. Sprawdzanie i wyszukiwanie elementów

const miasta = ["Lublin", "Kraków", "Warszawa"];

console.log(miasta.includes("Kraków"));  // true
console.log(miasta.includes("Gdańsk")); // false
console.log(miasta.indexOf("Warszawa")); // 2
console.log(miasta.indexOf("Poznań"));   // -1
MetodaWynik
includes(wartosc)true lub false
indexOf(wartosc)indeks pierwszego wystąpienia lub -1

14. Przechodzenie po elementach – forEach()

Metoda forEach() wykonuje funkcję dla każdego elementu tablicy.

const produkty = ["Monitor", "Mysz", "Klawiatura"];

produkty.forEach(function(produkt) {
    console.log(produkt);
});

Możemy także odczytać indeks elementu:

produkty.forEach(function(produkt, indeks) {
    console.log((indeks + 1) + ". " + produkt);
});

Wynik:

1. Monitor
2. Mysz
3. Klawiatura
Nazwa parametru produkt jest dowolna. W każdej iteracji oznacza aktualnie przetwarzany element tablicy.

15. Wybieranie i przekształcanie danych

filter() – wybór elementów spełniających warunek

const ceny = [40, 120, 75, 300, 20];

const drogie = ceny.filter(function(cena) {
    return cena > 100;
});

console.log(drogie); // [120, 300]

map() – utworzenie nowej tablicy wyników

const brutto = ceny.map(function(cena) {
    return cena * 1.23;
});

console.log(brutto);

find() – znalezienie pierwszego pasującego elementu

const znaleziona = ceny.find(function(cena) {
    return cena > 100;
});

console.log(znaleziona); // 120
MetodaZwraca
filter()nową tablicę pasujących elementów
map()nową tablicę przekształconych wartości
find()pierwszy pasujący element albo undefined

16. Tablice obiektów – powtórzenie z Lekcji 10

Tablica może zawierać obiekty opisujące produkty, uczniów lub usługi.

const produkty = [
    { nazwa: "Mysz", cena: 50, stan: 8 },
    { nazwa: "Klawiatura", cena: 120, stan: 4 },
    { nazwa: "Monitor", cena: 850, stan: 2 }
];

produkty.forEach(function(produkt) {
    console.log(produkt.nazwa + " – " + produkt.cena + " zł");
});

Filtrowanie dostępnych produktów

const dostepne = produkty.filter(function(produkt) {
    return produkt.stan > 0;
});

console.log(dostepne);
W zapisie produkty[0].nazwa najpierw wybieramy pierwszy obiekt z tablicy, a potem jego właściwość nazwa.

17. Tablica i HTML – przykład w stylu INF.03

Na egzaminie przydatna jest umiejętność wyświetlenia danych z JavaScript na stronie.

Skopiuj cały przykład do pliku lista.html:

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <title>Lista produktów</title>
</head>
<body>
    <h1>Produkty</h1>
    <button id="pokaz">Pokaż produkty</button>
    <ul id="lista"></ul>

    <script>
        const produkty = ["Mysz", "Monitor", "Klawiatura"];
        const przycisk = document.getElementById("pokaz");
        const lista = document.getElementById("lista");

        przycisk.addEventListener("click", function() {
            lista.replaceChildren();

            produkty.forEach(function(produkt) {
                const element = document.createElement("li");
                element.textContent = produkt;
                lista.appendChild(element);
            });
        });
    </script>
</body>
</html>

Jak działa przykład?

  1. Tablica produkty przechowuje trzy nazwy.
  2. Przycisk uruchamia obsługę zdarzenia click.
  3. replaceChildren() usuwa poprzednią zawartość listy.
  4. forEach() przetwarza każdy produkt.
  5. createElement("li") tworzy element listy.
  6. textContent wstawia tekst, a appendChild() dodaje element do strony.

📌 Zapamiętaj

  • Tablica przechowuje wiele wartości pod jedną nazwą.
  • Indeks pierwszego elementu to 0.
  • length określa długość tablicy.
  • Za pomocą for, for...of i forEach() możemy przechodzić po elementach.
  • push() i pop() działają na końcu tablicy, a unshift() i shift() na początku.
  • splice() zmienia tablicę, a slice() kopiuje jej fragment.
  • sort() bez funkcji porównującej nie sortuje liczb według ich wartości.
  • reverse() odwraca kolejność, a nie wykonuje sortowania.
  • filter() wybiera elementy, map() je przekształca, a find() wyszukuje pierwszy pasujący.
  • Tablice można łączyć z obiektami, formularzami HTML i zdarzeniami JavaScript.

Zadanie 15 – Miniarkusz praktyczny: sklep komputerowy

Utwórz plik sklep.html zawierający nagłówek, tabelę produktów, pole ceny minimalnej i przyciski „Filtruj”, „Sortuj rosnąco” oraz „Pokaż wszystkie”.

  6. Pod tabelą wyświetl liczbę widocznych produktów oraz sumę wartości ich stanów magazynowych (cena * stan).

Wskazówka do INF.03: nie wpisuj wyników ani wierszy tabeli na stałe. Przygotuj funkcję wyświetlającą dane na podstawie aktualnej tablicy. Użyj createElement(), textContent i appendChild().
