JavaScript: Funkcje

Deklarowanie i wywoływanie funkcji, parametry, zwracanie wartości, funkcje anonimowe i strzałkowe, callbacki oraz przetwarzanie tablic.
Cel główny: poznanie zasad tworzenia funkcji w JavaScript i wykorzystanie ich do organizowania kodu, wykonywania obliczeń oraz obsługi aplikacji internetowych zgodnie z umiejętnościami przydatnymi na egzaminie INF.03.

1. Czym jest funkcja?

Funkcja to wydzielony fragment programu, który realizuje określone zadanie i może być wielokrotnie wywoływany w różnych miejscach kodu.

Funkcje pozwalają unikać powtarzania tych samych instrukcji, ułatwiają poprawianie błędów i zwiększają czytelność programu.

Przykład bez funkcji:

console.log("Witaj, Anno!");
console.log("Witaj, Janie!");
console.log("Witaj, Olu!");

Przykład z funkcją:

function przywitaj(imie) {
    console.log("Witaj, " + imie + "!");
}

przywitaj("Anno");
przywitaj("Janie");
przywitaj("Olu");

Wynik:

Witaj, Anno!
Witaj, Janie!
Witaj, Olu!
Ważne! Funkcję definiujemy jeden raz, ale możemy wywoływać ją wielokrotnie z różnymi danymi.

2. Deklaracja i wywołanie funkcji

Podstawowy sposób tworzenia funkcji polega na użyciu słowa kluczowego function. 

function powitanie() {
    console.log("Cześć!");
}

Samo zdefiniowanie funkcji nie powoduje wykonania jej instrukcji.

Aby ją uruchomić, należy ją wywołać:

powitanie();

Ogólna budowa funkcji

function nazwaFunkcji() {
    // instrukcje
}

nazwaFunkcji();
Fragment Znaczenie
function słowo kluczowe służące do deklarowania funkcji
nazwaFunkcji nazwa, za pomocą której wywołujemy funkcję
() miejsce na parametry funkcji
{ } blok instrukcji wykonywanych przez funkcję
Zapamiętaj: powitanie oznacza odwołanie do funkcji, a powitanie() oznacza jej wywołanie.

3. Parametry i argumenty funkcji

Funkcje mogą przyjmować dane przekazywane podczas wywołania. 

function powitaj(imie) {
    console.log("Cześć, " + imie);
}

powitaj("Anna");

imie jest parametrem funkcji, natomiast "Anna" jest argumentem przekazanym podczas jej wywołania.

Funkcja z dwoma parametrami

function dodaj(a, b) {
    console.log(a + b);
}

dodaj(5, 3);
dodaj(10, 20);

Wynik:

8
30
Parametr to nazwa zmiennej występująca w definicji funkcji.
Argument to konkretna wartość przekazana podczas wywołania funkcji.

4. Zwracanie wartości – return

Funkcja może nie tylko wykonywać instrukcje, lecz także zwracać wynik obliczeń. 

function suma(a, b) {
    return a + b;
}

let wynik = suma(5, 3);

console.log(wynik); // 8

Słowo kluczowe return zwraca wynik działania funkcji do miejsca jej wywołania.

Wykorzystanie wyniku funkcji

function poleProstokata(a, b) {
    return a * b;
}

let pole = poleProstokata(5, 4);

console.log("Pole: " + pole); // Pole: 20

Funkcja zwracająca wartość logiczną

function czyParzysta(liczba) {
    return liczba % 2 === 0;
}

console.log(czyParzysta(8)); // true
console.log(czyParzysta(5)); // false

return kończy działanie funkcji

function sprawdzWiek(wiek) {
    if (wiek < 18) {
        return "Niepełnoletni";
    }

    return "Pełnoletni";
}

console.log(sprawdzWiek(16));
Ważne! Instrukcje znajdujące się po wykonanym return nie zostaną wykonane. Jeżeli funkcja kończy się bez zwrócenia wartości, jej wynikiem jest undefined.

5. Parametry domyślne

Funkcja może posiadać parametr, który otrzyma wartość domyślną, jeśli podczas wywołania nie zostanie przekazany odpowiedni argument lub przekazana będzie wartość undefined. 

function powitaj(imie = "Gościu") {
    console.log("Witaj, " + imie + "!");
}

powitaj("Anna");
powitaj();

Wynik:

Witaj, Anna!
Witaj, Gościu!

Parametry domyślne w obliczeniach

function obliczCene(cena, ilosc = 1) {
    return cena * ilosc;
}

console.log(obliczCene(50));    // 50
console.log(obliczCene(50, 3)); // 150

6. Zakres zmiennych w funkcjach

Zmienne zadeklarowane wewnątrz funkcji za pomocą let lub const nie są dostępne poza jej zakresem. 

function oblicz() {
    let wynik = 10 + 5;
    console.log(wynik);
}

oblicz(); // 15

// console.log(wynik); // ReferenceError

Zmienna globalna i lokalna

let nazwaSzkoly = "STREFA IT";

function pokaz() {
    let klasa = "3TI";

    console.log(nazwaSzkoly);
    console.log(klasa);
}

pokaz();
Dobra praktyka: unikaj niepotrzebnego tworzenia zmiennych globalnych. Przekazuj dane do funkcji za pomocą parametrów i odbieraj wynik przez return.

7. Funkcje anonimowe

Funkcja anonimowa to funkcja, która nie posiada własnej nazwy w miejscu jej utworzenia.

Funkcję anonimową możemy przypisać do zmiennej. 

const dodaj = function(a, b) {
    return a + b;
};

console.log(dodaj(5, 3)); // 8

Mimo że funkcja nie ma własnej nazwy, możemy ją wywołać za pomocą zmiennej dodaj.

Funkcja anonimowa w obsłudze zdarzenia

const przycisk = document.getElementById("przycisk");

przycisk.addEventListener("click", function() {
    alert("Kliknięto przycisk");
});

Funkcje anonimowe często przekazujemy bezpośrednio jako argumenty innych funkcji.

8. Funkcje strzałkowe – arrow functions

Funkcje strzałkowe to krótszy sposób zapisywania funkcji w JavaScript. Wykorzystują operator =>.

Tradycyjny zapis

const suma = function(a, b) {
    return a + b;
};

Funkcja strzałkowa

const suma = (a, b) => {
    return a + b;
};

Skrócony zapis

const suma = (a, b) => a + b;

console.log(suma(5, 3)); // 8

Jeżeli funkcja składa się z jednego wyrażenia, możemy pominąć nawiasy klamrowe i słowo return. Wtedy wartość wyrażenia jest zwracana automatycznie.

Jeden parametr

const kwadrat = x => x * x;

console.log(kwadrat(5)); // 25

Brak parametrów

const powitanie = () => "Cześć!";

console.log(powitanie());

Więcej instrukcji

const sprawdzLiczbe = liczba => {
    if (liczba > 0) {
        return "Dodatnia";
    }

    return "Niedodatnia";
};
Ważne! Funkcje strzałkowe nie mają własnego this. Dlatego nie zawsze nadają się do zastępowania zwykłych metod obiektu. Ten temat poznaliśmy w Lekcji 10.

9. Trzy sposoby tworzenia funkcji

1. Deklaracja funkcji

function dodaj(a, b) {
    return a + b;
}

2. Funkcja przypisana do zmiennej

const dodaj = function(a, b) {
    return a + b;
};

3. Funkcja strzałkowa

const dodaj = (a, b) => a + b;
Rodzaj Cechy
Deklaracja czytelny zapis, można ją wywołać również przed miejscem deklaracji
Funkcja anonimowa często przypisywana do zmiennej lub przekazywana jako argument
Funkcja strzałkowa krótsza składnia, nie posiada własnego this
Uwaga: Wszystkie trzy przykłady przedstawiają alternatywne sposoby utworzenia funkcji. Nie należy deklarować ich jednocześnie pod tą samą nazwą dodaj w jednym zakresie.

10. Funkcja przekazywana jako argument – callback

Callback to funkcja przekazywana do innej funkcji, która może ją następnie wywołać. 
function wykonajDzialanie(a, b, dzialanie) {
    return dzialanie(a, b);
}

function suma(a, b) {
    return a + b;
}

console.log(wykonajDzialanie(5, 3, suma)); // 8

Funkcja suma została przekazana jako argument do funkcji wykonajDzialanie.

Callback jako funkcja anonimowa

let wynik = wykonajDzialanie(5, 3, function(a, b) {
    return a * b;
});

console.log(wynik); // 15

Callback jako funkcja strzałkowa

let wynik = wykonajDzialanie(5, 3, (a, b) => a - b);

console.log(wynik); // 2
Zapamiętaj: przekazując funkcję jako argument, używamy jej nazwy bez nawiasów, np. suma. Zapis suma() oznacza wywołanie funkcji.

11. Metoda forEach()

Metoda forEach() wykonuje przekazaną funkcję dla każdego elementu tablicy. 

const liczby = [10, 20, 30];

liczby.forEach(function(liczba) {
    console.log(liczba);
});

Wynik:

10
20
30

forEach() z funkcją strzałkową

const liczby = [10, 20, 30];

liczby.forEach(liczba => {
    console.log(liczba);
});

Element i jego indeks

const imiona = ["Anna", "Jan", "Ola"];

imiona.forEach((imie, indeks) => {
    console.log((indeks + 1) + ". " + imie);
});

Wynik:

1. Anna
2. Jan
3. Ola
forEach() służy przede wszystkim do wykonywania operacji na elementach tablicy. Sama metoda nie tworzy nowej tablicy i zwraca undefined.

12. Metoda map()

Metoda map() przetwarza każdy element tablicy i tworzy nową tablicę wyników. 

const liczby = [2, 4, 6, 8];

const kwadraty = liczby.map(function(liczba) {
    return liczba * liczba;
});

console.log(kwadraty);

Wynik:

[4, 16, 36, 64]

map() z funkcją strzałkową

const liczby = [2, 4, 6, 8];

const kwadraty = liczby.map(liczba => liczba * liczba);

console.log(kwadraty);

Przeliczanie cen

const ceny = [100, 200, 300];

const poRabacie = ceny.map(cena => cena * 0.9);

console.log(poRabacie); // [90, 180, 270]
map() służy do przekształcania danych, np. obliczenia kwadratów liczb, zmiany cen lub przygotowania nowej listy wartości.

13. Metoda filter()

Metoda filter() wybiera elementy spełniające określony warunek i zwraca nową tablicę. 

const liczby = [5, 12, 7, 20, 3];

const duze = liczby.filter(function(liczba) {
    return liczba > 10;
});

console.log(duze); // [12, 20]

filter() z funkcją strzałkową

const liczby = [5, 12, 7, 20, 3];

const duze = liczby.filter(liczba => liczba > 10);

console.log(duze); // [12, 20]

Wybieranie liczb parzystych

const liczby = [1, 2, 3, 4, 5, 6];

const parzyste = liczby.filter(liczba => liczba % 2 === 0);

console.log(parzyste); // [2, 4, 6]
Ważne! Funkcja przekazana do filter() powinna zwracać warunek. Element zostanie zachowany, jeśli wynik warunku jest prawdziwy.

14. Metoda find()

Metoda find() zwraca pierwszy element spełniający podany warunek. 

const liczby = [5, 12, 7, 20, 3];

const wynik = liczby.find(liczba => liczba > 10);

console.log(wynik); // 12

Wyszukiwanie obiektu

const produkty = [
    { nazwa: "Mysz", cena: 50 },
    { nazwa: "Klawiatura", cena: 120 },
    { nazwa: "Monitor", cena: 850 }
];

const znaleziony = produkty.find(produkt => {
    return produkt.nazwa === "Klawiatura";
});

console.log(znaleziony.cena); // 120
Różnica: filter() zwraca tablicę wszystkich pasujących elementów, a find() zwraca pierwszy pasujący element. Jeśli nic nie znajdzie, zwraca undefined.

15. Metoda reduce()

Metoda reduce() pozwala przetworzyć wszystkie elementy tablicy i obliczyć jeden wynik, np. sumę. 

const liczby = [10, 20, 30, 40];

const suma = liczby.reduce(function(wynik, liczba) {
    return wynik + liczba;
}, 0);

console.log(suma); // 100

Parametr wynik przechowuje dotychczas obliczoną wartość, a liczba oznacza aktualny element tablicy.

Wartość 0 jest wartością początkową.

Skrócony zapis strzałkowy

const liczby = [10, 20, 30, 40];

const suma = liczby.reduce((wynik, liczba) => wynik + liczba, 0);

console.log(suma); // 100

Obliczanie wartości zamówienia

const koszyk = [
    { nazwa: "Mysz", cena: 50, ilosc: 2 },
    { nazwa: "Monitor", cena: 850, ilosc: 1 }
];

const suma = koszyk.reduce((wynik, produkt) => {
    return wynik + produkt.cena * produkt.ilosc;
}, 0);

console.log(suma); // 950
Ważne! Podawanie wartości początkowej, np. 0, ułatwia przewidywanie wyniku i pozwala bezpiecznie sumować także pustą tablicę.

16. Funkcje jako metody obiektów

Funkcja przechowywana jako właściwość obiektu może być wywoływana jako jego metoda. 

const produkt = {
    nazwa: "Monitor",
    cena: 850,

    pokazDane: function() {
        return this.nazwa + " – " + this.cena + " zł";
    }
};

console.log(produkt.pokazDane());

Skrócony zapis metody

const produkt = {
    nazwa: "Monitor",
    cena: 850,

    pokazDane() {
        return this.nazwa + " – " + this.cena + " zł";
    }
};

W metodzie wywołanej przez produkt.pokazDane() słowo this wskazuje obiekt produkt.

Ważne! Funkcji strzałkowej nie należy automatycznie używać zamiast zwykłej metody, która korzysta z this. Funkcje strzałkowe nie tworzą własnego kontekstu this.

17. Funkcje w obsłudze zdarzeń

Funkcje wykorzystujemy do określania, co ma się wydarzyć po kliknięciu przycisku, zmianie pola formularza lub innym zdarzeniu.

Kod HTML:

<button id="przycisk">Kliknij</button>

Funkcja nazwana

const przycisk = document.getElementById("przycisk");

function pokazKomunikat() {
    alert("Witaj!");
}

przycisk.addEventListener("click", pokazKomunikat);

Funkcja anonimowa

przycisk.addEventListener("click", function() {
    alert("Witaj!");
});

Funkcja strzałkowa

przycisk.addEventListener("click", () => {
    alert("Witaj!");
});
Uwaga: wszystkie trzy sposoby przedstawiają alternatywne rozwiązania tego samego zadania. W ćwiczeniu wybierz jeden z nich.

18. Funkcje i sprawdzanie danych

Przy tworzeniu formularzy ważne jest sprawdzenie poprawności danych wprowadzonych przez użytkownika.

Funkcja sprawdzająca liczbę

function czyDodatnia(liczba) {
    return Number.isFinite(liczba) && liczba > 0;
}

console.log(czyDodatnia(5));  // true
console.log(czyDodatnia(-2)); // false

Funkcja obliczająca rabat

function obliczRabat(cena, procent) {
    return cena - cena * procent / 100;
}

console.log(obliczRabat(200, 10)); // 180

Dzięki oddzielnym funkcjom łatwiej przetestować obliczenia i wykorzystać je w kilku miejscach witryny.

Dobra praktyka: funkcja obliczeniowa powinna otrzymywać dane jako parametry i zwracać wynik przez return. Osobny kod powinien pobierać dane z HTML i wyświetlać wynik.

19. Funkcja rekurencyjna

Rekurencja polega na tym, że funkcja wywołuje samą siebie.

Przykładem jest obliczanie silni liczby naturalnej. 

function silnia(n) {
    if (n === 0) {
        return 1;
    }

    return n * silnia(n - 1);
}

console.log(silnia(5)); // 120

Obliczenie przebiega następująco: 

5! = 5 × 4 × 3 × 2 × 1 = 120
Ważne! Funkcja rekurencyjna musi posiadać warunek zakończenia. Powyższy przykład zakłada, że przekazujemy nieujemną liczbę całkowitą. Dla innych danych trzeba dodać walidację.

20. Kompletny przykład INF.03 – kalkulator rabatu

Przykład łączy funkcje, formularz HTML, obsługę zdarzeń i wyświetlanie wyniku na stronie.

Utwórz plik rabat.html i wklej poniższy kod. 

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <title>Kalkulator rabatu</title>

    <style>
        body {
            font-family: Arial;
        }

        .wynik {
            color: darkgreen;
            font-weight: bold;
        }

        .blad {
            color: red;
        }
    </style>
</head>
<body>

    <h1>Kalkulator rabatu</h1>

    <label for="cena">Cena produktu:</label>
    <input type="number" id="cena" min="0" step="0.01">

    <label for="rabat">Rabat (%):</label>
    <input type="number" id="rabat" min="0" max="100">

    <button type="button" id="oblicz">Oblicz</button>

    <p id="wynik"></p>

    <script>
        function obliczRabat(cena, procent) {
            return cena - cena * procent / 100;
        }

        const przycisk = document.getElementById("oblicz");
        const wynik = document.getElementById("wynik");

        przycisk.addEventListener("click", function() {
            const cena = Number(document.getElementById("cena").value);
            const rabat = Number(document.getElementById("rabat").value);

            const cenaPole = document.getElementById("cena");
            const rabatPole = document.getElementById("rabat");

            if (
                cenaPole.value.trim() === "" ||
                rabatPole.value.trim() === "" ||
                !Number.isFinite(cena) ||
                !Number.isFinite(rabat) ||
                cena < 0 ||
                rabat < 0 ||
                rabat > 100
            ) {
                wynik.textContent = "Podaj poprawne dane.";
                wynik.className = "blad";
                return;
            }

            const cenaKoncowa = obliczRabat(cena, rabat);

            wynik.textContent =
                "Cena po rabacie: " + cenaKoncowa.toFixed(2) + " zł";

            wynik.className = "wynik";
        });
    </script>

</body>
</html>

Jak działa program?

  1. Użytkownik podaje cenę produktu oraz wysokość rabatu.
  2. Po kliknięciu przycisku uruchamia się funkcja obsługująca zdarzenie.
  3. Skrypt odczytuje wartości z formularza.
  4. Sprawdza, czy podano poprawne dane.
  5. Funkcja obliczRabat() oblicza cenę końcową.
  6. Wynik zostaje wyświetlony w akapicie bez przeładowania strony.
Na egzaminie INF.03: zwracaj uwagę na nazwy identyfikatorów, sposób pobierania danych, walidację, prawidłowe obliczenia i miejsce wyświetlania wyniku.

  • find() wyszukuje pierwszy pasujący element.
  • reduce() pozwala obliczyć wynik na podstawie całej tablicy.
  • Funkcje są wykorzystywane w obsłudze zdarzeń i formularzy HTML.
  • Rekurencja to wywoływanie funkcji przez samą siebie.
  • Dobra funkcja powinna mieć jasno określone zadanie.

📝 Zadania

W zadaniach 1–10 wyniki wyświetlaj w konsoli przeglądarki, chyba że polecenie stanowi inaczej. W zadaniach 11–16 utwórz stronę HTML i wyświetl wyniki na stronie za pomocą DOM.

Wykorzystuj funkcje z parametrami i return. Nie wpisuj wyników na stałe.

Część A – podstawy funkcji

Zadanie 1 – Powitanie

Napisz funkcję powitanie(imie), która przyjmuje imię i wyświetla komunikat „Witaj, [imię]!”. Wywołaj ją trzykrotnie dla różnych imion.

Zadanie 2 – Pole i obwód prostokąta

Napisz dwie funkcje: pole(a, b) i obwod(a, b). Każda funkcja ma zwracać wynik przez return. Dla boków 6 i 4 oczekiwane wyniki to 24 i 20.

Zadanie 3 – Parzystość liczby

Utwórz funkcję czyParzysta(liczba), która zwraca true dla liczby parzystej i false dla nieparzystej. Przetestuj ją dla liczb 8, 13 i 0.

Zadanie 4 – Wartość bezwzględna

Napisz funkcję wartoscBezwzgledna(x), która zwróci wartość bezwzględną liczby bez korzystania z Math.abs(). Sprawdź wyniki dla -7, 0 i 12.

Zadanie 5 – Cena z rabatem

Utwórz funkcję rabat(cena, procent = 10). Funkcja ma obliczać cenę po rabacie. Przetestuj ją dla ceny 200 zł z rabatem domyślnym oraz rabatem 25%. Oczekiwane wyniki: 180 zł i 150 zł.

Część B – funkcje anonimowe i strzałkowe

Zadanie 6 – Trzy sposoby zapisu funkcji

Utwórz funkcję obliczającą sześcian liczby: najpierw jako deklarację funkcji, następnie jako funkcję anonimową przypisaną do zmiennej, a na końcu jako funkcję strzałkową. Zastosuj różne nazwy i porównaj wyniki dla liczby 4.

Zadanie 7 – Kalkulator działań

Utwórz funkcję oblicz(a, b, dzialanie), która przyjmuje dwie liczby i funkcję wykonującą działanie matematyczne. Wywołaj ją dla dodawania, odejmowania i mnożenia, przekazując odpowiednie callbacki.

Zadanie 8 – forEach()

Utwórz tablicę pięciu imion. Za pomocą forEach() wyświetl każde imię z numerem porządkowym, np. „1. Anna”, „2. Jan”. Zastosuj funkcję strzałkową.

Zadanie 9 – map() i filter()

Dla tablicy [5, 12, 8, 20, 3, 15] utwórz za pomocą filter() tablicę liczb większych niż 10, a następnie za pomocą map() oblicz ich kwadraty. Oczekiwane wyniki: [12, 20, 15] oraz [144, 400, 225].

Zadanie 10 – reduce()

Dla tablicy [10, 20, 30, 40, 50] oblicz sumę elementów metodą reduce(). Następnie oblicz średnią, wykorzystując długość tablicy. Oczekiwane wyniki: 150 i 30.

Część C – funkcje w aplikacjach internetowych

Zadanie 11 – Kalkulator pola

Utwórz plik prostokat.html. Dodaj dwa pola liczbowe na długości boków, przycisk i akapit wyniku. Funkcja obliczPole(a, b) ma zwracać pole prostokąta. Po kliknięciu przycisku wyświetl wynik na stronie. Sprawdź, czy oba boki są większe od zera.

Zadanie 12 – Sprawdzanie wieku

Utwórz stronę z polem do wpisania wieku i przyciskiem „Sprawdź”. Funkcja sprawdzWiek(wiek) ma zwracać komunikat „Osoba pełnoletnia” lub „Osoba niepełnoletnia”. Nie dopuszczaj ujemnego wieku, wartości niecałkowitych ani pustego pola.

Zadanie 13 – Lista produktów

Utwórz tablicę obiektów opisujących pięć produktów. Każdy obiekt zawiera nazwę i cenę. Na stronie dodaj przycisk „Pokaż produkty” oraz pustą listę ul. Napisz funkcję wyswietlProdukty(tablica), która utworzy elementy li za pomocą DOM i forEach().

Zadanie 14 – Filtr cen

Rozbuduj zadanie 13 o pole ceny minimalnej i przycisk „Filtruj”. Napisz funkcję filtrujProdukty(tablica, cenaMin), która za pomocą filter() zwróci produkty o cenie większej lub równej wskazanej wartości. Wynik wyświetl na stronie bez przeładowania.

Zadanie 15 – Kalkulator kosztów zamówienia

Utwórz stronę zamowienie.html, która pozwala wybrać produkt z listy, podać liczbę sztuk i obliczyć koszt zamówienia. Dane produktów umieść w tablicy obiektów.

  1. Utwórz funkcję znajdzProdukt(id), wykorzystującą find().
  2. Utwórz funkcję obliczKoszt(cena, ilosc), zwracającą wynik przez return.
  3. Utwórz funkcję pokazWynik(tekst), która wyświetla komunikat w odpowiednim elemencie HTML.
  4. Obsłuż przycisk za pomocą addEventListener().
  5. Nie dopuszczaj zerowej, ujemnej ani niecałkowitej liczby sztuk.

Zadanie 16 – Miniarkusz praktyczny INF.03: serwis komputerowy

Utwórz plik serwis.html zawierający formularz zgłoszenia usługi oraz podsumowanie kosztów. Do rozwiązania wykorzystaj funkcje, tablicę obiektów, metody tablic i obsługę zdarzeń.

W tablicy uslugi umieść następujące dane:

Usługa Cena
Instalacja systemu 120 zł
Konfiguracja routera 80 zł
Czyszczenie komputera 100 zł
Wymiana dysku 150 zł

Wymagania:

  1. Przygotuj formularz zawierający wybór usługi, liczbę urządzeń i przycisk „Oblicz”.
  2. Opcje listy wyboru utwórz na podstawie tablicy obiektów, wykorzystując forEach().
  3. Napisz funkcję znajdzUsluge(id), która wyszukuje usługę metodą find().
  4. Napisz funkcję obliczKoszt(cena, ilosc).
  5. Utwórz funkcję sprawdzIlosc(ilosc), która zwraca informację, czy podano dodatnią liczbę całkowitą.
  6. Po kliknięciu przycisku wyświetl nazwę usługi, liczbę urządzeń oraz koszt całkowity.
  7. W razie błędnych danych wyświetl komunikat za pomocą klasy CSS blad.
  8. Dla poprawnego wyniku zastosuj klasę CSS wynik.
  9. Wynik ma się aktualizować bez przeładowania strony.
  10. Kod JavaScript podziel na funkcje o jasno określonych zadaniach.
Wskazówka INF.03: nie wpisuj kosztów ani wyników na stałe w kodzie obsługującym przycisk. Pobieraj dane z tablicy obiektów, obliczaj wyniki w funkcjach i wyświetlaj je za pomocą DOM.
