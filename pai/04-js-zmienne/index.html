JavaScript: Zmienne – let, const i var

Przygotowanie środowiska pracy w Visual Studio Code, deklarowanie zmiennych oraz podstawowe typy danych w JavaScript.

1. Przygotowanie środowiska pracy – Visual Studio Code

Visual Studio Code (VS Code) jest edytorem kodu umożliwiającym tworzenie i edytowanie plików HTML, CSS oraz JavaScript.

Do pracy z projektem należy utworzyć osobny folder, a następnie otworzyć go w Visual Studio Code.

Visual Studio Code nie jest tym samym programem co Visual Studio. VS Code jest lekkim edytorem kodu, często wykorzystywanym do tworzenia stron internetowych.

Podstawowe czynności:

  1. uruchomienie Visual Studio Code,
  2. utworzenie folderu projektu,
  3. otwarcie folderu za pomocą File → Open Folder,
  4. utworzenie plików HTML, CSS i JavaScript.

2. Struktura projektu HTML + CSS + JavaScript

Przykładowy projekt może składać się z trzech plików: 

lekcja04/
│
├── index.html
├── style.css
└── skrypt.js

Poszczególne pliki pełnią różne funkcje:

  • index.html – struktura i treść strony,
  • style.css – wygląd strony,
  • skrypt.js – kod JavaScript.
STRONA INTERNETOWA │ ├── index.html → STRUKTURA ├── style.css → WYGLĄD └── skrypt.js → DZIAŁANIE

Plik index.html

<!DOCTYPE html>
<html lang="pl">

<head>
    <meta charset="UTF-8">
    <title>Lekcja 04</title>
    <link rel="stylesheet" href="style.css">
</head>

<body>

    <h1>JavaScript – zmienne</h1>

    <script src="skrypt.js"></script>

</body>

</html>

Plik style.css

body {
    font-family: Arial, sans-serif;
}

h1 {
    color: darkblue;
}

Plik skrypt.js

console.log("Plik JavaScript został poprawnie podłączony.");
Ważne!
Poprawność podłączenia pliku JavaScript można sprawdzić w konsoli przeglądarki.

3. Co to jest zmienna?

Zmienna jest nazwanym miejscem w pamięci programu, służącym do przechowywania danych.

W zmiennych można przechowywać między innymi:

  • liczby,
  • tekst,
  • wartości logiczne,
  • wyniki obliczeń.

Przykład:

let imie = "Anna";
let wiek = 18;

Zmienna imie przechowuje tekst "Anna", natomiast zmienna wiek przechowuje liczbę 18.

4. Deklarowanie zmiennych – let

Zmienną, której wartość może ulegać zmianie, deklaruje się za pomocą słowa kluczowego let. 

let imie = "Kasia";
let imie = "Kasia"; ↓ ↓ ↓ ↓ słowo nazwa operator wartość kluczowe zmiennej przypisania

Możliwe jest również najpierw zadeklarowanie zmiennej, a następnie przypisanie jej wartości: 

let imie;

imie = "Kasia";

5. Zmiana wartości zmiennej

Wartość zmiennej zadeklarowanej za pomocą let może zostać zmieniona. 

let punkty = 10;

punkty = 15;

console.log(punkty);

W konsoli zostanie wyświetlona wartość: 

15
Ważne!
Przy zmianie wartości istniejącej zmiennej nie zapisuje się ponownie słowa let.

6. Stałe – const

Jeżeli do zmiennej nie ma być ponownie przypisywana inna wartość, można użyć słowa kluczowego const. 

const pi = 3.14;

Próba ponownego przypisania innej wartości: 

pi = 3.14159;

spowoduje błąd.

Komunikat o błędzie można odczytać w konsoli przeglądarki.

7. var – starszy sposób deklarowania zmiennych

var jest starszym sposobem deklarowania zmiennych w JavaScript. 

var liczba = 10;

Zapis ten można spotkać w starszych skryptach, podręcznikach i materiałach edukacyjnych.

W nowych skryptach zaleca się stosowanie let oraz const.

Szczegółowe różnice związane z zakresem zmiennych zostaną omówione w osobnej lekcji.

8. let, const czy var?

Sposób Czy można ponownie przypisać wartość? Zastosowanie
let tak gdy wartość może się zmieniać
const nie gdy nie planuje się ponownego przypisania
var tak starszy sposób deklarowania zmiennych
Zasada stosowana w STREFIE IT:
let – gdy wartość może się zmieniać.
const – gdy nie będzie ponownie przypisywana.
var – należy rozpoznawać, ale nie jest stosowane w nowych przykładach.

9. Zasady nazywania zmiennych

Nazwa zmiennej powinna informować, jakie dane są w niej przechowywane.

Przykłady czytelnych nazw:

let imie = "Anna";
let wiek = 17;
let cenaProduktu = 29.99;
let liczbaPunktow = 45;

Nazwa zmiennej:

  • nie może zawierać spacji,
  • nie może zaczynać się od cyfry,
  • może zawierać litery, cyfry, znak _ i $,
  • rozróżnia wielkie i małe litery.

Przykład:

let wiek = 18;
let Wiek = 20;

wiek oraz Wiek są dwiema różnymi zmiennymi.

camelCase

Przy nazwach składających się z kilku słów często stosuje się zapis camelCase. 

let cenaProduktu;
let liczbaUczniow;
let wynikEgzaminu;

10. Typy danych

Number – liczby

let wiek = 18;
let cena = 29.99;

String – tekst

let imie = "Anna";
let miasto = "Lublin";

Boolean – wartość logiczna

Typ logiczny może przyjmować dwie wartości: 

true
false

Przykład:

let pelnoletni = true;
let zalogowany = false;

undefined

Jeżeli zmienna zostanie zadeklarowana bez przypisania wartości, jej wartością będzie undefined. 

let wynik;

null

Wartość null może zostać przypisana celowo, aby oznaczyć brak wartości. 

let wybranyProdukt = null;

11. Wyświetlanie wartości zmiennych

Do sprawdzania wartości zmiennych można wykorzystać metodę console.log(). 

let imie = "Kasia";
let wiek = 18;

console.log(imie);
console.log(wiek);

Możliwe jest również wyświetlenie tekstu wraz z wartością zmiennej: 

let imie = "Kasia";

console.log("Imię:", imie);

W konsoli:

Imię: Kasia

12. typeof – sprawdzanie typu danych

Operator typeof służy do sprawdzania typu wartości. 

let imie = "Anna";
let wiek = 18;
let uczen = true;

console.log(typeof imie);
console.log(typeof wiek);
console.log(typeof uczen);

W konsoli zostanie wyświetlone:

string
number
boolean

13. Przykład

Poniższy przykład wykorzystuje zmienne, stałą oraz metodę console.log(). 

let imie = "Anna";
let wiek = 17;
const szkola = "Technikum";

console.log("Imię:", imie);
console.log("Wiek:", wiek);
console.log("Szkoła:", szkola);

wiek = 18;

console.log("Nowy wiek:", wiek);

📌 Zapamiętaj

  • Zmienna służy do przechowywania danych.
  • let stosuje się wtedy, gdy wartość może się zmieniać.
  • const stosuje się wtedy, gdy nie planuje się ponownego przypisania wartości.
  • var jest starszym sposobem deklarowania zmiennych.
  • JavaScript rozróżnia wielkie i małe litery.
  • Nazwy składające się z kilku słów można zapisywać w stylu camelCase.
  • Do podstawowych typów danych należą number, string oraz boolean.
  • Operator typeof pozwala sprawdzić typ danych.
  • console.log() służy do wyświetlania informacji w konsoli.

const rok = 2026;
