JavaScript: Błędy w kodzie

Rodzaje błędów w JavaScript, konsola przeglądarki oraz sposoby odnajdywania i poprawiania błędów w kodzie.
Cel główny: Poznanie rodzajów błędów występujących w kodzie JavaScript oraz nabycie umiejętności ich odnajdywania i poprawiania z wykorzystaniem narzędzi deweloperskich przeglądarki.

1. Błędy w programowaniu

Podczas pisania programu mogą pojawić się błędy, przez które kod nie zostanie wykonany albo jego wynik będzie inny niż oczekiwany.

Przykład poprawnego kodu:

let liczba = 10;

document.write(liczba);

Niewielka pomyłka, np. błędna nazwa zmiennej, może jednak spowodować problem: 

let liczba = 10;

document.write(liczbaa);
Zmienna została utworzona jako liczba, ale później użyto nazwy liczbaa.

W większych programach odnalezienie takiej pomyłki może być trudniejsze. Dlatego podczas programowania korzystamy z narzędzi pomagających odnajdywać, analizować i usuwać błędy.

2. Rodzaje błędów

Podczas tworzenia programów możemy spotkać różne rodzaje błędów.

Błąd składniowy

Powstaje wtedy, gdy kod został zapisany niezgodnie z zasadami składni języka JavaScript.

Przykład:

let liczba = 10;

if (liczba > 5 {
    document.write("Liczba jest większa od 5");
}

W instrukcji if brakuje nawiasu ).

Ważne!
Przy błędzie składniowym przeglądarka może nie być w stanie prawidłowo wykonać kodu.

Błąd wykonania

Kod może wyglądać poprawnie składniowo, ale podczas jego wykonywania pojawi się problem. 

let liczba = 10;

document.write(liczbaa);

Próbujemy użyć zmiennej liczbaa, która nie została wcześniej utworzona.

Błąd logiczny

Program działa, ale daje inny wynik niż oczekiwaliśmy. 

let a = 10;
let b = 5;

let suma = a - b;

document.write(suma);

Program się wykona, ale zamiast dodać liczby, odejmuje je.

Ważne!
Błędy logiczne bywają trudniejsze do znalezienia, ponieważ program może działać bez wyświetlenia komunikatu o błędzie.

3. Konsola przeglądarki

Przeglądarka może pomóc nam znaleźć błędy w kodzie JavaScript.

W przeglądarce Google Chrome otwieramy Narzędzia dla deweloperów. Możemy to zrobić naciskając:

F12

Następnie wybieramy zakładkę: Console (Konsola).

W konsoli możemy zobaczyć między innymi:

  • komunikaty generowane przez JavaScript,
  • błędy,
  • ostrzeżenia,
  • informacje o miejscu wystąpienia błędu.
Zapamiętaj!
Jeśli skrypt JavaScript nie działa tak, jak powinien, jednym z pierwszych miejsc, które warto sprawdzić, jest konsola przeglądarki.

4. Narzędzia deweloperskie

Narzędzia deweloperskie przeglądarki pomagają programiście sprawdzać działanie strony i kodu.

Podczas pracy z JavaScript szczególnie przydatne są:

Console – komunikaty i błędy JavaScript.
Sources – pliki źródłowe strony i skrypty JavaScript.
Elements – struktura dokumentu HTML.

Na początku nauki JavaScript najczęściej będziemy korzystać z zakładki Console.

5. Komunikaty o błędach

Spójrz na poniższy kod:

console.logg("Wykonanie kodu JavaScript");

Zamiast:

console.log("Wykonanie kodu JavaScript");

zapisano console.logg. Jest to zwykła literówka.

Po uruchomieniu strony przeglądarka wyświetli w konsoli informację o błędzie.

Komunikat o błędzie jest podpowiedzią.
Nie należy go ignorować. Trzeba przeczytać komunikat i sprawdzić wskazane miejsce w kodzie.

Możemy spotkać między innymi następujące nazwy błędów: 

SyntaxError
ReferenceError
TypeError
Na tym etapie nie musisz zapamiętywać wszystkich nazw błędów. Ważniejsze jest nauczenie się czytania komunikatu i odnajdywania miejsca problemu.

6. Numer linii i lokalizacja błędu

Konsola często podaje również nazwę pliku oraz numer linii, np.: 

index.html:18

lub:

skrypt.js:12

Informacja skrypt.js:12 wskazuje 12. linię pliku skrypt.js.

Po kliknięciu informacji znajdującej się przy błędzie narzędzia deweloperskie mogą pokazać odpowiedni fragment kodu.

Uwaga!
Wskazana linia jest miejscem, w którym przeglądarka zauważyła problem. Przyczyna błędu może czasem znajdować się również nieco wcześniej.

7. console.log() – sprawdzanie działania programu

Polecenie console.log() pozwala wyświetlać informacje w konsoli.

Przykład:

let liczba = 10;

console.log(liczba);

W konsoli zobaczymy:

10

Możemy również sprawdzać wartości kilku zmiennych: 

let a = 5;
let b = 7;

console.log("a =", a);
console.log("b =", b);

let wynik = a + b;

console.log("wynik =", wynik);

Dzięki temu możemy sprawdzić, jakie wartości mają zmienne podczas wykonywania programu.

console.log() może służyć nie tylko do wyświetlania komunikatów, ale również pomagać w poszukiwaniu błędów.

8. Jak szukać błędu w kodzie?

Jeżeli program nie działa prawidłowo, warto postępować według prostego schematu:

KOD NIE DZIAŁA ↓ OTWÓRZ NARZĘDZIA DEWELOPERSKIE – F12 ↓ WYBIERZ CONSOLE ↓ PRZECZYTAJ KOMUNIKAT O BŁĘDZIE ↓ SPRAWDŹ NUMER LINII ↓ SPRAWDŹ WSKAZANY FRAGMENT KODU ↓ W RAZIE POTRZEBY UŻYJ console.log() ↓ POPRAW BŁĄD ↓ ZAPISZ PLIK ↓ ODŚWIEŻ STRONĘ I SPRAWDŹ PONOWNIE
To będzie nasz podstawowy sposób postępowania podczas kolejnych lekcji JavaScript.

9. Najczęstsze błędy początkujących

Literówka w poleceniu

Znajdź błąd:

console.logg("Witaj");

Poprawnie:

console.log("Witaj");

Literówka w nazwie zmiennej

Znajdź błąd:

let liczba = 20;

document.write(liczbaa);

Poprawnie:

let liczba = 20;

document.write(liczba);

Brak cudzysłowu

Znajdź błąd:

let imie = "Anna;

Poprawnie:

let imie = "Anna";

Brak nawiasu

Znajdź błąd:

let liczba = 15;

if (liczba > 10 {
    document.write("Liczba jest większa od 10");
}

Poprawnie:

let liczba = 15;

if (liczba > 10) {
    document.write("Liczba jest większa od 10");
}

Błąd logiczny

let a = 10;
let b = 5;

let suma = a - b;

document.write(suma);

Kod nie zawiera błędu składniowego. Program się uruchomi, ale wykonuje odejmowanie zamiast dodawania.

Powinno być:

let suma = a + b;

10. Poprawianie błędnego kodu

Podczas szukania błędu nie zmieniamy przypadkowo wielu fragmentów programu naraz.

Najpierw:

  1. sprawdzamy konsolę,
  2. czytamy komunikat,
  3. odnajdujemy wskazane miejsce,
  4. sprawdzamy zapis kodu,
  5. poprawiamy błąd,
  6. zapisujemy plik,
  7. ponownie uruchamiamy lub odświeżamy stronę.

Jeżeli nadal występuje problem, powtarzamy te czynności.

📌 Zapamiętaj

  • Błędy są naturalną częścią tworzenia programów.
  • Błąd składniowy oznacza niepoprawny zapis kodu.
  • Błąd wykonania pojawia się podczas wykonywania programu.
  • Przy błędzie logicznym program działa, ale daje nieprawidłowy wynik.
  • F12 pozwala otworzyć narzędzia deweloperskie w Chrome.
  • W zakładce Console możemy znaleźć informacje o błędach JavaScript.
  • Konsola może wskazać plik oraz numer linii, w której wystąpił problem.
  • console.log() pozwala wyświetlać informacje i wartości zmiennych w konsoli.
  • Po poprawieniu błędu należy zapisać plik, odświeżyć stronę i ponownie sprawdzić działanie programu.

📝 Zadania

Zadanie 1

Utwórz stronę HTML i umieść w niej: 

<script>
    console.log("JavaScript działa");
</script>

Uruchom stronę, otwórz narzędzia deweloperskie za pomocą F12 i odszukaj komunikat w konsoli.

Zadanie 2

Uruchom kod:

console.logg("JavaScript działa");

Sprawdź komunikat w konsoli i odszukaj informację o miejscu wystąpienia błędu. Następnie popraw kod.

Zadanie 3

Znajdź i popraw błąd:

let liczba = 15;

if (liczba > 10 {
    document.write("Liczba jest większa od 10");
}

Zadanie 4

Sprawdź poniższy program:

let a = 10;
let b = 20;

let suma = a - b;

document.write(suma);

Program działa, ale wynik jest nieprawidłowy. Znajdź przyczynę i popraw kod.

Zadanie 5

Dodaj odpowiednie polecenia console.log(), aby w konsoli zostały wyświetlone wartości zmiennych a, b oraz wynik. 

let a = 8;
let b = 4;

let wynik = a * b;

document.write(wynik);

🎯 Sprawdź, czy potrafisz

Po tej lekcji powinieneś potrafić:

  1. wyjaśnić, czym jest błąd w kodzie,
  2. rozróżnić podstawowe rodzaje błędów,
  3. otworzyć narzędzia deweloperskie i konsolę,
  4. odczytać podstawowy komunikat o błędzie,
  5. odnaleźć wskazany numer linii,
  6. użyć console.log(),
  7. znaleźć i poprawić prosty błąd w JavaScript.
