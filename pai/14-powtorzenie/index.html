JavaScript: Powtórzenie egzaminacyjne

Kompendium praktyczne przygotowujące do egzaminu INF.03 i wcześniejszej kwalifikacji EE.09. Formularze, obliczenia, walidacja, zdarzenia, modyfikowanie DOM, galerie oraz tablice.
Cel główny: samodzielne tworzenie skryptów JavaScript na podstawie wymagań zadania egzaminacyjnego.

O powtórzeniu

Zestaw zawiera 30 autorskich zadań praktycznych wzorowanych na typowych wymaganiach arkuszy INF.03 oraz EE.09. Zadania nie są dosłownymi kopiami arkuszy CKE.

Ćwiczenia zostały podzielone na pięć części:

Część Zakres Zadania
A Obliczenia z formularzy 01–08
B Formularze i walidacja 09–14
C Zdarzenia, DOM, CSS i galerie 15–21
D Tablice, losowanie i algorytmy 22–28
E Rozbudowane zadania egzaminacyjne 29–30
Zasady pracy:
  • Każde zadanie wykonaj w osobnym pliku HTML.
  • Otrzymujesz potrzebne elementy HTML i wybrane style CSS.
  • Twoim zadaniem jest napisanie działającego JavaScript.
  • Nie korzystaj z PHP ani bazy danych.
  • Wyniki wyświetlaj w wyznaczonych elementach strony.
  • Sprawdź działanie skryptu na danych kontrolnych.
  • Nie wpisuj wyników obliczeń na stałe.

Jeżeli przy zadaniu nie zamieszczono osobnego CSS, wystarczy wspólny szablon znajdujący się poniżej. Fragmenty HTML wstawiaj do znacznika <main> własnego pliku.

Schemat rozwiązywania zadania egzaminacyjnego

  1. Przeczytaj wymagania skryptu. Zaznacz, jakie dane ma pobrać i gdzie wyświetlić wynik.
  2. Sprawdź identyfikatory HTML. Ustal, z jakich elementów korzysta skrypt.
  3. Pobierz dane. Zastosuj getElementById() lub querySelector().
  4. Zamień typ danych. W obliczeniach często konieczne jest Number().
  5. Wykonaj obliczenia lub instrukcje warunkowe. Nie pomijaj szczególnych przypadków.
  6. Wyświetl rezultat. Użyj odpowiedniego elementu HTML.
  7. Przetestuj działanie. Sprawdź przykład poprawny, błędne dane oraz wartości graniczne.
Ważne dla INF.03: arkusz może wymagać konkretnego sposobu wyświetlania wyniku lub przypisania zdarzenia. Na egzaminie zawsze pierwszeństwo mają dokładne wymagania danego arkusza.

Szablon strony do wykonywania zadań

Skopiuj szablon do nowego pliku HTML. Następnie zamień przykładową zawartość bloku main na HTML wybranego zadania. 

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Powtórzenie JavaScript</title>
    <style>
        body {
            font-family: Arial, sans-serif;
            background-color: #f3f6fb;
            margin: 30px;
            color: #20324a;
        }

        main {
            max-width: 800px;
            margin: 0 auto;
            padding: 25px;
            background-color: white;
            border: 1px solid #d6e0ed;
            border-radius: 8px;
        }

        input, select, textarea, button {
            font: inherit;
            padding: 8px;
            margin: 5px;
        }

        button {
            cursor: pointer;
        }

        .wynik {
            margin-top: 15px;
            padding: 12px;
            background-color: #edf5ed;
        }

        .blad {
            color: darkred;
            font-weight: bold;
        }

        .poprawny {
            color: darkgreen;
            font-weight: bold;
        }
    </style>
</head>

<body>
    <main>
        <h1>Zadanie egzaminacyjne</h1>

        <!-- Tutaj umieść HTML wybranego zadania -->

    </main>

    <script>
        // Tutaj napisz rozwiązanie JavaScript.
    </script>
</body>
</html>
W poniższych ćwiczeniach podaję jedynie fragmenty HTML do umieszczenia w main. Nie trzeba przepisywać całego szablonu dla każdego zadania.
