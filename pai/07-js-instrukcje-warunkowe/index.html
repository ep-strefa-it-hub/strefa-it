JavaScript: Instrukcje warunkowe

Podejmowanie decyzji w programie za pomocą instrukcji if, else if, else, operatorów porównania i operatorów logicznych.

1. Do czego służy instrukcja warunkowa?

Instrukcja warunkowa umożliwia wykonanie określonego fragmentu programu tylko wtedy, gdy podany warunek jest spełniony.

Przykład:

let wiek = 18;
if (wiek >= 18) {
    console.log("Osoba pełnoletnia");
}

Instrukcja wewnątrz bloku if zostanie wykonana tylko wtedy, gdy warunek: 

wiek >= 18

ma wartość true.

2. Wartość logiczna warunku – true i false

Wynikiem sprawdzenia warunku jest wartość logiczna:

  • true – prawda,
  • false – fałsz.
let liczba = 10;
console.log(liczba > 5);
console.log(liczba < 5);

Wynik:

true
false

3. Instrukcja if

Instrukcja if wykonuje blok kodu, jeżeli warunek ma wartość true.

Składnia:

if (warunek) {
    instrukcje;
}

Przykład:

let temperatura = 30;
if (temperatura > 25) {
    document.write("Jest gorąco");
}

4. Instrukcja if...else

Instrukcja else określa kod wykonywany wtedy, gdy warunek w instrukcji if nie jest spełniony. 

let wiek = 17;
if (wiek >= 18) {
    document.write("Osoba pełnoletnia");
} else {
    document.write("Osoba niepełnoletnia");
}
Ważne!
Przy konstrukcji if...else wykonana zostaje tylko jedna z dwóch gałęzi.

5. Instrukcja if...else if...else

Jeżeli należy sprawdzić kilka różnych przypadków, stosuje się konstrukcję else if. 

let liczba = Number(prompt("Podaj liczbę:"));
if (liczba > 0) {
    document.write("Liczba dodatnia");
} else if (liczba < 0) {
    document.write("Liczba ujemna");
} else {
    document.write("Liczba równa 0");
}

Warunki sprawdzane są kolejno od góry. Po znalezieniu pierwszego spełnionego warunku dalsze gałęzie nie są wykonywane.

6. Operatory porównania

Operatory porównania służą do porównywania wartości. Wynikiem jest true albo false.

Operator Znaczenie
> większe niż
< mniejsze niż
>= większe lub równe
<= mniejsze lub równe
=== równa wartość i ten sam typ danych
!== różna wartość lub różny typ danych

Przykład:

let a = 10;
let b = 20;
console.log(a < b);
console.log(a === b);

Wynik:

true
false
Uwaga!
Operator = nie oznacza tego samego co operator przypisania =.

7. Operatory logiczne

Operatory logiczne umożliwiają łączenie i negowanie warunków.

Operator Nazwa Znaczenie
&& AND i
|| OR lub
! NOT negacja

AND – &&

Wynikiem jest true wtedy, gdy oba warunki są prawdziwe. 

let wiek = 20;
let bilet = true;
if (wiek >= 18 && bilet === true) {
    document.write("Można wejść");
}

OR – ||

Wynikiem jest true wtedy, gdy przynajmniej jeden warunek jest prawdziwy. 

let dzien = "sobota";
if (dzien === "sobota" || dzien === "niedziela") {
    document.write("Weekend");
}

NOT – !

Operator ! odwraca wartość logiczną. 

let zalogowany = false;
if (!zalogowany) {
    document.write("Należy się zalogować");
}

8. Klamry i blok instrukcji

Klamry { } wyznaczają blok instrukcji należących do danego warunku.

Przykład bez klamer:

let a = 1;
let b = 1;
let c = 1;
if (a > 5)
    b++;
c++;

Warunek dotyczy wyłącznie instrukcji: 

b++;

Instrukcja: 

c++;

wykona się niezależnie od warunku.

Zasada:
W blokach if, else if i else należy stosować klamry { }, również wtedy, gdy blok zawiera tylko jedną instrukcję.

9. Sprawdzanie parzystości liczby

Liczba jest parzysta, jeżeli reszta z dzielenia przez 2 jest równa 0. 

let liczba = Number(prompt("Podaj liczbę:"));
if (liczba % 2 === 0) {
    document.write("Liczba parzysta");
} else {
    document.write("Liczba nieparzysta");
}

10. Sprawdzanie znaku liczby

let liczba = Number(prompt("Podaj liczbę:"));
if (liczba > 0) {
    document.write("Liczba dodatnia");
} else if (liczba < 0) {
    document.write("Liczba ujemna");
} else {
    document.write("Liczba równa 0");
}

11. Łączenie kilku warunków

Kilka warunków można połączyć za pomocą operatorów logicznych.

Sprawdzenie, czy liczba należy do przedziału:

let liczba = 15;
if (liczba >= 10 && liczba <= 20) {
    document.write("Liczba należy do przedziału od 10 do 20");
}

Sprawdzenie jednej z kilku możliwych wartości:

let miesiac = "lipiec";
if (miesiac === "lipiec" || miesiac === "sierpień") {
    document.write("Wakacje");
}

12. Zagnieżdżone instrukcje if

Zagnieżdżenie oznacza umieszczenie jednej instrukcji warunkowej wewnątrz drugiej. 
let dzien = "wtorek";
let pora = "rano";
if (dzien === "wtorek") {
    if (pora === "rano") {
        console.log("Wtorek rano");
    }
}

Ten sam warunek można w niektórych przypadkach zapisać za pomocą operatora &&: 

let dzien = "wtorek";
let pora = "rano";
if (dzien === "wtorek" && pora === "rano") {
    console.log("Wtorek rano");
}

13. Instrukcja switch

Instrukcja switch służy do wyboru jednej z wielu możliwych gałęzi programu. 

let opcja = Number(prompt("Wybierz opcję 1, 2 lub 3:"));
switch (opcja) {
    case 1:
        document.write("Wybrano opcję 1");
        break;
    case 2:
        document.write("Wybrano opcję 2");
        break;
    case 3:
        document.write("Wybrano opcję 3");
        break;
    default:
        document.write("Nieprawidłowa opcja");
}

W instrukcji switch można również porównywać wartości tekstowe. 

let kolor = "czerwony";
switch (kolor) {
    case "czerwony":
        document.write("STOP");
        break;
    case "zielony":
        document.write("IDŹ");
        break;
    default:
        document.write("Nieznany kolor");
}

14. break, default i continue

break kończy wykonywanie aktualnego przypadku w instrukcji switch.
default określa kod wykonywany wtedy, gdy żaden z przypadków case nie pasuje do sprawdzanej wartości.
Brak break może spowodować wykonanie kolejnych przypadków znajdujących się poniżej.

Instrukcja continue

Instrukcja continue stosowana jest w pętlach. Powoduje przerwanie bieżącej iteracji pętli i przejście do następnej. 

for (let i = 1; i <= 5; i++) {
    if (i === 3) {
        continue;
    }
    console.log(i);
}

Wynik:

1
2
4
5

Dla wartości i === 3 wykonana zostaje instrukcja continue, dlatego instrukcja console.log(i) zostaje pominięta. Pętla przechodzi bezpośrednio do kolejnej iteracji.

Ważne!
Instrukcja break kończy wykonywanie, natomiast continue pomija tylko bieżącą iterację pętli. Instrukcja continue zostanie dokładniej omówiona w lekcji dotyczącej pętli.

15. Operator warunkowy ?:

Prosty warunek if...else można czasem zapisać w krótszej formie za pomocą operatora warunkowego.

Klasyczny zapis:

let liczba = 10;
let wynik;
if (liczba > 0) {
    wynik = "dodatnia";
} else {
    wynik = "niedodatnia";
}

Zapis skrócony:

let liczba = 10;
let wynik = liczba > 0 ? "dodatnia" : "niedodatnia";
Operator ?: najlepiej stosować przy prostych warunkach. Przy bardziej rozbudowanej logice czytelniejsza jest konstrukcja if...else.

16. Wartości truthy i falsy

JavaScript może traktować niektóre wartości jako prawdę lub fałsz również bez bezpośredniego porównania.

Do podstawowych wartości falsy należą: 

false
0
""
null
undefined
NaN

Przykład:

let tekst = "";
if (tekst) {
    console.log("Tekst nie jest pusty");
}

Warunek nie zostanie spełniony, ponieważ pusty ciąg znaków jest wartością falsy.

Pozostałe wartości są zazwyczaj traktowane jako truthy.

17. Przykłady praktyczne

Pełnoletność

let wiek = Number(prompt("Podaj wiek:"));
if (wiek >= 18) {
    document.write("Osoba pełnoletnia");
} else {
    document.write("Osoba niepełnoletnia");
}

Podzielność dwóch liczb

let a = Number(prompt("Podaj pierwszą liczbę:"));
let b = Number(prompt("Podaj drugą liczbę:"));
if (a % b === 0) {
    document.write("Pierwsza liczba jest podzielna przez drugą");
} else {
    document.write("Pierwsza liczba nie jest podzielna przez drugą");
}

Bezpieczne dzielenie

let a = Number(prompt("Podaj liczbę a:"));
let b = Number(prompt("Podaj liczbę b:"));
if (b !== 0) {
    document.write(a / b);
} else {
    document.write("Nie można dzielić przez zero");
}

📌 Zapamiętaj

  • Instrukcja if wykonuje kod po spełnieniu warunku.
  • else określa kod wykonywany po niespełnieniu warunku.
  • else if umożliwia sprawdzanie kolejnych warunków.
  • Wynikiem warunku jest true albo false.
  • Do porównywania wartości stosuje się operatory porównania.
  • && oznacza AND, || oznacza OR, a ! oznacza negację.
  • Klamry { } wyznaczają blok instrukcji.
  • Operator % jest przydatny przy sprawdzaniu parzystości i podzielności.
  • switch umożliwia wybór jednej z wielu gałęzi.
  • break kończy wykonywanie przypadku case.
  • default obsługuje przypadek niepasujący do żadnego case.
  • continue powoduje przerwanie bieżącej iteracji pętli i przejście do następnej.
  • Operator ?: jest skróconą formą prostego warunku.
