JavaScript: Zdarzenia

Reagowanie na działania użytkownika, obsługa myszy, klawiatury i formularzy oraz zmiana wyglądu elementów strony.
Cel główny: Poznanie zasad obsługi zdarzeń w JavaScript i samodzielne tworzenie interaktywnych elementów strony.

1. Czym są zdarzenia?

Zdarzenie (event) to sytuacja, na którą może zareagować kod JavaScript, np. kliknięcie przycisku, naciśnięcie klawisza lub wpisanie tekstu do pola formularza.

Dzięki zdarzeniom strona może reagować na działania użytkownika bez konieczności jej ponownego wczytywania.

Typowy schemat działania:

  1. Wybieramy element HTML.
  2. Określamy zdarzenie, np. click.
  3. Podajemy funkcję wykonywaną po wystąpieniu zdarzenia.

3. Wybieranie elementów HTML

Aby przypisać zdarzenie, trzeba najpierw wskazać element strony.

getElementById()

Wyszukuje element po identyfikatorze id.

<button id="przycisk">Kliknij mnie</button>
let przycisk = document.getElementById("przycisk");

W getElementById() nazwę identyfikatora zapisujemy bez znaku #.

querySelector()

Wyszukuje pierwszy element pasujący do selektora CSS.

document.querySelector("#przycisk"); // element o id
document.querySelector(".karta");    // pierwszy element klasy karta
document.querySelector("h2");        // pierwszy nagłówek h2

querySelectorAll()

Wyszukuje wszystkie elementy pasujące do selektora CSS.

<p class="tekst">Pierwszy</p>
<p class="tekst">Drugi</p>
<p class="tekst">Trzeci</p>
let paragrafy = document.querySelectorAll(".tekst");
paragrafy[0].style.color = "red";
paragrafy[1].style.color = "blue";

📌 Zapamiętaj

querySelectorAll() zwraca kolekcję elementów (NodeList). Jej elementy są numerowane od 0.

4. Kiedy uruchamiać skrypt?

JavaScript musi mieć dostęp do elementów HTML, do których się odwołuje. Jeśli skrypt wykona się przed utworzeniem przycisku, jego wyszukanie może zwrócić null.

Sposób 1 – skrypt na końcu strony

<button id="start">Start</button>

<script>
    let start = document.getElementById("start");
    start.addEventListener("click", function() {
        alert("Uruchomiono!");
    });
</script>
</body>

Sposób 2 – DOMContentLoaded

Zdarzenie DOMContentLoaded występuje, gdy przeglądarka zakończy budowanie struktury HTML dokumentu (DOM). 

document.addEventListener("DOMContentLoaded", function() {
    let start = document.getElementById("start");

    start.addEventListener("click", function() {
        alert("Dokument jest gotowy!");
    });
});
W tej lekcji: w ćwiczeniach umieszczaj własny kod JavaScript tuż przed </body> albo korzystaj z DOMContentLoaded.

5. Trzy sposoby przypisywania zdarzeń

Sposób 1 – atrybut zdarzenia w HTML

<button onclick="alert('Kliknięto!')">Kliknij</button>

Zapis jest prosty, ale miesza JavaScript z HTML. Poznajemy go, aby rozumieć istniejący kod; do nowych projektów preferujemy oddzielenie JavaScript od HTML.

Sposób 2 – właściwość onclick

Kod HTML:

<button id="przycisk">Kliknij</button>

Kod JavaScript:

let przycisk = document.getElementById("przycisk");

przycisk.onclick = function() {
    alert("Kliknięto przycisk!");
};

Podobnie można używać ondblclick, onmouseover lub onkeyup. Ponowne przypisanie do onclick zastępuje poprzednią funkcję.

Sposób 3 – addEventListener()

let przycisk = document.getElementById("przycisk");

przycisk.addEventListener("click", function() {
    alert("Kliknięto przycisk!");
});

Ogólna postać:

element.addEventListener("nazwaZdarzenia", function() {
    // instrukcje wykonywane po zdarzeniu
});
FragmentZnaczenie
elementwybrany element HTML
"click"nazwa zdarzenia, bez przedrostka „on”
function() { ... }funkcja reagująca na zdarzenie
Najczęściej wybieramy addEventListener(), ponieważ pozwala wygodnie dodawać kilka funkcji obsługujących zdarzenia i oddzielić kod JS od HTML.

6. Kilka zdarzeń i kilka reakcji

Różne zdarzenia dla jednego elementu

<div id="pole">Najedź na mnie lub kliknij</div>
let pole = document.getElementById("pole");

pole.addEventListener("mouseenter", function() {
    pole.style.backgroundColor = "yellow";
});

pole.addEventListener("mouseleave", function() {
    pole.style.backgroundColor = "white";
});

pole.addEventListener("click", function() {
    pole.textContent = "Kliknięto!";
});

Dwie funkcje dla tego samego kliknięcia

let przycisk = document.getElementById("przycisk");

przycisk.addEventListener("click", function() {
    console.log("Kliknięcie przycisku");
});

przycisk.addEventListener("click", function() {
    przycisk.style.color = "red";
});

Po kliknięciu wykonają się obie funkcje. To ważna różnica w porównaniu z wielokrotnym przypisaniem do onclick.

7. Obiekt zdarzenia

Funkcja obsługująca zdarzenie może otrzymać obiekt zawierający informacje o tym, co się wydarzyło. Najczęściej nazywamy go e lub event. 

<button id="info">Sprawdź zdarzenie</button>
let przycisk = document.getElementById("info");

przycisk.addEventListener("click", function(e) {
    console.log(e.type);   // click
    console.log(e.target); // element, który wywołał zdarzenie
});
WłaściwośćZnaczenie
e.typerodzaj zdarzenia
e.targetelement, od którego pochodzi zdarzenie
e.keywartość klawisza w zdarzeniach klawiatury

8. Zdarzenia klawiatury

Do obsługi klawiatury najczęściej wykorzystujemy keydown (naciśnięcie) i keyup (zwolnienie klawisza).

Odczyt naciśniętego klawisza

<input type="text" id="poleTekstowe" placeholder="Naciśnij klawisz">
let pole = document.getElementById("poleTekstowe");

pole.addEventListener("keyup", function(e) {
    console.log("Klawisz:", e.key);
});

Wykrywanie klawisza Enter

pole.addEventListener("keyup", function(e) {
    if (e.key === "Enter") {
        console.log("Naciśnięto Enter");
    }
});

Klawisze modyfikujące

WłaściwośćZnaczenie
e.altKeyczy jest wciśnięty Alt
e.ctrlKeyczy jest wciśnięty Ctrl
e.shiftKeyczy jest wciśnięty Shift
pole.addEventListener("keydown", function(e) {
    if (e.shiftKey && e.key === "Enter") {
        console.log("Shift + Enter");
    }
});
Ważne! Do rozpoznawania klawiszy używaj e.key. Starsza właściwość keyCode jest przestarzała i nie należy jej stosować w nowych skryptach.

9. Zdarzenia formularzy

input – reagowanie na każdą zmianę tekstu

<input type="text" id="imie">
<p id="podglad"></p>
let imie = document.getElementById("imie");
let podglad = document.getElementById("podglad");

imie.addEventListener("input", function() {
    podglad.textContent = "Wpisujesz: " + imie.value;
});

submit – obsługa wysłania formularza

<form id="formularz">
    <input type="text" id="nazwisko" required>
    <button type="submit">Wyślij</button>
</form>
<p id="wynik"></p>
let formularz = document.getElementById("formularz");

formularz.addEventListener("submit", function(e) {
    e.preventDefault();

    let nazwisko = document.getElementById("nazwisko").value;
    document.getElementById("wynik").textContent =
        "Witaj, " + nazwisko + "!";
});
e.preventDefault() zatrzymuje domyślną akcję zdarzenia – w tym przykładzie wysłanie formularza i przejście do innego adresu lub ponowne wczytanie strony.

10. Zmiana klas CSS – classList

Zamiast zmieniać pojedyncze style w JavaScript, możemy przygotować klasę w CSS i dodawać ją do elementu.

Kod CSS:

.aktywny {
    background-color: lightblue;
    font-weight: bold;
    border: 2px solid navy;
}

Kod HTML:

<p id="komunikat">Kliknij przycisk, aby mnie wyróżnić.</p>
<button id="zmien">Zmień wygląd</button>

Kod JavaScript:

let komunikat = document.getElementById("komunikat");
let zmien = document.getElementById("zmien");

zmien.addEventListener("click", function() {
    komunikat.classList.toggle("aktywny");
});
MetodaZastosowanie
classList.add("aktywny")dodaje klasę
classList.remove("aktywny")usuwa klasę
classList.toggle("aktywny")dodaje lub usuwa klasę
classList.contains("aktywny")sprawdza, czy klasa istnieje
if (komunikat.classList.contains("aktywny")) {
    console.log("Element jest wyróżniony");
}

11. Zdarzenia dla wielu elementów

Gdy kilka elementów ma reagować podobnie, możemy pobrać je przez querySelectorAll(), a następnie użyć forEach().

Kod HTML:

<button class="wybor">Przycisk 1</button>
<button class="wybor">Przycisk 2</button>
<button class="wybor">Przycisk 3</button>

Kod JavaScript:

let przyciski = document.querySelectorAll(".wybor");

przyciski.forEach(function(przycisk) {
    przycisk.addEventListener("click", function() {
        przycisk.classList.toggle("aktywny");
    });
});

📌 Jak to działa?

  1. querySelectorAll() pobiera trzy przyciski.
  2. forEach() przechodzi po każdym przycisku.
  3. addEventListener() przypisuje reakcję na kliknięcie.
  4. classList.toggle() zmienia klasę tylko klikniętego przycisku.

12. Kompletny przykład – interaktywna wiadomość

Poniższy program łączy HTML, CSS i JavaScript. Skopiuj cały kod do pliku zdarzenia.html i uruchom w przeglądarce. 

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <title>Zdarzenia – przykład</title>
    <style>
        .aktywny { background: lightblue; font-weight: bold; }
    </style>
</head>
<body>
    <h1>Zdarzenia w JavaScript</h1>
    <p id="tekst">Przykładowa wiadomość</p>
    <button id="przycisk">Zmień wygląd</button>

    <script>
        let przycisk = document.getElementById("przycisk");
        let tekst = document.getElementById("tekst");

        przycisk.addEventListener("click", function() {
            tekst.classList.toggle("aktywny");
        });
    </script>
</body>
</html>

Każde kliknięcie przełącza klasę aktywny akapitu. Element nie musi być ponownie wczytywany.

📌 Zapamiętaj

  • Zdarzenie pozwala uruchomić kod w reakcji na działanie użytkownika.
  • getElementById() wybiera element po identyfikatorze.
  • querySelector() wybiera pierwszy pasujący element.
  • querySelectorAll() wybiera wszystkie pasujące elementy.
  • DOMContentLoaded oznacza, że struktura dokumentu jest gotowa.
  • addEventListener() jest zalecanym sposobem przypisywania zdarzeń.
  • e.target wskazuje element, od którego pochodzi zdarzenie.
  • e.key umożliwia odczytanie klawisza.
  • input umożliwia reagowanie na zmiany w polu na bieżąco.
  • e.preventDefault() zatrzymuje domyślną akcję zdarzenia.
  • classList pozwala dodawać, usuwać i przełączać klasy CSS.
  • forEach() ułatwia przypisywanie zdarzeń wielu elementom.

📝 Zadania

Każde zadanie wykonaj w osobnym pliku HTML lub w wyraźnie wydzielonej części własnego projektu. Skrypty umieszczaj przed znacznikiem </body>.

Zadanie 1 – Kliknięcie

Dodaj przycisk i akapit. Po kliknięciu przycisku zmień tekst akapitu na „Witaj w JavaScript!”.

Zadanie 2 – Podwójne kliknięcie

Utwórz nagłówek. Po jego podwójnym kliknięciu zmień jego treść na „Kliknięto dwa razy”.

Zadanie 3 – Najechanie kursorem

Utwórz element div. Po najechaniu zmień jego kolor tła, a po opuszczeniu przywróć pierwotny.

Zadanie 4 – Podgląd wpisywanego tekstu

Dodaj pole tekstowe. Pod nim na bieżąco wyświetlaj jego aktualną zawartość, używając zdarzenia input.

Zadanie 5 – Licznik znaków

Dodaj pole tekstowe i licznik pokazujący liczbę wpisanych znaków. Aktualizuj licznik po każdej zmianie.

Zadanie 6 – Klawisz Enter

Po naciśnięciu klawisza Enter w polu tekstowym wyświetl komunikat w akapicie.

Zadanie 7 – Przełączanie klasy

Przygotuj klasę CSS aktywny. Przycisk ma dodawać i usuwać ją z wybranego akapitu po kolejnych kliknięciach.

Zadanie 8 – Wiele przycisków

Dodaj pięć przycisków o wspólnej klasie. Po kliknięciu zmieniaj wygląd tylko klikniętego przycisku. Użyj querySelectorAll() i forEach().

Zadanie 9 – Formularz

Utwórz formularz z polem na imię. Po wysłaniu wyświetl „Cześć, [imię]!” bez przeładowania strony.

Zadanie 10 – Licznik kliknięć

Utwórz przycisk i licznik. Każde kliknięcie ma zwiększać wartość licznika o 1.

🎯 Sprawdź, czy potrafisz

  • wyjaśnić, czym jest zdarzenie w JavaScript,
  • rozróżnić zdarzenia myszy, klawiatury i formularzy,
  • wybrać element za pomocą getElementById() lub querySelector(),
  • wyjaśnić zastosowanie DOMContentLoaded,
  • przypisać zdarzenie za pomocą addEventListener(),
  • przypisać kilka funkcji obsługujących to samo zdarzenie,
  • odczytać e.key i sprawdzić klawisze modyfikujące,
  • obsłużyć zdarzenia input i submit,
  • wykorzystać classList.add(), remove() i toggle(),
  • przypisać zdarzenia wielu elementom za pomocą forEach().
