JavaScript: obsługa kodu JS

Sposoby umieszczania kodu JavaScript w dokumencie HTML oraz dołączanie zewnętrznych plików JavaScript.

1. Co to jest JavaScript?

JavaScript (JS) jest językiem skryptowym wykorzystywanym przede wszystkim do tworzenia interaktywnych elementów stron internetowych.
Ważne!
JavaScript jest interpretowany po stronie klienta, czyli w przeglądarce internetowej użytkownika.
JavaScript ↓ PRZEGLĄDARKA INTERNETOWA ↓ KOMPUTER UŻYTKOWNIKA

HTML odpowiada przede wszystkim za strukturę strony, CSS za jej wygląd, natomiast JavaScript pozwala określić jej zachowanie.

Za pomocą JavaScript możemy między innymi:

  • reagować na działania użytkownika,
  • zmieniać zawartość strony,
  • wykonywać obliczenia,
  • pobierać dane wprowadzone przez użytkownika,
  • sprawdzać formularze,
  • modyfikować wygląd elementów strony.

2. Gdzie można umieścić kod JavaScript?

Kod JavaScript możemy umieścić na kilka sposobów.

Bezpośrednio w dokumencie HTML

<script>
    // kod JavaScript
</script>

W osobnym lokalnym pliku .js

<script src="js/skrypt.js"></script>

W pliku znajdującym się pod zewnętrznym adresem

<script src="https://adres-strony.pl/skrypt.js"></script>

3. Znacznik <script>

Do umieszczania kodu JavaScript bezpośrednio w dokumencie HTML służy znacznik <script>. 

<script>
    document.write("Witaj na stronie!");
</script>
W HTML5 nie ma potrzeby stosowania type="text/javascript". Wystarczy znacznik <script>.

4. JavaScript w sekcji <body>

Kod JavaScript możemy umieścić bezpośrednio wewnątrz części <body> dokumentu HTML. 

<!DOCTYPE html>
<html lang="pl">

<head>
    <meta charset="UTF-8">
    <title>JavaScript</title>
</head>

<body>

    <h1>Moja pierwsza strona z JavaScript</h1>

    <script>
        document.write("Kod JavaScript został wykonany.");
    </script>

</body>

</html>

5. JavaScript w sekcji <head>

Kod JavaScript może znajdować się również w części <head> dokumentu. 

<!DOCTYPE html>
<html lang="pl">

<head>
    <meta charset="UTF-8">
    <title>JavaScript</title>

    <script>
        function komunikat() {
            alert("Witaj!");
        }
    </script>

</head>

<body>

    <button onclick="komunikat()">Kliknij</button>

</body>

</html>

W tym przykładzie funkcja została zdefiniowana w części <head>, a uruchamia się po kliknięciu przycisku.

6. Zewnętrzny plik .js

Kod JavaScript możemy przechowywać w oddzielnym pliku z rozszerzeniem .js.

Przykładowa nazwa pliku:

skrypt.js

W pliku zapisujemy sam kod JavaScript:

alert("Plik JavaScript został poprawnie dołączony!");
W pliku .js zapisujemy kod JavaScript bez znaczników HTML <script>.

7. Atrybut src

Atrybut src wskazuje ścieżkę lub adres pliku zawierającego kod JavaScript.

Jeżeli plik skrypt.js znajduje się w folderze js, zapisujemy: 

<script src="js/skrypt.js"></script>

8. Struktura katalogów projektu

Podczas tworzenia strony warto od początku zachowywać uporządkowaną strukturę katalogów. 

moja-strona/
│
├── index.html
│
├── css/
│   └── style.css
│
└── js/
    └── skrypt.js

Arkusz stylów dołączamy:

<link rel="stylesheet" href="css/style.css">

Plik JavaScript dołączamy:

<script src="js/skrypt.js"></script>

9. Gdzie dołączać JavaScript?

W prostych ćwiczeniach kod JavaScript może występować zarówno w części <head>, jak i <body>.

Zewnętrzny plik JavaScript możemy dołączyć pod koniec części <body>: 

<body>

    <h1>Moja strona</h1>
    <p>Treść strony...</p>

    <script src="js/skrypt.js"></script>

</body>

Możemy również umieścić odwołanie do skryptu w części <head> i zastosować atrybut defer: 

<script src="js/skrypt.js" defer></script>

Atrybut defer powoduje, że wykonanie skryptu zostanie odłożone do czasu przetworzenia dokumentu HTML.

10. Zasady poprawnego dołączania JavaScript

Podczas pracy z zewnętrznym plikiem JavaScript pamiętaj o kilku zasadach:

  • plik JavaScript zapisujemy z rozszerzeniem .js,
  • w pliku .js zapisujemy sam kod JavaScript,
  • atrybut src musi wskazywać właściwy plik,
  • ścieżka musi uwzględniać położenie pliku w katalogach projektu,
  • nazwa podana w HTML musi odpowiadać nazwie pliku.

Poprawna struktura:

projekt/
│
├── index.html
└── js/
    └── skrypt.js

Poprawne dołączenie:

<script src="js/skrypt.js"></script>

📌 Zapamiętaj

  • JavaScript jest interpretowany po stronie klienta, czyli w przeglądarce internetowej.
  • Kod JavaScript możemy zapisać bezpośrednio w dokumencie HTML lub w osobnym pliku .js.
  • Do umieszczania kodu JS w HTML służy znacznik <script>.
  • Atrybut src określa ścieżkę lub adres do pliku JavaScript.
  • W pliku .js nie umieszczamy znaczników <script>.
  • W HTML5 nie trzeba stosować type="text/javascript".

📝 Zadania

  1. Utwórz dokument index.html. W części body umieść kod JavaScript wyświetlający napis „Witaj na mojej stronie!”.
  2. Utwórz projekt zawierający plik index.html oraz folder js z plikiem skrypt.js. W pliku JavaScript wyświetl okno z komunikatem „Skrypt działa poprawnie!”.
  3. Utwórz projekt zawierający plik index.html oraz foldery css i js. Utwórz i poprawnie dołącz pliki style.css oraz skrypt.js.
  4. Utwórz stronę zawierającą nagłówek i przycisk. Kod JavaScript zapisz w osobnym pliku skrypt.js i poprawnie dołącz go do dokumentu HTML.
