Wybieranie elementów strony

Aby JavaScript mógł reagować na zdarzenie, najpierw musimy wskazać element lub elementy HTML, których zdarzenie będzie dotyczyć.

getElementById()

Metoda getElementById() wyszukuje element na podstawie jego identyfikatora id. 

<div id="kontener">Jan Kowalski</div>
let element = document.getElementById("kontener");

W metodzie getElementById() podajemy samą nazwę identyfikatora – bez znaku #.

querySelector()

Metoda querySelector() pozwala wyszukiwać elementy za pomocą selektorów CSS.

Element o id:

let element = document.querySelector("#kontener");

Element należący do klasy:

let paragraf = document.querySelector(".wyroznione");

Element określonego typu:

let naglowek = document.querySelector("h1");

📌 Zapamiętaj

querySelector() zwraca pierwszy element pasujący do podanego selektora.

querySelectorAll()

Jeśli chcemy pobrać wszystkie elementy pasujące do selektora, używamy: 

document.querySelectorAll()

Przykład:

<p class="tekst">Pierwszy paragraf</p>
<p class="tekst">Drugi paragraf</p>
<p class="tekst">Trzeci paragraf</p>
let paragrafy = document.querySelectorAll(".tekst");

Zmienna paragrafy przechowuje kolekcję wszystkich elementów posiadających klasę tekst.

Do poszczególnych elementów możemy odwołać się za pomocą indeksu: 

paragrafy[0].style.color = "red";
paragrafy[1].style.color = "blue";

Pamiętaj, że numerowanie elementów rozpoczyna się od 0.

Zdarzenia

Zdarzenie to czynność występująca na stronie, na którą może zareagować JavaScript.

Zdarzenie Znaczenie
click kliknięcie elementu
dblclick podwójne kliknięcie
mouseover najechanie kursorem
mouseout opuszczenie elementu przez kursor
keydown naciśnięcie klawisza
keyup puszczenie klawisza
focus uzyskanie aktywności przez element
blur utrata aktywności przez element
change zmiana wartości elementu formularza
submit wysłanie formularza

Przypisywanie zdarzeń

Zdarzenie możemy przypisać do elementu na kilka sposobów.

Sposób 1 – właściwość zdarzenia

let przycisk = document.getElementById("przycisk");

przycisk.onclick = function() {
    alert("Kliknięto przycisk");
};

W podobny sposób możemy korzystać z właściwości ondblclick, onmouseover, onmouseout czy onkeyup.

Sposób 2 – addEventListener()

Bardziej uniwersalnym sposobem obsługi zdarzeń jest metoda: 

addEventListener()

Przykład:

let przycisk = document.getElementById("przycisk");

przycisk.addEventListener("click", function() {
    alert("Kliknięto przycisk");
});

Metoda przyjmuje między innymi dwa argumenty: 

element.addEventListener("zdarzenie", function() {
    // instrukcje
});

Pierwszy argument określa rodzaj zdarzenia, a drugi – co ma zostać wykonane.

Wiele zdarzeń dla jednego elementu

Do jednego elementu możemy przypisać kilka różnych zdarzeń. 

let pole = document.getElementById("pole");

pole.addEventListener("mouseover", function() {
    pole.style.backgroundColor = "yellow";
});

pole.addEventListener("mouseout", function() {
    pole.style.backgroundColor = "white";
});

pole.addEventListener("click", function() {
    pole.innerHTML = "Kliknięto!";
});

Obiekt zdarzenia

Funkcja obsługująca zdarzenie może otrzymać informacje o zdarzeniu, które właśnie wystąpiło. 

let pole = document.getElementById("artykul");

pole.addEventListener("keyup", function(e) {
    console.log(e.key);
});

Parametr e oznacza obiekt zdarzenia. Zawiera on dodatkowe informacje dotyczące zdarzenia.

W przypadku klawiatury bardzo przydatna jest właściwość: 

e.key

Informuje ona, jaki klawisz został naciśnięty.

Przykład:

pole.addEventListener("keyup", function(e) {

    if (e.key == "Enter") {
        console.log("Naciśnięto Enter");
    }

});

Zmiana klas elementu – classList

Nie zawsze musimy zmieniać wygląd elementu bezpośrednio w JavaScript za pomocą style.

Możemy przygotować odpowiednią klasę w CSS, a następnie dodawać ją lub usuwać za pomocą JavaScript.

Przykładowa klasa CSS:

.aktywny {
    background-color: yellow;
    font-size: 24px;
    font-weight: bold;
}

Do pracy z klasami elementu służy właściwość classList.

Dodawanie klasy – add()

let element = document.getElementById("kontener");

element.classList.add("aktywny");

Usuwanie klasy – remove()

element.classList.remove("aktywny");

Dodawanie lub usuwanie klasy – toggle()

element.classList.toggle("aktywny");

toggle() działa jak przełącznik: jeżeli element nie ma danej klasy – dodaje ją, a jeżeli już ją ma – usuwa ją.

Sprawdzenie klasy – contains()

if (element.classList.contains("aktywny")) {
    console.log("Element ma klasę aktywny");
}

📌 classList – zapamiętaj

  • classList.add() – dodaje klasę,
  • classList.remove() – usuwa klasę,
  • classList.toggle() – przełącza klasę,
  • classList.contains() – sprawdza, czy element ma klasę.

Zdarzenia dla wielu elementów

querySelectorAll() jest szczególnie przydatne, gdy chcemy przypisać zdarzenie do wielu podobnych elementów.

Przykładowy kod HTML:

<button class="przycisk">Przycisk 1</button>
<button class="przycisk">Przycisk 2</button>
<button class="przycisk">Przycisk 3</button>

Pobieramy wszystkie przyciski:

let przyciski = document.querySelectorAll(".przycisk");

Następnie możemy przejść przez pobrane elementy i każdemu z nich przypisać zdarzenie: 

let przyciski = document.querySelectorAll(".przycisk");

przyciski.forEach(function(przycisk) {

    przycisk.addEventListener("click", function() {
        przycisk.classList.toggle("aktywny");
    });

});

Dzięki temu nie musimy osobno przypisywać zdarzenia do każdego przycisku.

📌 Jak działa ten przykład?

  1. querySelectorAll() pobiera wszystkie przyciski klasy przycisk.
  2. forEach() przechodzi kolejno przez każdy pobrany przycisk.
  3. addEventListener() przypisuje do niego zdarzenie kliknięcia.
  4. classList.toggle() dodaje lub usuwa klasę aktywny.
