JavaScript: Obiekty

Tworzenie obiektów, właściwości i metody, this, tablice obiektów oraz wykorzystanie obiektów w aplikacjach internetowych.
Cel główny: nauczyć się przechowywać powiązane dane w obiekcie JavaScript i wykorzystywać je w skryptach współpracujących z HTML i DOM, zgodnie z praktycznymi umiejętnościami przydatnymi na INF.03.

1. Czym jest obiekt?

Obiekt to struktura danych, która przechowuje powiązane ze sobą informacje w postaci właściwości i może zawierać metody, czyli funkcje.

Przykładowy produkt ma nazwę, cenę i dostępność. Może także obliczać wartość zamówienia.

Element obiektuPrzykładZnaczenie
Właściwośćnazwa: "Monitor"przechowuje tekst
Właściwośćcena: 850przechowuje liczbę
Właściwośćdostepny: trueprzechowuje wartość logiczną
Metodaprzedstaw()wykonuje określone instrukcje

2. Budowa obiektu

Obiekt można utworzyć za pomocą literału obiektowego, czyli nawiasów klamrowych { }.

const produkt = {
    nazwa: "Monitor",
    cena: 850,
    dostepny: true
};
FragmentZnaczenie
const produktutworzenie zmiennej przechowującej obiekt
{ ... }zawartość obiektu
nazwaklucz (nazwa właściwości)
:oddziela klucz od wartości
,oddziela kolejne właściwości
Ważne! Właściwości jednego obiektu mogą przechowywać różne typy danych: tekst, liczbę, wartość logiczną, tablicę, inny obiekt lub funkcję.

3. Odczytywanie właściwości

Zapis z kropką

console.log(produkt.nazwa);      // Monitor
console.log(produkt.cena);       // 850
console.log(produkt.dostepny);   // true

Zapis z nawiasami kwadratowymi

console.log(produkt["nazwa"]);  // Monitor
console.log(produkt["cena"]);   // 850

Nazwa właściwości w zmiennej

let pole = "cena";
console.log(produkt[pole]);      // 850
Nie pomyl zapisów: produkt.pole szuka właściwości o nazwie pole, a produkt[pole] korzysta z wartości zmiennej pole, czyli w tym przykładzie z nazwy cena.

4. Zmiana i dodawanie właściwości

Po utworzeniu obiektu można zmieniać istniejące właściwości:

produkt.cena = 799;
produkt.dostepny = false;
console.log(produkt.cena); // 799

Można też dodać nową właściwość:

produkt.producent = "ABC";
produkt["gwarancja"] = 24;

console.log(produkt.producent); // ABC
console.log(produkt.gwarancja); // 24
Przypisanie do istniejącego klucza zmienia wartość, a przypisanie do nowego klucza dodaje właściwość.

5. Usuwanie i sprawdzanie właściwości

Usuwanie – delete

delete produkt.gwarancja;
console.log(produkt.gwarancja); // undefined

delete usuwa wskazaną właściwość, nie usuwa całego obiektu.

Sprawdzanie obecności właściwości

console.log("cena" in produkt);      // true
console.log("gwarancja" in produkt); // false

Operator in sprawdza, czy właściwość jest dostępna w obiekcie (także odziedziczona).

Uwaga: Odczyt nieistniejącej właściwości zwykle zwraca undefined. Nie jest to to samo co wartość 0, false lub pusty tekst.

6. Metody obiektu

Jeżeli właściwość obiektu przechowuje funkcję, możemy wywołać ją jako metodę.

const uczen = {
    imie: "Anna",
    klasa: "3TI",
    przedstaw: function() {
        console.log("Cześć! Jestem Anna.");
    }
};

uczen.przedstaw(); // Cześć! Jestem Anna.

Metodę można też dodać później:

uczen.pozegnaj = function() {
    console.log("Do zobaczenia!");
};

uczen.pozegnaj();
Zapamiętaj: uczen.imie odczytuje właściwość, natomiast uczen.przedstaw() wywołuje metodę. Nawiasy () mają tutaj znaczenie.

7. Słowo kluczowe this

W zwykłej metodzie wywołanej jako obiekt.metoda() słowo this odwołuje się do tego obiektu.

const samochod = {
    marka: "Toyota",
    predkosc: 90,
    pokazDane: function() {
        console.log(this.marka + " jedzie " + this.predkosc + " km/h");
    }
};

samochod.pokazDane();
// Toyota jedzie 90 km/h

Metoda wykonująca obliczenia

const prostokat = {
    szerokosc: 5,
    wysokosc: 3,
    pole: function() {
        return this.szerokosc * this.wysokosc;
    }
};

console.log(prostokat.pole()); // 15
Ważne! W tym zastosowaniu piszemy metodę jako function() { ... } lub skróconą metodę pole() { ... }. Funkcja strzałkowa nie tworzy własnego this, dlatego nie jest zamiennikiem zwykłej metody w każdym przypadku.

8. Obiekt zadeklarowany przez const

Deklaracja const nie oznacza, że właściwości obiektu są niezmienne.

const komputer = { cena: 3000 };

komputer.cena = 2800;  // poprawne
komputer.ram = 16;     // poprawne

// komputer = { cena: 1000 }; // błąd: próba przypisania nowego obiektu
const blokuje ponowne przypisanie zmiennej, ale nie blokuje zwykłych zmian właściwości obiektu.

9. Obiekty zagnieżdżone

Właściwość może przechowywać inny obiekt, co ułatwia porządkowanie danych.

const klient = {
    imie: "Maria",
    adres: {
        miasto: "Lubartów",
        kod: "21-100"
    }
};

console.log(klient.adres.miasto); // Lubartów
console.log(klient["adres"]["kod"]); // 21-100

10. Obiekt a tablica

Obiekt opisuje jedną rzecz za pomocą nazwanych właściwości, a tablica przechowuje kolejne elementy, do których odwołujemy się indeksami.

const produkt = { nazwa: "Mysz", cena: 50 };
const ceny = [50, 120, 300];

console.log(produkt.nazwa); // Mysz
console.log(ceny[0]);       // 50

11. Tablica obiektów – zastosowanie w praktyce

W aplikacji internetowej często przechowujemy wiele produktów jako tablicę obiektów.

const produkty = [
    { nazwa: "Mysz", cena: 50, stan: 8 },
    { nazwa: "Klawiatura", cena: 120, stan: 4 },
    { nazwa: "Monitor", cena: 850, stan: 2 }
];

console.log(produkty[1].nazwa); // Klawiatura

Wypisywanie wszystkich produktów

produkty.forEach(function(produkt) {
    console.log(produkt.nazwa + " – " + produkt.cena + " zł");
});

Obliczanie wartości magazynu

let suma = 0;

produkty.forEach(function(produkt) {
    suma += produkt.cena * produkt.stan;
});

console.log("Wartość magazynu: " + suma + " zł"); // 2580 zł
W tablicy obiektów produkty[1] oznacza drugi obiekt, a produkty[1].cena – cenę z drugiego obiektu.

12. Obiekty wbudowane w JavaScript

Niektóre obiekty są dostępne od razu w przeglądarce. Korzystaliśmy już z nich na poprzednich lekcjach.

Math – obliczenia matematyczne

console.log(Math.round(8.6)); // 9
console.log(Math.max(4, 9, 2)); // 9
console.log(Math.sqrt(81));     // 9

let los = Math.floor(Math.random() * 10) + 1;
console.log(los); // liczba całkowita od 1 do 10

Date – data i czas

const dzisiaj = new Date();

console.log(dzisiaj.getFullYear());
console.log(dzisiaj.getMonth() + 1);
console.log(dzisiaj.getDate());
Metoda getMonth() zwraca miesiąc w zakresie od 0 (styczeń) do 11 (grudzień), dlatego dodajemy 1.

document i window – przeglądarka

console.log(window.innerWidth); // szerokość obszaru okna
console.log(document.title);     // tytuł dokumentu HTML

13. Obiekty a model DOM

Elementy HTML pobrane przez JavaScript są reprezentowane jako obiekty DOM. Mają właściwości i metody.

<p id="opis">Tekst początkowy</p>
<button id="zmien">Zmień tekst</button>
const opis = document.getElementById("opis");
const zmien = document.getElementById("zmien");

zmien.addEventListener("click", function() {
    opis.textContent = "Nowa treść akapitu";
    opis.style.color = "green";
});
ZapisZnaczenie
opis.textContentwłaściwość przechowująca tekst elementu
opis.style.colorwłaściwość określająca kolor tekstu
zmien.addEventListener(...)wywołanie metody przypisującej zdarzenie
To połączenie obiektów, DOM i zdarzeń jest szczególnie przydatne w zadaniach praktycznych z aplikacji internetowych.

14. Kompletny przykład INF.03 – kalkulator zamówienia

Przykład łączy obiekt produktu, jego metodę, formularz HTML, zdarzenie click oraz wyświetlanie wyniku na stronie.

Utwórz plik zamowienie.html i wklej poniższy kod:

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <title>Kalkulator zamówienia</title>
    <style>
        body { font-family: Arial; }
        .wynik { font-weight: bold; color: darkgreen; }
    </style>
</head>
<body>
    <h1>Kalkulator zamówienia</h1>
    <p>Produkt: Klawiatura, cena: 120 zł</p>
    <label for="ilosc">Liczba sztuk:</label>
    <input type="number" id="ilosc" min="1" value="1">
    <button type="button" id="oblicz">Oblicz</button>
    <p id="wynik"></p>

    <script>
        const produkt = {
            nazwa: "Klawiatura",
            cena: 120,
            wartosc: function(ilosc) {
                return this.cena * ilosc;
            }
        };

        const przycisk = document.getElementById("oblicz");
        const wynik = document.getElementById("wynik");

        przycisk.addEventListener("click", function() {
            const ilosc = Number(document.getElementById("ilosc").value);

            if (!Number.isInteger(ilosc) || ilosc < 1) {
                wynik.textContent = "Podaj dodatnią liczbę całkowitą.";
                wynik.classList.remove("wynik");
                return;
            }

            const suma = produkt.wartosc(ilosc);
            wynik.textContent = "Do zapłaty: " + suma.toFixed(2) + " zł";
            wynik.classList.add("wynik");
        });
    </script>
</body>
</html>

Jak działa program?

  1. Obiekt produkt przechowuje nazwę i cenę.
  2. Metoda wartosc(ilosc) oblicza wartość zamówienia.
  3. Po kliknięciu przycisku skrypt odczytuje liczbę sztuk.
  4. Warunek sprawdza, czy użytkownik podał dodatnią liczbę całkowitą.
  5. Wynik jest wyświetlany w akapicie bez przeładowania strony.

📌 Zapamiętaj

  • Obiekt przechowuje powiązane dane w nazwanych właściwościach.
  • Właściwość odczytujemy przez kropkę albo nawiasy kwadratowe.
  • Obiekt może zawierać metodę, czyli funkcję.
  • Metodę wywołujemy z nawiasami ().
  • W zwykłej metodzie wywołanej przez obiekt this wskazuje ten obiekt.
  • Właściwości można zmieniać, dodawać i usuwać.
  • const nie blokuje zmian właściwości obiektu.
  • Tablica obiektów pozwala przechowywać listy produktów, uczniów lub usług.
  • Elementy strony pobrane przez DOM również są obiektami.
  • Na INF.03 ważne jest łączenie danych, obliczeń, zdarzeń i zmian treści HTML.

📝 Zadania

Wykonuj zadania kolejno. W zadaniach 1–9 wyniki możesz wyświetlać w konsoli. W zadaniach 10–13 przygotuj pliki HTML, zastosuj addEventListener() i wyświetl wyniki na stronie. Nie wpisuj rozwiązań na stałe – wynik powinien wynikać z danych obiektu.

Część A – podstawy obiektów

Zadanie 1 – Wizytówka ucznia

Utwórz obiekt uczen z właściwościami imie, nazwisko, klasa i wiek. Wyświetl komunikat: „Anna Kowalska, klasa 3TI, 17 lat”, korzystając wyłącznie z właściwości obiektu.

Zadanie 2 – Karta produktu

Utwórz obiekt produkt zawierający nazwę, cenę, liczbę sztuk i dostępność (true/false). Wyświetl jego właściwości raz przez kropkę, a raz przez nawiasy kwadratowe. Wyświetl też komunikat „Dostępny” lub „Niedostępny” na podstawie wartości logicznej.

Zadanie 3 – Właściwość wskazana przez użytkownika

Korzystając z obiektu z zadania 2, pobierz za pomocą prompt() nazwę właściwości (nazwa, cena, ilosc lub dostepny). Odczytaj ją przez zapis produkt[klucz]. Jeśli właściwość nie istnieje, wyświetl odpowiedni komunikat.

Zadanie 4 – Aktualizacja obiektu

Utwórz obiekt telefon z nazwą i ceną. Zmień cenę, dodaj właściwość gwarancja (24 miesiące), a następnie ją usuń. Wyświetl wartości przed zmianami i po nich. Sprawdź obecność właściwości operatorem in.

Zadanie 5 – Metoda i this

Utwórz obiekt prostokat z właściwościami a = 6 i b = 4. Dodaj metody pole() i obwod(), korzystające z this. Oczekiwane wyniki: pole 24, obwód 20.

Część B – obliczenia i tablice obiektów

Zadanie 6 – Koszt przejazdu

Utwórz obiekt samochod z właściwościami spalanie = 6.5 (l/100 km) i cenaPaliwa = 6.20 (zł/l). Dodaj metodę koszt(trasa), obliczającą koszt przejechania określonej liczby kilometrów. Dla 200 km wynik powinien wynieść 80,60 zł.

Zadanie 7 – Oceny ucznia

Utwórz obiekt uczen z imieniem i tablicą ocen [3, 5, 4, 5]. Dodaj metodę srednia(), która obliczy średnią z ocen za pomocą pętli i zwróci wynik. Oczekiwana średnia: 4,25.

Zadanie 8 – Magazyn

Utwórz tablicę co najmniej pięciu obiektów produkty. Każdy produkt ma mieć nazwa, cena i stan. Za pomocą forEach() wyświetl nazwy i ceny, policz łączną wartość magazynu (cena * stan) oraz liczbę produktów o stanie mniejszym niż 5 sztuk.

Zadanie 9 – Najdroższy produkt

Wykorzystaj tablicę z zadania 8. Znajdź produkt o najwyższej cenie bez wpisywania jego nazwy na stałe. Wyświetl nazwę i cenę produktu. Rozwiązanie powinno działać także po zmianie cen w tablicy.

Część C – zadania praktyczne w stylu INF.03

Zadanie 10 – Konfigurator zamówienia

Utwórz plik zamowienie.html. Na stronie umieść nagłówek, pole liczbowe id="ilosc", przycisk id="oblicz" i akapit id="wynik". W skrypcie utwórz obiekt towar z nazwą, ceną 75 zł i metodą wartosc(ilosc). Po kliknięciu oblicz wartość zamówienia. Dla 4 sztuk wynik ma wynosić 300,00 zł. Nie dopuszczaj wartości 0 ani liczb ujemnych.

Zadanie 11 – Cennik usług komputerowych

Utwórz tablicę trzech obiektów opisujących usługi: Instalacja systemu – 120 zł, Czyszczenie komputera – 80 zł i Wymiana dysku – 150 zł. W pliku serwis.html wyświetl nazwy usług w elemencie select, dodaj przycisk i akapit wyniku. Po wybraniu usługi i kliknięciu przycisku pokaż jej cenę. Opcje listy mają powstawać w JavaScript na podstawie tablicy obiektów.

Zadanie 12 – Koszyk zakupowy

Utwórz stronę z trzema przyciskami „Dodaj do koszyka”, po jednym przy każdym produkcie. Produkty przechowuj w tablicy obiektów (nazwa, cena). Kliknięcie ma zwiększać łączną kwotę koszyka i liczbę dodanych sztuk, widoczne w dwóch akapitach. Dodaj przycisk „Wyczyść koszyk”. Do przypisania zdarzeń wielu przyciskom użyj querySelectorAll() i forEach().

Zadanie 13 – Miniarkusz praktyczny: wypożyczalnia rowerów

Utwórz plik rowery.html oraz kod CSS i JavaScript. Witryna ma zawierać nagłówek, formularz z listą rodzaju roweru (id="rower"), pole liczby godzin (id="godziny"), przycisk (id="policz") i blok wyniku (id="wynik").

  1. W JavaScript utwórz tablicę obiektów: { nazwa: "Miejski", cena: 15 }, { nazwa: "Górski", cena: 20 } oraz { nazwa: "Elektryczny", cena: 35 }. Cena oznacza koszt jednej godziny.
  2. Wypełnij listę wyboru danymi z tablicy za pomocą DOM.
  3. Po kliknięciu przycisku odczytaj rodzaj roweru i liczbę godzin.
  4. Oblicz koszt wypożyczenia jako iloczyn ceny i liczby godzin.
  5. Jeżeli liczba godzin jest mniejsza niż 1 lub nie jest liczbą całkowitą, wyświetl komunikat błędu.
  6. Dla roweru górskiego i 3 godzin pokaż: Do zapłaty: 60,00 zł.
  7. Poprawny wynik wyróżnij klasą CSS poprawny, a błędny klasą blad, używając classList.
Wskazówka egzaminacyjna: pracuj na danych przechowywanych w obiektach, użyj addEventListener(), nie wyświetlaj wyniku przez alert() i nie wpisuj cen bezpośrednio do warunków if.

🎯 Sprawdź, czy potrafisz

  • wyjaśnić różnicę między właściwością a metodą,
  • utworzyć obiekt i odczytać jego dane na dwa sposoby,
  • zmodyfikować, dodać i usunąć właściwość,
  • sprawdzić istnienie właściwości,
  • napisać metodę obiektu wykorzystującą this,
  • wyjaśnić zachowanie obiektu zadeklarowanego przez const,
  • odczytać dane z obiektu zagnieżdżonego i tablicy obiektów,
  • wykorzystać Math i Date,
  • połączyć obiekty, formularz HTML i zdarzenie click,
  • wyświetlić obliczony wynik na stronie za pomocą DOM,
  • sprawdzić i poprawić błędy w konsoli przeglądarki.
