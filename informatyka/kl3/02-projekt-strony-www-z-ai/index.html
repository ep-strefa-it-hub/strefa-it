🌐 Projekt – Tworzenie i publikowanie strony WWW

Temat projektu: Najciekawsze miejsca w Polsce

Cel projektu: Samodzielne utworzenie strony WWW w HTML i CSS, jej rozbudowanie z pomocą AI oraz opublikowanie w Internecie za pomocą GitHub Pages.

Jak pracować z projektem?

Wykonuj kolejne kroki po kolei. Nie przechodź do następnego etapu, dopóki poprzedni nie działa poprawnie.

Po każdej większej zmianie zapisz pliki i sprawdź stronę w przeglądarce.

Nie musisz wykonać całego projektu podczas jednej lekcji. Na kolejnych zajęciach kontynuujesz pracę od miejsca, w którym skończyłeś.

Każdy uczeń wykonuje własną wersję projektu. Samodzielnie wybierasz miejsca, teksty, zdjęcia, tytuły sekcji, ciekawostki i wygląd strony.

ETAP 1 – Tworzymy podstawę strony

1. Przygotowanie projektu

Na komputerze utwórz folder (najlepiej na dysku D): 

projekt-www
Nie zmieniaj nazwy tego folderu podczas wykonywania projektu.

Wewnątrz folderu utworzysz później: 

projekt-www
│
├── index.html
├── style.css
└── img

Na początku potrzebny jest tylko plik: 

index.html

2. Otwórz projekt w edytorze

Uruchom Visual Studio Code.

Wybierz:

File → Open Folder

i wskaż folder:

projekt-www

Utwórz w nim plik:

index.html

3. Utwórz podstawową stronę HTML

W pliku index.html wpisz: 

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <title>Najciekawsze miejsca w Polsce</title>
</head>
<body>
</body>
</html>

Zapisz plik:

Ctrl + S

4. Sprawdź stronę w przeglądarce

Otwórz folder:

projekt-www

Kliknij dwa razy:

index.html

Strona otworzy się w przeglądarce.

Na razie będzie pusta. To jest prawidłowe.

5. Dodaj główny nagłówek strony

Wewnątrz:

<body>

dodaj:

<h1>Tutaj wpisz własny tytuł strony</h1>

Nie zostawiaj tekstu:

Tutaj wpisz własny tytuł strony

Wymyśl własny tytuł związany z tematyką projektu.

Przykłady:

  • Polska warta odkrycia,
  • Miejsca, które warto zobaczyć,
  • Odkrywamy Polskę,
  • Moje najciekawsze miejsca w Polsce.

6. Dodaj tekst wprowadzający

Pod nagłówkiem dodaj akapit: 

<p>Tutaj wpisz krótki tekst wprowadzający.</p>

Zastąp przykładowy tekst własnym.

Napisz 2–3 zdania wyjaśniające, czego dotyczy Twoja strona.

Nie kopiuj przykładowych opisów. Napisz własny tekst.

7. Sprawdź efekt

Zapisz plik:

Ctrl + S

Przejdź do przeglądarki i odśwież stronę:

Ctrl + R

Powinny być widoczne:

  • własny nagłówek,
  • tekst wprowadzający.
